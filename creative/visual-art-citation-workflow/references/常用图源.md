# 常用图源（v1.0 实测清单）

适用：考据国风/武侠/志怪/古装类创作项目时找实物图的 6 路图源，**按优先级排序 + 失败路径**。

## P0 - Wikimedia Commons（最高优先级）

**用法**（Python 探针）：
```python
import urllib.request, urllib.parse
def head(url):
    req = urllib.request.Request(url, method='HEAD', headers={'User-Agent': 'Mozilla/5.0'})
    try:
        with urllib.request.urlopen(req, timeout=10) as r:
            return r.status, r.url
    except Exception as e:
        return None, str(e)
# 探测
url = f'https://commons.wikimedia.org/wiki/Special:FilePath/{urllib.parse.quote("越王勾践剑.jpg")}'
status, real_url = head(url)
# status=200 → real_url 是真实图地址
# 下载（中文名 quote 编码）
fn = urllib.parse.quote("越王勾践剑.jpg")
full_url = f'https://commons.wikimedia.org/wiki/Special:FilePath/{fn}'
data = urllib.request.urlopen(urllib.request.Request(full_url, headers={'User-Agent': 'Mozilla/5.0 (research)'})).read()
```

**优**：高清扫描 / 公共版权 / 直链稳定
**劣**：
- 文件名误导（中文/英文文件名都可能不准）——**必须 vision_analyze 视觉验证**
- 部分国宝级文物不让外网下载真品（如李思训《江帆楼阁图》台北故宫藏）
- 缩略图路径 `/thumbnail/` 与原图 `/media/` 路径不同

## P4 - ddgs images 反查（关键破局工具）

```python
from ddgs import DDGS
with DDGS() as ddgs:
    for img in ddgs.images("敦煌莫高窟359窟藻井金翅鸟", max_results=15):
        print(img.get("image"), "|", img.get("title")[:50])
```

**优**：**ddtext 搜不到时，image 搜索一秒命中**（本会话 359窟金翅鸟的关键突破）
**劣**：返回的是第三方网站嵌入图，版权/出处需人工核验

## P5 - 维基百科 API（开放图源反查）

```python
import urllib.request, urllib.parse, json
# 1. 通过文件名直接命中
url = f'https://commons.wikimedia.org/wiki/Special:FilePath/{urllib.parse.quote("越王勾践剑.jpg")}'
# 2. 通过搜关键词找页面 → 看页面图片
api = 'https://commons.wikimedia.org/w/api.php?action=query&list=search&srsearch=Dunhuang+Garuda&srnamespace=6&srlimit=20&format=json'
data = json.loads(urllib.request.urlopen(urllib.request.Request(api)).read())
for r in data.get('query', {}).get('search', []):
    print(r['title'])
```

**优**：可批量找 WikiCommons 上**所有相关文件**——本会话发现 WikiCommons 没敦煌金翅鸟真品，但有大量印度/尼泊尔 Garuda
**劣**：仅命中 WikiCommons 范围

## 失败路径处理

| 场景 | 退路 |
|---|---|
| WikiCommons 没某图 | 走数字敦煌 / 公开图源聚合站 / ddgs images |
| 数字敦煌要登录 | 用缩略图（带水印，作为参考图）+ caption 标注"待用户浏览器补图" |
| 博物馆不让下载真品 | 走集古作网/书格中转 |
| ddgs 搜不到 | 换关键词（中英文、实物名 vs 文物名）/ 加朝代限定 / 退到 web_search |
| 全失败 | 写"待补图"留档给用户浏览器补 |

## 视觉验证铁律（最关键）

**每张图嵌入飞书 doc 前必须 vision_analyze**——文件名不可信。例：

- `Garuda_cliff_in_Tirumala.jpg` —— 文件名含 Garuda，但内容是印度山崖，不是金翅鸟造像
- `江帆楼阁图.jpg`（WikiCommons 版）——可能是仿本/摹本，与台北故宫真品不同

**verification prompt 模板**（vision_analyze）：
```
这张图是什么？请描述图中央主体（动物/神佛/人首鸟身等）。
这是<考据对象名>吗？能看到<该对象的特征特征 1>/<特征 2>吗？
水印不算请专注内容
```
