# CHANGELOG — AI导演助手

## v12.0.0 — 2026/07/17

### 格式范式转换

基于 Seedance 2.0 优质案例（飞书文档 AwKkds5GxoxxHzxmDHtcfO5jnRg）的生产验证格式，将分镜输出格式从结构化标签转为自然描述。

### 修改

- **分镜代码块格式**（§2.3）：取消独立配置行（`景别 | 运镜 | 日夜`）、独立焦点转移行、`[音效: xxx]` 标签，全部融入自然描述行。用"切"字标记镜头切换
- **段级资产锁**（§2.1, §2.3）：`配音` → `音色`；去掉 `【场景】` `【资产】` 独立行要求
- **空间继承**（§2.4）：从显式声明块（段前/段末）简化为自然描述保持一致性
- **格式标准**（§2.6）：更新为新格式规范
- **自检清单**（§6.1）：去掉格式维度，保留创意维度+剧本遵循维度
- **校验脚本**（scripts/validate_format.sh）：更新为Seedance约束检查（精确秒数/表格/资产锁/@Tag/旧格式残留）
- **提示词写作约束**（§4.5）：从 AI提示词助手 v1.3.0 同步（焦点转移融入、音效自然融入）

### 创意加强

- **视点选择**（§1.1）：增加案例级写法示例（视点融入描述行的具体写法）
- **镜头对**（§1.4）：增加案例级接缝设计（碰撞型/问答型/延续型/库里肖夫型）
- **情绪工程**（§1.8）：增加肌肉级精细描述（眼轮匝肌、颧大肌、口轮匝肌等）
- **初感协议**：增加四问——视觉种子发现（海报镜头/声音Motif/光的叙事/道具叙事）

### 不变

- 核心哲学（§一）：视点/空间/光/镜头对/节奏/海报镜头/声音/情绪工程
- 剧本遵循协议（铁律三条+台词映射+自检）
- 导演反问机制
- 导演主动性原则
- 父-子Agent系统
- 地基五件套

### 来源

- 用户提供飞书优质案例文档，展示生产验证的有效格式
- 与 AI提示词助手 v1.3.0 格式对齐
