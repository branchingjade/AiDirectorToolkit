## 1. 场景标题 Slugline / Scene Heading

**写法：单行、全大写、三个信息块**（室内外 + 地点 + 时间），中间用空格分隔，地点与时间之间用 `–`（短横线）：

```
EXT. KEVIN'S HOUSE – DAY
```

- **INT./EXT.**：`INT.` = INTERIOR（内景），`EXT.` = EXTERIOR（外景）。来源 S1：*"Whether the scene takes place inside (INT., short for INTERIOR) or outside (EXT., short for EXTERIOR)"*；来源 S4：*"whether the scene is set inside or outside (INT. or EXT.; interior or exterior), the specific location, and the time of day"*。
- **地点**：具体到地点名。室内场景可再加细分，房间名放在前面、逗号分隔：`INT. BATHROOM, KEVIN'S HOUSE – MORNING`（S1 原例）。
- **时间**：DAY / NIGHT / MORNING / AFTERNOON / EVENING 等（S1）。
- **全大写**：S2：*"It should always be in CAPS."*（场景标题必须全大写）
- 每个 slug line 开启一个新场景；shooting script（拍摄台本）中场景标题按顺序编号（S4：*"In a 'shooting script' the slug lines are numbered consecutively"*）。
- 变体：不需要新场景标题但需要区隔时用 Subheader（副标题），如两地点快速切换的 `INTERCUT`（S2）；StudioBinder 称之为 General 段落，用于"同一地点的新区域或电话对切"（S3）。
- John August 的建议：找一份格式正确的正式剧本照着抄，格式的标准化程度远超想象（S5：*"find a properly formatted script and copy it exactly"*）。

## 2. 动作描述 Action / Description

- **现在时态**：S2：*"The narrative description of the events of a scene, written in the present tense."*
- **只写可见可听之物**：S2：*"only things that can be seen and heard should be included in the action"*——摄像机拍不到的心理活动不要写进 Action。
- **人物首次出场名字全大写**：S2：*"When a character is introduced, his name should be capitalized within the action. For example: The door opens and in walks LIAM..."*
- **关键道具/声音/动作可全大写强调**：S1 示例 `a BAG OF GROCERIES`，并提醒 *"This technique should be used sparingly"*（滥用会失去强调效果）。
- **场景标题后先给几行 Action 让读者进入情境**（S1：*"After you write your scene heading, you should always start with a few lines of action to get the reader situated"*）。
- **段落**：Action 是剧本的"散文"，按自然段落书写，避免大段文字墙（S3 称其为 *"the 'prose' of a screenplay"*）。S2 未规定句数上限，但行业惯例为每段 1–4 行，保持页面留白。
- **长度/密度**：Action 页 vs 对白页的屏幕时间不同（见 §5 页速规则）。

## 3. 对白 Dialogue

- **角色名（Character Cue）**：大写、居中，位于对白块上方；比对话缩进多约 1 英寸（S1：*"indented approximately an inch more than the dialogue"*）。S2 缩进规格：Character 左缩进 2.0"，Dialogue 左缩进 1.0"（宽度 3.5"）。
- **角色名一致性**：通常用名字（多角色时用全名或名+姓），全剧本必须一致（S3：*"make sure you're consistent with Character Cues throughout the script"*）。次要角色可用职业代称，如 `TAXI DRIVER`、`CUSTOMER`（S2）。
- **对话块**：居中偏左，左缩进约 1.0–1.5"、右缩进约 1.5"（S1：*"left indent is between an inch and one-and-a-half inches from the left margin, and a right indent of about an inch and a half"*）。
- **括注 Parenthetical**：角色名下方、对白上方的括号内文字，指示语气/动作/说话对象，**必须少用**。S1：*"A parenthetical should be used when the dialogue doesn't exactly convey how the actor might deliver the dialogue"*，例：`(to self)`。S2 更严格：*"today, parentheticals are used very rarely, and only if absolutely necessary"*——如果非要括注才能表达，说明对白该重写；指导演员表演是导演的职权。S3 补充：括注也用于对白中间。
- **扩展名 Extension**：紧接角色名同行括号内，标注声音来源：`(V.O.)` 画外音 / `(O.S.)` 画外（同一场景但不在画面内）/ `(CONT'D)` 续上页对白（S1、S3）。
- **跨页对白**：页底显示居中大写 `(MORE)`，下一页角色名后加 `(CONT'D)`；对白只允许在句末断页（S1）。
- **O.S. 与 V.O. 区别**：S3 定义 O.S. = off-screen（角色在本场景内但画面外），V.O. = voice-over（画外音/旁白）。

## 4. 转场 Transition

- **格式**：右对齐（flush right）。S1：*"will format the transition flush right according to industry standards"*。S2 缩进规格：左缩进 4.0"、宽 2.0"，即靠右。
- **常用语**：`CUT TO:`、`DISSOLVE TO:`、`SMASH CUT:`、`QUICK CUT:`、`FADE TO:`（S2 原文列表）；另见 `FADE TO BLACK`（S1）。
- **要不要用**：S1：*"You don't need to include a transition between scenes, as it's understood that one scene naturally flows into the next"*——场景间默认自然衔接，转场仅作风格选择（如 SMASH CUT、FADE TO BLACK）。S3：*"used sparingly and only when noting the transition is necessary"*。
- **spec script 铁律**：S2：*"Transitions are film editing instructions, and generally only appear in a shooting script"*——转场是剪辑指令，投稿用的 spec script 应避免；只有无其他方式表达剧情要素时才用（如 `DISSOLVE TO:` 表示大段时间流逝）。S2 还警告：*"A spec script should NEVER contain the elements of shooting script"*（镜头角度、剪辑转场一律不要写）。

## 5. 页面布局

| 项目 | 规范 | 来源 |
|------|------|------|
| 纸张 | 北美：US Letter（8.5"×11"）；英国用 A4（210×297mm），但为美国读者常改用 Letter | S4 |
| 字体 | **Courier 12pt**（等宽），10 pitch。S1：*"It must be the Courier font and 12 points"*；S4：*"The standard font is 12 point, 10 pitch Courier typeface"*；S5：*"'Real' scripts are still written in Courier"*（出版社有时改 Times 只为大众阅读，原文更优） | S1/S4/S5 |
| 上边距 | 1 英寸 | S1 |
| 下/右边距 | 可浮动 ±0.25 英寸 | S1 |
| 左边距 | 约 1.5 英寸（为三孔打孔装订留空间）；S4 称 *"Wide margins of at least one inch...usually larger for the left to accommodate hole punches"* | S1/S4 |
| 页眉 | 仅页码，右对齐，距页顶约 0.5"，页码后带句点；**第一页不显示页码** | S1 |
| 标题页 | 居中：标题 + "written by" + 作者名；左下角联系方式；可选 WGA 注册号；无插图无花哨字体（仍用 Courier 12pt） | S1/S2 |
| 装订 | 三孔打孔，铜扣（brads）穿 1、3 孔（中孔不穿），封面封底空白；Acco 5 号 1¼" 适用 ≤120 页 | S2 |
| 页速 | **1 页 ≈ 1 分钟银幕时间**。S4：*"one page equates to roughly one minute of screen time"*，但注明这是粗略估算，*"a page of dialogue usually occupies less screen time than a page of action"*，且该经验法则在好莱坞仍被广泛使用（1 页/分钟规则最著名的反对者正是 John August） | S4 |
| 篇幅 | 长片剧本约 90–120 页（S1：*"Keep writing those elements for 90 to 120 pages"*） | S1 |

## 6. 补充要点

- **格式的目的**：统一格式使每部影片能用同一套规则排期与预算（S1：*"With a consistent format, each film can be scheduled and budgeted using the same rubrics"*）。格式是行业"必要性之恶"，规则有硬性也有弹性（S3）。
- **spec script vs shooting script**：投稿剧本（spec）严格遵循上表；售出后转为拍摄台本（shooting script），才加入场景编号、镜头、剪辑注记和彩色修订标记（S2）。
- **工具**：Final Draft / Highland / StudioBinder 等软件自动套格式；John August 认为用这些软件的默认格式即可放心（S5）。他参与开发了 Fountain 纯文本格式以"把写作和排版解耦"（format-johnaugust-origins.txt）。
- **反例警示**：非 Courier 字体（Times 等）→ 业余感（S1：*"Try to get fancy, with any other font, and your script looks amateurish"*）；对白标注过多括注 → 需要重写（S2）。
