# CHANGELOG — AI编剧助手

## v2.3.0 — 2026/08/04

### 新增
- **改编专项（二·五章）**：单元剧/短剧 → 电影改编方法论，五条铁律：
  1. 改编≠压缩，选一条主线（拆层：案件层/身世层；段落感检测）
  2. 反派动机：从「它要什么」改成「它缺什么」
  3. 一切不合理交给一个角色（角色性格消化巧合）
  4. 用户否定信号二分法（方向不对=停 / 内容不够=对症加深）
  5. 改编文档去AI味（评述腔/不是X是Y/术语堆砌/重复强调）
- **来源**：《民间伏妖记》50集短剧→75分钟电影改编实战沉淀（镜妖五轮迭代、小白角色设计）
