# CHANGELOG — AI电影导演

## v1.3.0 — 2026/08/05

### 实战迭代（项目测试发现的缺口）

- **视点切换频率纪律**：一场戏主导视点 ≥80%、单场切换 ≤2 次、切换落在节拍转折处、切换后不回切——切换本身有成本，观众需要稳定代入
- **场景类型×生成倍率参考表**：室内×1.5-2 / 日景×2-2.5 / 夜景×2.5-3.5 / 特效×3-4 / 群像×4-6 / 动作×4-5（标注推断）+ 预算公式（Σ场景时长×单价×倍率）
- **段内镜头数参考**：常规段 2-4 镜 / 动作段 4-6 镜快切 / 情绪段 1-2 镜——段=剪辑单元，镜=段内切点（衔接 EDL）
- 来源：真实项目测试（《鼓停河涨》）中发现的三个操作空白

  - 东方：黑泽明（Wipe转场/极端天气/动态风格）、小津（榻榻米机位/静态转场/运镜递减）、侯孝贤（极长镜头/即兴/省略叙事）、王家卫（非线性/饱和色彩）、张艺谋（视觉感知/简单色彩）、李安（压抑情感/武侠浪漫史诗）、塔可夫斯基（雕刻时光/水云倒影）、杨德昌（城市诗人/碎片叙事）、宫崎骏（手绘美学）、奉俊昊（类型混搭/阶级空间）
- **21:9 影院宽银幕**：Seedance 原生比例。构图纪律（人物占比30-50%/横向分区/环境即角色）
