# AiDirectorToolkit — 妖玉影视 Skill 三件套

AI 短剧/中剧从剧本创作到视频生成的完整流水线。三个 Skill 运行在 Hermes Agent 上。

```
妖玉影视/
├── AI编剧助手    v2.2.0  →  剧本创作（画面锚定→锁定剧本）
├── AI导演助手    v12.0.0 →  制作执行（分镜+资产+字幕）
└── AI提示词助手  v1.4.0  →  约束主本（提示词写作规范）
```

---

## AI编剧助手 v2.2.0

**从画面到锁定剧本的电影创作引擎。** 先锚定一个三秒画面，然后让它长出整个故事。

- **画面锚定**：故事开始前，先找到摄影机能拍到的三秒画面
- **创作宪法（七条）**：每条保护电影的一项能力——不是禁止，是让画面不被稀释
- **提问（11条）**：宪法管底线，提问开上限
- **视觉写作精度五条**：两个△之间、动作微序列、用动作证明动作、重复即定义、物件的时态
- **六轮自审**：画面锚点→内容密度→感情语言→三问+Q4/Q5/Q6→结构审视→信息载体
- 产出标准 AI 剧本格式的锁定剧本，交接给 AI导演助手

## AI导演助手 v12.0.0

**制作/执行阶段** — 以电影导演思维驱动分镜设计。

- **导演初感协议（三问+四问）**：读完剧本，先找定义性一帧
- **剧本遵循协议**：台词逐字嵌入 + 动作强制继承 + 门禁级自检
- **导演创作原则**：视点权力/空间地理/光叙事/镜头对/节奏呼吸/海报镜头/声音第二层叙事
- **情绪工程**：情绪→生理映射 + 四层动作体系 + 环境反馈
- **父-子Agent架构**：叙事聚簇并行，父审子产，导演意志不分裂
- **地基五件套**：角色/场景/道具/配音/全局锁
- 产出 Seedance 2.0 标准分镜 + 字幕

## AI提示词助手 v1.4.0

**Seedance 2.0 提示词约束主本**（canonical source）。AI导演助手和AI编剧助手的约束从此同步。

- 不编造原则 · 禁文学化修辞 · 精确数值→身体参照系
- 物理优先法则 · 动作四层体系 · 焦点转移融入描述行
- 音效自然融入 · 反AI木偶化 · 运镜光线速查

## 安装

将 `妖玉影视/` 目录放入 Hermes 技能库：

```
~/AppData/Local/hermes/skills/妖玉影视/
```

加载时用 `妖玉影视/AI编剧助手` 路径。
