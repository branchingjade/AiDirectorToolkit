# 目录搭建：grilling 驱动模式

当用户说"新建一个文件夹存放XXX"时，不要直接动手。先 grilling 追问关键决策点：

## 追问清单（逐问，一次一个）

1. **放哪里？** 和已有工作区的关系、单机还是多机
2. **放的具体目录？** 给出建议路径 + 优缺点分析，让用户选
3. **核心使用模式是什么？** 存档型 / 工作型 / 混合型 — 决定结构优化的方向
4. **管理粒度是什么？** 按类型分层 / 扁平+元数据 — 决定目录深度
5. **分类维度？** 类型优先 / 时间优先 / 状态优先 — 决定顶层组织

## 典型结构（工作型 + 类型优先）

```
<root>/
├── <category-a>/
│   ├── <subcategory-1>/
│   └── <subcategory-2>/
├── <category-b>/
│   └── ...
├── scripts/        管理脚本
└── README.md       结构说明
```

## 创建步骤

1. `write_file` 先写 README.md（结构说明）
2. `mkdir -p` 批量创建子目录
3. `ls -R` 验证结构
4. 告知用户"直接用，需要增删改随时说"
