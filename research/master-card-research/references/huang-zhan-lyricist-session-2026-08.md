## 歌词文本验证通道（本会话实测，全部 curl + python 直连，无需浏览器/web_extract）

1. **网易云音乐 API（首选：无鉴权、纯 curl、带署名）**：
   - 搜索：`curl -sL -A "$UA" -H "Referer: https://music.163.com/" "https://music.163.com/api/search/get/web?s=<percent-encode 歌名 歌手>&type=1&limit=5"` → JSON `result.songs[].id`
   - 歌词：`curl -sL -A "$UA" -H "Referer: https://music.163.com/" "https://music.163.com/api/song/lyric?id=<id>&lv=1&kv=1"` → JSON `lrc.lyric`（带 `[mm:ss.xx]` 时间轴，正则剥掉即纯歌词）
   - 关键：**必须带 `Referer: https://music.163.com/`** + 浏览器 UA。歌词文件头常含「作词/作曲/编曲」标注，顺带验证词曲署名（本会话《上海滩》song 320950 验证「作词：黄霑、作曲：顾嘉辉」）。
2. **igeci.cn（歌词大全）**：URL 模式 `http://m.igeci.cn/<歌手拼音>/<歌曲id>.html`（黄霑《沧海一声笑》= /huangzhan/49669.html）；curl 直连 + python 剥 script/style/标签 + html.unescape 可用。⚠️ 歌手页 `/singer/<拼音>.html` 会 404，歌曲页 URL 靠 web_search 找。
3. **lugeci.com（录歌词）**：URL 模式 `https://www.lugeci.com/geci/<id>`（《狮子山下》= /geci/8264），页面含「作词」字段；⚠️ 站内搜索 `/search?q=` 实测不给结果，用 web_search 找站内 URL 再直连。
4. 本会话不可用通道：gequ.dawneve.top 连不上、kugeci.com 503、web_search 后端（DuckDuckGo）全程超时、r.jina.ai 代理 Bing 被 Cloudflare 挑战页拦截——不要死磕，直接走 1-3 直连。

## 粤语歌词技法拆解方法（可操作）

- **粤语韵脚分析**：用粤拼归韵母，一句话概括「主押 X 韵 + 个别句破韵换气」——本会话三例：-iu（笑 siu³/潮 ciu⁴/朝 ziu¹/晓 hiu²/遥 jiu⁴/娇 giu¹/照 ziu³/寥 liu⁴，《沧海一声笑》）；-au（流/休/忧/否/收/斗/够/有，《上海滩》）；-eoi（泪/嘘/虑/对/追/随/惧/句，《狮子山下》）。这是歌词实证里最硬的可验证论点。
- **文体分层**：文言/白话/俗语逐句归类 + 各自功能（文言=庄重意象、白话=叙述、俗语=烟火气）——黄霑的「三及第」文体。
- **结构**：段式复沓/顶针（《沧海一声笑》五段全以「X笑」起句）、先副歌后主歌（《上海滩》黄霑自述）。
- **拆解点模板**：押韵/对仗/文言入词/意象系统/结构/视角（如全词无「我」字=物象拟人、主体退场）。

## 创作背景来源（卡片③的金矿）

- **中文维基「单曲专条」创作背景段**（与配乐轴黄霑轮同法，作词角度再看一遍）：《滄海一聲笑》《上海灘(歌曲)》《獅子山下(歌曲)》条目直接给创作轶事与一手转述引语：
  - 《沧海一声笑》：草稿被徐克退六次；黄友棣《中国音乐思想批判》引《礼记·乐记》「大乐必易」；取简单五声音阶来回上下行；词意一半来自毛泽东《沁园春·雪》；黄霑「中港台，哪里不都是一样？」引语。
  - 《上海滩》：顾嘉煇电话口述简谱；先填副歌「因为受欢迎的多数是情歌」；二十分钟成稿（黄霑自称写得最快最流畅的一首）；为证「黄浦江有没有浪」查陈定山《春申旧闻》《春申续闻》凌晨 2:20 查到 6:00 未果，次日叶丽仪录音遂定稿。
  - 《狮子山下》：张敏仪忆述黄霑再三推辞，「觉得香港精神这种题材很闷，比较喜欢写爱情」；2002 年电台访问自述把 1949 年逃港后左右派倾轧→和解写进词；手稿「香港千秋万岁」改为「不朽香江名句」，郑国江评「没具体所指，让听众自行解读，是词人的聪明之处」。
- **中文维基「黄霑」条目「语言、手法及评价」节**：三及第文体、1970s 口语词→1980s 减少、全口语实验《梦断城西》(1980) 劣评如潮、林夕评选字「允执中庸」、黄志华评文言词「句式工整、词采斐然」、第二代词人定位（1974-79）、1990 金针奖、博士论文及考委会评语、顾嘉煇谈合作流程引语（「一般都是歌星来到，歌词才到」）。
- **维基 HTML 直抓法**：`curl -sL -A "$UA" "https://zh.wikipedia.org/zh-cn/<percent-encode 标题>"` + python 剥 script/style/标签 + html.unescape + 压空行；创作背景段用 `sed -n '/创作背景/,/下一节标题/p'` 截取。
