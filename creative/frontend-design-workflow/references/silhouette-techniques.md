# 剪影设计技术

在 HTML 海报/视觉作品中画人物和动物剪影的正确方法。

## 核心原则

**vision 模型能辨认什么、不能辨认什么，决定了剪影的成败。**

## 反模式：CSS clip-path polygon

```css
/* ❌ vision 模型识别结果："锯齿状抽象竖条" */
clip-path: polygon(
  38% 0%, 44% 0.4%, 48% 0.3%, ...
);
```

根因：polygon 由直线段组成，视角上形成锯齿边缘，vision 模型无法将其匹配到"人"的范畴。无论迭代多少次、调整多少个顶点——它永远是几何抽象，不会是"人"。

## 正确做法：SVG `<path>` + 自然曲线

```svg
<!-- ✅ vision 模型识别结果："一个人，头、肩膀、手臂、腿都很清晰" -->
<svg viewBox="0 0 105 550">
  <defs>
    <linearGradient id="manGrad" x1="0" y1="0" x2="0" y2="1">
      <stop offset="0%" stop-color="#1c1814"/>
      <stop offset="100%" stop-color="#2e2924"/>
    </linearGradient>
  </defs>
  <!-- 头：椭圆而非多边形 -->
  <ellipse cx="52" cy="24" rx="16" ry="18" fill="url(#manGrad)"/>
  <!-- 躯干：贝塞尔曲线而非直线 -->
  <path d="M 24 52 Q 30 48 34 46 L 70 46 Q 74 48 80 52 ..." fill="url(#manGrad)"/>
  <!-- 手臂：自然弧度 -->
  <path d="M 28 52 Q 18 68 16 86 Q 14 96 18 100 ..." fill="url(#manGrad)"/>
</svg>
```

关键：用椭圆画头、用 `Q`（二次贝塞尔）画躯干和四肢的弧度，不用直线段。

## 暗色叠暗色 = 不可见

vision 模型的对比度感知与人眼不同——即使是人眼能勉强辨认的微弱差异，vision 模型可能完全看不到。

**错误**：人物 `#141210` + 背景 `#13110f`（几乎同色）→ vision 输出："没有发现人物剪影"

**正确**：建立至少两档亮度差——
```
天空（#4e4842 中灰）     ← 最亮层
人物（#2a2620 中深灰）   ← 中层
钢厂（#13110f 近黑）     ← 最暗层
```

三层对比策略：
1. **最亮层**（天空）：人物头部突破钢厂线后在这层形成清晰剪影
2. **中层**（人物）：比背景亮一档，确保在暗背景上可见
3. **最暗层**（钢厂/地面）：纯剪影，承载其他元素

## 验证方法

每版迭代后用 `browser_vision` 检查，问题是"人物剪影是否可辨认"。不要相信自己的 CSS 代码——只相信 vision 模型的确认。
