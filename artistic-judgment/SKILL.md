# 艺术判断 v1.0.0

> **目的**：补充 AI短剧编剧助手 宪法/精度层之上缺失的一层。宪法守底线，精度拉细节——艺术判断告诉你**什么算好**。
>
> **触发**：剧本创作、初稿写作、自审打磨阶段——写完一段△后不自问不可替代性时触发。

---

## 一、不可替代性测试

写完整段△后，先不查宪法——先问自己：

> 这段△里，有没有任何一个瞬间是只有这个剧本、只有这个角色、只有这个演员才能成立的？

有 → 留着。没有 → 不管宪法过没过、精度够不够——都不算完成。

### 案例对比

| 通过审查但可替换 | 不可替代 |
|------|------|
| 「手指碰到电池外壳——温的」→ 任何换电池的场景都成立 | 「手指碰到电池外壳——烫的。缩了一下。」→ 植入物发过烧。他习惯了但还没完全习惯。只有老周 |
| 「风没停。他站了一会儿。」→ 任何天台场景 | 「风把植入物外壳吹得发颤——手指跟着共振抖。」→ 只有老周。植入物是身体的一部分 |
| 「他看着照片」→ 任何人看任何照片 | 「他拿起旧工牌。拇指在照片上蹭了一下——和擦外壳的动作一样。」→ 两个动作的重复定义了他对待活人和死人是同一只手 |

## 二、感知精度四维

不是规则。是写完后自问的四个方向。每维一个范本——范本来自《手心人》已验证的段落。

### 1. 温度——物件的物理质感

不是「冷/热」。是**一个度数对应一个身体反应**。

- 「温的」→ 手指没缩。习惯了。
- 「烫的」→ 缩了一下。还没完全习惯七年后。
- 「不烫。也不凉。是不该有的温度。」→ 她还在运行但她不说话了。

### 2. 时间——重复动作的渐变

不是「第一天做什么、第二天做什么」。是**同一个动作在连续时间里的细微变化**。

- 第一天擦外壳→机械的，和昨天一样
- 第二天还在擦→速度慢了一点。拇指在划痕上多停了半秒
- 第三天没擦→看雨。手指在下意识摸胸口的位置但没碰到

### 3. 不在场——物件替人说话

不是「他想她」。是**那个人不在之后，物件替他完成了在场**。

- 老头的门把手上多了一层灰——三个月里积累的。厚度 = 不在了多久。
- 无人机在天台转。画面里只有老太太晾衣服的背影。没说「我想她」——无人机在天上就是全部。

### 4. 空隙——两个△之间的空白

不是「然后」。是**两个动作之间空出来的那段物理时间**。

- 「回头——肩膀没动。」「肩膀没动」删掉比留着更重——读的人会自己补上那个没动的重量。
- 「签字。」「手垂下去。」不需要「然后」——签字到垂手之间的空白就是全部。

## 三、伟大电影参照系

不是「学他们的技巧」。是**看他们在追问什么**，然后问自己：我的剧本在追问什么？

| 电影 | 追问 | 你的剧本在追问 |
|------|------|:--:|
| 《一一》| 人为什么只能看到前面？ | ？ |
| 《诗》| 美如何在一个残酷的世界里发生？ | ？ |
| 《海边的曼彻斯特》| 有些伤口为什么会拒绝愈合？ | ？ |

**每个剧本必须有自己不可替代的问题。** 如果填不出第三列——不是缺答案，是缺问题。

## 四、和 AI短剧编剧助手 的关系

| | AI短剧编剧助手 | 艺术判断 |
|---|---|---|
| 管什么 | 不写错 | 算好 |
| 方法 | 宪法 + 审查 + 精度原理 | 自我追问 + 不可替代性测试 |
| 产出 | 合规的剧本 | 不可替代的剧本 |
| 顺序 | 先跑五轮审查 | 通过审查后再问「够好不够好」 |

### 在审查流程中的位置

跑完 AI短剧编剧助手 五轮审查后，加第六轮：

**第六轮：不可替代性审查**

- [ ] 全剧最重的三场戏——每一场里有没有「只能在这个剧本里」的时刻？
- [ ] 「通过审查」不等于「不可替代」——有没有一场戏可被任何剧本替换？
- [ ] 感知精度四维（温度/时间/不在场/空隙）——每一维至少有一场达到不可替代的精度？
