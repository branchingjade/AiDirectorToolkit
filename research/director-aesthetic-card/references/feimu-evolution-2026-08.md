## 新坑三例（㊿-费穆轮）

1. **PDF 提取文本的页眉噪音 = 跨页引文假 MISS**：王德威论文每页有页眉「春天帶來無盡的悔恨…王德威著 陳思齊譯」+页码，引文跨页时页眉插入短语中间 → 校验必 MISS。解法：norm 先剥页眉/页码行（或写引文时避开跨页断点，按页内连续片段取词）；`i = s.find()` 定位后先打印上下文确认是否跨页再定短语。
2. **繁体存档 vs 简体正文引文的双向兜底**：S7 存档全繁体、正文引文写简体——校验须双侧转换：`p in convert(sa,'zh-cn')` 失败再试 `convert(p,'zh-hant') in sa`（zhconv 词典双向不对称，单侧不够）。两个特例：①「過份/過分」——存档原文「過份」是 zhconv 词典差异（zh-cn 转「过分」、zh-hant 转「過分」都对不上存档「過份」），norm 双侧先 `過份→過分` 归一；②「爲/為」异体字——zhconv 转出「爲」而存档用「為」，norm 双侧 `爲→為` 归一。**凡繁体存档引文，校验脚本先做 過份/爲 类特例归一 + 双向转换兜底**。
3. **中维 API 403/429 → r.jina.ai 渲染页直抓**：zh.wikipedia.org API 无 UA 直接 403、带 UA 后 429 限流——本轮全部 API 失败，换 `r.jina.ai/https://zh.wikipedia.org/wiki/<标题>` 一次成功（小城之春 53KB/狼山 16KB/费穆 40KB）。**中维条目优先直接 jina 渲染页，别先试 API**（与既有「中维 raw 经 API」配方互补：API 限流时 jina 是即插通道）。
