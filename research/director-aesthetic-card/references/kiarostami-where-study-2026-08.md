## 渠道实测（新通道配方）

### 1. Criterion CF 壳 → WebBridge evaluate 直抓（curl/jina 双灭时）
- criterion.com 搜索/影片页经 curl 与 r.jina.ai 均回「Just a moment...」CF 壳（6KB 签名）。
- Kimi WebBridge（127.0.0.1:10086，POST /command，body `{"action","args","session"}`，先 /status 确认 extension_connected:true）：
  - `navigate` films/28638 页 → `evaluate {"code": "document.body.innerText"}` 一次拿全文。
  - **搜索页定位**：`navigate` 到 `criterion.com/search?q=<片名>` → evaluate 提取 `document.querySelectorAll('a')` 中 href 含 `/films/` 的链接（本例 films/28638）→ 影片页再提 `/current/posts/` href（本例 6555+6565 两篇 essay）——免猜 post id，绕过 jina 吞 essay href 的旧坑。
  - essay 正文 33KB/3.6KB 完整（innerText 含导航噪音，正文从标题行后取）。

### 2. DDG html 经 WebBridge 搜索（搜索引擎全灭破局）
- 直连 html.duckduckgo.com 与 r.jina.ai 均 CF 拦时：WebBridge `navigate` `https://html.duckduckgo.com/html/?q=<urlencoded>` → evaluate：
  ```js
  document.querySelectorAll('.result a.result__a') → href
  ```
- 结果 href 是 `duckduckgo.com/l/?uddg=<urlencoded真实URL>`——**uddg= 参数 URL 解码即真实地址**（本轮 rogerebert.com 专题/kiarostami.org 官方页由此定位）。
- 与既有的「维基 ref 挖 URL」互补：搜索引擎全灭时先试本配方再走 ref 挖掘。

### 3. 发行方 presskit PDF 一手通道
- 发现路径：grep enwiki 导演条目 ref 的域名（`zeitgeistfilms.com` 等发行域名）→ ref 的 archive-url 直抓 PDF（wayback 1.7MB 一次到手）。
- 提取：无 pdftotext 时 `pip install pypdf` → `PdfReader` 逐页 `extract_text()`（6 页 7KB 干净文本）。
- 价值：presskit 含名人背书英文原话（黑泽明整段）、导演名言（「truth except through lying」）、发行方命名（Earthquake Trilogy）、Synopsis 由权威影评人撰写（Chris Darke, Sight & Sound）——与 landmarktheatres Filmmaker Letter 同族，**发行物料=一手引文富矿**。

### 4. 豆瓣 rexxar 三端点（本轮完整配方）
- suggest：`movie.douban.com/j/subject_suggest?q=<片名>` → id 1301897（zhwiki {{Douban|1301897}} 可交叉确认）。
- 列表：`m.douban.com/rexxar/api/v2/movie/<id>/reviews?start=0&count=30&sort_by=hotest`（**必须带 Referer: https://m.douban.com/**）→ JSON reviews[].title/useful_count/id。
- 单篇：`m.douban.com/rexxar/api/v2/review/<id>`（同 Referer）→ content 字段含 HTML，**须剥标签+html.unescape 再校验**（与 JSON \uXXXX 转义双坑并存）。
- 选稿：按有用数+主题关键词（学术/访谈/拉片/规训/奔跑/结尾花）一次连抓 10 篇零失败。

### 5. 百度百科消歧义页 → WebBridge 提 href 定位义项
- 裸词条 `item/何处是我朋友的家` = 多义词页（电影+2025 图书），jina 只回 535 字节。
- WebBridge navigate 后 evaluate 提取含「阿巴斯」文本的 `/item/.../<id>?fromModule=disambiguation` href → 电影义项 /2744206 → 再 navigate 抓 9KB 正文。

### 6. 维基 429 限流
- Python urllib 连续 action=query 全 429；curl 带桌面 UA + 请求间隔 2-3s 稳定通过（与影武者轮「zh API 429→带 UA 退路」互证；本轮 enwiki+zhwiki 均适用）。

## 校验方法升级：全量引文段扫描校验（本轮新技）

手工短语清单 grep（skill 既有纪律）漏错——本轮误引「老师的思维」实为「孩子的思维」、句号改逗号、多字「也」三处全由自动扫描抓到：

1. **提取**：正则 `[「『]([^」』]+)[」』]` 扫两份产出全文（引号段）+ `["“](...12-250字...)["”]` 扫英文段。
2. **归一**：剥 `**` 加粗、按 `…+` 省略号拆段、norm 管道（html.unescape/剥标签/弯引号直引号/破折号→连字符/压空白/标点前空格/去引号）+ **CJK 段额外生成去空格变体**（「20 世纪」vs 存档「20世纪」）。
3. **双池验证**：存档池（pages/kiaro_*.txt，剥豆瓣 TITLE 头后全量 join）+ **本地转引池**（[卡小城·S#] 类转引对《小城之春_技法卡片.md》本体校验——㊿③ 应用）。
4. **分类输出**：arch（存档命中）/xiaocheng（转引池命中）/title（豆瓣 TITLE 头池命中）/short（len<12 跳过）/None=真 MISS——**概念标签（自拟分析术语）与影评标题必须单独成类**，否则假 MISS 刷屏（本轮 318 段仅 2 残留，均为来源表 URL/自拟小标题，非引文）。
5. 真 MISS 逐条带行号+上下文人工复核。
