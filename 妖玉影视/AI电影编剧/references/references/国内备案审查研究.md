## 一、审查制度框架（《电影管理条例》第三章）

### 国家实行电影审查制度

**第二十四条**（原文）："国家实行电影审查制度。未经国务院广播电影电视行政部门的电影审查机构审查通过的电影片，不得发行、放映、进口、出口。" [1]

→ 含义：**审查关口在成片**（公映许可证），但剧本阶段已有备案预审（见第二十六条）。

### 剧本投拍审查与备案

**第二十六条**（原文）："电影制片单位应当依照本条例第二十五条的规定，负责电影剧本投拍和电影片出厂前的审查。电影制片单位依照前款规定对其准备投拍的电影剧本审查后，应当报电影审查机构备案；电影审查机构可以对报备案的电影剧本进行审查，发现有本条例第二十五条禁止内容的，应当及时通知电影制片单位不得投拍。" [1]

→ 含义：**剧本投拍前要过制片单位自审 + 报电影审查机构备案**；发现禁止内容 → 不得投拍。这就是"剧本（梗概）备案"制度的行政法规依据。

## 二、禁止内容清单（《电影管理条例》第二十五条，原文十项）

**第二十五条**："电影片禁止载有下列内容：" [1]

| 序号 | 禁止内容（原文） |
|---|---|
| (一) | 反对宪法确定的基本原则的 |
| (二) | 危害国家统一、主权和领土完整的 |
| (三) | 泄露国家秘密、危害国家安全或者损害国家荣誉和利益的 |
| (四) | 煽动民族仇恨、民族歧视，破坏民族团结，或者侵害民族风俗、习惯的 |
| (五) | 宣扬邪教、迷信的 |
| (六) | 扰乱社会秩序，破坏社会稳定的 |
| (七) | 宣扬淫秽、赌博、暴力或者教唆犯罪的 |
| (八) | 侮辱或者诽谤他人，侵害他人合法权益的 |
| (九) | 危害社会公德或者民族优秀文化传统的 |
| (十) | 有法律、行政法规和国家规定禁止的其他内容的 |

**《电影产业促进法》**（上位法，2017 施行）延续同一禁止框架（第十六条），并增加了"尊重知识产权""未成年人保护"等导向要求（主席令公告确认该法于 2017-03-01 施行）[2]。

## 三、对剧本创作阶段的实际约束（预检转化）

把法规禁止条款转译为**剧本创作阶段的预检问题**（写作时自由，交付前逐项自查）：

| 法规条款 | 剧本里的表现形态 | 预检问题 |
|---|---|---|
| (一) 反对宪法基本原则 | 颠覆国家政权情节、丑化国体政体 | 是否有涉及国家根本制度的负面呈现？ |
| (二) 危害国家统一/主权/领土完整 | 分裂主义内容、领土争议不当呈现 | 涉及港澳台/边疆题材时立场是否正确？ |
| (三) 危害国家安全/荣誉/利益 | 泄密情节、丑化国家形象 | 涉军警/保密题材是否触碰红线？ |
| (四) 煽动民族仇恨/侵害民族风俗 | 民族冲突煽动、歪曲民族习俗 | 涉少数民族/宗教题材是否尊重？ |
| (五) 宣扬邪教迷信 | 邪教正面化、封建迷信宣扬 | 灵异/民俗题材是否明确批判立场？ |
| (六) 扰乱社会秩序/破坏社会稳定 | 群体事件煽动、敏感事件影射 | 现实题材是否涉及敏感社会事件？ |
| (七) 宣扬淫秽赌博暴力/教唆犯罪 | 露骨情色、血腥暴力美化、犯罪方法展示 | 暴力/情色/犯罪内容是否超标或美化？ |
| (八) 侮辱诽谤他人 | 真实人物丑化、名誉侵害 | 涉及真实人物/事件是否有依据？ |
| (九) 危害社会公德/民族优秀文化传统 | 价值观导向问题、历史虚无主义 | 历史/传统文化题材是否符合主流价值观？ |

## 四、备案流程要点（创作侧需要知道的）

1. **剧本（梗概）备案**：制片单位（有资质的电影制作公司）向省级电影主管部门报备剧本或梗概（梗概约 1500-2000 字），备案公示通过后方可开机投拍 [1][3]
2. **审查关口**：成片送电影审查机构审查，合格发《电影片公映许可证》[1]
3. **创作侧注意**：
   - 备案是**制片单位的义务**——编剧/导演侧由制片公司走流程
   - **立项前评估**：敏感题材（重大历史、民族宗教、真实案件）在动笔前就要评估风险，改稿成本远低于退改成本
   - 审查标准随政策动态调整，以国家电影局现行规定为准 [3]

## 诚实声明

- 《电影管理条例》2002 版全文已抓取核实（政府网公报），第二十四/二十五/二十六条为逐字原文
- 《电影产业促进法》仅抓到主席令公告页（确认施行日期与法律地位），第十六条全文未抓到——禁止内容以条例第二十五条为准，两法框架一致
- 国家电影局法规栏目页面已抓取（确认存在该栏目），具体规章全文（如《电影剧本（梗概）备案、电影片审查暂行规定》）未抓取——**备案流程细节以国家电影局现行规定为准**，本笔记只做框架性说明
- 审查尺度为动态政策，本笔记不构成法律意见
