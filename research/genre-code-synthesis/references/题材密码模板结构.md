# 题材密码文档模板结构（对齐《志怪题材密码.md》v1.1 实测）

产出路径约定：`<skills>/妖玉影视/_知识库/references/题材密码/<题材>题材密码.md`

## 头部格式

```markdown
# <题材>题材创作密码（AI电影编剧 · 题材库 NN）

> 触发：写<题材>题材电影时加载。创作密码库——不是规则清单，是"这个题材怎么才成立"的根因研究。
> 方法：范本实证（<范本列表>）+ 大师做法。每条带来源。
> 版本：v1.0（2026-08-07，N范本实证完整）
```

## 八段结构（写死的章节骨架）

### 一、<题材>的定义与谱系（先分清楚你在写什么）
- 一句话边界辨析（如"志怪≠恐怖≠玄幻"、"科幻≠奇幻≠寓言"）
- 谱系分层表或示意图（分层依据=规则来源/内核，不是表面元素）
- 关键认知：题材的核心不是表面元素（吓人/奇观），是"借X说人"

### 二、世界观规则（题材的"物理定律"）
- 立规则三问：规则从哪来 / 限制是什么（=冲突来源） / 人怎么对付（=怎么利用反制）
- 进阶纪律：规则可计算（汇率/倍率让观众心算）、规则被用满（一条规则长出三幕）、规则与美术语言分清
- 规则自洽检查法

### 三、核心结构范式（2-3 个，每个带步骤）
- 每个范式：编号步骤（① ② ③ ④ ⑤）+ "**关键**：…"点出范式落点/主题机制
- 范式的命名用"可迁移动作"（如：奇观开场→规则揭示→代价兑现）

### 四、调性混搭（题材独有能力）
- 表格：调性 | 功能 | 范本切换点
- 混搭要领（节奏切换、切换点必须是剧情节点）

### 五、范本分析
- 每部格式：**核心密码**（1-2 句）/ **可复用技法**（编号列表，每条带[片名卡片]/[片名研报]标注）/ **一句话来源**
- 引用标注格式：[2001卡片]、[星际研报]、[诺兰深化]——卡片=技法卡片，研报=研习报告，深化=导演手法体系深化

### 五·五、N部范本横向对比（创作密码汇总表）
- 表格列：维度 | 范本1 | 范本2 | …；行：设定/规则/反派形态/情感引擎/最高技法/结局方式

### 六、常见坑（至少5条，本题材为什么烂）
- 编号列表，每条=坑名+为什么烂+反例/正例（带来源）

### 七、自检清单（至少8条）
- `- [ ]` 可勾选条目，覆盖：规则自洽/规则进战术层/调性切换节点/主题落点/解释度/静默段落/开放结局/首尾闭环

### 八、来源清单
- 按素材类别分组列出文件名（技法卡片目录/研习报告目录/导演深化文档目录）+ 本任务未引用但存在的相关资产

## 可选附加章节
- 附：范本横向对比表（可并入五·五）
- 实战回写记录（早期/进化史）：用表格记录"发现→修复→回写"，含回测结论——题材密码是活文档，随项目回测进化

## 质量纪律（任务下发时通常自带）
1. 所有论断从素材源提炼，禁止凭空发明
2. 引用卡片论断标注出处
3. 抓不到的标"未取证到"（不抓网，素材里没有的就是没有）
4. 聚焦可落地：每条密码都要能指导写一场戏
5. 输出中文；完成后回复：文件绝对路径 + 用了哪些素材 + 最重要发现

## 证据层级注意（继承自研习报告的严谨传统）
- 官方剧本 > 拍摄稿（IMSDb/Script Slug）> 影迷记录台词 > 转引媒体——引用时注明层级（如星际穿越无官方剧本，台词标注"影迷记录层级"）
- 版本差异（早期稿 vs 成片）要标注，如罗伊独白"tears in rain"为成片即兴改写、楚门"see ya"为金·凯瑞即兴
