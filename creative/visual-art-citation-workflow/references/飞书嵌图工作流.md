# 飞书 docs 嵌图工作流（lark-cli 5 步）

适用：把本地图片嵌入飞书 docx，含删图、改 caption、视觉验证回写。

## Step 1 - 准备本地图片（cwd 相对路径）

```python
import os, shutil
cwd_imgs = r'C:\Users\HMSJ\Documents\Hermes\_imgs'  # cwd 下的子目录
os.makedirs(cwd_imgs, exist_ok=True)
# 把要嵌入的图拷到 cwd_imgs（lark-cli --file 限制）
shutil.copy(r'C:\Users\HMSJ\_content\imgs\越王勾践剑.jpg', cwd_imgs)
```

**关键铁律**：`--file` 必须是 cwd 相对路径。绝对路径 `C:/...` 报 `unsafe file path: --file must be a relative path within the current directory`。同理 `--output`。

## Step 2 - 插入图片

```python

cmd = [lark_cmd, 'docs', '+media-insert',
       '--doc', doc_token,
       '--file', './_imgs/越王勾践剑.jpg',  # cwd 相对
       '--caption', '越王勾践剑（春秋晚期，湖北省博物馆藏）',
       '--width', '1200']
r = subprocess.run(cmd, capture_output=True, text=True, timeout=120)
# 成功返回 block_id + file_token
```

## Step 3 - 验证图片真的进了（**必做**）

### 3a. fetch 看 block 数

```python

r = subprocess.run([lark_cmd, 'docs', '+fetch',
    '--doc', doc_token, '--scope', 'full', '--detail', 'full', '--format', 'pretty'],
    capture_output=True, text=True, timeout=30)
# 找 img 标签
import re
imgs = re.findall(r'<img [^>]*name="([^"]+)"[^>]*id="([^"]+)"', r.stdout)
for n, bid in imgs:
    print(n, bid)
```

### 3b. 视觉验证图片内容（关键——）

```python

# 下载回本地（用 media-preview 而不是 drive +download——后者会 403）
cmd = [lark_cmd, 'docs', '+media-preview',
       '--token', file_token,
       '--output', './_verify/越王勾践剑.jpg']
r = subprocess.run(cmd, capture_output=True, text=True, timeout=60)
# vision_analyze 验证
vision_analyze('C:/Users/HMSJ/Documents/Hermes/_verify/越王勾践剑.jpg',
    question="这是什么？请描述图中物体的形态、颜色、关键特征。这是越王勾践剑吗？")
```

**铁律**：每张图嵌入前必须 vision_analyze 视觉验证——文件名不可信。Wikimedia Commons 中文文件名误导的典型案例：`Garuda_cliff_in_Tirumala.jpg` 实际是印度天然山崖不是金翅鸟造像。

## Step 4 - 改 caption（**不能直接用 block_replace**）

❌ **错误姿势**（block_replace 会把整张图替换为 caption 文本块，图像消失）：
```python
cmd = [lark_cmd, 'docs', '+update',
       '--doc', doc_token,
       '--command', 'block_replace',
       '--block-id', img_id,
       '--content', '新 caption']  # 整张图替换为文本！
```

✅ **正确姿势**（先删旧图 + 再插新图）：
```python
# 1. 删旧图
cmd = [lark_cmd, 'docs', '+update',
       '--doc', doc_token,
       '--command', 'block_delete',
       '--block-id', img_id]
subprocess.run(cmd, ...)

# 2. 插新图（带新 caption）
cmd = [lark_cmd, 'docs', '+media-insert',
       '--doc', doc_token,
       '--file', './_imgs/越王勾践剑.jpg',
       '--caption', '新 caption（更精确的文物依据说明）',
       '--width', '1200']
subprocess.run(cmd, ...)
```

## 顺序陷阱（**最常见翻车点**）

**先写文本 → 最后 media-insert 图**。反过来（先 media-insert → 再 overwrite 文本）会冲掉已插的图：

```python
# ❌ 错误顺序
media-insert（图1）→ overwrite 文本 → 图1 被冲到文末（甚至消失）
# ✅ 正确顺序
overwrite 文本 → media-insert（图1）→ media-insert（图2）→ ...
```

## markdown 图片语法 vs 真下载

❌ **错误姿势**：把 Wikimedia URL 直接放 markdown 里：
```markdown
![越王勾践剑](https://upload.wikimedia.org/wikipedia/commons/b/bd/越王勾践剑.jpg)
```
飞书 docs `+update --command overwrite` **不会触发服务端下载 Wikimedia URL**——返回 `partial_success degrade_code=2108` 警告，图位置但占空。

✅ **正确姿势**：本地 media-insert（见 Step 2）。

## 完整脚本模板

```python
import subprocess, os, shutil

lark_cmd = r'C:\Users\HMSJ\AppData\Local\hermes\node\lark-cli.CMD'
doc_token = '<文档 token>'
cwd = r'C:\Users\HMSJ\Documents\Hermes'

def embed_image(doc, img_local_path, caption, width=1200):
    """嵌入图到飞书 doc，返回 (block_id, file_token)"""
    fn = os.path.basename(img_local_path)
    cwd_imgs = os.path.join(cwd, '_imgs')
    os.makedirs(cwd_imgs, exist_ok=True)
    cwd_path = os.path.join(cwd_imgs, fn)
    if os.path.abspath(img_local_path) != os.path.abspath(cwd_path):
        shutil.copy(img_local_path, cwd_path)
    
    cmd = [lark_cmd, 'docs', '+media-insert',
           '--doc', doc, '--file', f'./_imgs/{fn}',
           '--caption', caption, '--width', str(width)]
    r = subprocess.run(cmd, capture_output=True, text=True, timeout=120)
    if r.returncode != 0:
        raise RuntimeError(f'media-insert failed: {r.stderr[:300]}')
    import json
    data = json.loads(r.stdout)['data']
    return data['block_id'], data['file_token']

def delete_image(doc, block_id):
    cmd = [lark_cmd, 'docs', '+update',
           '--doc', doc, '--command', 'block_delete', '--block-id', block_id]
    return subprocess.run(cmd, capture_output=True, text=True, timeout=30)
```
