# 导演侧取证渠道地图（导演美学卡片的一手来源）

> 2026-08-07 徐克导演美学卡片实战验证（Film Comment 两篇访谈 + 中英维基 + 百度百科 + 豆瓣长评，13 组来源产出 23KB 卡片）。
> 2026-08-07 第七轮 8 位导演再验证（小津/塔可夫斯基/杨德昌/是枝裕和/诺兰/科恩兄弟/吴宇森/杜琪峰），新增渠道见下文「第七轮新验证渠道」。
> 用途：双轨研习的"导演轨"子代理拿到目标导演后，按此表找一手资料。
> 抓取机制细节（Wayback 配方/Wikipedia 剥壳/串页规避/反爬）见 `cn-content-site-extraction` 技能。

## 第七轮新验证渠道（2026-08-07，8 位导演 691s 内全完成）

- **导演著作/自传全本 = 比访谈更系统的一手源**：塔可夫斯基《雕刻时光》（Sculpting in Time）英文全本在 archive.org 有扫描件 djvu.txt（474KB，含页码级转引）——"sculpting in time"定义、两段公开拒绝蒙太奇的原话（"I reject the principles of 'montage cinema'"、"Eisenstein makes thought into a despot"）全直取。**搜导演英文著作书名 + archive.org（djvu.txt 可全文 grep）优先于访谈拼凑**。小津《豆腐匠的哲学》日文书名「僕はトウフ屋だからトウフしか作らない」经 Sight & Sound Tony Rayns 英译 + 百度百科词条双源佐证。
- **学术论文 = 导演技法的硬数据**：David Bordwell 学术研究给杨德昌掐表数据（《牯岭街》4 小时约 520 镜、均 28 秒/镜——"固定长镜+中远景"从印象变硬数据）；Deakins 访谈实证科恩兄弟运镜哲学（全片开拍前全部分镜、从不用变焦"我甚至不带变焦镜头"、硬币场景极慢推轨）。Criterion 的论文级 essay（Kent Jones/Cheshire 论杨德昌、Prose 论老无所依）质量高于普通影评。
- **一手访谈富矿（本轮新增）**：The Talks 2023 诺兰（"在完全掌控结构之前我不会动笔写剧本"）、Guardian 2014 诺兰长文、MUBI 2009 是枝裕和（"保持它干爽、轻盈……太感伤我就失败了"=最轻动作的导演原话）、NYT 1996 吴宇森（"In action I feel like I'm creating a ballet"）、Salon 1997 吴宇森（"doves represent the spirit"——白鸽=灵魂原话）、卫报 2004/2014 科恩兄弟访谈。
- **预设证伪纪律（第七轮 3 次）**：科恩"对称构图"全源无据（真实签名是"三人几乎从不同框的隔离构图"A.O. Scott）；诺兰"香港跳楼"实为 IFC 楼顶航拍+C-130 抓机（港方否决特技）；塔可夫斯基"拍梦用柔焦/雾化"是反的（导演要求"cinema must expose reality, not cloud it"，梦的怪来自全是真元素组合不可能）。**导演卡片任务预设常错——子代理必须把"预设 vs 取证"的差异写进诚实声明，不硬凑**。
- **中文一手渠道补充**：杜琪峰在第廿四届香港电影节特刊访谈（"没有黑泽明的电影我根本拍不到《鎗火》""那种静中的动，单单站在那儿已很厉害"）经学术影评（张凤麟/Senses of Cinema Stephen Teo）转引可查；香港媒体（东方日报 2016 吴宇森、HK01）经 Wayback 可回源。
- **版本/数字纠偏**：吴宇森《辣手神探》拍摄天数 123 vs 150 两说并存、诺兰 Memento 预算 $4.5M vs $9M 矛盾——多源矛盾进诚实声明，正文不采用。

## 来源优先级（一手 > 二手）

1. **导演访谈**（最高价值：导演自己的话 = 创作思路/工作方法的直接证据，可直接引用原话）
2. **成片影评分析**（画面/声音/调度/角色维度的"成片表现"证据）
3. **制作特辑 / 百科幕后 / 获奖记录**（工作方法与工业事实）
4. **维基二手手法清单**（只作背景线索，不作卡片论断来源）

## 英文访谈渠道（最富矿藏）

- **Wikipedia EN 词条 References 是访谈链接索引**：抓词条 HTML 后过滤
  `grep -oE 'href="https?://[^"]+"'`（或 python 正则），媒体白名单：
  filmcomment / nytimes / theguardian / scmp / bfi.org / sightandsound /
  variety / hollywoodreporter / indiewire / time.com / asiasociety / mubi。
- **Film Comment 长访谈**：该刊有"导演长访谈 + 注释版（Annotated Interview）"传统
  （如 2011 Graham Fuller 访徐克 + Grady Hendrix 注释版 Part II）。
  一手引语密度极高：徐克原话覆盖快剪成因（"我们是紧张的人"）、特效缘起（《蝶变》朋友
  一句"为什么不用特效"）、3D 与剪辑的关系、午夜场试映重剪、逐片创作动机（5 岁看李翰祥
  《倩女幽魂》）、《刀》的纪录片式动作设计（全片仅两处威亚）。
  注释版还有工业考据（从零建香港特效工业：招《星球大战》团队、自造 motion-control 摄影机）。
- **直链失效处理**：媒体改版后旧 URL 常 404 → Wayback Machine：
  `curl -sL "https://web.archive.org/web/2023/<原URL>" -H "User-Agent: Mozilla/5.0..." -o out.html`
  （`/web/2023/` 取近年快照；实测 Film Comment 两篇 404 访谈均经此回源 200）。
  维基引用里直接给 web.archive.org 链接的条目，链接本身可用。
- NYT/SCMP/Time 的导演专访也是高质量渠道（维基引用里常见，NYT 旧文常被存档）。

## 卡片质量纪律（本类任务专属）

- 每个论断挂来源（访谈原话 / 影评 / 百科 / URL）；**不许凭印象写**。
- **未取证到的具体技法**（如"广角变形""仰拍英雄""青蛇绿调"）不写进正文论断——
  放 ⚠️ 诚实声明，并给最接近的间接佐证（例：青蛇绿调 = 翠绿蛇身（影评）+
  "迷幻佛教史诗"（Film Comment）+ "超凡脱俗的神话色彩"（维基）三源并置）。
- 引语优先导演自述原话（Film Comment 这类一手访谈）；二手转引（如"香港电影资料馆访谈"
  经 Film Comment 注释转引）要标注转引层级。
- 事实多源矛盾（如百度百科生年 1950 vs 维基 1951）时：正文不采用，声明里列出矛盾。
- 任务引语（如"武侠片是东方特有的类型"）找不到中文原话时：标"未取证到"，
  给最接近的权威英文表述（Film Comment："wuxia is to China what the Western is to America"）。
