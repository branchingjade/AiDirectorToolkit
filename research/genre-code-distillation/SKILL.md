# 题材密码提炼（Genre Code Distillation）

> 用途：把分散的存量知识资产（大师技法卡片/研习报告/导演深化文档）沉淀为一份面向编剧的《<题材>题材创作密码》文件。**零网络抓取**——只从本地资产提炼，每条论断带来源。
> 产出位置：`C:/Users/HMSJ/AppData/Local/hermes/skills/妖玉影视/_知识库/references/题材密码/`
> 程序背景：妖玉影视题材密码系列（志怪01/悬疑02/喜剧03/爱情04/武侠05/剧情06 → 批产扩容中），父代理常以并行子代理批派本类任务。
> 编号现状：`references/题材库编号现状-2026-08-07.md`（13 文件编号快照与撞号统计，批产/整理前先读）。

## 何时用
- 收到"产出《X题材创作密码》"子代理任务（题材库系列批产）
- 需要把 N 部电影的技法卡片+研习报告+深化文档收敛成一份题材级创作密码
- 任务要求"零网络抓取/存量提炼/对齐现有模板"时

## 工作流（步骤）
1. **先读模板，再动笔**：读同目录已有题材密码（志怪题材密码.md 为系列基准模板：定义谱系/世界观规则/结构范式/调性混搭/范本分析/常见坑/自检清单/来源清单八段）。完整复刻结构，别凭印象写。
2. **定位素材**：中文文件名/中文路径用 `terminal find` 一次到位——本库实测 `search_files` 对中文路径与中文模式返回 0 命中而 find 可靠（`find "目录" -name "*关键词*"`；文件多时先 `wc -l` 摸底再决定读取顺序）。
3. **编号对齐**：写文件前 `grep "题材库" *.md` 看全部现有编号。**并行批产时编号冲突必然发生**（实测 07 被三文件共用、02 被四文件共用）——子代理按规范序列取号并在最终总结中明示冲突，统一整理留给父代理/策展。
4. **通读全部素材**：技法卡片（主源，含可复用时机/画面锚点）→ 研习报告（含结构观察/一句话/桥段/诚实声明）→ 深化文档（含演变链/跨片对比/可复用工具箱）。每份都要读，卡片与报告互补：卡片给单场技法，报告给结构与"最值得偷的一招"。
5. **写作**：八段结构；范本分析每部 = 核心密码 / 可复用技法（带编号）/ 一句话来源；常见坑与自检清单一一对应、可落地。
6. **验证**：写后 `ls -la` + `wc -l` 确认落盘；检查引用标注无越界编号。

## 模板结构（八段，对齐志怪基准）
1. **定义与谱系**：亚型三分（如犯罪片=事件/黑帮片=世界/警匪片=对位）+ 定位光谱（浪漫化↔写实化↔荒诞化）+ 关键认知（题材的魂不在表层奇观）
2. **世界观规则**：立规则三问 + 范本规则清单 + 规则自洽检查（每现象问"为什么能/不能"）
3. **核心结构范式**：2-3 个范式，每个带 ① ② ③ 步骤与范本锚点；范式后给"关键"提炼句
4. **调性混搭**：调性×功能×范本语法表格 + 切换要领（切换点必须是剧情节点；反差即主题）
5. **范本分析**：每部电影一节 = 核心密码 / 可复用技法（每条带[卡X]标注）/ 一句话来源（取研习报告"一句话"段）
6. **常见坑**：≥5 条，每条 = 坑 + 范本反例 + 修正做法
7. **自检清单**：≥8 条 checkbox，与常见坑对应；含备案审查项（参照志怪模板写法：明确批判立场、不美化/不教唆）
8. **来源清单**：完整列出素材文件绝对路径与编号体系说明

## 引用标注体系（跨文档互引，沿用不另起炉灶）
- `[卡X·N]` = 技法卡片第 N 张（如 [卡教父3]、[卡枪火2]）
- `[研X]` / `[研X·S#]` = 研习报告及单片来源编号（黑社会/枪火/严肃的男人用 [研S#] 独立体系，见各自报告文末来源表）
- `[深化X S#]` = 手法体系深化文档编号（如 [深化杜S1]、[深化科恩S13]；吴宇森深化无 S 编号，用存档文件名）
- 引文逐字摘自存档；转引标注层级；**抓不到的标"未取证到"，不硬凑**

## 质量纪律
- 零网络抓取：所有论断从素材源提炼，禁止凭空发明
- 每条论断带来源；引用卡片论断时标注卡片号
- 一句话来源必须可回溯（研习报告末尾"一句话：这部片最值得偷的一招"是最佳素材）
- 范本"可复用技法"写成可执行指令（何时用/怎么用），不是复述剧情
- 诚实声明继承：素材本身的版本不确定性（流传稿/无剧本/影迷解读）要在来源清单或文中注明

## 坑与对策
1. **题材库编号冲突**：并行子代理各自取"下一个编号"必然撞号。对策：写前 grep 现有编号；按规范序列取号；总结中明示冲突。
2. **search_files 对中文路径零命中**：定位中文文件名改用 terminal find（见工作流步骤 2）。
3. **技法卡片没有现成"常见坑"章节**：坑位从各卡"可复用时机/纪律/诚实声明"提炼——例：烟枪卡"巧合必须有物理地基"→ 坑"巧合天降无前置机关"；冰血暴卡"口音拼写要克制"→ 坑"方言堆砌"。这是六、七两段的素材来源。
4. **引用前确认被引文件存在**：模板中引用的文件（如《国内备案审查研究.md》）可能实际不存在——先搜索，找不到就标"待补"，别照抄引用。
5. **备案/审查纪律**：题材密码系列惯例在自检清单含备案审查项（批判立场、不美化、防教唆），写法参照志怪模板。
