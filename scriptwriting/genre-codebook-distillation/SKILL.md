# 题材密码提炼（Genre Codebook Distillation）

> 从存量知识资产提炼某题材的"创作密码"文件（写入 `妖玉影视/_知识库/references/题材密码/`）。**零网络抓取**，全部论断带来源标注，抓不到的标"未取证到"。**题材库编号（2026-08-07 统一后的正式序列，写文件时必须用对）**：01 志怪、02 悬疑、03 喜剧、04 爱情、05 武侠动作、06 剧情作者电影、07 科幻奇幻、08 家庭温情、09 犯罪黑帮、10 都市情感、11 历史史诗、12 梦境超现实、13 底层时间青春。⚠️ 子代理产新密码时**不要在文件里自编编号**——编号冲突是已知坑（见坑7），统一由主线程入库前分配。

## 触发场景
- 父代理派发"题材密码提炼子代理"任务（本技能即此类子代理的执行手册）
- 需要新增或更新 `references/题材密码/*.md`
- 需要横向对比多部范本、提炼可复用技法（常见配套任务：写范本时"先读卡片2与卡片6"这类指引）

## 核心流程

### 1. 读模板（格式对齐，必做）
先完整读最新的题材密码文件（如 `志怪题材密码.md`）对齐八节结构 + 头部元信息（触发/方法/版本）+ 实战回写记录格式。输出必须同构，不要自创结构。

### 2. 盘点素材（路径固定，先 ls 验证存在）
- 大师技法卡片：`C:/Users/HMSJ/AppData/Local/hermes/skills/妖玉影视/_知识库/references/大师技法卡片/`
- 研习报告（**分海外/华语两目录**）：`C:/Users/HMSJ/Documents/KnowledgeBase/Obsidian Vault/剧本库/海外剧本/研习报告/` + `.../华语剧本/研习报告/`
- 导演深化文档（*_手法体系深化.md）：`C:/Users/HMSJ/Documents/Hermes/film-suite-research/技法卡片源稿/`

### 3. 读取策略（保护上下文，实测有效）
- **技法卡片**：全部完整读（每张 80-150 行，含"可复用时机/画面锚点/诚实声明"，都是提炼原料）
- **研习报告**：先用 execute_code 扫全部 `#` 标题行，再只读关键节——"结构观察 / 一句话：最值得偷的一招 / 桥段设计 / 可复用工具箱"。画面锚点、对白手法与卡片重叠度高，可跳过
- **深化文档**：读"可复用工具箱"节 + "vs 其他导演"对比节（含独特性定位句，是密码库"谱系"部分的直接原料）

### 4. 交叉提炼
同一技法在 卡片+研习报告+深化文档 三处互证时取最强证据链；**发现"同工具两种用法"的对比是密码库最高价值**（例：饭桌容器——李安用"人数递减"推进 vs 是枝用"关系不变"蓄力；小津空镜画句号 vs 是枝日常保温）。

### 5. 写文件 + 6. 校验
写完重读文件扫标题结构；统计各来源标注出现次数确认无漏；**核对文件名与任务指定路径逐字一致**。

## 输出文件结构（对齐志怪题材密码）
```
# <题材>题材创作密码（AI电影编剧 · 题材库 NN）
> 触发：…（这个题材怎么才成立的根因研究）
> 方法：范本实证。每条带来源。
> 版本：v1.0（日期）
一、定义与谱系（题材≠相邻题材的根因区分，先分清楚在写什么）
二、世界观规则（题材的"物理定律"；立规则三问/四问 + 范本规则 + 自洽检查）
三、核心结构范式（2-4 个，每个带编号步骤）
四、调性混搭（题材独有能力 + 三调切换要领）
五、范本分析（每部：结构/创作密码/一句话来源）
五·五、横向对比表（维度 × 范本，含核心密码行）
六、常见坑（≥5 条，从范本"反例"提炼，每条带范本证据）
七、自检清单（≥8 条，写完逐项对照）
八、来源清单（本次引用过的全部文件路径）
+ 备注（质量纪律：沿用各卡片诚实声明；未取证到事项单列；适用边界）
+ 实战回写记录（实战回测后追加：回测结论 + 发现/修复/回写表）
```

## 坑（实战踩过）
1. **文件名写死勿改**：任务指定 `家庭温情题材密码.md`，写成"…创作密码.md"会偏离——固定路径一个字都不能加，写完 `ls` 核对
2. **研习报告别全文读**：8 份报告 ~1300 行会烧穿上下文；先扫标题再读关键节（见流程 3）
3. **华语/海外研习报告分目录**：饮食男女/一一/悲情城市等华语片在 `华语剧本/研习报告/`，海外片在 `海外剧本/研习报告/`——按片别查对，别假设全在一边
4. **引用标注别打错片名**（本会话"步履停停"→"步履不停"）：写完 grep 核对标注关键词
5. **素材可能双份**：`film-suite-research/技法卡片源稿/` 与 skills 正式库各有一份卡片——以正式库为准，源稿目录用于找深化文档
6. **沿用诚实声明**：每张卡片自带取证局限（整理稿/转载剧本/转述台词/未逐帧看片），提炼时必须带进"备注"节，否则下游误以为一手剧本
7. **编号冲突（2026-08-07 十五轮实战，7 子代理并行时 02/05/07 被多个文件共用）**：并行子代理各自按模板自编"题材库 NN"编号必撞——**子代理产文件时不要写死编号或先写占位**，主线程入库前统一分配（先盘点既有 01-N，新产物按顺序接续）；文件头部写"AI电影编剧 · 题材库 NN"时若不确定编号，写"题材库 <主线程分配>"留待替换
8. **密码版本升级（回测回写后 v1.0→v1.1）**：回测结论回写密码时，**版本行、SKILL.md 题材密码索引状态列两处同步改**——只改一处会版本漂移（Skill 维护自检铁律③同款）
