# 视觉验证步骤（嵌入飞书前必走）

适用：每张图嵌入飞书 doc 前**必须 vision_analyze 视觉验证**——文件名不可信，特别 Wikimedia Commons 中文文件名。

## 为什么必要（反面教训）

**v1.0 实测案例**：本会话用 Wikimedia Commons `Special:FilePath/Garuda_cliff_in_Tirumala.jpg` 探测到 200，下载到本地 3.6MB，命名为"金翅鸟.jpg"嵌入剑器 doc。后续用户视觉验证发现——文件名叫 Garuda 但实际是**印度 Tirumala 山崖的天然岩壁**，不是金翅鸟/迦楼罗造像。

**代价**：嵌入飞书后用户视觉验证才暴露错图，已 block_delete 删除重抓。

**根因**：Wikimedia Commons 文件名由上传者自命名，**英文/中文文件名都不可信**——上传者可能图与名错位，类别归属也可能错。

## 验证步骤（5 步，每张图嵌入前必走）

### Step 1 - 本地下载完图后立刻 vision_analyze

```python

vision_analyze(
    image_url='C:/Users/HMSJ/_content/imgs/Garuda_cliff_in_Tirumala.jpg',
    question='这是什么？请描述图中央主体（动物/神佛/人首鸟身等）。这是金翅鸟/迦楼罗吗？能看到翅膀/羽翼特征吗？水印不算请专注内容'
)
```

### Step 2 - 看视觉回答是否符合考据对象

| 考据对象 | 必须看到 | 不可接受 |
|---|---|---|
| 越王勾践剑 | 菱形八面剑身 / 同心圆剑首 / 绿松石剑格 / 鸟篆铭文 | 模糊文物图 / 普通装饰剑 |
| 莫高窟 359 窟金翅鸟 | 人首鸟身/双翅展开 / 莲花座 / 石绿赭红暖底 | 飞天（女身飘带）/ 凤凰/朱雀 |
| 江帆楼阁图（李思训）| 朱漆楼阁+琉璃瓦+朱红江面+几叶扁舟+松林掩映 | 普通山水画 / 无楼阁 |
| 婴戏图（宋代）| 双丫髻儿童 + 麻衣短衫 + 嬉戏活动 | 写意山水 / 佛像 |

### Step 3 - 视觉不符合时立刻处理

```python
# 1. 删除本地错图
import os
os.remove('C:/Users/HMSJ/_content/imgs/Garuda_cliff_in_Tirumala.jpg')

# 2. 退回图源搜索（参见 references/常用图源.md）
# 优选：换文件名 / 换关键词 / 走 P2 集古作网或书格 / 走 P3 公开博物馆新闻

# 3. 重抓后视觉验证 → 通过 → 才嵌入飞书
```

### Step 4 - 通过后嵌入飞书 + caption 标注

```python
cmd = [lark_cmd, 'docs', '+media-insert',
       '--doc', doc_token,
       '--file', './_imgs/越王勾践剑.jpg',
       '--caption', '越王勾践剑（春秋晚期，湖北省博物馆藏；来源：维基共享资源/Commons）',
       '--width', '1200']
```

caption 必须明确标注：
- **实物/仿本/真迹**：仿本要标"WikiCommons 来源仿本/摹本"；真品要标"藏地：XX博物馆"
- **朝代/作者/年代**：避免"古画"这种模糊
- **来源 URL**：溯源出处

### Step 5 - 嵌入后从飞书回本地二次视觉验证

```python
# 用 file_token 下载回本地
cmd = [lark_cmd, 'docs', '+media-preview',
       '--token', file_token,
       '--output', './_verify/越王勾践剑.jpg']
subprocess.run(cmd, ...)
# 视觉验证
vision_analyze(
    image_url='C:/Users/HMSJ/Documents/Hermes/_verify/越王勾践剑.jpg',
    question='这张图是从飞书 doc 下载回来的原图，请视觉验证它是否是越王勾践剑真品？'
)
```

**为什么还要二次验证**：lark-cli 服务端可能在上传时压缩/转码——本地原图 OK 不代表飞书服务端存的一样。**二次验证确保飞书里的图和本地原图一致**。

## 视觉验证 prompt 模板

每张图根据考据对象定制 prompt。**核心要素**：明确说出考据对象名 + 询问关键特征 + 提醒忽略水印。

```
这张图是什么？请描述图中央主体（动物/神佛/人首鸟身等）。
这是<考据对象名>吗？能看到<该对象的特征 1>/<特征 2>/<特征 3>吗？
水印不算请专注内容。
```

**反例**（prompt 模糊）：
- 「这张图是什么？」——太宽，视觉可能答非所问
- 「请告诉我图中的内容」——同样宽泛

**正例**（具体到特征）：
- 「请描述图中央主体（动物/神佛/人首鸟身等）。这是金翅鸟/迦楼罗吗？能看到翅膀/羽翼特征吗？」——视觉能精确判断
