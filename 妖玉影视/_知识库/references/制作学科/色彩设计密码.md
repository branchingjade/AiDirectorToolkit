# 色彩设计密码

> 触发：设计世界观色彩系统/色彩分区叙事/把颜色写进提示词时加载。制作学科密码——不是规则清单，是"色彩这个专业领域怎么设计才成立"的根因研究。
> 方法：范本实证（张艺谋/王家卫/库布里克/安德森/费穆已取证卡片与深化文档）+ 伏妖记实战回写（颜色语义体系）。每条带来源。
> 版本：v1.1（2026-08-09，河底灯回测回写）
> 姊妹文档：《调色密码》（后期调色分级，本文不覆盖——本文只管前期美术配色的设计决策）

## 一、色彩设计的定义与谱系（先分清楚你在设计什么）

**本文管前期美术配色（设计层）**：色票怎么定、每幕每段用什么主色、颜色承担什么语义、饱和度/对比度作为叙事参数怎么规划——"画之前"的决策。
**《调色密码》管后期调色分级（执行层）**：成片素材的色温/对比/胶片模拟/场景匹配——"拍完/生成完"的修正。

| 维度 | 配色设计（本文） | 调色分级（姊妹文档） |
|---|---|---|
| 时机 | 剧本/分镜/世界观阶段 | 成片后期 |
| 对象 | 服装、布景、道具、光源的颜色选择 | 整段画面的色彩倾向、对比、色温 |
| 性质 | 语义决策（这颜色在说什么） | 质感决策（这画面像什么介质拍的） |

**分工铁律【推断】**：前期没做配色决策的戏，后期调色救不回来——调色只能统一质感，不能凭空给颜色装上语义；配色语义再完整，不锁饱和度/对比约束，AI 生成阶段就会漂（见第六章）。依据：张艺谋为色彩换胶片、现场实物直接构成黑白灰（[卡·张艺谋] 1.3/创作思路5）。

**谱系定位**：色彩设计处于"编剧（语义）×导演（画面）"的接缝——张艺谋把颜色当叙事引擎（[卡·英雄]）、王家卫把颜色当记忆显影液（[深·王家卫] 工具4）、库布里克/安德森把颜色纳入秩序/舞台的形式系统（[深·库布里克]、[深·安德森]）。共同指向：**颜色不是装饰，是携带信息的结构**。

## 二、核心语法（本学科的"物理定律"）

### 2.1 色彩分区章节制（四色段真相）

**定律**：给每个叙事层/章节/人物阶段锁一种主色，颜色一变，观众自动知道"视角/状态/时间层变了"。

- **《英雄》五色章节**：黑=现实框架（秦尚黑），红/蓝/白=三重叙事版本，绿=闪回；意图是"以视觉模式令观众更有条理地看整个故事"（[卡·英雄]）。
- **《大红灯笼》四色基调（四色段真相）**：暖（初入，未被同化）→ 大红（参与争宠）→ 阴冷（绝望）→ 全白（精神死亡）——**四色不是气氛，是人物被制度吞没的四个阶段**（[卡·大红灯笼高高挂#8]；[深·张艺谋] 2.1）。四色段的真相：**色彩分区章节制的本质是"色=语义单元"，每换一档颜色就是人物跨过一道坎**。
- **演变链（张艺谋自证进化）**：红高粱的红=情绪呐喊 → 大红灯笼四色=状态编码 → 英雄五色=叙事结构 → 黄金甲的金=权力本身 → 影的水墨=留白。**早期色彩是故事的皮肤，后期色彩是故事的骨架**（[深·张艺谋] 2.1）。
- **落地**：多版本叙事/回忆交错 → 每层一色；人物沉沦线 → 一条色彩状态轴；章节制结构 → 色变=章变。东邪西毒用节气做时间骨架、色彩抽干成沙漠一色，是"时间骨架配色"极值（[卡·东邪西毒]；[深·王家卫] 2.3）；重庆森林抽帧+手持让色彩拖成残影，是都市孤独的色度错位（[卡·重庆森林]）。

### 2.2 对称构图 + 色彩仪式感

**定律**：对称构图让"秩序"可见，仪式化的颜色让"权力"可重复——叠加即压迫翻倍。

- **对称三系**（[深·安德森] §4）：库布里克=秩序（对称是囚笼，闪灵镜像迷宫，"秩序越精确、失控越恐怖"，[深·库布里克] 演变链1/工具1）；安德森=舞台（对称是展台，舞台化 tableau，陈列情绪，[深·安德森] 工具2）；张艺谋=权力（对称是家规/王权可见化——"构图多采用轴对称……就像陈府那些个看不见的条规条例"，[卡·大红灯笼高高挂#2]；从宅院到家国，[深·张艺谋] 2.2）。
- **色彩仪式感（点灯仪式）**：把抽象的"宠爱"翻译成可执行的视觉仪式——点灯/捶脚/点菜，红灯笼=被选中；封灯=黑布罩灯，"从喜庆而张扬的红到死灰般沉寂的黑"（[卡·大红灯笼高高挂#1]）。**仪式每重复一次，窒息感加深一分**（[卡·张艺谋] 1.5）；反讽律：最喜庆的色=最残酷的制度——"大红，本是大吉大利的祝愿，却成了阴森狰狞的血舌"（[卡·大红灯笼高高挂#8]）。
- **仪式主体两分（河底灯回测）**：仪式重复的语义取决于"谁在重复"——**权力侧仪式**（压迫者对受害者重复：大红灯笼家长点灯）="压迫加深"，重复一次窒息一分；**受害者侧自我仪式**（被困者自我重复：魂每夜在河心点灯、一盏盏亮起，等一个不来的渡）="自我困锁/等待消耗"，重复一次执念深一分——等待的重复即执念的加深【河底灯回测】。仪式美学随主体变：权力侧=对称压迫（家规/王权可见化），受害者侧=环形等待（河心一圈灯=魂的环形等待）。
- **落地**：权力戏/封闭空间悲剧 → 对称构图+仪式化颜色（红灯笼/金甲/朱门）；仪式重复即节奏（[知识库·招式表] 仪式化暴力）；先问"谁在重复仪式"——权力侧=压迫加深，受害者侧=自我困锁。

### 2.3 颜色语义体系（力量/状态编码 + 稀缺色纪律）

**定律**：力量/状态用颜色编码，颜色即状态——观众不需要台词解释，看颜色就知道角色状态；稀缺色=全片只给 N 处，出现即重音（[知识库·招式表] 颜色语义体系，伏妖记 2026-08-07 实战）。

- **伏妖记编码（实战）**：**金光=失控**（力量暴走，混合/过曝色）、**青光=受控**（法力纯正，色相分明）、**红色纪律**（全片红色只给 N 处，出现即重音）（[知识库·招式表]）。
- **编码总则**：**失控=混合色（脏/杂/溢出），受控=纯色分明**（[知识库·招式表]）。
- **存在编码分层法（河底灯回测）**：力量编码之外的第二形态——志怪/鬼魂题材没有"法力"体系，颜色绑定的是"存在/执念/渡"而非力量，须分层：**色相管身份、光行为管状态**。河底灯：魂的灯焰=暖黄（身份色，全片唯一暖色域只给这一盏灯）；受控=色相分明、边缘清晰，执念爆发=溢出/混合过曝/光晕扩散——状态切换不必换色相，换光的行为即可【河底灯回测】。迁移模板：先定"身份色"（存在唯一，不许中途改义），再定"状态参数"（溢出/混合/边缘清晰度）。
- **影视先例印证**：大红灯笼四色状态轴（[卡·大红灯笼高高挂#8]）；英雄色=视角编码（[卡·英雄]）；影"唯一一抹溅开的鲜红"=稀缺色极值（[卡·张艺谋] 1.3）；辛德勒红衣控诉（[知识库·导演索引]）。
- **落地规则**：① 先定 N（各重音色出现次数），写进分镜资产锁；② 每色绑定唯一语义，写进世界观，不许中途改义——"唯一语义"指色相的身份语义（存在编码）或状态语义（力量编码）；③ 状态切换=颜色或光行为切换，切换本身是叙事动作（青光→金光=受控→失控；灯焰纯正→溢出=执念翻涌，观众秒懂）。

### 2.4 色彩心理学基础（红/蓝/黄/绿的情感负载）【通用理论】

> 本节为通用色彩心理学（非知识库取证）。用法：**心理负载只做初始设定，具体含义由影片内部语义覆盖**——张艺谋/杜可风明确主张"色彩选择是美学直觉而非符号学"（[卡·张艺谋] 1.3）。

| 色 | 通用情感负载【通用理论】 | 片内实证用法 |
|---|---|---|
| 红 | 唤起注意/兴奋/危险，情绪强度最高（[AI导演 三·五 3] 实证） | 欲望/嫉妒（英雄红段）；生命力（红高粱，[深·张艺谋] 1.1）；压迫（红灯笼反讽） |
| 蓝 | 冷静/疏离/忧郁/放松（[AI导演 三·五 3]） | 理性/计谋（英雄蓝段）；孤独（重庆森林冷蓝调，[卡·重庆森林]） |
| 黄 | 乐观/能量/警示/注意力 | 金色=极权（黄金甲，[深·张艺谋] 2.1）；金=失控警示色（伏妖记，[知识库·招式表]） |
| 绿 | 自然/平静/生机；亦含不安与毒性 | 回忆/平和（英雄绿段，[卡·英雄]）；妖域主色（[深·王家卫] 工具4） |

- **冷暖对立总纲**：暖=唤起/接近，冷=冷静/疏离；**饱和度=情绪强度**——高饱和=情感强烈/梦幻，低饱和/褪色=压抑/回忆/纪实；通用负载当"默认值"，片内语义当"锁定值"——一旦片内锁定（如金光=失控），通用含义作废，全片服从片内编码（[AI导演 三·五 3]）。

### 2.5 低饱和时代褪色感

**定律**：褪色不是"高级感滤镜"，是信息的载体——**色彩服从时代与记忆**。

- **时代褪色**：《布达佩斯大饭店》战前=sharp 红粉紫，战后=subdued 米/橙/淡蓝，色彩随时代明灭（[深·安德森] 演变链3）；《活着》服装/室内随年代越来越朴素统一（[深·张艺谋] 1.3）。
- **情绪灰色**：费穆"我为了传达古老中国的灰色情绪，用'长镜头'和'慢动作'构造我的戏"（[深·费穆] 2.2）——灰色调=时代情绪底色，不是调色参数。
- **记忆反向**：王家卫记忆色板——现在时=低饱和/素色，回忆/鬼域=高饱和记忆色（[深·王家卫] 工具4）。
- **创伤记忆反向（河底灯回测）**：记忆色第二方向——**创伤/未解的记忆=褪色冷**（费穆灰模型）：死者世界没有颜色，水淹村的人集体停留在十年前，龙宫青灰=创伤记忆色【河底灯回测】。
- **落地**：多时代戏 → 每时代一套饱和度档位；回忆戏 → **记忆色的饱和度方向由记忆的情感属性决定**：温暖回忆=高饱和暖（王家卫），创伤/未解记忆=褪色冷（费穆灰/河底灯）；时代灰不是脏，是"没希望"的色（费穆模型）。

### 2.6 单季色调贯穿

**定律**：全片锁死一个色域再变奏，比多色堆砌高级——"单色做到极致"是张艺谋三线共同基因（[深·张艺谋] 1.4）。

- **单季结构**：《大红灯笼》四季结构（夏→秋→冬→次年夏）+"没有春天"——单季色调贯穿=全片一种色温/饱和度纪律，季节与色调共同承担时间叙事（[卡·大红灯笼高高挂#5]）。
- **色域变奏与沙漠极值**：九儿红→浅粉（随人生阶段变，[深·张艺谋] 1.1）——锁死"红"色域，只动明度/饱和度；东邪西毒把色彩抽干成一种，"从记得太多到只剩记得这件事本身"（[深·王家卫] 2.3）。
- **落地**：先定"本片默认色"（安德森模型：淡黄是跨片默认色，[深·安德森] 演变链3）；情绪变化只动饱和度与明度，不动色相。

### 2.7 黑白-彩色切换语法

**定律**：黑白与彩色不是两种风格，是两个叙事层——**切换即叙事动作，必须绑定语义**。已取证语法：黑白=编造/非现实层（英雄棋馆对决，"此段为虚构"，[卡·英雄]）；黑白=水墨世界，彩色=唯一重音（影，[卡·张艺谋] 1.3）；黑白=不美化，彩色=控诉（辛德勒名单红衣，[知识库·导演索引]）；黑白-彩色二元=精神/世俗两层（卢布廖夫，[知识库·检索表]）；饱和切换=记忆层标记（现在低饱和 vs 回忆高饱和，[深·王家卫] 工具4）。

- **纪律**：黑白段必须答"为什么是黑白"（时间层/真实层/编造层/水墨美学），彩色段必须答"为什么这时恢复彩色"（重音/真相/记忆苏醒）；切换点=情绪拐点，不许乱切（[知识库·导演索引] 姜文条同此律）。
- **明度轴切换语法（由暗转明，河底灯回测）**：无黑白段项目的明度高潮形态——同一色域内"由暗转明/由明转暗"是黑白切换的明度版，纪律同源：**切换必须绑定语义**（真相/苏醒/被渡 vs 压抑/死亡/时间停滞）、**切换点=情绪拐点**、**禁止乱切**。河底灯决战"由暗转明"=魂被渡/阿九承认"我也曾被丢下"，切换点落在决断时刻；只动明度不动色相，与 2.6 色域纪律同时成立【河底灯回测】。
- **AI 生成注意**：黑白-彩色切换易做成"滤镜感"——《影》的做法是现场实物直接构成黑白灰，拒绝"拍彩色再转黑白"（[卡·张艺谋] 创作思路5）；提示词应写"布景道具服装本身是黑白灰"而非"黑白滤镜"。

## 四、常见坑（本领域为什么烂）

1. **五彩斑斓**——症状：每场换色，颜色无记忆点。根因：没锁主色。修法：先定全片默认色+每幕主色，幕内禁止主色以外饱和色闯入（[卡·张艺谋] 五）。
2. **符号学滥用**——症状：每个颜色硬贴含义，观众觉得说教。根因：违背"色彩是感性选择/美学直觉"（[卡·张艺谋] 1.3）。修法：颜色先为画面成立，语义由片内叙事锁定。
3. **稀缺色失效**——症状：红色纪律定了 N=3，结果每场都有红。根因：没把 N 写进资产锁。修法：重音色次数写进分镜资产锁（[知识库·招式表]）。
4. **状态编码无纪律**——症状：受控青光与失控金光在画面里分不出来。根因：编码没写进画面参数。修法：受控=纯色分明，失控=混合/溢出/过曝（[知识库·招式表]）。
5. **配色与视角脱节**——症状：颜色变了，观众不知道"谁在讲故事"变了。根因：色变没绑定叙事层切换。修法：切换点落在叙述权易手处（英雄切蓝，[卡·英雄]）。
6. **为高级而褪色**——症状：低饱和但没信息，只觉得脏。根因：褪色没绑定语义。修法：褪色必须回答"谁在褪、为什么褪"（[深·安德森]；[深·费穆]）——创伤用例：死者世界没有颜色，龙宫青灰=水淹记忆色，褪色绑"未渡之人"的语义【河底灯回测】。
7. **黑白切换无语法**——症状：黑白彩色乱切，像素材混用。根因：没定"黑白=什么层"。修法：切换绑定语义+切换点落在情绪拐点（[卡·英雄]；[知识库·导演索引]）。
8. **前后期分工混乱**——症状：前期不管配色，指望后期调色救。根因：误解调色能力边界。修法：语义决策前移到美术/分镜阶段（[卡·张艺谋]）。
9. **AI 生成饱和失控**——症状：生成画面颜色漂移、饱和乱跳。根因：提示词没写饱和度/主色/禁色约束。修法：见第六章（[AI导演 4.3]；[Seedance 2.5]）。

## 五、自检清单（设计完过一遍）

- [ ] 全片有没有"默认色/主色"？（没有 = 五彩斑斓风险）
- [ ] 每幕/每章/每个叙事层是否锁定专属主色？颜色一变，观众能否自动知道"视角/状态/时间层变了"？
- [ ] 颜色语义体系：每色是否绑定唯一状态语义？受控纯色/失控混合色是否在画面上拉开？重音色次数是否定好 N 并写进资产锁？
- [ ] 仪式感/权力戏：是否有可重复的仪式颜色？对称构图是"秩序/囚笼/展台/权力"中的哪一种？承载了什么语义？
- [ ] 低饱和段：褪色有没有语义（时代/记忆/压抑）？还是为了"高级"？
- [ ] 黑白-彩色切换：每处切换是否绑定语义层？切换点是否在情绪拐点？
- [ ] 色彩心理学：通用负载只当默认值，片内语义是否已锁定并覆盖？
- [ ] 提示词层：主色/辅色/对比色/饱和度约束是否写进每段风格行？负面词是否含"杂色闯入/饱和度漂移"？
- [ ] 前后期分工：配色语义是否全部在分镜/美术阶段决策完，没有留给调色兜底？

## 六、AI 提示词对接（Seedance 落地）

> 主本约束以 AI提示词助手 skill 为准；本节是"配色知识"的转译层。官方提示词基础公式：主体+动作/事件+场景环境+视觉风格+运镜切镜+声音（[Seedance 2.5] 四）。

**配色四要素写法（主色/辅色/对比色/饱和度约束）**：
```
【主色】全段锁定单一主色调：{色名}，服装/布景/光线全部{色系}；
【辅色】仅允许{1-2个辅色}点缀，占比不超过画面10-15%；
【对比色】{对比色}只出现在{关键情节点/关键道具}；
【饱和度】主色段饱和度{高/中/低}；禁止出现主色以外的饱和色；禁止杂色闯入。
```

- **色彩分区章节**（英雄五色模式）："共N幕，每幕锁定单一主色调；【第1幕·红】服装布景光线全红系，象征欲望与嫉妒；【第2幕·蓝】全蓝系，象征理性；【第3幕·白】全白系，象征真相；现实框架用黑金。每幕内不许出现主色以外的饱和色；人物服装纯色无花纹；转场=色调硬切"（[卡·张艺谋] AI对接A；[深·张艺谋] 工具1）。
- **颜色语义体系**（伏妖记实战）："受控时法术为纯正青光（色相分明、边缘清晰）；失控时金光溢出（混合色、过曝、光晕扩散）；全片红色只出现{N}次，每次出现即重音——红=死亡/献祭/真相"（[知识库·招式表]）。
- **水墨黑白灰**（影模式）："全片黑白灰+唯一红色（血/印章/灯笼）；大远景留白构图；禁止全彩画面；禁止'彩色转黑白'滤镜感——让布景道具本身就是黑白灰"（[卡·张艺谋] AI对接C）。
- **记忆色板/时代褪色**（王家卫/安德森模式，详见 2.5/2.6 与 [深·王家卫] 工具4、[深·安德森] 工具5）："现实世界低饱和青灰调，回忆/鬼域高饱和记忆色；或 per-era color grading：战前高饱和红粉紫，战后低饱和米橙蓝，色彩承担时间叙事"。

**提示词级约束清单**：
- 风格行示例："21:9 影院宽银幕，风格：{主色+质感}，电影级质感，8K超精细"（[AI导演 4.3]）；负面词必含：画面抖动，人物变形，时间闪烁，构图混乱，字幕/Logo/水印，BGM + 配色专项："杂色闯入，饱和度漂移，主色调不一致，滤镜感"。
- 视觉风格是官方公式第四要素，配色约束放视觉风格与负面控制两处（[Seedance 2.5] 四）；@闪回/@回忆/@幻觉 自动追加"视觉不一致"负面（[AI导演 4.3]）。
- 一致性兜底：参考图锁定服装颜色；"服装颜色漂移"是失败高发区，逐段检查（[AI导演 四·五 3]）。
