# 题材密码提炼（Genre Code Synthesis）

## 触发条件
- 用户/父代理要求产出《X题材创作密码》（题材库系列 14 套：志怪=01/悬疑=02/喜剧=03/爱情=04/武侠动作=05/剧情作者电影=06/科幻奇幻=07/家庭温情=08/犯罪黑帮=09/都市情感=10/历史史诗=11/梦境超现实=12/底层时间青春=13/战争=14（2026-08-09 合成轮新增））
- 任务声明"零网络抓取"——素材源全部是本地存量资产（大师技法卡片/研习报告/导演深化文档）
- 需要对齐同系列既有模板文档的格式

## 素材定位（2026-08-09 复核：知识库已整体迁入技能目录 `妖玉影视/_知识库/references/`）
- 知识库根：`<skills>/妖玉影视/_知识库/references/`——注意目录名是 `_知识库`（中文），任务稿里的 `_knowledge` 旧路径是错的；子目录：题材密码/ 大师技法卡片/ 导演美学卡片/ 制作学科/ 实战回测/
- 大师技法卡片：`<skills>/妖玉影视/_知识库/references/大师技法卡片/<片名>_技法卡片.md`（每张 10-17KB，含"技法卡片 NN/场景/技法/原文摘录/可复用时机/对接"结构）
- 导演深化文档（导演美学卡片）：`<skills>/妖玉影视/_知识库/references/导演美学卡片/<导演>_手法体系深化.md`（跨片演变矩阵+可复用工具箱；⚠️ 旧路径 `film-suite-research/技法卡片源稿/` 已过时，2026-08-09 实测现存于技能目录内）
- 题材密码模板与既有密码：`<skills>/妖玉影视/_知识库/references/题材密码/<X>题材密码.md`（对齐结构用；战争=14 与历史=11 有分工参照先例）
- 研习报告：`~/Documents/KnowledgeBase/Obsidian Vault/剧本库/海外剧本/研习报告/<片名>_研习报告.md`（11-29KB，含结构观察/画面锚点/对白手法/桥段设计/一句话/诚实声明）

## 工作流
1. **先验证路径**：`search_files` 对含中文/空格路径可能返回 0 结果（本任务两次实测均 0）——用 terminal `ls` 确认目录实况，再定读取清单
2. **先看体量**：`wc -c` 列全部素材大小（典型单文件 10-30KB、全任务 200-300KB），按大小分批并行读取，防上下文爆炸（技法卡片 2 张/批，研习报告 2 份/批）
3. **先读模板**：读同目录最新一篇题材密码（如 志怪题材密码.md），对齐八段结构与引用格式——模板骨架见 `references/题材密码模板结构.md`
4. **批量精读**：技法卡片优先（每张卡=一个可复用技法，信息密度最高）→ 研习报告补充（结构占比/桥段/一句话/诚实声明）→ 导演深化文档（跨片演变规律、导演方法论原话）
5. **提炼纪律**：
   - 所有论断从素材源提炼，禁止凭空发明；引用标注出处（[2001卡片]、[星际研报]、[诺兰深化]）
   - **原文摘录必须 grep 验证**：写作前把将引用的所有原文（含英文原句）按来源文件批量 grep——一次 terminal 调用验证一个来源文件的 N 条引文（2026-08-09 战争轮实测：4 批 35 条全部命中）；验证批次与条数写进文档"诚实声明"，不许凭记忆转述
   - **合成 vs 推断分离**：框架/命名/分类表等由本代理提炼的部分标注【推断】，素材论断带各自来源标注；诚实声明章节逐条列出推断范围（战争轮先例：四类谱系/五语法命名=【推断】）
   - 素材里没有的标"未取证到"；注意证据层级（官方剧本/影迷记录/转引）并在文档里注明
   - 聚焦可落地：每条密码都要能指导写一场戏
   - 输出中文
6. **写文件**：产出路径由任务指定（写死勿改），write_file 完整覆盖；完成后回复：文件绝对路径 + 用了哪些素材 + 最重要发现

## 跨题材通用发现（志怪+科幻奇幻+战争三篇已验证，可复用）
- **"规则进战术层"是跨题材铁律**：立的规则必须被主角利用/兑现（先给汇率→事件兑现；规则用满四次），不能靠力量碾压跳过
- **"借异类/异界说人"**：题材内核是借容器装人间事——纯吓人/纯奇观/纯打怪都是失败写法
- **相邻题材先分工**：新题材与既有密码重叠时（战争×历史），先读相邻密码定分工边界（战争管战场/士兵/对人的改变，历史管朝代/权谋/史诗），引用相邻密码论断但不重复展开其结构范式，需要时回读该密码
- **解释度管理三招**：删解释（库布里克：成片比稿子狠，全删）、禁特效滤镜标梦境（塔可夫斯基：越像梦越要实）、主题不靠音量（诺兰 calm certainty）
- **范本分析格式**：每部 = 核心密码/可复用技法（每条带[卡X]标注）/一句话来源；附七范本横向对比表
- 文档自带"实战回写记录"章节——题材密码会随项目回测持续进化（v1.0→v1.1），提炼时注意继承

## 常见坑
- `search_files` 中文/空格路径 0 结果 → 用 terminal `ls` 兜底，不要据此判断文件不存在
- 素材总量大（实测 285KB）→ 分批读取，别一次性全读
- **编号不自编**：并行批派时子代理各自按模板自编"题材库 NN"会撞号（十五轮实战：02/05/07 被多文件共用）——**编号由主线程统一分配**（盘点既有序列→按顺序补号→跑"编号唯一性"验证），子代理产出时先留占位或按主线程给定编号；版本 v1.0（日期），回测回写后 v1.1
- 引用格式统一：卡片用[片名卡片]，研报用[片名研报]，深化文档用[导演深化]；避免混用编号体系

- 自查八段齐全（定义谱系/世界观规则/结构范式/调性混搭/范本分析/常见坑/自检清单/来源清单）、来源清单覆盖全部引用文件
