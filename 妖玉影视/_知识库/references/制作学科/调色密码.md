## 一、调色的定义与谱系（先分清楚你在调什么）

**本文管后期调色分级（执行层）**：成片素材的色温/对比/饱和度/风格化处理/镜头间匹配——"拍完/生成完"之后的修正与统一。
**《色彩设计密码》管前期美术配色（设计层）**：色票怎么定、每幕主色、颜色语义、饱和度/对比度作为叙事参数——"画之前"的决策（[卡·色彩设计密码] 一）。

| 维度 | 配色设计（姊妹文档） | 调色分级（本文） |
|---|---|---|
| 时机 | 剧本/分镜/世界观阶段 | 成片后期 |
| 对象 | 服装、布景、道具、光源的颜色选择 | 整段画面的色彩倾向、对比、色温、质感 |
| 性质 | 语义决策（这颜色在说什么） | 质感决策（这画面像什么介质拍的） |
| 失败后果 | 语义缺失 → 调色救不回 | 质感漂移 → 重渲/重拍 |

**分工铁律【推断】**：前期没做配色决策的戏，后期调色救不回来——调色只能统一质感，不能凭空给颜色装上语义（[卡·色彩设计密码] 一）。**调色的权力边界**：它能改"倾向、对比、质感、匹配"，不能改"这场戏的主色语义是什么"——语义在前期定。

**谱系定位**：调色处于"成片（画面）×观众（感知）"的接缝。已取证的三类调色哲学：**调色=介质模拟**（维伦纽瓦《沙丘》35mm 转印回 4K 追求"更像胶片"，[深·维伦纽瓦] 演变链D；库布里克《大开眼戒》用推冲乳剂增强色彩与高光，[深·库布里克] 演变链3）；**调色=状态编码**（张艺谋《大红灯笼》四色基调=人物被制度吞没的四个阶段，[卡·大红灯笼高高挂#8]）；**调色=记忆/情绪显影**（王家卫"颜色如此鲜活，因为记忆里的一切都是鲜活的"，[深·王家卫] 2.3；费穆"我为了传达古老中国的灰色情绪"，[深·费穆] 2.2）。

## 二、核心语法（本学科的"物理定律"）

> 2.1–2.6 为行业通用调色流程【行业通用】，非知识库取证；2.7 为工具/素材约束。导演风格化配方见 §三。

### 2.1 一级校色（先校正，后风格）

**定律【行业通用】**：一级校色让画面"回到正确"，是一切风格化的地基——顺序不可颠倒：先一级后二级、先校正后风格。四个旋钮：

1. **曝光**：用波形图/示波器判断，不靠肉眼。暗部细节保留在"有细节的黑"而非死黑；高光不裁切。
2. **对比**：影调层次=暗部/中间调/高光的分布。S 曲线是电影感对比的基础（暗部微压、高光微提、中间调保持）。
3. **白平衡**：色温/色调校正。肤色是第一参照——人的皮肤偏了，观众最先察觉。
4. **饱和度**：整体校正在局部之前；先定"这部片的饱和度档位"，再谈风格。

**8bit 素材约束（重要）**：8bit h264 素材的调色天花板很低——**暗部不提、压黑保中间调、冷调容易做、暖调容易爆**（[Resolve skill] 原则）。

### 2.2 二级校色（选区/跟踪/局部修正）

**定律【行业通用】**：二级校色只动"该动的地方"——把观众的注意力引向画面里的叙事焦点，其余保持自然。三件套：

1. **选区**：HSL 限定器（按色相/饱和度/亮度选）选天空、肤色、服装；或键控选主体。
2. **跟踪**：选区随物体运动（面部、行走的人）——跟踪不稳是二级校色最常见的翻车点。
3. **局部修正**：Power Window 局部压暗/提亮（眼神光、窗光、暗部收拢）、肤色统一（把同场景不同机位的肤色拉到同一色线上）。

**工具边界**：Resolve MCP 可脚本化控制 CDL 值（Slope/Offset/Power/Saturation）、LUT 套用/导出、版本管理、Gallery 静帧；但 Qualifier/Power Window/Tracker/曲线等**不可脚本化**——局部修正需人工操作（[Resolve skill] 调色 API 边界）。

### 2.3 色彩空间与流程（Rec.709 / S-Log / RAW / ACES）

**定律【行业通用】**：调色前必须知道素材"从哪来、到哪去"——色彩空间不匹配，一切操作都是错的。做素材技术分析是调色决策第一步：用 ffprobe 提取编码/分辨率/色彩空间/位深/帧率（[Resolve skill] 素材技术分析）。

| 素材类型 | 特征 | 调色含义 |
|---|---|---|
| Rec.709 | 标准交付色域（709 gamma） | 直接可调，但动态范围窄，宽容度低 |
| S-Log / Log 灰片 | 低对比灰画面，保留高动态范围 | 必须先套色彩空间转换（CST）/还原 LUT 再调色；调色空间=Log 或宽色域 |
| RAW | 传感器原始数据 | 白平衡/ISO/曝光后期可重设；调色自由度最大，需全套色彩管理 |
| ACES | 全链路色彩管理（输入→工作→输出） | 跨素材统一：不同摄影机/不同格式进 ACES，输出再转换，避免色域错乱 |

**10bit 与 8bit 的差别**：位深决定调色余量——10bit 可大幅调整不裂色，8bit 大幅调色即色阶断裂（同 §2.1 的 8bit 约束）。**交付约束**：无论工作空间多宽，最终必须转回交付规格（通常 Rec.709）并检查是否越界。

### 2.4 风格化调色（LUT / 胶片模拟 / 色调分离 / Teal-Orange）

**定律【行业通用】**：风格化是"介质与情绪的声明"，不是滤镜堆叠——每个风格参数都要能回答"它替谁说话"（呼应姊妹文档：褪色必须回答"谁在褪、为什么褪"，[卡·色彩设计密码] 四·坑6）。

- **LUT**：查色表把输入色映射到风格色。Resolve 可套用/导出 LUT（[Resolve skill] 调色 API 边界）。LUT 是"风格快照"，套用前必须已做好一级校正——LUT 不是校色工具。
- **胶片模拟**：模拟胶片的肩部/趾部曲线（高光柔和滚降、暗部压缩）、颗粒、色染。已取证案例：《沙丘》35mm 转印回 4K 的"更胶片"工艺（[深·维伦纽瓦] 演变链D）——胶片感=介质模拟，不是加个滤镜。
- **色调分离（Split Toning）**：暗部与高光分别染色（暗部偏青/高光偏暖是最常见组合）。
- **Teal-Orange**：肤色偏橙、环境偏青绿——橙色与青色互为补色，人物从背景中弹出。**注意**：这是商业类型片最常用的配方，也是滥用率最高的"网红色调"；是否成立取决于它是否为叙事服务（脏科幻的苍白肤色刻意反其道而行，[深·维伦纽瓦] 工具4）。

### 2.5 镜头间一致性（匹配剪辑点 / 肤色统一 / 场景连戏）

**定律【行业通用】**：调色的隐藏功能是"缝合"——观众不该因为调色而注意到剪辑点。三件事：

1. **匹配剪辑点**：相邻镜头（尤其同一场景不同机位/不同时间拍的）必须在亮度、色温、饱和度上对齐；剪辑点两侧各留参考帧反复比对。
2. **肤色统一**：同一人物跨场景肤色一致（矢量示波器拉肤色线）；人物服装颜色漂移是失败高发区（[卡·色彩设计密码] 六，AI 生成段同理）。
3. **场景连戏**：同一场景的戏无论分几天拍，色温/对比基调必须一致；不同场景之间的"色差"只能是风格设计，不能是工艺事故。

**AI 素材场景级一致性三步法【河底灯回测】**：Seedance 每镜头独立生成，"连戏"机制与实拍不同——实拍靠后期拉齐，AI 素材要在生成前就统一，三步缺一不可：
1. **提示词级统一**：同场景所有镜头共用同一参考图 + 同一风格词（青灰基调/关键道具色锁定），从源头压住段间漂移；
2. **整场统一 grade**：生成后同场景整场套同一 grade 基底/同 LUT，再在基底上做镜头微调——不做逐镜头自由发挥；
3. **逐帧比对**：gallery 抓帧 + vision_analyze 逐帧比对（沿用下方评估工具），确认帧间色温/饱和度无跳变。

**评估工具**：Resolve 工作流——切 Color 页 → grade_boundary_report 看调色痕迹 → probe_node_graph 查节点/LUT → gallery 抓帧 → vision_analyze 逐帧问"色彩色调/冷暖/反差/饱和度/一致性"→ 聚合确认帧间色温跳变 → 产出图文报告（用户偏好 HTML 内嵌帧图，非纯文字）（[Resolve skill] 调色状态评估 + 帧采样→HTML 报告工作流）。

### 2.6 电影感配方（暗部细节 / 高光柔和 / 肤色保留）

**定律【行业通用】**：所谓"电影感"不是一种滤镜，是三件事的合成：**暗部有细节**（黑里有层次，不 crush 成死黑）、**高光柔和**（高光滚降/肩部曲线，不硬切过曝）、**肤色保留**（风格化不得牺牲肤色——肤色在矢量示波器上保持在同一色线上）。叠加颗粒与介质质感（胶片颗粒/门板颗粒）完成"介质声明"。

**对照系——风格化可以反着来，但要自觉**：
- 维伦纽瓦《降临》刻意让主角肤色"pasty"（苍白、不修饰），配合自然光与忧郁空间——**"脏"是设计，不是失误**（[深·维伦纽瓦] 演变链D/工具4）。
- 库布里克《大开眼戒》推冲增饱和，让派对灯光"俗艳如城市杂耍"（Ebert 评）——**饱和是情绪装置**（[深·库布里克] 演变链3，[卡·库布里克] 2.3）。
- 王家卫记忆色板**双档**：**鲜活记忆=高饱和**（花样年华/2046 的回忆、鬼域，[深·王家卫] 工具4）；**死亡/褪色记忆=低饱和青灰**——《河底灯》龙宫为证：水淹的记忆是褪色的，低饱和青灰比高饱和更贴"死去的人"【河底灯回测】。**记忆不是一种状态而是两种：鲜活的与褪色的，方向相反，各成立一档**（提示词模板同步见 §六）。
- **色调分区第二维——空间/心理分区【河底灯回测】**：安德森时代分区是时间轴（战前/战后，[深·安德森] 演变链3）；《河底灯》证明同属"现实"层的空间也能分区——龙宫青灰=执念空间、灯市暖黄=现实异象，切换语义是"进入执念 vs 回到人间"，不是"现实/非现实"也不是时间（坑10 切换语义清单补第三类：空间/心理层）。

**国风水墨/留白配方（新条目）【河底灯回测】**：水墨美学的调色逻辑与西方电影感配方方向不同甚至相反——它是"纸墨质感"的声明，不是胶片声明（本条为回测提炼，纸上验证，未入知识库取证资产）：
- **墨分五色递进替代 S 曲线**：S 曲线（压暗部、提高光）是西方电影感对比；水墨要的是"焦浓重淡清"的层次递进——低对比、中间调分层，靠墨色浓淡而非明暗对比建立画面结构；
- **大面积留白=有意的空**：留白不是死黑也不是噪点，是"高信息密度刻意留低"——处理前先问"这块黑/空是设计还是事故"，再决定去留（自检见 §五）；
- **纸墨质感声明**：颗粒与介质声明对应纸/墨（宣纸吸墨、墨色晕染），不是胶片颗粒。

### 2.7 素材格式对调色的约束（超分先于调色 / Seedance mov）

**定律**：调色的可能性上限在素材进入调色软件之前就定了——**先超分再调色**（超分模型在线性空间表现更好；视频逐帧超分需时域平滑否则闪烁；扩散类超分可能"发明"细节，电影修复应保守使用）（[Resolve skill] 素材分辨率不足处理）。

**Seedance 2.5 输出规格（调色友好）**：
- 输出格式 mp4 + **mov**（H.264 + **yuv444p 色度采样** + **PCM 音频**）——4:4:4 色度采样保留了全部色彩信息，**调色/抠像/合成友好**；编辑、延长任务官方建议 input/output 都用 mov，无缝衔接最好（[Seedance 2.5] 六·3）。2.0 仅 mp4，2.5 新增 mov 专业后期格式（[Seedance 2.5] 二）。**位深确认纪律【河底灯回测】**：yuv444p 只保证色度采样（解决色度下采样伪影），**不解决亮度位深**——H.264 编码的 mov 大概率仍为 8bit，动工前必须 ffprobe 确认（见 2.3）；8bit yuv444p 的夜景大暗部仍按 8bit 约束（暗部不提/压黑保中间调），"大幅调色"只在确认 10bit 后才成立。
- ⚠️ 2.5 仅支持 480p/720p 输出（暂不支持 1080p/4k）——**要交付高清规格必须超分**，超分先于调色（[Seedance 2.5] 二；[Resolve skill] 超分原则）。输入规格：mp4/mov（H.264/H.265），单段 2–30s，FPS 24–60（[Seedance 2.5] 五）。

**8bit h264 对比**：普通网络素材多为 8bit 4:2:0 h264——调色天花板低（2.1）；Seedance 的 yuv444p mov 色度信息完整，抠像（绿幕/合成）友好（[Resolve skill] 8bit 约束；[Seedance 2.5] 六·3）。**但"大幅调色都可行"要加位深前提**：ffprobe 确认 10bit 才可大幅调色；8bit yuv444p 的暗部大幅提亮照样色阶断裂——全片夜景类项目（如《河底灯》）按 8bit 约束操作【河底灯回测】。

## 四、常见坑（本领域为什么烂）

1. **一级没做就上风格**——症状：套了 LUT 画面发灰/色偏，怎么调都不对。根因：LUT 是风格快照不是校色工具。修法：先曝光/白平衡/饱和度校正，再套风格（【行业通用】；[Resolve skill] LUT 套用边界）。
2. **8bit 素材当 10bit 调**——症状：暗部提亮出现色阶带，暖调一拉就爆。根因：素材位深/色度采样决定了调色余量。修法：先 ffprobe 看规格，按 8bit 约束操作——暗部不提、压黑保中间调、冷调优先（[Resolve skill] 8bit 约束）。
3. **暖调暴力**——症状：肤色拉暖后全片发黄，人像蜡像。根因：白平衡与风格混为一谈。修法：肤色永远先校正到中性，风格色加在环境上；肤色在矢量示波器上守住（【行业通用】；[Resolve skill] 帧评估）。
4. **调色救前期**——症状：主色语义没设计，指望后期"调出感觉"。根因：误解调色能力边界。修法：语义决策前移到美术/分镜（[卡·色彩设计密码] 四·坑8）。
5. **风格无语义（为高级而调）**——症状：Teal-Orange 全套上，观众只觉得"网红滤镜"。根因：风格没绑定叙事。修法：每个风格参数回答"它替谁说话"；对照维伦纽瓦的脏科幻——他的苍白是世界观声明（[深·维伦纽瓦] 工具4；[卡·色彩设计密码] 坑6）。
6. **一致性失控**——症状：相邻镜头色温跳变、同一人物肤色每场不同。根因：没有参考帧与肤色线纪律。修法：剪辑点两侧抓帧比对；gallery 静帧 + vision_analyze 逐帧评估一致性（[Resolve skill] 调色状态评估）。
7. **超分后调色（顺序反了）**——症状：先调色再放大，噪点/色块一起放大。根因：超分模型在线性空间表现更好。修法：**先超分再调色**（[Resolve skill] 超分原则）。
8. **无视交付规格**——症状：调色时好看，交付转换后偏色/裁切。根因：工作空间与输出空间不分。修法：色彩空间转换（CST）+ 交付前越界检查（【行业通用】；[Resolve skill] 素材技术分析）。
9. **DRX 覆盖节点图**——症状：导入一个 DRX/套用整版 grade，之前的调色全没了。根因：DRX 是"替换整个节点图"不是追加。修法：先做 version snapshot（grade_version_snapshot）再导入（[Resolve skill] 调色版本保护）。
10. **黑白/色调切换无语法**——症状：黑白彩色乱切，像素材混用。根因：没定"黑白=什么层"。修法：切换绑定语义（英雄黑白=编造层 [卡·英雄]；辛德勒黑白=不美化 [知识库·导演索引]；**空间/心理层=进入执念 vs 回到人间**，《河底灯》青灰龙宫×暖黄灯市【河底灯回测】）+ 切换点落在情绪拐点（[卡·色彩设计密码] 2.7）。

## 五、自检清单（调色完过一遍）

- [ ] 素材规格确认：ffprobe 看过编码/位深/色彩空间/帧率？yuv444p 只保证色度采样，位深另查（见 2.7）；8bit 素材按 8bit 约束操作？
- [ ] 顺序正确：一级校色（曝光/白平衡/饱和度）→ 二级（选区/局部）→ 风格化（LUT/胶片模拟）？
- [ ] 色彩空间：Log/RAW 素材做了还原/CST？交付转换后检查过越界？
- [ ] 曝光：暗部有细节不死黑？高光未裁切？波形图验证过？**自觉压黑/留白例外【河底灯回测】**：黑与空是设计还是事故（志怪夜景"不可知的黑"/水墨留白）？先问再决定去留。
- [ ] 肤色：矢量示波器上肤色在线？风格化没有牺牲肤色？同人物跨场景肤色一致？
- [ ] 一致性：剪辑点两侧参考帧比对过？同一场景连戏基调一致？帧间色温跳变检查过（gallery + vision_analyze）？**AI 素材**：同场景提示词级统一（同参考图+同风格词）→ 整场同 grade 基底/同 LUT → 逐帧比对（三步法，见 2.5）？【河底灯回测】
- [ ] 风格语义：每个风格参数能回答"它替谁说话"？还是"为高级而调"？
- [ ] 黑白/色调切换：每处切换绑定语义层？切换点在情绪拐点？
- [ ] 超分顺序：需要放大的素材先超分后调色？逐帧超分做了时域平滑？
- [ ] 版本保护：导入 DRX/整版 grade 前做了 version snapshot？
- [ ] 交付：转回 Rec.709 后颜色与调色页一致？输出格式符合交付规格？

## 六、AI 提示词对接（调色思路→提示词）

> 主本约束以 AI提示词助手 skill 为准；本节是"调色知识"的转译层——**AI 生成阶段没有后期调色台，调色思路必须写进提示词**。官方公式：主体+动作/事件+场景环境+视觉风格+运镜切镜+声音（[Seedance 2.5] 四）。

**电影感配方（暗部细节/高光柔和/肤色保留）直译**：
```
视觉风格：电影级调色——暗部保留细节（黑而不死），高光柔和滚降（不过曝），
中间调对比柔和有力；肤色自然保留（暖而不黄）；轻微胶片颗粒；21:9 影院宽银幕质感。
负面词：死黑，过曝，色阶断层，肤色发黄，滤镜感，饱和度漂移。
```

**风格化配方模板（调色思路→约束）**：
- **时代分区**（安德森模型）："per-era color grading：战前高饱和红粉紫，战后低饱和米橙蓝，色彩承担时间叙事"（[深·安德森] 工具5）。
- **记忆色板双档**（王家卫模型）：鲜活档——"现实世界低饱和青灰调，回忆/鬼域高饱和记忆色；同一空间两种色调标记时间（过去=暖饱和，现在=冷寡淡）"（[深·王家卫] 工具4）；**褪色档【河底灯回测】**——"记忆/鬼域空间低饱和青灰，水淹的褪色感；红盖头/红烛=低饱和场里唯一高饱和残留色"（死亡/褪色记忆，方向与鲜活档相反）。
- **脏科幻**（维伦纽瓦模型）："未来像今天的工业区——锈蚀、旧招牌、阴天自然光；肤色保留苍白不修饰；全片唯一干净的是那个未来元素；世界'有点无聊'让异常显得真实"（[深·维伦纽瓦] 工具4）。
- **黑白语义层**（英雄模型）："编造/闪回段黑白处理（或单色），现实段彩色；黑白=非现实层，切换点=叙述权易手/情绪拐点"（[卡·英雄]）。
- **高饱和情绪段**（库布里克模型）："灯光比实际亮得多的高饱和暖光，俗艳而不柔和，情绪浓度拉满"（[深·库布里克] 演变链3）。

**提示词级约束清单**：
- 风格行示例："21:9 影院宽银幕，风格：{主色+质感+电影感配方}，电影级质感，8K超精细"（[AI导演 4.3]，经 [卡·色彩设计密码] 转引）；负面词必含：画面抖动，人物变形，时间闪烁，构图混乱，字幕/Logo/水印 + 配色专项："杂色闯入，饱和度漂移，主色调不一致，滤镜感"（[卡·色彩设计密码] 六）。
- 一致性兜底：参考图锁定服装颜色；"服装颜色漂移"是失败高发区，逐段检查（[AI导演 四·五 3]，经 [卡·色彩设计密码] 转引）。
- **Seedance 后期衔接**：生成时选 mov 输出（yuv444p + PCM），调色/抠像/合成友好；编辑、延长任务 input/output 都用 mov（[Seedance 2.5] 六·3）。2.5 仅 480p/720p——高清交付需超分，**先超分再调色**（[Seedance 2.5] 二；[Resolve skill] 超分原则）。
