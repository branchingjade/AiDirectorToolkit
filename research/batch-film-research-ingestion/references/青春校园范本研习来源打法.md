# 青春校园范本研习来源打法（《那些年，我们一起追的女孩》轮实测 2026-08-09）

研习对象为华语青春校园片（《那些年》/《壁花少年》类，为题材密码打地基的范本轮）时使用。华语青春片的「台词/剧本/情感文本」比画面更易取证——本打法围绕这三类文本来源设计。

## 来源优先级（实测排序）

1. **维基语录 zh.wikiquote.org/wiki/<片名>（必抓，台词一手级）**
   - 成片经典台词按角色分组的原文页，curl 直抓 + python 剥标签（切 `mw-content-text` 到 `catlinks`）即可，**可 grep 验证的台词取证源**。华语片（尤其台湾/香港片）收录率高。
   - URL 需百分号编码（`urllib.parse.quote`）。例：《那些年》页含 40+ 条台词，覆盖「成长最残酷的部分/平行时空/徒劳无功」等全部金句——遗憾美学、对白手法的论断全从这里出。
   - 维基语录台词可跨题材复用（武侠/爱情/喜剧都适用），凡华语片研习先查此页。

2. **知乎长答（r.jina.ai 可抓，准一手）**
   - 深度影评常附**完整剧本转录**（幕号/旁白/片尾字幕原文）与导演自述。实测孔鲤《那些年》长答（zhihu.com/question/22004308/answer/52750161）含剧本 10.1 版 108 幕转录 + 九把刀「婚礼抢吻特别版结局」创作动机自述——「为什么这样拍」的一手证据就在这类回答里。
   - 引用标「网友转录」并 grep 校验原文；转录存在个别传抄误差（如歌词「温柔的吗/温柔的骂」），引用时以原档为准。

3. **维基百科 zh.wikipedia.org/wiki/<片名>（二手汇编）**
   - 故事/角色/制作/评价/票房/**删减史**齐全。华语青春片的「版本差异」是必写项：台版/大陆删减版时长、删改逐条明细（维基「审查」节常有清单），量化数据以条目为准并标注口径。
   - 条目名用繁体/港版原名；直抓两坑（百分号编码、真实条目名）见 `cn-content-site-extraction` 技能。

4. **豆瓣移动版（PC 版 jina 必挂）**
   - `https://r.jina.ai/https://movie.douban.com/subject/<id>/` 报 422 `application/octet-stream`——**别走 PC 版**；`https://m.douban.com/movie/subject/<id>/` + iPhone UA 直抓得剧情简介+高赞影评标题。
   - 高赞影评标题本身就是情感定位素材（「新婚快乐，我的青春」「喜欢妳，就像喜欢青春时的自己」），可作怀旧叙事/遗憾美学的观众侧证据。

5. **主题曲歌词站**（lrc99.com 等，curl 直抓）
   - 华语青春片主题曲歌词常是遗憾美学的核心文本（《那些年》：「那些年错过的大雨/平行时空下的约定」），作词人署名可引。歌词与成片台词互文（「平行时空」在歌词与地震戏同时出现）是桥段设计的证据链。

## 观察点五件套（青春校园范本轮）

①青春片语法（校园→毕业→婚礼三幕；毕业=分水岭；兄弟帮+共同暗恋靶心结构）②遗憾美学（错过的最小单位=「不要告诉我答案」；平行时空对话=遗憾出口；婚礼抢吻=仪式性告别）③怀旧叙事（回忆框架旁白/时代锚点开场/片尾元叙事打字机字幕）④喜剧青春（恶作剧=糖衣、纯爱=内核；绰号文化/身体喜剧）⑤可复用时机（对接国风：书院同窗/科考放榜/年号锚点/前世今生/说书人合卷）。

## 坑（本轮实测新增）

1. **Unicode 兼容字符假 MISS**：抓取的繁体文本常把常用字存为兼容区字符——了→U+F9E2、不→U+F967、来→U+F9ED、沈→U+F9F2（字形与标准字完全一致），肉眼核对无误的短语 grep 零命中。验证脚本先 `unicodedata.normalize('NFKC', text)` 再匹配，或直接 python `str.find` 打印上下文确认。归入假 MISS 分类（与繁简/弯引号并列），别当真错改稿。
2. **时光网(mtime) 链接已失效**：r.jina.ai 只回 ~163 字节空壳。别浪费时间重试；其专访信息可从维基引用二手转述并标注「经维基转述」。
3. **版本口径**：华语青春片台版/大陆版情节有实质差异（大陆版吻新郎段落遭剪辑等）——分析以台版为基准，报告诚实声明版本差异。
