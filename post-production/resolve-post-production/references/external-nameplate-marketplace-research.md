# 年代感人名条模板外部市场调研

> 2026-07-30 · 全平台搜索结论：**年代感/年代剧人名条模板作为产品品类不存在。**

| 平台 | 类型 | 结果 |

## 搜索方法论

- DuckDuckGo HTML 版（`html.duckduckgo.com/html/?q=...`）可用 curl 绕过 JS 渲染
- 多数模板网站有 Cloudflare 防护，需用真实浏览器
- 搜索关键词尝试：`vintage name plate` / `retro lower third` / `period drama title` / `cinematic character introduction` + `DaVinci Resolve template`

## 结论

- **没有现成的年代剧人名条模板可下载。**
- 最接近的 TiKa-Studios "15 Cinematic Retro Film Titles" 可作为结构参考（.drfx/.setting 包装方式）
