# 电影大师研习 v1.0.2

## 🔒 门禁（加载后第一步，三问未答不进入渠道选择）

学习不是泛泛而读——先问清楚：

1. **学谁？**（哪位大师：黑泽明/贾樟柯/王家卫/诺兰/科恩兄弟…）
2. **学什么？**（哪部片 / 哪类手法：群像戏 / 对白潜台词 / 悬念铺设 / 转场 / 暗线埋设…）
3. **为什么？**（要解决自己创作里的什么问题——"我要写一场重场戏" 而不是 "随便看看"）

三问没答案时，不给渠道清单、不推片单，先反问你：你手上正在写的这场戏卡在哪？

---

## 定位：电影树的输入侧（土壤，不是上游）

AI电影编剧 / AI电影导演 是**产出侧**（写），本 Skill 是**输入侧**（学）——读大师的一手剧本原文，把手法提炼成技法卡片，作为创作时的土壤。

```
短剧树：AI编剧助手 → AI导演助手（9:16 竖屏）
电影树：AI电影编剧 → AI电影导演（21:9 宽银幕）
土壤层：电影大师研习（本Skill，读大师一手剧本）+ AI提示词助手（Seedance 约束主本）
```

- **一手 > 二手**：电影套件已有《导演研究-东方/西方》（二手理论，来自维基等），本 Skill 补**一手剧本原文**——从大师亲手写的字里行间学，不从别人总结里学
- **不污染电影套件**：技法卡片是参考土壤，不写进 AI电影编剧/导演的正文
- **与 screenplay-research 分工**：那边管"怎么抓 / 怎么统计格式实证"（技术），本 Skill 管"去哪儿读 + 怎么学"（方向）

## 二、大师创作学习法（本 Skill 核心）

### 1. 从画面出发——读剧本先锚画面，不从概念出发

读大师的剧本，第一遍不做"分析"，只做**锚定**：每个场景读完，问自己——

> 这个场景最强的那个画面是什么？

写下来，一句话。整部片读完，你手上有一串画面。**这串画面就是大师的骨相**——结构可以被模仿，画面感模仿不来。技法卡片从画面长出来，不从术语长出来。

### 2. 三读法

**第一读·粗读（结构层）**：一口气读完，只记三件事
- 三幕的转折点在哪一页/哪一场
- 每幕多少场、节奏是紧是松
- 哪个角色在什么时候"变了"

**agent 的粗读 = 程序化粗读**（agent 无法逐字读完 15 万字符，用统计代替通读，实测可行）：
1. 场景统计：正则 `^\d+\s+(INT|EXT|INT/EXT)` 数场景总数，看格式方言（双破折号/句点制）
2. 时间跨度：场标题年份（`(19\d\d|20\d\d)`）取首尾——跨度就是结构尺度（肖申克 1946→1967 共 21 年）
3. 转折点定位：用主题词 grep 找关键事件行号，**行号/总行数 = 结构占比**（肖申克 "nineteen years" 在 71.9%——全片重心靠后，第二幕末才引爆）
4. 三幕推断：把 2-3 个转折事件的行号占比排列，自然分出幕（注意标注"占比推断，非作者声明"）
5. 角色变化点：grep 主角的关键转变台词（"I'm innocent"→"I killed her, Red" 的转变线）

**第二读·细读（手法层）**：挑印象最深的 3-5 场，逐句读
- **画面锚点**：这场戏哪个画面装着"不在场之物"（例：手放在胸口，她就被感觉到了）
- **对白层**：每句台词在"给信息"还是"藏信息"；潜台词在哪；谁在说反话
- **动作层**：行文怎么暗示景别/节奏（"壁上一排油灯，火光颤动"=全景慢镜；短句连发=快切）
- **信息控制**：观众什么时候知道角色不知道的事（悬念的根）

**agent 挑场景 = 关键场景定位法**（用主题词 grep 定位再精读，实测高效）：
1. 定主题词：这场戏的"功能"（如屋顶戏→beer/roof；结局→Zihuatanejo/Get busy；开场→murder/gun）
2. grep 主题词拿行号 → 找所在场景边界（上一个/下一个场景标题行）
3. 提取该场景全文精读
4. 从精读的场景里 grep 出可摘录原文——**卡片摘录必须是 grep 出来的，不许凭记忆**
5. 全片反复出现的道具词（rock-hammer/tunnel/poster）grep 出全部出现行——伏笔的埋设/回收位置一目了然

**第三读·反拆（为什么成立）**：选一场戏，问到底——
- 这场戏为什么**现在**出现？（往前删掉它行不行？往后挪行不行？）
- 观众此刻**以为**什么、**实际**什么？
- 如果把这场戏的对白全删了，画面还讲得清吗？（讲不清=这场戏靠对白活，不是好戏）

### 3. 技法卡片（产出物 #1）

每部片读完，产出 5-10 张卡片。模板：

```
## 技法卡片 ·《片名》· 第N场
- **大师**：谁
- **场景**：一句话（这场戏发生了什么）
- **技法**：一句话（这场戏在手法上做了什么）
- **原文摘录**：剧本原文（英文保留原文，注明版本）
- **画面锚点**：最强画面是什么
- **可复用时机**：我自己的戏里哪种情况能用上
- **对接**：编剧（结构/对白）or 导演（画面/节奏）
```

**写卡片的纪律**：原文摘录必须真实（从渠道页面/PDF 里 grep 出来），不许凭记忆写台词。摘不到的标注"原文未取到"。

### 4. 研习报告（产出物 #2）

每部片一张，结构：

```
# 研习报告 ·《片名》
- 大师 / 编剧 / 版本（初稿 or 拍摄稿，必须注明；**流传稿 vs 上映版差异需核查**——实测 IMSDb 肖申克场景 205 标注 1966 年，电影为 1967，网上流传稿与上映版常有出入）
- 来源渠道 + URL
- 结构观察（三幕转折/序列/节奏）
- 画面锚点清单（8-15 个，一句话一个）
- 对白手法（潜台词实例 3 个，带原文）
- 动作层写法（景别暗示 3 例，带原文）
- 技法卡片链接（5-10 张）
- 一句话：这部片最值得偷的一招
- ⚠️ 诚实声明：文本层质量/版本不确定性
```

报告存 Obsidian（`工具与集成/妖玉影视skill/` 或创作项目目录），wikilink 可达。

### 5. 问题集不是禁令集

学习产出是**提问式**的，不是规则式的：

- ❌ "大师从不给观众答案"（禁令式，且常错）
- ✅ "这场戏为什么不给观众答案？如果给了会怎样？"（问题式，逼出手法根因）

读到任何手法，先问"它在这里成立，是**因为什么**"，不急着总结成"大师的规矩"。规矩会骗人，根因不会。

## 四、对接 AI电影编剧 / AI电影导演

技法卡片怎么用（创作时）：

1. **编剧侧**：写某类场景前，翻对应卡片——"群像戏怎么开场"→ 读大师群像戏的卡片，看信息怎么铺
2. **导演侧**：分镜前翻画面锚点卡片——"这场戏的最强画面"直接变成分镜锚点
3. **不引用进正文**：卡片是土壤，不是模板。土壤供养分，不长出一样的树
4. **学习是持续的**：每个项目做完，缺哪类手法 → 回渠道库找对应剧本 → 新卡片入库
