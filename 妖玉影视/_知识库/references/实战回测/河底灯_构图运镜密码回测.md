## 〇、项目设定速记（回测基准）

- 类型/规格：志怪武侠，90min，21:9 影院宽银幕，起承转合，纯架空时代（明代市井骨干/宋代水墨留白）
- 六场景（按序）：①渡口废墟（日/外，断流十年的干河床+搁浅旧渡船，阿九船底捞灯）②河心灯市（夜/外，无月之夜魂们点灯等渡）③岸上客栈（夜/内，江湖人歇脚，阿九挂灯柜台，掌柜变色）④水淹村遗址（雾/外，半露水面屋顶）⑤河底龙宫（暗/内，灯魂嫁妆箱沉处）⑥渡口决战（夜/外，断流河重新涨水）
- 人物：阿九（24，渡河人，水性好怕水，十年前被母亲推上船、母没上来）；灯魂（无名，出嫁路上死，魂困于灯）；老船工（60，守灯人/师父）；疤脸客（30+，当年抢财盗匪，来河底找东西）
- 核心冲突：阿九怕水却必须为灯魂渡河（渡的不是河是自己的怕）；灯魂等的是「当年有人来救」的承认——船来了，人没上来
- 关键道具：铜灯（灯芯烧的是嫁妆箱里的红盖头——「她的喜事就是她的牢」）、嫁妆箱（红盖头/铜镜/红烛）、撑船篙（渡河也渡魂）
- 基调备忘：龙宫段低饱和青灰、灯市段暖黄（灯=唯一暖色）、决战由暗转明；无配乐、环境声主导；灯魂=实体可触半透明、不可穿物

## 一、逐节对照摘要

### 1.1 定义与谱系（密码「一、」）
密码管画面层一切（画框/景别/机位/运镜/调度/剪辑节奏），不管色彩/声音/叙事结构——边界与本项目匹配：灯=唯一暖色归色彩密码，无配乐归声音密码，本回测只处理画面层。两个总命题对项目**直接可用且几乎互为题眼**：
- **画框即世界观**：断流河床开场即「河死了」的世界观陈述——搁浅船/干河床不是背景，是「渡」这个动词在本片里已经失败过一次的证据（十年前船来了人没上来）。
- **运动即情感语言**：全片无配乐，情绪全靠画面运动与调度承担——运动语义学的权重在本片被放大。

### 1.2 核心语法（密码「二、」十条，重点七项）
| 密码条目 | 对照结果 |
|---|---|
| 2.1 画框即世界观 | **高度命中**：21:9 横向分区=关系默认语言，密码原文「画左的人在等画右永远不回来的人」几乎就是本片题眼——阿九在画左（岸/生），灯魂在画右（河心/死），开场即预告。三级用法「框住人→框成为观看媒介→框退为空气」与三幕对应：龙宫框住灯魂（命运被框住）→船窗看灯市（框成为观看媒介）→决战涨水后框退为空气（世界活了） |
| 2.2 景别语义 | **高度命中**：远景渡口=命运（阿九=干河床上的黑点，人在天地间的位置）；中景客栈群像=关系；特写灯芯=情绪交付给物件（小津《晚春》花瓶式：情绪最浓处不拍脸，拍灯芯——红盖头在烧） |
| 2.3 固定 vs 运动 | **命中+证伪-1**：渡河戏双轨——岸边固定远镜=静观（船入画出画，观众承受时间）；船上跟拍=陪伴认同（「渡」的语义即摄影机的语义）。但密码「固定=静观」的静止假设被水上戏证伪（详 F1） |
| 2.4 运镜语义学 | **高度命中**：升降=开场建世界（渡口废墟 crane up 揭示干河床全貌）/终场抽离（决战结束 crane up）；推=侵入（灯魂逼近真相揭示时 dolly in）；**方向纪律直接贡献本片生死轴**：河=单向推进空间，「往左=回岸/生、往右=入河心/死」全片保持（雪国列车式纪律） |
| 2.5 对称与去中心 | 命中：河底龙宫用对称=执念的牢（秩序越精确越恐怖）；客栈/灯市去中心=生活流（魂们各占一角） |
| 2.6 画中画 | **高度命中**：船窗看灯市=框内框+偷窥视点（王家卫「让观众成为邻居之一」）；水淹村半露水面的屋顶门框=框住旧家记忆 |
| 2.7 深焦与层次 | **高度命中**：河底龙宫三层——前景石梁/水草、中景灯魂站宫门前（不敢走近）、背景嫁妆箱在纵深尽头（执念终点）——「不敢」与「想要」同框；反向压平：灯市用 telephoto 把魂们压成平面灯海 |
| 2.8 剪辑造动作 | 中等可用：本片打戏仅一场（疤脸客抢灯），「先写剪辑清单而非动作流程」+ 关键一击才快切，篙点水=开路可写六短镜 |
| 2.9 静态对峙 | **高度命中+证伪-3**：渡口决战前=「没开枪的时间」——魂们静止如石、环境声当剪辑点、一次爆发、爆发后静默窗口；但爆发事件本体被密码窄化（详 F3） |
| 2.10 站位即关系 | **高度命中**：客栈五方站位=关系图；空间剪彩（客栈先空镜登场再进店）；高度即权力（灯挂柜台高处=灯魂俯视全场）；垂直分层（楼上疤脸客密谋/楼下群像） |

### 1.3 范本实证（密码「三、」13 行）
直接可取 6 行：固定远镜+深焦（悲情城市/等待题材）、画中画构图（身不由己人物）、空镜句号（小津：决战涨水后水满河床的空镜收束——离别/死亡戏后情绪收束）、前景遮挡（志怪「越看不清越怕」）、静态对峙（高手相遇）、站位即关系（群像对峙）。山水画构图（人物如黑点/卷轴横移）与本片「宋代水墨留白」基调直接同源，渡河戏可作横移卷轴处理。方向纪律行与渡河生死轴吻合。

### 1.4 常见坑（密码「四、」10 条）
坑 1「运镜无动机」直接预判本项目最大风险：渡河戏每镜都要有运镜动机句（跟=陪伴、固定=承受、手持=怕），动得越少每次越重。坑 2「景别单一化」提示客栈群像必须走完建立→主镜头→中景→特写序列。坑 4「画框没理由」提示船窗框、门框每处要答「框在说什么」。坑 10「21:9 构图失衡」对河床开场大远景（主体占比过小）是显性风险。其余坑（对称滥用/深焦糊/打戏写流程/对峙无静/群像靠对白/人海无人味）均有对应。

### 1.5 自检清单（密码「五、」12 条）
12 条全部可直接执行，无不适配条目——这是密码对项目可用性的最强证据：运镜动机句、景别序列、动静比例、对称语义、画框理由、深焦三层、剪辑清单、对峙静默、站位图、方向纪律、画面元素陈述、21:9 纪律，逐条对应本片设计动作。

### 1.6 AI 提示词对接（密码「六、」）
运镜语义直译、固定远镜静观、画中画（含志怪版「纱帘前景/浅景深偷窥视点」）、静态对峙、站位即关系五组提示词模板对本片**逐字可用**——尤其「translucent gauze curtain…voyeur viewpoint」正是船窗看灯市的标准写法；「figures like ants」正是渡口废墟 crane up 的写法。

1. **画内光源构图纪律（补 2.1 画框即世界观）**——灯/烛/火把=画内光源+道具+情感焦点三位一体时，光源位置即构图支点：灯居中=执念在场、灯被遮挡=威胁、灯出画=失去；灯影参与站位（灯照到谁=谁被审判/被看见）。回写位置：2.1 新增小节「画内光源三态」；同步补六·提示词（`lantern centered as the sole light source, shadows cast by the lantern define who is seen`）。范本线索：大红灯笼（灯=权力）、卧虎藏龙客栈夜戏。
