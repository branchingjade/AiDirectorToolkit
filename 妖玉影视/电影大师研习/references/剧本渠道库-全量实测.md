本次全量实测背景：用户为 AI电影 skill 建立「土壤/知识库」——能读到**著名影视剧完整剧本**的渠道。测试方法：curl HTTP 状态探测（走 Clash 代理）+ 首页 title/关键词定位抽查 + 核心库深度抽查（能读到完整正文才算数）+ Kimi WebBridge 浏览器实测（反爬站）。测试时间：2026-08-05。

## 一、可用渠道（能读到完整剧本）

### 国内

#### juben.pro（华语剧本网/中国编剧网）《剧本名作》—— 国内稀缺主力 ✅
- 入口：https://www.juben.pro/Famous/
- HTTP 200（curl 实测）
- 栏目内容（首页实测）：小山回家(贾樟柯1995)、黑客帝国(沃卓斯基，**中英对照**·独家)、家里家外(短剧79集)、你好李焕英(贾玲2021，独家)、乔乔的异想世界(2019)、荒野猎人、鸟人(2014)、托尼·厄德曼、布鲁克林、胡丽叶塔、生存家族、房间、造梦之家、史蒂夫·乔布斯(2015)、总统杀局、婚姻故事、摄影机不要停、平行母亲、黑暗弥漫、她(2013)
- 分类标签：豆瓣评分排行 · 原版剧本 · 奥斯卡获奖剧本
- **⚠️ 登录门槛（2026-08-05 自测纠错）**：未登录只显示**前 N 场试读**——《你好，李焕英》试读 9 场 2105 字（页面标注全文 31990 字），《小山回家》试读 2 场 2288 字。页面隐藏提示「没有登录，免费注册并登录后方可阅读作品正文！」——**全文需免费注册登录**。早期调研误判为"全文直读"，已纠正
- **试读部分价值**：试读即国内标准格式实证范本：《你好，李焕英》`1、职工医院新生儿室，日，内`（场号+地点+时间+内外）、对白`贾晓玲（画外音）：都说女儿是妈妈的小棉袄。`（人名+冒号无引号、画外音中文标注）；页注「本作品仅供编剧学习、研究其创作技巧之用」。**节选也够做精细拆解**（《小山回家》前两场拆出 4 个手法：愤怒的物理化/字幕卡交代人物/辞退三段式对白/道具作证）
- 来源佐证：知乎「有什么网站可以找到国内电视剧剧本？」回答（https://www.zhihu.com/question/357488781）：「华语剧本网《名作》栏目发布了部分国内知名电视剧剧本和大量的国内外知名电影剧本」
- 结论：国内公开完整剧本的地方极少，juben.pro 名作是稀缺渠道

## 四、检索方法备忘（搜索引擎全反爬时）

2026-08-05 实测：Bing（验证挑战）、DDG HTML 版（首次可成、二次限流 HTTP 202）、Mojeek（验证码）在代理下全被挡。

成功路径 = Kimi WebBridge（localhost:10086，继承用户登录态）：
1. navigate `https://www.baidu.com/s?wd=<URL编码查询词>`
2. evaluate 提取：`document.querySelectorAll('#content_left h3 a')` 拿标题+href
3. 百度结果 href 是 `baidu.com/link?url=...` 跳转链接——navigate 过去才拿到真实 URL（知乎/微博）
4. Windows 下请求体含中文必须 write_file 写 JSON 文件 + `curl.exe --data-binary @file` 发送，shell 内联破坏中文
