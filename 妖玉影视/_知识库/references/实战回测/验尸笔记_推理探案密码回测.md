## 〇、项目设定速记（回测基准）

- 一句话故事：架空边城永宁县连环七尸案，贱籍老仵作陆九发现每具尸体伤口里都塞着验尸簿的一页纸——凶手正按他口述、师爷代笔的笔记杀人，而笔记恰好缺了七页
- 类型：推理探案（本格骨架 + 社会派血肉），国风架空（似宋非宋，市井/衙门/殡葬文化），90min
- 主角：陆九，五十三岁，仵作行第九，贱籍出身，识字不多（笔记全靠代笔），爱用歇后语与比喻句推理；缺陷=手抖（旧年尸毒）+咳喘（重场戏身体代价）；学徒阿蛮=身体测谎（闻尸味就干呕，鼻子能辨谎）
- 反方：师爷温良，字迹工整、代笔验尸簿二十年——第二幕交底真凶；其身后另有策划者（二十年前旧案苦主之后）
- 场次一：开场验尸房（夜/内）——建筑宣言：刀剪钳针挂满墙、验尸簿摊开、夜合花首现（观众与陆九同步拿到全部线索）
- 场次二：公堂三证人（日/内）——证词博弈三段式：更夫攻感官（耳背）、绣娘攻立场（与死者有旧）、游方郎中物证当堂引爆（药箱里翻出笔记纸页）
- 场次三：义庄终局（夜/内）——四连反转：温良认罪→页码倒序揭露（第七页对应首具尸体）→"第七具尸体"系伪造→策划者现形，温良只是执行者
- 场次四：公堂尾场（日/内）——首尾闭环：同一公堂，陆九由验尸者变被告（二十年前旧案被翻），权力完全倒转
- 关键道具链：验尸簿（口述代笔/缺七页）→ 夜合花（每尸伤口之花，全城无人识）→ 银针+药渣（二十年前陆九漏掉的细节=职业原罪）→ 公堂鼓
- 信息控制三层剥离：第一幕 whodunit（信息公平承诺，七页全部在场）→ 第二幕交底（观众得知真凶=温良，且死者皆二十年前作伪证者，悬念换轨成"陆九会不会发现"）→ 第三幕再翻回 whodunit（真凶≠认罪者）
- 社会派血肉：案件结局=价值判断——贱籍仵作之言能否定案，职业身份=证据资格
- 仪式与意象：开验即仪式（围观群像每人一句话+一个身体反应）、送葬鼓、水墨冷调、义庄

## 一、逐节对照摘要

### 1.1 定义与谱系（密码"一、""二、"）
密码定义"推理=信息博弈+真相结构，命门是信息公平：信息不是被藏住，而是被公平地摆在桌上，靠结构让人看不见"【推理·一】。项目是这一定义的**正面标本**：七页验尸簿全部出现在观众眼前，遮蔽它们的不是藏匿而是"页码倒序+代笔人"这层结构——正是"被结构遮蔽的物品"。谱系选择判据【推断】对项目直接可用：写"谜题"→本格（连环谜题骨架），写"世道"→社会派（贱籍仵作证据资格=案件即社会批判）——项目即密码明示的"本格骨架+社会派血肉"组合（利刃出鞘式类型化嵌入【卡·利刃出鞘#6】）。法庭派部分适用：公堂戏是支线而非主体（仵作是物证派，主战场在验尸房与义庄），见缺口 G2。硬汉派行密码自认无范本（仅布兰克的可伦坡血脉【卡·利刃出鞘#2】），但国风仵作恰是硬汉派国风化最肥的一块地，见证伪 F3。

### 1.2 核心语法（密码"三、"）
- **语法1 信息控制三层剥离**：**完全适用，且项目即以此命名**——whodunit→希区柯克惊悚→回到 whodunit 的三层结构【卡·利刃出鞘#1】就是项目全片骨架（第一幕同步推理/第二幕交底换轨/第三幕再翻）；"开场让观众 100% 毫无矛盾地觉得她逃脱才是正确结局"【卡·利刃出鞘#1】直接指导交底段设计：死者皆二十年前作伪证者，观众盼温良成事、怕陆九发现。
- **语法2 侦探反传统**：完全适用——陆九=贱籍+歇后语+手抖咳喘，推理能力藏在喜感与身体之下；与阿蛮"闻尸味干呕"形成"侦探靠推理、学徒靠身体"的对照，即玛尔塔呕吐结构【卡·利刃出鞘#2】的国风转译。
- **语法3 庄园家族遗嘱**：需扩展——项目无庄园无遗嘱，对应物是"义庄+开验仪式"：验尸房"刀剪钳针挂满墙"=建筑宣言国风化【卡·利刃出鞘#3】；"遗嘱宣读=仪式性引爆群像"【卡·利刃出鞘#4】换轨为"开验围观群像"（衙役/家属/士绅/百姓各一句话+一个身体反应）。空间容器从庄园换为"衙门-义庄-市井"三级，仪式从宣读换为开验——结构不变，但密码缺国风仪式清单，见 G5。
- **语法4 证词博弈三段式**：部分适用需扩展——公堂三证人（更夫感官/绣娘立场/郎中物证当堂引爆）直接套用"每个证人一个可攻击支点"【卡·控方证人#2】；但项目主体是物证推理，**尸体证词**才是主战场，密码只有人证版、缺尸证版，见 G2。
- **语法5 反转链**：完全适用——四连反转结构直接落地（认罪→页码倒序→伪造第七尸→策划者现形），"每一环提前埋伏笔、伏笔埋在人设细节而非线索道具"【卡·控方证人#4】直接指导：温良"字迹太工整"、陆九"识字不多全靠代笔"是伏笔位；"真相揭晓后必须再翻一次"【卡·控方证人#4】即温良认罪后再翻两环。
- **语法6 结局保密管理**：适用——现代版（8.8）直接可用：结局分层发放、夜合花造型宣传不露、杀青前禁剧透、卡司名单藏关键角色【卡·控方证人#5】。

## 三、缺口清单（密码未覆盖、项目暴露的盲区）

| # | 缺口 | 说明 |
|---|---|---|
| G1 | **连环案"序列结构"语法缺失** | 密码六条语法全是单案结构（利刃出鞘一案、控方证人一案）。《验尸笔记》是连环七尸案，需要专属问题：①序列规律即证据（杀人顺序=密码本，页码倒序是核心反转装置）；②交底点选择（第几具尸体交底最划算——项目选第七具=数字游戏高潮点）；③疲劳管理（每具尸体必须给"新信息增量"，否则观众对验尸麻木——项目用夜合花递进+纸页序号递进双轨）；④"第一具/最后一具"倒序装置（末尸=首案的揭晓位）。密码"信息表"自检（七·）是单案工具，管不住多案 |
| G2 | **物证派/尸证博弈语法缺失** | 证词博弈三段式【卡·控方证人#2】只有人证版（感官/立场/物证引爆）。仵作戏的主战场是"尸体证词"——尸体不会说谎，但尸证会说谎：①死后伤 vs 生前伤（尸体腐败度=感官缺陷版，开验时机决定证据可信度）；②伪造死因（自缢 vs 他杀=二十年前旧案原罪装置，即立场版）；③体内异物当庭引爆（伤口里的纸页/夜合花=物证版）。需要"尸证博弈三段式"条目，与公堂戏（8.1）组成"验尸房+公堂"双战场 |
| G3 | **"记录介质污染"类信息控制装置未单列** | 密码的信息控制装置有两类：信息在场但被结构遮蔽（利刃出鞘【推断】）、证词被立场污染（控方证人【卡·控方证人#2】）。项目核心装置是第三类：**信息在生成环节被污染**——验尸簿是口述代笔，代笔者即真凶，他写的"记录"本身是伪造证据。真凶=记录者，这在单案密码里没有对应装置（利刃出鞘的真凶不碰证据记录；控方证人的假信是庭外道具）。"记录者即凶手"是国风衙门戏的高频结构（刀笔吏/师爷代笔），值得单列 |
| G4 | **贱籍/证据资格社会装置未覆盖** | 社会派条款（8.6 阶层审判）只给了"继承权归属=立场"【卡·利刃出鞘#6】。国风仵作是贱籍：不能科举、不与士绅同席，"卑贱者之言能否定案"是**法律与叙事的双重障碍**——验尸结论要过"证据资格关"（仵作画押不算数、须县令/师爷转述才成文书）。这是西方社会派没有的社会装置（西方对应物=法医出庭资格，密码未写），项目需要"证据资格博弈"条目：每份验尸结论都要先打赢"我的证词算不算数"，再谈真假 |
| G5 | **民俗验尸/仪式层未系统化** | 密码 8.4 只提了一句"滴血认亲式民俗测谎的反用"【卡·利刃出鞘#5】。国风推理的民俗层是成体系的：银针试毒（可被反用：毒可事后涂抹）、滴血认亲（可被反用：血型/水质干扰）、破腹开膛礼仪（仪式性群像场景）、厉鬼索命叙事（案情的民俗解释 vs 仵作的专业解释之争）。仵作的专业判断 vs 民俗信仰的冲突=国风推理独有的"伪证词"来源，需要系统条目（民俗法=伪科学证据链，专门制造反转燃料） |

## 六、最值得回写 3 条

1. **连环案序列结构语法（新条目，§三 核心语法第 7 条或独立小节）**——单案语法扩出多案维度：①序列规律即证据（杀人顺序=密码本，可做核心反转装置）；②交底点选择纪律（第几具尸体交底最划算——数字游戏高潮位优先）；③疲劳管理（每具尸体必须给新信息增量，双轨递进防麻木）；④"末尸=首案揭晓位"的倒序装置；⑤信息表升级为"每具尸体的信息增量表"（观众/侦探/凶手/记录者 × 各尸+旧案）。回写位置：§三 + §七 自检清单。佐证可引《悬疑题材密码》七宗罪研习（序列类范本，密码来源清单已有）。
2. **尸证博弈三段式（新条目，§三·语法4 的物证派变体）**——证词博弈扩出"尸证版"：①死后伤 vs 生前伤（尸体腐败度=感官缺陷版，开验时机即证据纪律）；②伪造死因（自缢 vs 他杀=立场版，职业原罪装置）；③体内异物当庭引爆（物证版）。配套"验尸房+公堂"双战场结构与 §八·8.1 公堂戏骨架扩为"公堂戏+开验戏"双场景骨架。回写位置：§三·语法4 + §八·8.1。
3. **"记录介质污染"信息控制变体 + 证据资格博弈（§三·语法1 与 §八·8.6 扩展）**——①语法1 信息控制扩出第三类装置：信息在生成环节被污染（口述代笔=记录者即凶手，真凶=代笔者），与"结构遮蔽""立场污染"并列；②8.6 阶层审判补国风社会装置：贱籍职业的"证据资格博弈"（卑贱者之言能否定案=法律与叙事双重障碍，验尸结论先过资格关再谈真假）；③同步补 F1 修正（机制可混的前提=主机制独占公平承诺）。回写位置：§三·语法1 + §八·8.6 + §二 谱系表。
