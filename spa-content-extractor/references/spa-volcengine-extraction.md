# 火山引擎文档抓取实战记录

> 2026-07-21 | 火山引擎豆包语音API文档（docs.volcengine.com/docs/6561/）

## 背景

从火山引擎官方文档抓取豆包语音全部29个API接口的完整参数说明。

## 有效方法

### 直接页面（21个）

```
browser_navigate(URL) → browser_console('document.body.innerText') → write_file
```

每页约30秒，innerText包含完整文档正文，格式干净（参数名/类型/说明的表格形式）。

### 重定向页面（4个：异步TTS、声音复刻、音色设计、音色管理）

URL直接访问会重定向到"产品动态"页。必须通过侧边栏点击：

1. `browser_navigate(任意一个API参考页)` — 进入API参考模式
2. `browser_snapshot` — 获取侧边栏ref
3. `browser_click(目标菜单项ref)` — 展开子菜单
4. `browser_snapshot` — 获取子菜单ref
5. `browser_click(具体API文档ref)` — 进入目标页面
6. `browser_console('document.body.innerText')` — 提取内容

### 并行提取

`delegate_task` 子agent拥有独立浏览器实例，可以并行。但需注意：
- 指令必须完整（如何提取、是否需要点击、输出格式）
- 不要假设工具约束（如"浏览器是单tab"）——先测试再下结论
- 子agent返回的数据需要认真解析，不能因为格式不完美就全盘否定

## 踩坑记录

### 1. SPA页面URL重定向

火山引擎文档部分URL（如2536398、1374038、1598072、1630433）直接访问会重定向到产品动态页。这些页面的API内容需要通过侧边栏导航才能到达。

### 2. snapshot格式不是纯文本

browser_snapshot返回的是DOM树（StaticText节点），有大量嵌套重复。用于提取纯文本时质量很差。innerText是唯一可靠的文本提取方式。

### 3. 子agent指令质量决定结果质量

- ❌ "不要点任何东西" → 4个页面拿到的是产品动态页内容
- ❌ 没告诉如何从snapshot提取文本 → 子agent自行处理，质量参差
- ✅ 允许点击 + 完整提取规则 + 输出格式要求 → 质量可控

### 4. 过度优化导致时间浪费

29页抓取 = 重复同一个已验证动作29次。不需要优化、不需要并发、不需要创新。
正确做法：第一页成功后直接重复29次，约15分钟完成。
