# KB Codex Synthesis（知识库密码文件合成）

> 从存量知识资产（导演卡片/技法卡片/手法体系深化/创作 skill 约束章节/检索表）合成《XX密码.md》的工作流。模板规范在知识库内（如 `妖玉影视/_知识库/references/制作学科/00-模板规范.md`），本技能管"怎么执行合成"——模板管结构，本技能管过程与坑。

## 何时用

- 任务要求撰写/更新《题材密码》《学科密码》《导演密码》等知识库密码文件
- 任务明示"从存量资产合成，零新抓取"
- 知识库入库/沉淀/提炼类批派任务（批 1/批 2/批 3 轮次）

## 核心工作流

1. **先读模板规范，再动笔**：知识库内 `00-模板规范.md` 定义文件结构（定义谱系/核心语法/范本实证/常见坑/自检清单/AI 提示词对接/来源清单/实战回写记录）、引用约定、质量纪律。模板是权威，其引用约定直接决定文档内来源编号写法。
2. **定位存量资产（中文路径坑）**：Windows/MSYS 上 ripgrep 系工具（search_files）对中文文件名/中文 glob 会**静默返回 0 结果**。用 terminal `ls`/`find` 枚举目录结构，再 `grep -n` 定位关键词行段。本会话实证：`search_files` 三个中文 glob 全部 0 结果，`ls` 一次到位。
3. **定向提取而非整读**：卡片文件大（100-250 行），先 `grep -n "光\|夜\|雾\|阴影\|暗"` 定位，再 read_file 精确行段。多文件素材先并行 grep 一轮，再决定精读哪些——省 token 且覆盖全。
4. **按模板结构写作，每条论断带来源编号**：编号体系照模板引用约定（制作学科模板示例：[AI导演 3.3]=创作 SKILL.md 章节、[卡·片名#N]=大师技法卡片卡 N、[深·导演名]=手法体系深化文档、[知识库检索]=_知识库/SKILL.md 检索表行）。角色表/导演原话可照录，标注"表格照录/原文摘录"。
5. **诚实标注三件套**（模板质量纪律要求）：
   - 【通用理论】=外部通用理论（如光的情绪心理学），大师案例只能作实证、不能作证明
   - 【综合】=自己从素材归纳的框架（如"五种功能"）
   - 【推断】=基于原理的推导（如黑墨水雨→逆光雨丝提示词）
6. **大小控制到目标字节**：`wc -c` 是精确字节数；中文 UTF-8 ≈ 3 字节/字（18KB≈6000 汉字）。压缩手段按性价比排序：来源清单说明精简 → 删重复表格行（正文已覆盖的）→ 合并短行/删解释尾巴 → EN 模板删冗余条目。**每轮 patch 后 wc -c 验证**，迭代 2-3 轮。任务目标与家族常模冲突时见常见坑 2。
7. **终验**：read_file 通读全文（分段）；`grep -c "^## "` 核对章节数；确认诚实声明与实战回写记录存在；确认压缩时没删掉正文/声明还在引用的条目（先 grep 交叉引用再删）；**任务指定素材逐项核对正文落点**——每个导演/片名/文档名 grep 正文出现处，只在来源清单出现即漏项（见常见坑 7）。

## 常见坑

1. **search_files 中文路径静默 0 结果或显式报错**——不是文件不存在。两种形态都实测过：静默返回 0 结果（光影轮）、显式报错 `rg: ... IO error for operation on ... (os error 3)`（视效轮，中文路径+`*` glob）。一律换 terminal `ls`/`find`/`grep`（先 `cd` 到中文目录再 grep，`grep -rn` 带路径参数会踩同样编码问题）。
2. **初稿必然超目标体积**（23.4KB 压到 18KB）——计划 2-3 轮压缩，不要指望一次到位；先保内容完整性，压缩轮再删冗余。**反向情况**：任务目标体积低于家族常模（如任务说 15-20KB，而同级文件实际 18.5-30.5KB）——以覆盖任务指定主题为先，体量向家族常模靠拢（每份密码主题数不同，不强行削内容凑字节），取舍理由写进交付汇报。
3. **压缩误删交叉引用条目**——如删掉 EN 模板里被诚实声明引用的"雨战逆光"条目。压缩前 grep 一遍"引用编号 ↔ 正文出现处"。
4. **任务描述里的素材编号 ≠ 模板引用约定**——任务给的"①②③④"是任务内编号，文档内统一用模板的引用约定，避免两套体系混用。
5. **素材在任务描述的路径下找不到**——先 `find` 知识库根目录找实际路径（本会话卡片在 `references/导演美学卡片/`、`references/大师技法卡片/`，与任务描述路径不同）。
6. **招式表/检索表登记出处 ≠ 实际卡片出处**——知识库 SKILL.md 招式表登记"画皮卡片4=同镜反转三拍"，实际出自《聊斋志异_原著_技法卡片》卡片 4（《画皮_技法卡片.md》卡片 4 实为"古典志怪→爱情片改造"）。引用招式表出处前必须 grep 实际卡片核对；不一致时以实际卡片为准，并把勘误写进成品文档诚实声明（本会话案例详见 `references/视效设计密码-合成实录.md`）。
7. **任务指定素材只进来源清单=漏项**——视效轮初稿把宫崎骏只写进来源清单、正文零落点，终验才发现。任务素材清单里的每个导演/片名/文档都要在正文有实际落点（语法节或范本实证行），"仅在来源清单出现"即漏项。

## 引用约定速查（制作学科模板 v1.0）

- 导演卡片 `[卡·导演名]` = references/导演美学卡片/<导演>_导演美学卡片.md
- 深化文档 `[深·导演名]` = references/导演美学卡片/<导演>_手法体系深化.md
- 技法卡片 `[卡·片名#N]` = references/大师技法卡片/<片名>_技法卡片.md 卡 N
- 创作 skill `[AI导演 3.x]` = AI电影导演/SKILL.md 章节 x
- 检索表 `[知识库检索]` = _知识库/SKILL.md 检索表行
