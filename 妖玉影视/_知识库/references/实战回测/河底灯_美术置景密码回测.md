## 〇、项目设定速记（回测基准）

- 一句话：渡河人阿九在断流十年的河里捞起一盏不灭的灯，灯里住着等摆渡的魂——她每夜在河心点灯，引渡十年前水淹村时没来得及上岸的人
- 六大场景：①渡口废墟（日/外，断流干河床+搁浅旧渡船）→ ②河心灯市（夜/外，无月之夜河心浮灯）→ ③岸上客栈（夜/内，江湖人歇脚处）→ ④水淹村遗址（雾/外，半露水面的屋顶=阿九旧家）→ ⑤河底龙宫（暗/内，嫁妆箱沉底）→ ⑥渡口决战（夜/外，断流河重新涨水）
- 人物：阿九（24，怕水却生在渡口的渡河人）/灯魂（出嫁路上死于水淹，嫁妆箱沉河底）/老船工（60，渡口守灯人，当年撑船救人的）/疤脸客（30+，当年抢财盗匪）
- 关键道具：铜灯（灯芯烧嫁妆箱里的红盖头——"她的喜事就是她的牢"）/嫁妆箱（红盖头/铜镜/未用红烛）/撑船篙（渡河也是渡魂）
- 已定美术基调（供对照）：龙宫段低饱和青灰（水淹的记忆色）/灯市段暖黄（灯=唯一暖色）/决战由暗转明；全片无配乐、环境声主导；灯魂实体可触、魂灯一盏盏亮起、涨水=水的实体化

## 一、逐节对照摘要

### 1.1 定义谱系（密码"一、"）

四子域（场景设计/空间造型/时代质感/道具陈设）对项目全部可用且边界清晰：渡口废墟=场景设计（选一个容器让空间先于人物成为主角）；干河床方向与"水陆双层"=空间造型；明代市井骨干=时代质感；铜灯/嫁妆箱=道具陈设。元定律"空间是先于人物出场的演员"直接指导开场——干河床+搁浅渡船应先于阿九单独登场。谱系无证伪，但见缺口-5（幻境层定义偏窄）。

### 1.2 核心语法（密码"二、"六条）

| 语法 | 对照结果 |
|---|---|
| 1 空间即命运 | **高度命中**：渡口废墟的干河床=命运通道被断流（方向纪律的"负形态"，H3）；水淹村旧家门框=画中画（阿九被自己淹掉的过去框住，H1）；河心灯市=浮动容器（见证伪-2）。"空间结构=命运结构"对三个核心场景全部直接可落 |
| 2 时代质感 | **高度命中**：项目设定"明代市井骨干/宋代水墨留白"即密码【用户决策】的原文落地；骨干层（渡口/客栈市井+更鼓宵禁声音坐标）、意境层（雾中水淹村/无月之夜）、幻境层（龙宫）三层可分工；但幻境层"唐代金碧"形态被项目修正（见证伪-1），物件矩阵缺情感维度（见缺口-4） |
| 3 场景即人物 | **高度命中**：阿九旧家在水下=环境是心理的镜子（他的过去被淹）；老船工守着断流渡口=人物与空间绑定（渡口是他的"龙门客栈"）；空镜句号（干河床/雾中水面） |
| 4 封闭容器 | 部分命中：岸上客栈=龙门客栈7件套逐条可套（见命中-10/-11）；但河心灯市是"无墙容器"，密码容器二分（封闭垂直/开放网格）未覆盖（见证伪-2/缺口-1） |
| 5 山水画构图 | **高度命中**：雾中水淹村=卷轴四式逐条可落（人物占1/10如黑点/左入右行/前景苇杆虚化+薄雾/横移展卷，H12）；雾=黑泽明式实景选景（H13）；留白三功能（空镜句号，H14） |
| 6 实景vs棚拍 | **高度命中**：干河床/水淹村实景为天气地貌，龙宫棚拍为水下奇观（水下实拍不可控=李翰祥"现实的合作者"演变内核，H15）；但渡口决战"涨水实体化"落在实景+数字混合区，密码两派二分未覆盖（见证伪-3） |

### 1.3 范本实证（密码"三、"）

14条中11条直接可用：空间剪彩/画中画/卷轴构图/空镜句号/实景调度/棚拍纪律/声音即时代坐标/空间即阶级/方向纪律/站位即关系/大漠孤烟画卷均对项目有明确落点。"汤屋规则"为部分命中——灯市=摆渡业异界（魂们是"等渡的客人"，规则驱动情节成立），但汤屋的"服务业生活感"骨架在灯市不成立（魂们不是来消费的，是来等的），归属缺口-1。"物件时代矩阵"需扩展情感维度（缺口-4）。

### 1.4 常见坑（密码"四、"）

坑2（时代质感靠贴标签）直接预判架空项目最大风险——明代市井骨干不能靠服装道具硬讲，靠声音坐标+物件+生活逻辑（项目设定"无配乐环境声主导"恰是密码修法的极端落地）；坑9（架空大杂烩）的修法=三层分工，项目设定即按此落地（命中-17）；坑4（道具用一次就扔）预判铜灯必须走四段弧（捞起→挂柜台→灯市→决战闭环）；坑5（棚拍细节崩盘）对龙宫棚拍适用，但"历史三档纪律"需改写为架空自洽三档（缺口-3）；坑6（画面塞满）预判灯市不能拍成灯海堆砌——每盏灯是点景不是布景（缺口-6）；坑1/3/7/8均有对应落点（空间语法先行/客栈垂直分层/空间主权/魂群慢镜烟雾）。

### 1.5 自检清单（密码"五、"）

11条中9条直接可勾（空间语法/方向纪律/空间剪彩/垂直分层/空间即关系/画中画/时代三层+声音坐标/物件闭环/留白）；第10条"实景/棚拍"需补第三元"实景+数字"（见证伪-3）；第11条"空间结局"只有破坏型（焚店/弃船/炸楼），项目结局是**恢复型**——断流河重新涨水=空间复活（见证伪-4）。

### 1.6 AI提示词对接（密码"六、"）

6条模板对 Seedance 21:9 直接可用：模板1（空间剪彩+垂直分层）→客栈开场空镜；模板3（时代质感三层）→全片基调主句（与项目"明代市井骨干/宋代水墨留白"设定逐字对应）；模板4（卷轴式构图）→水淹村雾戏；模板6（为天气选景）→渡口废墟。缺"水体空间"模板（灯市/龙宫/涨水），见缺口-1/-2。

## 三、缺口清单（密码未覆盖、项目暴露的盲区）

| # | 缺口 | 说明 |
|---|---|---|
| G1 | **水体空间/浮动容器无专属语法** | 河心灯市=无墙容器——边界是水与黑暗而非墙，封闭性来自"离岸即不可达"（规则封闭，见证伪-2）；密码容器二分（封闭垂直/开放网格）只覆盖陆地/建筑空间，志怪/武侠大宗的水面空间（渡口/灯市/水战）无语法。灯市是片名场景、项目核心引擎 |
| G2 | **"介质缺席/回归"作为空间反转引擎未覆盖** | 密码空间反转只有"反转=空间多出一层"（寄生虫地堡门）；《河底灯》的反转是**介质回归**——断流十年的河重新涨水=水回来=被淹的记忆/真相浮上来。密码无"介质状态"维度（水/火/雾/冰的在场与缺席） |
| G3 | **架空项目的考据纪律缺失** | 坑5"历史三档纪律"（大事不可改/制度细节术语级/生活方式不得违反）基于真实朝代；纯架空项目无"大事"可考，考据对象应转为**自洽三档**——骨干层生活逻辑不可违反（明代市井器物的使用方式/空间尺度必须真实）/意境层艺术真实/幻境层内部自洽。朱家溍式订正对架空项目=订正"生活逻辑"而非"历史细节" |
| G4 | **物件矩阵只有家国维度** | 密码锚点=徐克"一件小器物承载家国史"（手扇刻条约）；《河底灯》铜灯/嫁妆箱=个人情感史/执念物——"她的喜事就是她的牢"是物件承载**关系反转**（喜事物=牢狱物），情感维度的物件矩阵未写 |
| G5 | **幻境层形态单一** | 密码幻境层=唐代金碧（雕梁画栋/灯火通明）；《河底灯》龙宫=低饱和青灰（水淹的记忆色）——幻境层需补"沉没的金碧"（金碧的记忆泡在水里褪色）形态（见证伪-1） |
| G6 | **幻境层的色彩纪律/稀缺色管理未写** | 灯市暖黄=全片唯一暖色、灯=重音、"一盏盏亮起"=重音递增；密码只有意境层极值（水墨+唯一血色）与写实线纪律（色彩服从时代），幻境层的"稀缺色"管理（金碧也要稀缺化）无指导 |

## 四、证伪清单（密码说错或需修正）

| # | 密码原文指向 | 修正建议 |
|---|---|---|
| F1 | 语法2"幻境层取唐代金碧（雕梁画栋/灯火通明）" | **金碧是幻境层的一种实现，不是定义**。《河底灯》龙宫=金碧的记忆沉入水下褪成青灰+嫁妆箱里唯一未用的红烛（全片最重的颜色）——奇观可以低饱和；密码自引"色彩倒推故事"（黑宫殿→秦朝/敦煌色→唐朝）[深·张艺谋·工具6]已证明幻境层本质是"非现实奇观"。需放开为双形态：金碧辉煌（灯火通明）/沉没的金碧（水下褪色） |
| F2 | 语法4"封闭容器"隐含容器必有墙/建筑边界（客栈/汤屋/茶楼均建筑） | 河心灯市证明**无墙容器**成立：封闭性来自规则（无月之夜才开市/魂离灯即灭/岸上人看不见灯市）而非物理墙。需补"规则封闭"概念：物理封闭（客栈墙门）vs 规则封闭（灯市无月之夜）——"空间即命运"在水面空间同样成立：浮灯围成的圆=魂们的命运圈 |
| F3 | 语法6"实景vs棚拍"两派二分 | 缺第三元**"实景+数字"**：渡口决战"涨水实体化"=实景空间里的超现实事件（断流河床实拍+数字水实体回归）；黑泽明式实拍涨水在此不可行（断流十年无真实水源）。应三分：实景（天气/地貌）/棚拍（奇观/控制）/实景+数字（现实空间的超现实事件） |
| F4 | 五·自检清单"空间结局=人物选择（焚店/弃船/炸楼）"只有破坏型 | 《河底灯》结局=**恢复型**：断流河重新涨水=渡口功能恢复（空间复活），魂们过河、阿九渡了自己——空间结局两极性：破坏型（焚店，空间命运=人物决裂）vs 恢复型（复流，空间命运=人物和解）。空间结局不必然破坏 |

## 六、最值得回写 3 条

1. **新增"水体/介质空间"语法（语法7候选）**——水面/水下/断流是志怪武侠大宗空间（渡口/灯市/水战）。三要素：①介质状态作为空间语法——断流=介质死亡（方向被取消）、涨水=介质回归（真相浮出），介质在场/缺席即叙事状态；②浮动容器=规则封闭（无月之夜/离岸即失）而非物理封闭；③水下幻境=沉没的金碧（低饱和青灰+唯一重色）形态。同步新增 AI 提示词"水体空间"模板（灯市一盏盏亮起/涨水实体化）。回写位置：二、核心语法新增语法7 + 六、AI提示词对接。
2. **空间结局两型 + 容器边界两型修正**——空间结局=破坏型（焚店/弃船/炸楼，人物决裂）与恢复型（干河床复流/渡口功能恢复，人物和解）双极性；自检清单第11条改为"空间结局是破坏还是恢复？是否等于人物选择？"。容器边界=物理封闭（墙/门）与规则封闭（仪式/禁令/自然条件）两型并列。回写位置：语法4 + 五、自检清单。
3. **幻境层双形态 + 架空自洽三档考据纪律**——幻境层放开为"金碧辉煌"与"沉没的金碧"双形态（奇观可低饱和，重色稀缺化）；坑5历史三档纪律改写为架空自洽三档——骨干层生活逻辑不可违反（市井器物使用/空间尺度真实）/意境层艺术真实/幻境层内部自洽，供纯架空项目质检。回写位置：语法2 + 四·常见坑5。
