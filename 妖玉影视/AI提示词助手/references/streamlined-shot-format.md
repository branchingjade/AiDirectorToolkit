# 输出格式参考

Seedance 2.0 提示词的自然描述格式。

## 格式模板

```
景别运镜视点描述。角色动作+台词逐字嵌入，音效自然融入。
切下一镜景别运镜视点描述。角色动作+台词逐字嵌入。
```

## 规则

1. **景别运镜**：以自然语言描述开头（"中景正面跟拍"、"手持特写"、"切中景，越过王秀娟右肩框住"）
2. **镜头切换**：用"切"字标记（"切王秀娟特写"、"切中景"、"切手持特写"）
3. **焦点转移**：融入描述行（"焦点落在陈静脸上"、"视线从...摇至..."、"镜头从...缓缓摇至..."）
4. **音效**：作为物理描述自然融入（"金属撞击声短促清脆"、"钞票在空中翻转折开"），不用 `[音效: xxx]` 标签
5. **台词**：逐字嵌入，语气标注具体（"哭腔"、"声音发颤"、"声音陡然拔高"）
6. **无段级头行**：不写画幅/风格/角色@图片/场景@图片/道具@图片/配音声明
7. **无人物形象描述**：不描述角色的外貌、服装、发型等——除非用户明确要求
8. **无@Tag**：不引用资产编号，以角色名/场景名直接描述

## 示例

```
中景正面跟拍。王秀娟哭腔推开院门快步走进院子："嫂子，嫂子——"陈建国在后面佝偻着腰，慢慢跟着。
切王秀娟特写，框住胸部以上。王秀娟哭腔："嫂子，活不了了啊——"
切中景，从屋子右侧斜向框住屋门，跟拍。李素珍在前，陈静在后，两人从屋里走到院中。镜头继续跟拍框住四人——王秀娟双手拉住李素珍右手，举到自己胸前。
切手部特写，手持镜头微微仰拍。镜头从两人交握的手部缓缓摇至王秀娟面部。王秀娟眼眶发红，使劲眨眼，挤出两滴泪挂在颧骨上："嫂子，你得救我啊——"
切中景，越过王秀娟右肩框住李素珍和陈静。李素珍眉头皱起，嘴唇微张，双手不知放哪。焦点落在陈静脸上——陈静翻了个白眼，嘴角往下撇："这又是闹哪出。"说罢下唇往前一噘。
```

```
特写，微微俯拍，镜头从车内打向车门内侧。阿彪推车门，车门未开。"小子找死——"万倩画外音切入，声音平稳："阿彪，开车。"

切俯拍中景，透过汽车挡风玻璃。阿彪双手砸方向盘，方向盘震弹回位。
切汽车后排视角中景。焦点从阿彪后脑勺起——后脑勺在画左虚化——缓缓拉到中央后视镜。镜面映出万倩眉眼：墨镜遮住双眼，只露眉骨与鼻梁。万倩（VO）："查一下刚那人。"镜中万倩头部微微低下。
```
