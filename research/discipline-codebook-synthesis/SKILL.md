# 制作学科密码撰写（妖玉影视知识库·第五层）

> 定位：知识库第五层「制作学科库」的密码文件生产工作流——模板规划 9 份学科密码 + 制作大师卡片，本技能管学科密码这一族。与题材密码（genre-code-synthesis）同构：范本实证 + 带源标注，但服务对象不同——题材密码管「这个题材怎么写才成立」，学科密码管「这个专业领域怎么设计才成立」。
> 范本：《构图运镜密码.md》（2026-08-08 完成 v1.0，19.7KB）——本技能诞生于该文件撰写过程，格式/密度/诚实声明做法均以其为准。第二范本：《调色密码.md》（同日 v1.0，22.9KB，任务要求约 15-20KB）——覆盖点多的任务（12 节）终稿略超上限可接受，含「任务预设纠正」诚实声明实例。第三范本：《剪辑蒙太奇密码.md》（同日 v1.0，20.2KB，素材 9 导演卡+5 技法卡）——压缩轮次最多的一轮（10 轮），字节账工作流见 §4。

## 工作流（按序执行）

### 1. 模板规范先行

读 `_知识库/references/制作学科/00-模板规范.md`——七节结构（定义谱系/核心语法/范本实证/常见坑/自检清单/AI提示词对接/来源清单/实战回写记录）、引用约定、质量纪律全部在此，先读再写，不凭印象。

引用 key 速查：
- `[卡·导演名]` = `references/导演美学卡片/<导演>_导演美学卡片.md`（横向美学体系）
- `[深·导演名]` = `references/导演美学卡片/<导演>_手法体系深化.md`（跨作品演变+工具箱+AI 提示词对接+诚实声明）
- `[卡·片名#N]` = `references/大师技法卡片/<片名>_技法卡片.md` 卡片 N
- `[AI导演 三·五.x]` = `AI电影导演/SKILL.md` 章节 x（三·五=技法理论精要，三·六=场景构建，4.3=21:9 构图纪律，5.4=格式验收）
- `[知识库·招式表·空间类]` / `[知识库·检索表]` = `_知识库/SKILL.md`（招式表按类别引用，如「空间类」5 行；检索表按场景行引用，如「群像」「留白/意境」）

### 2. 素材定位（中文路径陷阱）

- **search_files 对中文路径目录返回 0 结果**——定位文件改用终端：`find /c/Users/HMSJ/AppData/Local/hermes/skills/妖玉影视 -name '*关键词*'`（MSYS 路径），然后 read_file 直接读。
- **动笔前查姊妹文档分工**：同目录已存在的密码会声明「姊妹文档」与分工表（《色彩设计密码》声明姊妹文档《调色密码》并给出前后期分工表）——边界先对齐再写，管后期就只写后期，前期配色只引用不重复。
- 素材四源（全部存量，零新抓取）：
  1. `AI电影导演/SKILL.md` 约束章节——运镜语义学/构图理论/场面调度原文跟脚在这
  2. 导演美学卡片 + 手法体系深化——深化文档的「可复用工具箱」直接带 AI 提示词写法，可整段转用
  3. 大师技法卡片——硬数据（逐镜拆解/镜头统计/访谈原文）在这
  4. `_知识库/SKILL.md` 招式表 + 检索表——速查入口，先查表再决定读哪张卡片

### 2.5 任务预设归属验证（grep 之后再写）

- **任务预设里「某导演卡片含 X 论断」必须 grep 源文件验证**，0 命中即换归属，别照抄任务描述。
- 实例（调色密码轮）：预设「库布里克 黑白=不美化」——grep 库布里克深化+导演卡片 0 命中；「黑白=不美化」实为斯皮尔伯格《辛德勒的名单》[知识库·导演索引]（经色彩设计密码转引）。
- 纠正写法：正文按真实归属引用，诚实声明里加「任务预设纠正」条目说明原委——不张冠李戴，也不默不作声地改。

### 3. 撰写纪律

- 每条论断带来源；核心命题引原文跟脚（Sikov/Cinematography 等原句），不转述成无主观点
- **诚实声明继承**：源卡片里的「未取证到」标记必须带进合成文档——合成不是把二手转成一手。范本做法：小津「对称构图」未取证到，正文改以「低机位稳定构图+并排构图」为准并标注 [深·小津 诚实声明1]
- 泛用导向：可复用时机按创作场景归类（动作戏/群像戏/留白意境戏…），不绑定单一项目
- 不重复题材密码：叙事结构/人物/题材成立性归题材密码，学科密码只讲本专业领域（画框/景别/运镜/调度/剪辑节奏这类画面层）
- 每节都要能回答「本学科怎么设计才成立」，不是规则清单

### 4. 中文体积预算（关键坑）

- **中文 UTF-8 ≈ 3 字节/字**：12-18KB 目标 ≈ 4000-6000 字；markdown 表格/标题/引用标注另占 ~30% 开销
- 初稿几乎必超（范本：初稿 26.5KB → 四轮压缩 → 19.7KB；剪辑蒙太奇密码轮：初稿 30.5KB → 10 轮 → 20.2KB——多出的轮次全耗在无效整写上，见下）。压缩策略：
  - 第一轮整体重写压密度：删重复论断、合并表格列（如运镜表的「来源」列并入标题行）
  - **密度轮之后禁止再整文件 write_file 重写**——内容没变字节数几乎不动（实测连续 4 次整写只从 30.5KB 降到 27KB，白费轮次）。压缩必须真的删内容：后续轮改用 execute_code 做节级字节账 + 定向字符串替换
  - 节级字节账：`re.split(r'(?=^#{2,3} )', text, flags=re.M)` 切分后逐节 `len(s.encode('utf-8'))` 打印（中文 1 字=3 字节），先打最大头，每轮替换后打印总字节验证收敛
  - **批量替换前 `assert old_block in text`**——old_string 与实际文本差一个字就静默失败（实例：来源清单 9 行合并 4 行的大块替换未生效，多轮后才在通读时发现）；断言失败说明该块此前已被微改过，先 read_file 核对实际文本再换
  - 优先保来源标注、EN 提示词块、硬数据、诚实声明
  - **patch 时 old_string 与 new_string 必须真实不同**——同文本替换是 no-op，白费轮次
  - 「约 15-20KB」容忍 ±10%：内容完整度优先于精确体积（同目录姊妹文件实际 18.5-23KB，与参考文件对齐即可）
- 压缩时注意保持 markdown 结构：列表与标题之间要有空行（列表后紧跟 `###` 会吞掉标题）

### 5. 收尾

- 通读全文查结构（表格/标题/空行），查引用 key 是否用对（[卡·]=美学卡片、[深·]=深化文档，易混）
- 目标路径：`_知识库/references/制作学科/<学科>密码.md`，文件名与目录内 00-模板规范 对齐

## 常见坑

1. 中文路径搜索 0 结果 → 用终端 find，别反复试 search_files
2. 初稿超体积 → 按 3 字节/字预算，预留压缩轮，别为体积砍必需主题或来源标注
3. [卡·] vs [深·] 混淆 → 导演美学卡片=卡，手法体系深化=深
4. 源卡片诚实声明未继承 → 合成文档凭空多出「已验证」论断，违反质量纪律第 4 条
5. 把题材密码内容写进来 → 学科密码只讲本专业领域，结构/人物归题材密码
6. 任务预设归属未 grep 验证就写入 → 误归属进正文（实例：库布里克「黑白=不美化」实为斯皮尔伯格）；0 命中即换归属并在诚实声明记「任务预设纠正」（见 2.5）
7. 没查姊妹文档分工就动笔 → 与已有密码重复或越界（前期配色写进调色密码类）；先对齐分工表（见 2）
8. 密度轮后继续整文件 write_file 压缩 → 字节数几乎不动，白费轮次；改用 execute_code 节级字节账 + 定向删除（见 4）
9. 大块字符串替换静默失败 → old_string 与实际文本差一个字就不命中；批量替换前 assert，失败先 read_file 核对实际文本（见 4）
