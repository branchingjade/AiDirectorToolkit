# 谍战特工范本研习来源打法（《谍影重重》轮 2026-08-09 实测）

为谍战/特工/写实动作题材范本（《谍影重重》《007：大破天幕杀机》类）打地基时的来源优先级、观察点与坑位。本片无公开剧本全文→文献研习法（同灾难片轮）。

## 来源优先级（实测有效）

1. **Wikiquote raw 直连 = 对白一手主力（免 jina 免登录）**：
   ```bash
   curl -sL -A "Mozilla/5.0" "https://en.wikiquote.org/w/index.php?title=<片名>&action=raw" -o wikiquote.md
   ```
   一次拿到：全部经典台词（带说话人分组）+ 对话往来（含场景标注如 `[during a car chase]`）+ **Taglines 段=主题浓缩**（《谍影重重》Taglines 直接给 "Who Am I?" / "He was the perfect weapon until he became the target."）。首尾呼应类结构论断可直接用台词集验证（开场 "What's your name?"→结尾 "You have ID?"）。**台词库多版本并存是常态**（Wikiquote "Look at this" vs Fandom "Look at us"）——双录标注，不强行统一。
2. **导演「拆解场景」访谈报道（低成本一手转述）**：搜 `"<导演> breaks down the scene" <片名>` 或 `<片名> <导演> interview`——CBR/IGN 类文章整段转述导演原话（本片：偷拍北站镜头、shaky cam 起源、'steal this' 全段采访），一次拿到幕后一手细节。引用时标注「经 <媒体> 转述」，不冒充直接采访。
3. **20 周年回顾文簇**：搜 `<片名> changed action cinema 20 years` / `<片名> turns 20`——Far Out / Collider / CBR 同期连发（2022-06），一次拿 legacy/impact 分析 + 系列对比数据（后作平均镜头 2.4 秒、Ultimatum 3200 镜头/105 分钟）+ 类型影响（重启 007 的 Daniel Craig "dirtier, back-to-basics"）。
4. **维基百科 EN 条目**：剧情/制作/拍摄地/训练细节（本片：三月训练拳击+武器+eskrima、第二组导演维特拍车戏、9·11 砍爆炸结局、农舍戏力保、真实海军陆战队员出演领事馆戏）。
5. **专业影评（Ebert 类）**：一手观点常是报告「反面参照」的素材（Ebert：「无好人无坏人，杀达蒙的人也只是在工作」「玛丽只是 false suspense + 给孤狼一个说话对象」）——文戏功能批评直接可引用。

## 观察点六件套（谍战特工范本）

1. **双线悬疑结构**：寻根线（我是谁）× 追杀线（谁在追我），两条线独立成立、在动作场面交汇；信息差分三层投放（观众知追杀者存在→伯恩知组织存在→闪回揭全部真相）。
2. **技能显影三幕**：能力「想起」而非「学会」，观众与主角同步发现身份（公园放倒两警察，观众和伯恩一样惊讶）；技能最高峰=拒绝使用技能（因孩子在旁放弃暗杀）是道德核心。
3. **镜像刺客**：同源同训练的对手，共享生理/职业「症状」（头痛/独来独往），对话交换情报（"I work alone, like you"），临终台词点题。
4. **官僚冷血对白**：反派=体制非暴君；「资产化」定性台词（"30-million-dollar weapon" / "I send you because you don't exist"）+ 推诿式办公室对白 + 系统灭口自己人。
5. **环境武器化动作**：周围物件皆兵刃（公寓战），借力打力武术（kali/eskrima 同源异名，双口径）；打击声混音与画面同等重要。
6. **实拍地理蒙太奇**：多地点拼接追车戏，剪辑逻辑>地理逻辑（导演自认 "anyone who really knows Paris will find it illogical"）；避重特效让凹痕侧滑成为真实后果。

## 坑位（本轮实测）

1. **r.jina.ai 429 限流（Per IP rate limit exceeded + retryAfter）**：错误体 `{"data":null,"retryAfter":1,...}`——不必等重试，维基/语录类站点直接 `action=raw` 直连绕开 jina（见 web-fetch-fallbacks 补丁）。
2. **SEO 聚合站正文缺失**：findthismovie.com 类页面抓回 24KB 但全是导航/相关文章，正文 0 字节——落盘前 grep 片名关键词（Bourne 0 命中），0 命中即弃，不登记来源。
3. **Wikiquote raw 的 `''强调''` 斜体标记打断短语**：`I send ''you'' because you don't exist` 精确 grep 必 MISS——归一化时剥 `''`（与剥 markdown 链接、弯引号同一函数，见下）。
4. **jina 转换页的 markdown 链接与弯引号打断引文**：`[Montreal](url)`、`aggressor's`（U+2019）——grep 前统一归一化：剥链接→弯引号转直→压空白；归一化后 0 MISS 才算验证通过（本片 60 条摘录全部通过）。

## 引文归一化函数（可直接复用）

```python
def normalize(t):
    t = re.sub(r"\[([^\]]+)\]\([^)]*\)", r"\1", t)   # 剥 markdown 链接
    t = t.replace("\u2019", "'").replace("\u2018", "'")
    t = t.replace("\u201c", '"').replace("\u201d", '"')  # 弯引号转直
    t = t.replace("''", "'")                            # wikiquote 强调斜体
    t = re.sub(r"\s+", " ", t)
    return t
```

## 007 轮补充（2026-08-09《007：大破天幕杀机》实测——经典特工/系列大片分支）

谍影重重轮为「写实谍战/无公开剧本」分支；本片为「经典特工/大IP系列」分支，来源打法差异明显：

**①剧本全文可得=骨架一手源**：scriptslug 页面 HTML 内 grep 真实 PDF 直链（`href="([^"]*assets/scripts[^"]*)"` → `assets.scriptslug.com/live/pdf/scripts/skyfall-2012.pdf?v=...`），curl 直连 243KB 真 PDF（`%PDF` 头验证），PyMuPDF 提取 139 页 142KB——对白/场景/舞台指示全一手。⚠️ 拍摄稿与成片有出入（对白措辞/场景细节），诚实声明标「拍摄稿」；剧本引文页码可作画面锚点定位（"剧本第 7 页"）。

**②系列官方制作站=制作细节一手主力**：007.com 的 "Focus of the Week" 系列（Eon 官方，`007.com/focus-week-<slug>/`）逐场拆制作，含特技协调员/部门主管原话（地铁战自制滑轨装置 Powell 原话）与拍摄分工（实景由主组+第二组拍、高潮段在松林 007 舞台）——同类大 IP 先查 franchise 官方站（星战/漫威类同构）。

**③导演评论音轨转引=导演原话低成本来源**：SlashFilm 类文章整段转引导演评论音轨（门德斯开篇追逐 11 分钟删减标准 "fetishized the action"、"shot over a number of weeks"），标注「经 SlashFilm 转引」即可当导演自述引用。

**④主流大报深度访谈/报道直连可抓**：Guardian/Observer 直连 curl 成功（门德斯 2012-12 凯特·凯拉韦访谈 482KB HTML、2012-10 范妮莎·索普深度报道 299KB 含克雷格/哈里斯/前军情五处处长 Stella Rimington 引语）——一手。Ebert 影评 rogerebert.com 直连 91KB 成功（与末路狂花轮「jina 域级封禁」记录互补：**先直连再降级，勿因旧记录直接放弃**）。
