# 动漫主题曲歌词研习（Lyric Study）

## When to Use

- 用户要求研究/拆解动漫主题曲歌词（歌词研习、歌词分析、歌词写法规律、OP/ED 怎么写）
- 需要抓取日文歌词原文（UtaTen / j-lyric.net 配方）
- 为动漫风主题曲写词前做范本研究

用途：研究日本动漫 OP/ED 歌词「怎么写」——只拆歌词文本，不拆编曲。产出研习卡：每首歌 ①原文 ②结构 ③主题 ④意象 ⑤宣言句 ⑥代词 ⑦押韵，最后提炼 8-10 条泛用写法规律。输出完整中文 markdown 研习卡并落盘（如 research_arrangement/ 下）。

## 工作流

1. **验证歌曲存在**：歌名先过 web_search 验证（本会话《僕だけの電車》查无此歌，替换为同类经典《君の知らない物語》）。找不到就标注「未验证」，不凭记忆誊写歌词。
2. **抓取原文**：优先 UtaTen / j-lyric.net，配方见 `references/lyrics-site-scraping.md`。抓到后立即备份原文到 `lyrics_raw/`，并记录来源 URL + 抓取日期。
3. **六维拆解**（每首）：
   - ① 歌词原文（标注来源；抓不到标注「未验证」）
   - ② 结构：Aメロ/サビ/B/C 分布，含プリサビ（副歌前转折段）、落ち（单独一行的神句）、英语 hook 段
   - ③ 主题：不写故事，写什么。内核 = 主角最痛 / 最渴望 / 最怕失去的点
   - ④ 意象：是一组可互衍生的意象链还是拼贴；从故事来还是跳出故事
   - ⑤ 宣言句：命令式 / 自誓式 / 定义式 / 祈求式
   - ⑥ 代词：无人称 / 君僕密集 / 私→あなた召唤 / 僕+誰か / 独白错位
   - ⑦ 押韵：语尾重复（て形/た形）、助词尾（よさか）、母音段、锚点词反复、英日双轨
4. **提炼泛用规律** 8-10 条（速查见下），每首歌一节 + 规律总结一节。

## 深度模式（用户要「狠狠研究透彻」时）

六维卡是速览；用户明确要求「透彻研究/狠狠拆解/逐句分析」时，必须升级为深度卡——每首歌 8 节：
①歌词完整原文（标注来源URL+抓取日期）②逐句拆解（**每一句**回答四问：在写什么/为什么这么写/用了什么技巧/这句的感觉是什么；重复段落只拆一次但注明重复；禁止「表达了坚强」式泛泛而谈）③内核（最痛/最渴望/最怕失去）④内核→歌词转化 ⑤有感觉的地方+为什么有感觉（机制）⑥「对抗世界」怎么写 ⑦「为爱」怎么写 ⑧能否用于目标主题+怎么用（含替换要点）。
最后加总结：多首歌共同点/不同点/目标主题写作配方（10条左右）。完整范例与逐句技法库见 `references/deep-line-analysis-4songs.md`。

## 写法规律速查（10 条）

1. **先找内核再写词**：内核=主角最痛/最渴望/最怕失去的点；故事是背景板（青鸟写挣脱飞翔，不写忍者）。
2. **跳出故事三档**：完全跳出（零剧情元素，只留情绪同构）/ 半跳出（意象带故事影子：走马灯、红莲）/ 意象化跳入（设定翻译成意象：死亡回归→坏钟+空圆+Restart）。判断标准：没看过动画也能 100% 感受到情绪。
3. **意象选一组不选一堆**：一组可互衍生的意象链（笼→窗→羽→天），核心意象要能当歌名（紅蓮華/前前前世/残酷な天使）。
4. **宣言句=副歌钉子**：命令式（少年よ神話になれ）/ 自誓式（飛翔いたら戻らないと言って）/ 定义式（真実は残酷だ）；必须可单摘当签名。
5. **代词定人际温度**：燃系无「君」（僕+誰か，守护对象模糊化）、恋爱系君僕密集（前前前世君×17）、宏大叙事私→あなた召唤、单恋用独白错位（我知你不知=戏剧结构）。
6. **押韵押「母音+语尾」**：て形/た形重复、助词尾、锚点词反复（蒼い蒼いあの空×5）；中文可借动词尾/语气词尾，重复本身就是韵。
7. **副歌黄金公式**：宣言 1 句 + 条件/理由 2 句 + 升华 1 句；サビ第一句必须抓耳，尾句必须是金句。
8. **一首歌只写一个情绪转折**（A→B：笼→天空、输→感谢悲伤、暗恋→珍藏）；转折点放桥句或落ち。
9. **英语词当概念钉**：短、名词化、能当口号（Restart / endless dead end）；英语 hook 押真韵，日语段负责叙事情感。
10. **OP 抒情体+宣言，ED 可叙事体**：叙事体靠「た形过去式」句尾天然造韵律（言った/笑った/歩いた）；情绪到顶用短句连发（言わなかった/言えなかった）。

## 陷阱

- utaten.com 的 `/search?q=` 参数会被忽略（永远返回最新歌单）——真实搜索是 `/lyric/search?title=&artist_name=&sort=score`。
- utaten 歌词带 ruby 注音：先删 `<span class="rt">…</span>` 再删标签、转义、折叠空格，否则原文被注音污染。
- j-lyric.net 站内搜索（search.php 带 ex/ct/ca/cl/ops/key 参数）本环境返回空——不要依赖，直接用 web_search `site:j-lyric.net <曲名> <歌手>` 找歌词页 URL（此方式有效）。
- 歌词页 URL 发现捷径：web_search `site:utaten.com <歌手>` 可搜到专辑页 `utaten.com/album/index/<id>`，专辑页列出全部歌曲的 `/lyric/<id>/` 链接。
- 抓取编码用回退链：utf-8 → shift_jis → euc-jp → big5。
