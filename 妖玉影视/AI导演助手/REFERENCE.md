## 1. 剧本解析与节奏拆分

### 1.1 输入格式规范

**标准短剧剧本格式**：
```
第{数字}集
场景{序号} {地点} {时间} {内外}
{角色名}（{情绪/动作}）：{台词}
```

**格式要素**：

| 要素 | 格式 | 可选值 | 示例 |
|------|------|--------|------|
| 集数 | `第N集` | 正整数 | 第1集 |
| 场景 | `场景N 地点 时间 内外` | - | 场景1 王家村 日 内 |
| 时间 | - | 日/夜/晨/昏 | 日=白天，夜=夜晚 |
| 内外 | - | 内/外 | 内=室内，外=室外 |
| 角色对话 | `角色名（情绪）：台词` | - | 张骞（焦急）：婉萍！ |
| 动作描述 | 无冒号的独立行 | - | 张骞急忙跑出去 |

### 1.2 节奏拆分理论框架

**三幕结构比例**：
```
第一幕（25%）建置
  ├─ Hook：开场抓人（前60秒）
  ├─ 催化剂：引发事件（~10%）
  └─ 争议点：无法回头（~12%）

第二幕（50%）对抗
  ├─ Act2a（25%）升级 + 中点反转（~30%）
  └─ Act2b（25%）危机 + 最低点（~50%）

第三幕（25%）解决
  ├─ 黑暗时刻：最终危机（~75%）
  ├─ 高潮：最终对决/选择（~90%）
  └─ 结局：新常态（100%）
```

**斯奈节拍器（15 Beat）**：

| # | Beat | 位置 | 核心功能 |
|---|------|------|----------|
| 1 | Opening Image | 0-60s | 视觉定调、建立世界 |
| 2 | Theme Stated | 前5% | 主题暗示/预告 |
| 3 | Set-Up | 5-10% | 建立"常态" |
| 4 | Catalyst | 10% | 改变发生的事件 |
| 5 | Debate | 10-12% | 犹豫/内心质疑 |
| 6 | Break Into Two | 12% | 决定行动，走向新世界 |
| 7 | B Story | 15% | 副线/感情线引入 |
| 8 | Fun and Games | 15-30% | 展示能力/甜蜜时光 |
| 9 | Midpoint | 30% | 重大转折（伪胜/伪败）|
| 10 | Bad Guys Close In | 30-35% | 压力增大，障碍升级 |
| 11 | All Is Lost | 35% | 最低点/重大打击 |
| 12 | Dark Night of Soul | 35-37% | 反思/内心挣扎 |
| 13 | Break Into Three | 37% | 找到方法/新计划 |
| 14 | Finale | 37-50% | 最终行动 |
| 15 | Final Image | 结尾 | 对比/升华/钩子 |

### 1.4 节奏拆分原则

1. **每节奏必须有明确功能** — 不能出现"过渡而过渡"的无意义节奏
2. **每节奏必须有变化** — 事件/情绪/信息/关系，至少一项在变
3. **时长与功能匹配** — 高潮节奏偏长（20-30s），过渡节奏偏短（8-12s）
4. **情绪不能连续** — 连续两个相同情绪值（差距≤1）需拆分
5. **钩子连续** — 每个节奏结尾留悬念，结尾节奏留续集钩子

## 3. 提示词工程详细规范

### 3.1 核心哲学：写意图、不写细节

Seedance 2.0 自带**世界知识**和**导演思维**，能自己编排分镜、选择镜头语言、控制叙事节奏。

**黄金法则**（来自即梦官方）：
1. **精准不模糊**：使用具体关键词如"暖色调柔光""金属细腻光泽"
2. **组合有逻辑**：按"角色资产+镜头视角+光影色彩+美术材质+时间节奏+听觉音效+叙事结构"顺序
3. **控制长度**：单条提示词50-100字最佳，200字以内
4. **写意图不写细节**：常见知识领域只需描述意图
5. **5%微调法**：效果不佳时仅修改1-2个关键词
6. **单镜头单重点**：每个镜头只描述一个核心动作

### 3.2 短剧快节奏时间轴设计

| 叙事节拍 | 时间段 | 内部镜头数 | 单镜头 |
|---------|--------|-----------|--------|
| 开场钩子 | 0-15秒 | 3-5个 | 2-5秒 |
| 冲突推进 | 15-30秒 | 3-5个 | 2-5秒 |
| 高潮/反转 | 30-45秒 | 3-5个 | 2-5秒 |
| 情绪释放 | 45-60秒 | 2-4个 | 3-6秒 |
| 悬念落版 | 60-75秒 | 2-4个 | 3-6秒 |
| ... | 可延长续拍 | ... | ... |

**视频延长续拍**：
```
将 @视频1 延长15秒
延续前视频的真人短剧写实主义风格：
0-X秒：[新内容描述]，与前视频无缝衔接
【要求】保持角色一致性，动作连贯流畅
【参考】@视频1 原视频，@图片1-4 角色参考
```

### 3.3 @Tag 角色锁定系统

**工作流程**：
1. **生成角色表**：为每个角色生成参考图，建立形象表
2. **@Tag 注册**：为每个角色分配唯一引用标签
3. **锁定使用**：跨镜头引用 @角色名 保持面部和服装一致

**角色表格式**：
```json
{
  "角色名": "张星",
  "参考图": ["characters/zhangxing_01.png"],
  "服装": "灰蓝粗布农家童装",
  "面部特征": "清秀少年，眼神坚毅，黑色短发",
  "体型": "6岁男童，偏瘦",
  "特殊标识": "右耳后三颗黑痣呈三角之势",
  "标签": "@张星"
}
```

### 3.6 音色与语音

> **分阶段策略**：资产阶段用文字描述音色（备案），视频生成阶段用音频文件（MP3）精确锁定，通过 `@音频:角色名` 引用。

**音色五维度**：

| 维度 | 说明 | 可选值/示例 |
|------|------|-----------|
| 性别音调 | 声线高低粗细 | 低沉男中音、清亮女高音、中性温和音 |
| 年龄感 | 音色体现的年龄 | 童声(清脆/稚嫩)、少年音(清亮/变声期)、青年音(饱满/中气足)、中年音(厚重/沙哑)、老年音(苍老/颤音) |
| 语速 | 说话节奏 | 缓慢(紧张/深沉)、正常(对话常态)、偏快(激动/争吵)、急速(恐惧/崩溃) |
| 语气特征 | 情绪和性格烙印 | 冷峻无情、温柔宠溺、嚣张跋扈、阴森诡异、沉稳威严、轻浮轻佻、戏谑调侃、绝望哽咽 |

```
       神力发动态：声音变低沉空灵，自带山谷回音混响。
```

**音频参考使用**（视频阶段）：

```
【音频参考】@音频:林墨 音色样本.mp3，@音频:混混甲 音色样本.mp3
```

> Seedance 2.0 原生支持音视频同步生成（`generate_audio: true`），`audio_files` 参数最多上传3段MP3作为音色参考。
> 
> **音频时长限制**：每段音频样本 / 配音示例台词时长 **≤5秒**（短剧快节奏约束）。资产阶段角色配音示例严格控制在 6-7词/3秒内。

| 固定锁焦 | 镜头不动，画面稳定 | 对话、表演为主 |
| 缓慢推进 | 镜头缓慢向前推进 | 情感聚焦、悬念揭示 |
| 缓慢拉远 | 镜头缓慢向后拉远 | 揭示环境、告别感 |
| 左/右摇 | 镜头水平转动 | 跟随主体、场景扫描 |
| 上/下摇 | 镜头垂直转动 | 展示高度、建筑 |
| 跟拍 | 镜头跟随主体移动 | 行走、追逐 |
| 环绕 | 镜头围绕主体旋转 | 英雄展示、产品展示 |
| 手持晃动 | 手持拍摄自然抖动 | 纪实感、紧张气氛 |
| 航拍/无人机 | 高空俯瞰 | 大场景建立 |

**One-Move Rule**：每个镜头只用一个运镜。

### 3.8 短剧题材风格预设

| 题材 | 主导运镜 | 推荐光线 | 镜头节奏 | 色彩调性 |
|------|---------|---------|---------|---------|
| **复仇类** | 手持晃动+急速推进 | 强烈明暗对比，顶光硬阴影 | 极快切(1-3s) | 冷色调+暗调 |
| **甜宠类** | 缓慢推进+固定 | 黄金时刻，柔光窗光 | 中等(2-4s) | 暖粉柔光 |
| **逆袭类** | 跟拍+环绕 | 轮廓逆光，日出背光 | 前慢后快(2-4s) | 前半暗→后半亮 |
| **悬疑类** | 缓慢摇镜+快切跳跃 | 雾光散射，月光，顶光 | 缓推+快切交替(2-4s) | 低饱和蓝绿 |
| **古装类** | 航拍+推进 | 自然日光，黄金时刻，烛光 | 中速(3-5s) | 古朴素雅 |
| **都市类** | 稳定器+快切 | 霓虹灯，窗光，冷荧光 | 快节奏(2-3s) | 现代冷调 |
| **奇幻类** | 环绕+推进+快切 | 神圣光晕，轮廓光，神光 | 中快(2-4s) | 高饱和特效光 |

**短剧通用强化**：开场3秒内出钩子、无BGM仅人声音效、每集结尾留悬念钩子、9:16竖屏。

结尾悬念类型：对话悬念（"你猜我发现了什么？"）、动作悬念（画面定格）、反转悬念（好人露邪恶笑容）、危机悬念（生命受威胁）。

## 5. 常见问题诊断

### 结构类

| 问题 | 诊断 | 修正 |
|------|------|------|
| 开头拖沓 | 第一幕 > 35% | 删减背景铺垫，直入冲突 |
| 高潮太弱 | 高潮节奏 < 15% | 延长高潮，增加冲突强度 |
| 结尾太急 | 第三幕 < 15% | 增加收尾节奏 |
| 中段断层 | Act2a/Act2b 失衡 | 重新分配节奏 |

### 节奏类

| 问题 | 诊断 | 修正 |
|------|------|------|
| 节奏过碎 | 单节奏 < 5s 连续 | 合并同类节奏 |
| 节奏太平 | 全程对话无事件 | 插入行动/事件节奏 |
| 类型单调 | 连续3个同类型 | 插入过渡/反差节奏 |
| 情绪单调 | 连续3个相同emotion_value | 插入情绪变化 |

### 张力类

| 问题 | 诊断 | 修正 |
|------|------|------|
| 全程高压 | 无舒缓节奏 | 插入"喘息"节奏 |
| 无爆点 | emotion_curve平缓 | 增加情感爆点 |
| 伏笔全丢 | 回收率 < 50% | 补设伏笔 |
| 无钩子 | 节奏结尾平铺直叙 | 增加悬念 |

## 6. 制作流水线

### 阶段1：剧本分析
- 完整阅读剧本，提取人物和场景
- 为每个人物和场景撰写AI生图提示词
- 输出：`script_analysis.md`

### 阶段2：生成参考图
- 使用AI生图功能生成人物和场景参考图
- 确保风格一致性
- 输出：`characters/`、`scenes/`、`asset_list.md`

### 阶段3：分镜设计
- 根据剧本内容设计详细分镜
- 撰写首帧描述和动态描述
- 输出：`storyboard.md`、`scene_index.json`

### 阶段4：生成首帧图片
- 使用图生图功能生成每个分镜的首帧
- 保持人物和场景视觉一致性
- 输出：`frames/`、`scene_index_with_frames.json`

### 阶段5：生成分镜视频
- 使用图生视频功能将首帧转化为视频
- 选择合适的时长和分辨率
- 输出：`clips/`、`clip_list.json`

### 阶段6：合成完整短剧
- 使用ffmpeg拼接所有视频片段
- 可选：添加字幕、背景音乐、转场效果
- 输出：`final_drama.mp4`、`production_report.md`

### 输出目录结构

```
output/
├── analysis/           # 剧本分析报告 + 素材清单
├── characters/         # 人物参考图
├── scenes/            # 场景参考图
├── storyboard/        # 分镜脚本 + 索引
├── frames/            # 分镜首帧图片
├── clips/             # 分镜视频片段 + 清单
├── subtitles.srt      # 字幕文件（可选）
├── bgm.mp3            # 背景音乐（可选）
├── final_drama.mp4    # 最终短剧
└── production_report.md
```
