# Obsidian 图谱颜色分组方案（2026-08-07 重构）

背景：Obsidian 1.13.4 升级清空了全部 colorGroups。重配时用户要求「颗粒度尽可能做细」，按 vault 真实结构重新梳理出 13 组方案。

## Vault 结构数据（分组依据，2026-08-07 实测）

10 个顶层目录、257 个 md。关键事实：

- **剧本库 152 个文件全部无 tag**（剧本原文/研习报告均无 frontmatter tags）→ 必须 path 分组
- 日志 17 个无 tag；项目文件（伏妖记 5 / 犬子无双 7 / 手心人 4）也无 tag
- 有效 tag 只有两簇：`飞书协作`（20 个，成员画像 13 + _hermes 3 + 其他 4）、`工具/妖玉影视skill`（10 个）
- 剧本库内部：华语剧本 49（剧本原文 10 + 研习报告 39）、海外剧本 102（剧本原文 40 + 研习报告 62）

## 13 组配色方案

| 颜色 | 类型 | 查询 | 覆盖 |
|---|---|---|---|
| 🟩 深绿 | path | `path:剧本库/华语剧本/剧本原文` | 10 |
| 🟢 浅绿 | path | `path:剧本库/华语剧本/研习报告` | 39 |
| 🟦 深蓝 | path | `path:剧本库/海外剧本/剧本原文` | 40 |
| 🔵 浅蓝 | path | `path:剧本库/海外剧本/研习报告` | 62 |
| 🔴 红 | path | `path:伏妖记` | 5 |
| 🟠 橙 | path | `path:犬子无双` | 7 |
| 🟣 紫 | path | `path:手心人` | 4 |
| 🟡 黄 | path | `path:工具与集成` | 32 |
| 🟤 棕 | path | `path:技术` | 4 |
| 🩵 青 | path | `path:Hermes运维` | 11 |
| ⚪ 灰 | path | `path:日志` | 17 |
| 🩷 粉 | tag | `tag:#飞书协作` | 20 |
| 白（可选） | path | `path:/` | 根文件 4（MOC/踩坑记录/知识库维护指南/AGENTS.md）|

原则：**path 管大块（无 tag 的剧本库/日志/项目），tag 管关联簇（飞书协作）**。剧本库按 语言×类型 拆 2×2 矩阵，比单一「剧本库」组更有区分度。

## 配置入口

图谱右上角 ⚙️ → 颜色组 → 添加 → 粘贴查询 + 选色。配完别删 `.obsidian/graph.json`——Obsidian 自己保存 UI 配置，agent 不写该文件。

## 恢复可行性判断

旧颜色值不可精确恢复：git 忽略 graph.json、hermes 备份不含 vault、Obsidian 升级无旧版备份。分组清单可从 skill/会话记忆恢复，颜色值只能重选标准色。
