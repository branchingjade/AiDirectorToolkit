## 一、逐节对照摘要

### 1.1 定义谱系（密码"一、"）
密码将悬疑/惊悚/恐怖三分，核心判据"信息差方向"（观众多=悬念/观众少=谜题/相等=共情）。《白夜理发店》可用此框架锁定体验设计：**若观众早于客人知道老周身份→"等何时"悬念**（等每场客人何时识破、老周何时动手），这是该结构的最优解。定义谱系对项目完全可用，但见证伪-3（片内张力切换无指导）。

### 1.2 信息控制（密码"二、"——世界观规则对应）
密码的信息表（时刻×观众/角色A/角色B）反转行"反转|被颠覆|被颠覆|早知道|重估"与项目每场审讯揭底时刻**逐字对应**：客人被颠覆、观众被颠覆、老周早知道。框架命中但见缺口-2/-3（角色维度静态、双案件叠合未覆盖）。

### 1.3 结构范式（密码"三、"七种）
| 范式 | 对照结果 |
|---|---|
| 一 非线性/双线 | 部分适用：二十年前灭门案为天然第二时间线，可作闪回层；但项目核心结构是线性三幕审讯，密码仅以"线性不是错"一句带过（见证伪-4） |
| 二 反套路断裂 | 不适用主体（无主角画外死设计）；其"仪式代替暴力"思想由范式五承接 |
| 三 密闭空间 | **高度命中**：受限视角→镜子镜像；物体人格化→刑具隐喻；视角反转→"凌晨理发店是全世界"（所有关联人聚齐） |
| 四 单场景偷窥 | 部分命中：镜子=偷窥装置、铁证=日常知识（剃刀无需法医鉴定）；但"升级阶梯"假设被项目证伪（见证伪-1） |
| 五 仪式感反派 | **高度命中**：凌晨营业=固定程序（对应"日历"）；三场审讯=布置出来的"作品"；老周开店二十年不跑=主动入局的极端形态（见证伪-2） |
| 六 多视角罗生门 | **高度命中**：三场审讯=三个利己版本（同伙美化/目击者淡化/弟弟复仇）；镜子/剃刀=道具杠杆；凌晨理发店=框架容器 |
| 七 封闭空间氛围 | **高度命中**：理发椅对称+理发师永远站客人背后=控制位几何；洗头→剪发→修面的流程重复=噩梦节奏；**镜子=REDRUM式字谜装置的天然物理载体**（镜像信息观众先见） |

### 1.4 常见坑（密码"四、"）
坑2"反转靠巧合"直接预判本项目最大风险：**三场客人全是关联人**是强巧合，必须设计成老周的布局（如何让二十年后的关联人陆续深夜上门）而非天降——项目合理性命门被密码点名。坑4"解释过度"提示第三场审讯应留白。坑3/坑1/坑5均有对应（见命中清单）。

### 1.5 自检清单（密码"五、"）
10条中8条可直接执行；第8条"视角装置有升级阶梯吗"对项目不适用（项目是镜子拓扑而非肉眼→望远镜→长焦），第5条"主动入局"需扩展第三档（见证伪-2）。

## 三、缺口清单（密码未覆盖、项目暴露的盲区）

| # | 缺口 | 说明 |
|---|---|---|
| G1 | **错位/身份伪装装置（结构级盲区）** | 项目核心引擎"客人以为在修面/相亲/闲聊，实际在被审讯"——场景错位×身份错位，密码七范式无一覆盖此装置；范本库无审讯型悬疑（《利刃出鞘》《看不见的客人》《十二怒汉》式），错位是悬疑大宗子类型 |
| G2 | **流动角色信息表** | 密码信息表为静态三角（观众/A/B）；本项目每场轮换新客人（角色C/D/E入场），知情者池流动，信息表如何按场维护无指导 |
| G3 | **双案件叠合的信息控制** | 小满查母亲失踪案（表层）×二十年前灭门案（深层），两案信息差分层管理密码无覆盖（七范本均单案件核心） |
| G4 | **密闭空间的权力归属维度** | 房间式=受害者被囚禁；闪灵式=空间吞噬主角；本项目第三种：**反派掌控空间、主角自愿走入棋盘**——密码只写了两极 |
| G5 | **视角装置的空间拓扑形态** | 镜子网络让"谁在哪面镜子里看见谁"成为可计算的空间关系（环形视野），非升级阶梯；密码仅假设升级式 |
| G6 | **每场信息差梯度重洗设计** | 三场审讯可设计为谜题→悬念→重估的梯度变化（每场重新洗牌），密码有后窗"12级台阶"单向升级，无"分段重洗"设计指导 |
| G7 | **时间封闭** | 密码论空间封闭（房间/闪灵）不论时间封闭；"营业到凌晨=反转正常时间表"的封闭维度未单独论述 |
| G8 | **刑具隐喻的"反派侧"物体人格化** | 范式三物体人格化基于受害者世界观（房间道具）；本项目把道具人格化用在反派侧（刑具隐喻=审讯布置），权力归属不同，写法应不同 |

## 五、结论评级

**🟡 需补充**（接近✅高可用，但有1个结构级盲区+4处需修正）

- 密码核心骨架（信息差控制/密闭空间/仪式反派/罗生门/自检清单）对项目命中率高，七范式中四个密集命中，直接可用；
- 但**错位/伪装审讯**这一悬疑大宗子类型完全无覆盖（G1），且视角装置（F1）、反派入局（F2）、类型张力（F3）、线性观（F4）四处需要修正或补档；
- 评级依据：🟡而非✅，因为G1是结构级盲区——项目最核心的引擎恰好是密码最空白的区域；🟡而非❌，因为其余章节（尤其信息控制与自检清单）几乎零返工可用。

## 六、最值得回写 3 条

1. **新范式候选：错位审讯（身份伪装×信息差重洗×单场景）**——单场景内连续多场"客人以为做A、实际被审讯"的错位结构：每场换一个关联人+一套日常伪装（修面/相亲/闲聊），信息表按场重洗（谜题→悬念→重估梯度），三版本陈述天然构成罗生门。需补范本：审讯/推理片系（《利刃出鞘》《看不见的客人》式）。回写位置：三、结构范式新增"范式八"。
2. **视角装置双形态修正**——升级阶梯式（后窗：肉眼→望远镜→长焦）与空间拓扑式（理发店：镜子网络"谁看谁"可计算、POV反转内建）并列，均为视角即主题的合法形态。同步改写自检清单第8条。回写位置：范式四+五、自检清单。
3. **反派入局三档修正**——被抓住 → 完成作品后主动现身（七宗罪）→ **持续经营型**（把犯罪日常化为永久经营，等猎物上门；《白夜理发店》老周）。"主动入局"从两档扩为三档，并注明经营型对"时间跨度大+反派存活"型故事更适配。回写位置：范式五。
