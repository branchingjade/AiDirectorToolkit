## 素材命名陷阱

剪映素材原名可能带「第N集 」前缀（如 `第3集 1_美图视频消除.mp4`），这是剪映「导出/另存」自动加的。转换器 asset name 用 `material_name`，复制到 NAS 保留原名——FCPXML name = NAS 文件名 = 媒体池项名三者一致时才自动套底。

## 套底最终方案（2026-08-11 定稿，取代两遍法）

**单遍法**（batch_import_manlv.py 当前实现）：
```
1. 删旧时间线（重名导入失败）
2. 循环清空 01素材/第N集 媒体池项直到 0 项（DeleteClips + sleep(1)，最多 8 轮）
3. SetCurrentFolder(01素材/第N集)   ← 当前夹必须是素材夹
4. ImportTimelineFromFile(fcpxml)   ← 素材不在池 → 达芬奇自动创建到当前夹 + 100% 套底
5. MoveClips(时间线对象, 00时间线)  ← 导入时时间线对象创建在素材夹，必须移走
6. 导入进程内验证套底（打印 N/N）   ← 见下方"跨进程假象"
```

**为什么两遍法被弃用**：第一遍导入后素材夹残留时间线对象（MoveClips 前的状态），第二遍清理不彻底时导入复用旧素材项 → 不套底。单遍法把顺序改成"先删时间线→清空到0→导入→移走对象"，一次到位。

**跨进程假象（本会话最大误导）**：`GetMediaPoolItem()` 在**导入进程之外的进程**查询返回 None。曾因此把全部成功的导入误判为"全套底失败"，全量重导 4 轮（第1/2/3/4次全量 + 逐集跑）才定位。**教训：套底验证必须写在导入脚本内（同进程），外部验证脚本的结果不可信**。批量脚本第6步输出 `导入进程内套底: 37/37` 才是真值。

旧两遍法数据（历史记录）：第4集 1/25 → 25/25；第5集 7/37 → 37/37；第6集 6/51 → 51/51。

## 达芬奇 API 关键事实（21.0.2.4 实测）

- `GetItemListInTrack('video', 1)` 获取片段（`GetItemListInTimeline` 已废弃，返回 None）
- `GetMediaPoolItem()` 返回 None = 未套底
- `GetClipProperty('Type')` 返回**中文**：「时间线」「视频 + 音频」「音频」「视频」
- `MediaPool.RelinkClips([MediaPoolItem], folderPath)` = 移动媒体池项位置，**不是**时间线片段套底（传配对列表返回 False）
- `MoveClips([clip], targetFolder)` 可移动时间线对象（时间线是 Type=时间线 的 clip）
- `MediaPool.DeleteTimelines([tls])` 删时间线；`DeleteClips()` 会连坐删掉 Type=时间线 的对象（清理媒体夹要过滤）
- 帧率取 `GetSetting('timelineFrameRate')`（可能是 30 而非草稿 fps，换算时长别用错）

## 时长验证换算

达芬奇 `GetEndFrame() - GetStartFrame()` 是帧数，秒 = 帧数 ÷ `GetSetting('timelineFrameRate')`。用错帧率会误判时长不一致（本会话 25fps 误判 163s vs 136s，实际 30fps = 136.1s 一致）。

## 2026-08-13 全量重导记录（50fps 定稿落地 + 未闭环问题）

### 背景与已闭环结论

- 用户反馈「从第5集开始后面都重新倒进达芬奇，之前你做的不对」——根因：**转换器漂回 25fps 旧版**（`frame_dur='1/25s'`），5-51 集全是旧版导入带 1 帧间隙；1-4 集是 8-11 定稿 50fps 版所以正确
- 转换器升级：50fps + `secs_to_us_rational()` 微秒有理数（offset/start/duration/sequence duration 全改）、timebase 25→50、删除 25fps 缝合并逻辑、clip_xml 去掉无用 fps 参数
- 第 5 集验证通过：37/37 套底、50.0fps、0 个 1 帧片段、0 主轨间隙
- **片段级帧数 API 实测**：`c.GetStartFrame()` 在达芬奇 21 报 TypeError（NoneType not callable），正确 API 是 `c.GetStart()/c.GetEnd()`（帧）；`tl.GetSetting('timelineFrameRate')` 查时间线帧率
- **草稿目录结构变化**：剪映整理后副本目录合并回主目录（`7 (1)`→`7` 等 7 个），批量脚本 VALID_DIRS 旧名单全部失效 → 5 集 FAIL_CONVERT「草稿不存在」。已修 VALID_DIRS；教训：批量前必须 `os.listdir` 重建名单（坑 25）
