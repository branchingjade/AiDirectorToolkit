# 剧本逐场打磨

对已有剧本（尤其已锁定/已交付的剧本）做逐场深度打磨的迭代工作流。用户发起"打磨剧本""优化每一场戏""考虑有没有其他可能"时使用。

**⚠️ 开工先确认哪条线（2026-08-08 实测，用户纠正"不是杨璇那版"）**：同一项目可能有多条并行剧本线——伏妖记有**电影版主线**（Obsidian 伏妖记-剧本.md，23场 v2.1.x，本 skill 打磨对象）和**飞书杨编精撰审读线**（token Q1tBdNP…，剧集结构，审读 cron 的对象，非同一版）。用户说"继续优化/打磨"时**先确认指哪条线**，别默认拿审读线文档开刀（本会话拉错 _work/fuyaoji/script.md 被纠正）。主文档台账（伏妖记.md「文档权威与同步台账」）会登记所有并行线的 token 和定位——开工前读台账分清"正本 vs 独立线"。

与相邻 skill 的分工：
- `AI电影编剧`（user-owned）：创作引擎——从零到锁定剧本
- `script-review`：审读他人剧本/飞书评论批注
- **本 skill**：自己项目的剧本打磨——逐场三关审查 + 决策留档

## 〇、创作立场：走国人的艺术（特定项目/题材专用，用户拍板）

**适用范围 = 国风/志怪/武侠等中国叙事项目**（如《伏妖记》）——结构语言用中国叙事，不用好莱坞教材术语（用户"建置？这些标题都是之前地垃圾产物吧""要，我们走的是国人的艺术"——西方术语被用户视为垃圾产物，直接否掉）。**非国风题材（西幻/都市/悬疑等）照用三幕结构，不受本节约束**（2026-08-07 用户纠正"走国人的艺术是特定项目/题材"——此前 agent 曾误扩张为"全套件默认约定"被打回）。**教训：用户对单个项目拍板的创作立场，适用范围先确认，不要擅自推广到整个套件。**

| 西方术语（国风项目禁用） | 中国叙事语言（用这个） | 说明 |
|---|---|---|
| 三幕结构 | **起承转合** | 诗论/戏曲骨架；伏妖记实测：起（师父走了，白骨开口）/ 承（花莲的兔子，韩家的祭品）/ 转·合（宫阙里的恨 / 你孤单吗） |
| 第一幕·建置 | **起** | 分段标题用**内容本位命名**（一句话说清这段讲什么），不用抽象结构标签 |
| 第二幕·对抗 | **承** | |
| 第三幕·解决 | **转·合** | 转（高潮反转）+ 合（收束和解）可合一 |
| 节拍 | **拍** | 戏曲用语，拍=一段戏的情绪单元 |
| 抽丝剥茧 / 信息释放链 | **信息一层一层揭开** | |
| 弧光 / 递进 | **用内容说**（"三场打斗一场比一场大"而非"打斗递进"） | 大白话优先 |

**落地纪律**：
- 文档标题/表格分组/时间轴分段全部用起承转合 + 内容命名；剧本头部注明"起承转合（分段见分场分析文档）"
- **镜头可以是电影的（21:9/宽银幕），骨架是国人的**——两者不冲突，也不要互相污染
- 大纲/分场分析/项目文档（飞书正本）三处同步改，不能只改剧本
- **术语重构必须同步飞书正本，mermaid 时间轴是高频漏网点**（伏妖记 08-07 实测：走国人的艺术重构只清了 Obsidian 本地，飞书正本 NSZK 的 mermaid timeline 仍是「三幕结构/第一幕建置/第二幕对抗/第三幕解决」，正文残留弧光/抽丝剥茧/节拍——直到用户抓用词错误才暴露）。grep 残留时飞书侧必须 `docs +fetch --scope full` 拉全文检查，别只查本地就下结论
- **清理边界**（伏妖记 08-07 实测）：活动文档（大纲/分场分析/项目文档）必清；**历史核验文档（复盘/自审报告）保留旧术语原样**——那是当时的记录，改=篡改历史；战斗描述词（"对抗手段"）不是结构术语，保留合法
- **对话回复里同样禁用西方术语**（伏妖记 08-07 实测：agent 回复里写「建置段」被用户当场抓「建置这种不是已经删了吗」）——跟用户说话时分段描述也用起承转合，不是只改文档
- 全文 grep 清理：`三幕\|第一幕\|第二幕\|第三幕\|建置\|对抗\|解决\|节拍\|抽丝剥茧\|弧光\|递进`（"对抗手段"这类战斗描述词不是结构术语，保留合法）
- **根源优先：规则没写进生成引擎 = 项目文档反复复发**（用户"从Skill的根源上解决了吗"，2026-08-07）：项目文档禁词反复出现 ≠ 打磨不够，先查**生成该项目的引擎 skill**（AI电影编剧/AI电影导演）是否带着这条规则——规则只在打磨/审查 skill、引擎还在教三幕，新项目必然复发。修法=改引擎（含共享知识库），不是只清文档。**套件已升级（2026-08-07）**：AI电影编剧 v2.14.2（第二章拆 2A 三幕=通用默认 / 2B 起承转合=国风项目专用）、AI电影导演 v1.3.3（幕→场→段→镜通用，国风项目=部（起/承/转·合）→场→段→镜）、妖玉影视知识库 v1.7.0（〇走国人的艺术铁律章节含适用范围）——新项目按题材选骨架（国风=起承转合，非国风=三幕）；短剧线（9:16 竖屏）的节拍/弧光残留待用户定夺

## 一、逐场三关审查（每场过三关）

| 关 | 问题 | 产出 |
|---|---|---|
| **合理性** | 这场有没有逻辑漏洞？ | 修复项 |
| **精彩度** | 这场够不够好？有没有"该更精彩但没做"的？ | 强化项 |
| **可能性** | 这场还有没有别的做法？当前方案是不是最优？ | 备选方案 |

**第三关是打磨的核心**：每场至少给 2-3 个备选方案，不只改，还要论证"为什么现在的方案赢/输"。

## 二、创作决策留档（用户拍板：放弃独立分支管理文档，2026-08-07）

> **用户拍板「分支管理直接放弃，删掉即可」**（2026-08-07）：不再维护独立的 `XX-分支管理.md`。原因：逐场推敲的决策已在剧本正文落地 + 项目文档（飞书正本）记录，独立留档文档维护成本高、易滞后（本仓库实测：git 有提交但分支管理文档停旧版本，需补录），价值不抵成本。
>
> **替代**：决策要点（用户拍板原话/方案对比/连锁影响）直接写进**项目文档**（飞书正本）的决策区或 **复盘**（Obsidian），不再单开分支管理文档。剧本打磨流程（三关审查/备选方案论证）照常，只是决策产出不再单独归档。

## 三、打磨技术库（实战验证的修复模式）

### 0. 戏量诊断：重点不是数据，是创作质量（用户拍板"重点不是数据，是剧本的创作质量"）

用户质疑"X场就想撑起一部电影？"时，**不要用场次数/时长数据论证戏量**（本会话教训：数了范本场次 19 vs 100-406、算了每分钟时长，用户直接否掉"重点不是数据"）。范本场次数是误导指标——罗生门406场是分镜式切分，饮食男女152场是动作节拍，它们好是因为**戏写满了**，不是场次堆出来的。

**正确诊断法**：逐场读戏，找"该重的戏写轻了"——情感/冲突节点被压缩成流水账的位置：

| 病灶 | 特征 | 例 |
|---|---|---|
| **情感核心仓促** | 中段情感主角的死亡/爆发只有30-40行 | 第14场莲儿之死38行（打斗流水账，无死前时刻） |
| **转折缺铺垫** | 黑化/背叛在3分钟内完成 | 第13场莲儿黑化一场带过 |
| **遭遇靠对白** | 该演的画面用台词说了（见§五.8①） | 镜妖遭遇在第17场已用画面演过 |
| **反派存在感弱** | 中段boss只有画外音/台词设定 | 镜妖第12场水面蛊惑只5句画外音 |

**修复方向**：不是"加场次"，是**把该重的戏写透**（恩情立住/黑化两段/死前时刻/反派交锋）。扩场只在"该重没重"的位置扩，前10场节奏正常就不动。

**一锅炖拆场模式**（第18场296行→5场实测）：单场塞 8 个高潮节点（吞丹/身份揭示/渡妖力/反杀/师傅黄光/封印/你孤单吗/由妒生恨）时，**拆场≠加戏**，是**按戏剧节拍切分**（内容零删减）——每场一个节拍、一个情绪：破封/逼问/渡妖力/反杀/你孤单吗。拆场后每场 15-25 行（对齐范本短场节奏），观众情绪不被连续高潮冲击；地点变化同步改（宫阙内→宫阙内→废墟外，内外/地点随节拍走）。拆场是"戏量诊断"的配套修复——先诊断"该重的写轻了"，再处理"一锅炖"。

### 0.5 "说了"变"演了"手术模式（中段情感线通用，第10-15场实测）

中段情感线塌陷的共性是"**说了**没**演了**"——角色的挣扎/抉择靠内心独白或旁白解说，没有外在动作/画面承载。四个具体手术：

| 病灶 | 手术 | 例（《伏妖记》第10-15场） |
|---|---|---|
| **内心独白纠结** | 换成**画面闪现**——角色闭眼/抬头看到的关键记忆画面，让"选择"有具象锚 | 第12场莲儿偷丹：删"她伸出手，又缩回来"→"再睁开时，眼前是庙门口的石阶，一只白兔被拎起来，砸下去，血溅在青石板上。花莲的脸。花莲的叫声。" |
| **反派单向灌输** | 改成**交锋**——对方反驳→反派用软肋接住→对方动摇（七宗罪卡片02机关） | 第12场镜妖蛊惑：莲儿"他救过我"→镜妖"花莲也救过你"→莲儿被掐住喉咙→"你拎得清吗？" |
| **被控制堕落** | 改成**清醒堕落**——保留主体性（"被迷"削弱悲剧，"知道是错的还是做了"才是悲剧） | 第13场：删"有人在我脑子里说话"（被控制）→"我眼前全是花莲姐姐……我控制不住，我一闭上眼就是她"（恨意放大） |
| **死亡仓促** | 加**死前时刻**——死法对称点破+死前清醒+道具细节回收 | 第14场：莲儿死在"和花莲死的地方是同一块石头"（第9场闪回回收）；死前喊花莲；"她偷了它。可她到死，也没吃"（回收第12场清醒偷丹） |

**核心**：每个手术都把"角色内心的纠结"翻译成**可拍的画面/可交锋的对白**——观众看到挣扎，不是听到解说。做完检查前后场衔接（第14场定格"抱着她"后，第15场不能重复"走过去抱起她"——从定格动作直接进入）。

场景间"角色怎么从 A 到 B"没交代（如配角扑向反派送死，下个场景却活着照顾主角）。**不要新增设定**，看已有规则能否延伸：

- 例：反派"香火=命"规则 → 延伸为**香火范围限制**（出庙门一炷香都撑不过）——逃脱从"编剧偷懒"变"规则驱动"
- 反哺检查：新限制是否给后续场次提供逻辑必然（例：反派出不来→配角只能进庙→"自投罗网"有了动机）

### 2. 矛盾设定 → 统一为双保险机制（H4 模式）

同一反派台词前后矛盾（如"丹锁着我" vs "我是人是锁"）。**不要二选一删掉一个**，看能否统一为互补机制：

- 例：丹=镇石（镇她的力，力量层）+ 我是人=锁（锁她的印，认知层）——双保险
- 连锁验证：统一后检查后续场次是否自然成立（例：反派抢丹→"你身上还剩下什么"更有底气；主角认妖→锁破；丹从"镇妖工具"变"护人武器"——主题升华自然发生，不需改台词）

### 3. 认知链递进（G3 模式）

真相揭示要层层递进，每层比前一层更接近主角自认：

```
反派视角确认（"他根本不是人！"）→ 反派临死点破（"你真的是妖——"）→ 镜妖逼认（"你是妖"）→ 主角自认（"我是妖。我认。"）
```

- 每层由不同角色/不同场景承担，观众和主角同步逼近真相
- 时序自洽检查：反派确认真相时主角不在场（他没听到）——他知道但带着秘密死去，主角还不知道

### 4. 信息差感动（G4 模式）

恩情/伏笔不点破，用轻暗示+结尾台词触发回看：

- 例：花莲的灵光"像在找什么→落下去，慢慢融进她眉心"（不写"这是花莲"）→ 配角临死喊"花莲姐姐……我替你讨到公道了"触发观众回看
- 信息差 = 感动：角色以为是自己的最后一口气，观众知道是花莲借给她的——角色不知道恩人刚护过她
- 轻暗示写法：用动作不用身份（"像在找什么"），留给观众自行连接
- **画面伏笔要强化到可对应前场具体动作**（第15-16场实测升级）：光里只写"像在找什么"太抽象，观众揭晓时回想不起来——改成**复用前场的具体动作画面**（"光里隐约有一道少女的影子，蹲着，像在给什么包扎"=第9场闪回花莲给白兔包扎的画面）——观众看到灵光时先疑惑（这影子是谁？），第16场莲儿说"是花莲姐姐的"时瞬间"啊"一声闭环
- **恩情闭环=同一恩人救两次**（生前+死后）：花莲生前救莲儿（包扎/取名）→ 死后18年灵光仍护着她（送她回来还丹）→ 莲儿死前喊"花莲姐姐，我替你讨到公道了"——恩情线从头到尾闭环，且"最亮的那道灵光"（第15场）事后看有了含义（她的爱最深）

### 5. 连锁修复检查（每次改动的必做项）

**修一处必须验证前后场连锁**：
- 新增限制 → 检查它反哺哪场（第11场香火限制 → 第14场进庙动机）
- 改台词 → 检查同角色其他场次的认知是否一致（第14场黑土妖知道真相 → 第15场临死台词接上）
- 改道具位置 → 检查所有涉及该道具的场次（丹：体内→怀里→被抢→夺回）
- **改设定 → grep 全局旧概念残留**（本次"心头血"改"十指连心"，大纲/分场分析/自审报告 3 文档残留全清）
- **改名/删道具 → grep 全部项目文档，不只剧本**（两案例：①黑土妖→山神，剧本正文 39 处清了，但分场分析还有 16 处、大纲 12 处残留；②v2.1.2 删烟袋/道髻——剧本+飞书正本已干净，但 Obsidian 侧主文档外形、分场分析埋点、分场分析锚点表 3 处残留；③分支管理文档废弃后，分场分析里的「（分支管理F-1）」编号标注要中性化为「（决策F-1）」——避免指向已删文档；④**正名批次漏飞书正本（黑土妖→山神，2026-08-07）**：正名时只清了剧本+Obsidian，飞书正本 NSZK 漏 12 处（概述/莲儿小传/大纲表格 3 格/打斗表/山神标题/妖有善恶 code——直到多轮审视才暴露）。**正名/改名批次收尾时，飞书正本必须单独 `docs +fetch --scope full` grep 旧名**——两侧分别 grep 是双向的：Obsidian 干净 ≠ 飞书干净）。**残留检查面 = 剧本正文+主文档+分场分析+大纲+自审报告 五文档 + 飞书正本**，每个都要 grep 旧名+旧形象词（半人半山/那团黑/黑山/烟袋/道髻）。**飞书正本干净 ≠ Obsidian 归档干净——两侧分别 grep**，别只查一侧就下结论

### 6. 声明的真实性核验

**审查记录声称"已修复"的内容，必须回到剧本验证真的落地**（本会话教训：分场分析写"独白拆成动作+台词交替"，剧本实际还是整段独白——声明与事实不符）。每轮修复后抽查 grep 关键句确认落盘。

**伏笔链逐环核对**（2026-08-07 伏妖记胸口闷链实测）：分支管理声称的伏笔回收点必须 grep 剧本逐环验证，两个断层形态：
- **声称的回收点不存在**：分支管理写"第17场镜妖点破'靠近妖气心口会闷'"——grep 剧本 0 命中。判断"该补还是不该补"：胸口闷的叙事功能是 L1 身世悬念（"我体内有东西"），回收已被第15场金光爆发+第17场"你身上那颗丹，是钥匙"（L4/L5）覆盖——**功能已被更高层信息覆盖就不补，避免重复点破**
- **机制与角色身份全局冲突（致命，用户拍板删除）**：补伏笔链时只查"回收点存在"不够，还要验证**机制在整部戏所有相关场景全局成立**——尤其角色职业/身份日常。实测教训：我按"丹排斥妖气→靠近妖就闷"补了第3/6/7场三处闷（还自以为做了"链中缺环修复"），被用户纠正"陆青山还是除妖师，你这样的设定，第一场戏的时候就该有反映了"——第1场他就在除树妖（直面妖气）、第11场进山神庙（妖气冲天），都没闷。除妖师天天跟妖打交道，靠近妖气就闷=身份崩。**拍板 C 删除胸口闷**，L1 改用既有载体：血能救妖（第8场）+画符总烧（第3场，观众以为他笨，第15场金光爆发才明白不是笨）。教训：**给角色加身体异常机制前，先列该机制会触发的所有场景（含角色职业日常/同类妖/同场景），任何一处不触发=机制不成立或需收紧触发条件**（如只对妖骨/残骸触发、触碰才触发）；补链前 grep 该机制相关词在全文的出现位置做全局一致性检查，别只看目标场次。**修复也要验证"修复本身"**——我补的"碰骨闷+他没退"后来随整个机制一起被删，前期"补链"工作全白做

**核验方法**：grep 伏笔关键词（胸口/闷）列出全部出现行，对照"预期链"逐环标"此环有没有"——声称存在和声称不存在都要验。

### 7. 终稿文笔打磨模式（结构已稳后的纯文笔层）

逻辑/结构修复完成后，还有一层**文笔打磨**——不动结构，只动句子。逐项 grep 扫描以下病灶（《伏妖记》终稿一轮清 11 处）：

| 病灶 | 写法 | 改法 |
|---|---|---|
| 叙事提前 | "他已经出手了。三张符甩出去…" | 删预判，动作直接进画面："甩出三张符…" |
| 动作逻辑断裂 | "烟袋往草丛一指——烟袋在嘴边停了停"（烟袋刚指出去，又回嘴边？） | 动作连贯："手在半空顿了顿" |
| 物品质感动词 | "像是有什么东西看了他一眼" | 换成物本体能做的动作："睁开了眼" |
| 叙事者提问 | "那火苗，是从哪里亮的？" | 改纯可见，让观众自己问："灯早灭了，屋里没有火" |
| 副词冗余 | "疯狂地往前挤" | 删副词，动作本身已表达 |
| 重复动作 | 同角色同动作两场重复（"张了张嘴又咽回去"×2） | 去重或换动作（"没接话"）——**但保留一处可成母题** |
| 跨场同义句 | 同一句意思在不同场重复（"你比你师父运气好"（第17场） vs "你比我有福气"（第18场）——同义句说两遍） | **删后句留前句**（第17场"运气好"更有力=她承认自己命不好），后场的同义由**动作/触发物**承担（见§三.10 情绪转折触发物） |
| 主题词堆积 | 核心词（如"信"）在一场内出现 17 次，堆积到麻木 | 删冗余句，让最高点只在关键处出现一次（"信"的最高点=渡妖力"我也把信给你"）；剩余分布全部是剧情核心（我信他/她信我/信来信去/他是信的）则保留 |
| 道具动作去重 | 同一道具的微动作三次（叶子"颤了一下/又颤/探出来"） | 只留**有功能**的两处：一处=角色感知（他蹲下看她，她颤=感觉到他回来），结尾一处=恢复/变化的开始（探出来认路）；中间无功能的删掉（她在睡，不需要每句都有反应） |
| 冗余括注 | "（最后一句，声音几乎听不见）" | 删"最后一句"，声音标注已够 |
| 矛盾句 | "屋里和走时一样——空了" | 删矛盾半句，直接给事实 |
| 叙事者解读 | "声音里有一种说不清的东西" / "这句话和她说过的所有话都不一样" | 删，让停顿/节奏自己表达 |
| 认知缺环 | 反派认出某物却无依据（"谁的丹？"） | 补辨认节拍（"这丹上，是那个伏妖师的血气"——呼应前场"你血里有东西"） |
| 新概念无铺垫 | 全库仅一次出现的专有名词/机制词（"香火甲"只在第15场出现，第11场山神战斗从没提过，观众困惑"香火甲是什么"） | 换成已有概念词（"香火甲"→"香灰"——与第11场"香灰凝形"同源），不引入新名词；grep 该词全库出现次数，1 次且无铺垫=候选替换 |
| 光源矛盾 | 场景主光已定义却出现与主光冲突的光源词（第8场救白骨：开场"月光从窗缝斜进来"为主光，第4场还立过"灯早灭了"，却写"他在**灯下**咬破指尖"） | 删冲突光源词（"他在灯下咬破指尖"→"他咬破指尖"）——月光下救妖的画面也更净；grep 该场的光源词（灯/烛/月光/火）与场景定义的主光对照 |
| 主语歧义 | "他走到门口，停了停，回头"紧接另一角色台词（读者误读为上一说话人，实际是别的角色——第5场实测：紧接陆青山台词，实为师父） | 明确角色名（"陆老邪走到门口"）+ 拆句分镜（"他看了很久。" / "陆青山站在屋里，没动。"分行给镜头切换留停顿） |
| 称呼语域不稳定 | 角色称呼全片仅出现一次且与后期感情线冲突（小白"老骗子"只在第3场，第20场喊"他是我师父！他给我饼吃！"——早期草案残留感） | grep 该称呼全片出现次数；单次出现=语域不稳，列为候选改动点。改动前给方案对比让用户拍板（保留=喜剧调节阀/改称呼=去"骗"指控/删=零跟脚），不擅自改台词。**用户拍板的改法=称呼弧线呼应（伏妖记 08-07）**：改"老骗子"→"老头儿"（不是"老头子"——用户嫌不好，倾向"老头儿/老家伙"类），让第3场没大没小的"老头儿"与第20场郑重喊"他是我师父！"形成称呼转变=对师父感情的弧线——改称呼时优先选能与后场郑重称呼呼应成弧线的方案 |

**母题化技巧**：删重复时不要全删——同动作第二次出现时改掉，第一次保留，反而形成"重复即弧光"（例：师父"烟袋在嘴边停了停"=每次做决定都停烟袋，成为人物母题）。打磨时留意"删掉后留下的一处是否恰好成为母题"，是白捡的收获。

### 8. 剧本去 AI 味判定标准（用户两次纠正后确立：大纲"AI感重"→剧本"AI味很重"）

用户对 AI 味零容忍，且判定标准明确。打磨剧本正文时逐项 grep 扫描，**只清 AI 味，不误伤电影语言**：

| 病症 | 例 | 改法 |
|---|---|---|
| 叙事者解读心理 | "他明白了：香火是它的命""她自己没察觉""像是问黑土妖，又像是问自己" | 删或行为化（对白/动作承载判断） |
| "不是X，是Y"句式（正文） | "他看的不是陆青山——是白骨""她不是妖的狰狞，是一张人的脸" | 删否定半句，直接给事实："他看的，是那副白骨" |
| 效果预判 | "疼得倒吸一口气""吓得往后缩""吓傻了" | 删程度标签，动作自己说话："倒吸一口气""往后缩" |
| 括注解读 | "（盯着丹，像在辨认什么）" | 换可拍动作："（凑近那颗丹，停住）" |

**grep 扫描模式**：`不是.*是.*` / `他明白了|没察觉|觉得|像是问|以为|知道` / `疼得|吓得|怕得|吓傻` / `像在找什么|像在辨认|像在.*什么`。

**刻意保留（不是 AI 味，误删伤剧本）**：
- **画面比喻**："像烧焦的树瘤""像落进干涸的河床""像一场倒着下的流星雨"——电影语言，可拍
- **重复即弧光母题**：孽徒/带着吧/看家/我是妖——设计过的重复，第9轮自审确认
- **对白金句**："他不是算好的。他是信的。"（"不是X是Y"句式但对白成立）
- **角色台词里的"不知道"**——对白是角色语言，不是叙事者解读
- **形态自洽检查**：改括注时核对角色形态（黑土妖无五官→不能"嗅"，改"停住"）

### 9. 知识库驱动创作——重场戏写之前先查库（用户追问"知识库能否让故事更好"后确立）

用户会直接问"挖的知识库到底有没有正向作用？""知识库没法让故事更好吗？"——答案是：**知识库能让故事更好，前提是"写之前查"不是"写之后审"**。若只把知识库当审查清单（写完对照），它永远只起防错作用；要让它增值，重场戏/重大决策**动手前**先查对应知识源：

| 决策类型 | 查什么 | 例 |
|---|---|---|
| 精彩度（重场戏写法） | 大师技法卡片（references/大师技法卡片/） | 第17场镜妖过往披露→查聊斋《画皮》卡片 |
| 可能性（题材机制） | 题材密码（references/题材密码/） | 时代切换→查志怪密码"机制层/皮肤层解耦" |
| 合理性（自检项） | 自审清单/验收层 | 新增世界观规则→查"规则立而未用"坑 |

**实证（《伏妖记》第17场镜妖过往披露段，查库前后对比）**——从聊斋技法卡片拿到可执行的招式：

- **画皮"同镜反转"三拍**（聊斋卡片4：偷窥视角→同镜头变形→复位）：
  1. 偷窥视角：平铺"宫阙里多了两个人影"→ 改为小白"缩到身后又忍不住探头"（观众视角=又怕又忍不住看的孩子）
  2. 同镜头变形：梳头"一下，一下，梳得很慢"→ 手滑到后颈→"那只手刚刚还在给她梳头。它忽然收紧，掐了进去"——**梳头的手=夺丹的手**（恶伪装成爱，同镜头完成，不切走）
  3. 复位拍（画皮最狠的一招）：变形后复位到美——"一张美人脸……她刚才给陆青山看的那只手，垂在身侧，指尖还在微微地蜷着"，让观众带着真相重新看她的美。**"指尖还在微微地蜷着"是查库带来的最大升级**——原版披露完就切走，情绪落地；现在那只手悬在空气里，观众会想：她是不是也在想掐他？
- **"投时好"**（聊斋《聂小倩》卡片2：恶=欲望镜像）：老道养她不为情，为等她长大丹成——"你猜他图的什么"是欲望索引
- **镜像对照**（妖猫传"执念即妖"卡片）：披露后加一刀——"你师父给你梳头的样子，和我师傅给我梳头的样子，像不像？"把刀转向主角（注意：这句是**故意的悬空**——反派不知道主角师父怎么养他，她用自己经历的形状去套他，这正是黑化的攻击手段，不是bug）

**核心教训**：大师技法是具体的招式（三拍结构/同镜头/复位），不是"写好看点"这种空话——查库一次（读2-3个文件）能直接让一段从"平铺直叙"变"三重反转+悬空余韵"。流程修正：**合理性查自审清单，精彩度查大师技法卡片，可能性查题材密码**。查库是创作动作的一部分，不是事后审计。

**补充实证（《伏妖记》11 轮验证中的另外两处落地）**：
- **声轨缺席**（罗生门卡片，第9场闪回）：闪回段标记"无音乐，只有水声和风声"——与第17场镜妖过往（配乐，她给自己记忆上的妆）形成声画对位：**莲儿的真相=静音，镜妖的记忆=配乐**。真相段静音处理（只留环境声），把音乐提示写进正文（"无音乐，只有……"），导演/作曲拿到明确的立场标记
- **克制美学**（悲情城市卡片4"连失去都是平和的"，第16场莲儿消散）：戏剧化标签"放声大哭"→具体的、孩子气的哭法"哭得直打嗝：兔子姐姐……你还没告诉我……你耳朵能不能变出来"——孩子的悲伤不懂死亡，只懂没说完的话，比大哭更疼，还顺手回收前场"你耳朵呢"的伏笔

**知识库先行验证法**（用户要求"多验证几轮，这很重要"时的方法论）：
- 选**不同场景类型**的重场戏各验证一轮（情感最高点/闪回/尾声/开场/打斗/心理战/留白……），每轮走"查库→对照落地"全流程
- **查库后两种结论都有效**：发现可优化点就落地（如情感交付方式/声轨策略），确认已达标就留档（"查库后确认已达标"同样是流程有效的证据，不是每场都要改——避免为用技法而堆技法）
- 每轮记录：查了哪张卡片/卡片给什么技法/落没落地/为什么。验证后把"查库前后对比"写回复盘——这是"知识库到底有没有正向作用"这个问题的最有力回答
- 发布 skill 升级前先过一轮"多场景类型验证"（覆盖检索表 9 类场景类型中的大多数），验证结论写入 CHANGELOG 作为发布背书

### 9.5 用知识库过项目（审视已完成剧本，用户"用知识库过伏妖记"实测 2026-08-07）

与 §三.9"写之前查库"方向相反的另一类任务：用户发起"用知识库过X"=**用知识库系统审视已完成剧本/项目文档**，验证招式落地密度+抓遗漏。流程：

1. **题材密码自检清单逐项 grep 实证**（不凭印象）：加载对应题材密码（志怪→志怪题材密码.md），把自检清单每项翻译成 grep 词跑剧本——三界规则/异类质感/人异情感/收=主题/三调性/借异类说人 全查
2. **核心招式速查表命中抽查**：从 SKILL.md 速查表挑与项目场景匹配的招式（异类出场/同镜反转/最轻动作/执念即妖/声轨缺席/四段弧/重复场景变奏/道具即叙事引擎…），每条给代表元素 grep 剧本
3. **导演美学卡片对照**：按项目题材选导演（国风志怪→胡金铨封闭空间群戏/徐克金碧奇观/王家卫暗线时间三极对照），检查场景设计/打斗/结局是否吃到对应手法
4. **产出双向**：真 bug 修复 + 确认命中密度 + 新招式回写知识库速查表（§八"知识库招式提取"）——用户问"知识库呢"就是这个闭环的另一半

**⚠️ grep 抽象招式词选错 = 误判高发（本会话 3 次）**：知识库招式词是抽象层（"妖是照妖镜""封回铜镜""树妖=哨兵"），剧本是具体层（"各取所需""落回铜镜""竹林那棵树，我放在山口三百年"）——**grep 抽象词 0 命中 ≠ 缺失**。判定缺失前先：①搜该招式的"实质表达"变体（同一意思的剧本原话）；②看剧本有没有用动作/台词承载该功能而非原词。误判会浪费时间重查+可能误改。**检查法：先 grep 剧本里与招式相关的具体台词/动作词，再下"缺失"结论**。

**高完成度剧本的审视预期 = 全维度命中 + 少数"该更精彩但没做"层缺口（2026-08-07 伏妖记 v2.1.3 用知识库过项目实测）**：20 轮打磨后的锁定剧本用知识库系统过一遍，正确预期是**大部分维度全绿**（志怪密码 8 大项/核心招式 10 组/文笔 8 类病灶全命中）——**全绿不是白干，是"确认已达标"同样有效**（§三.9 查库后两种结论都有效）。三关扫描仍能抓到的真缺口类型：
- **只存在于闪回/转述的线 = 断了**（grep 某角色/线索全部出现位置，若全是闪回+转述、无现形戏、且其恶行无后果，就是断线）——伏妖记案例：韩家老爷（体面的恶）3 处全在第9场闪回+第11场转述，观众全程没见过他本人，山神死后他**无任何后果**（人的恶线断了——志怪密码"借异类说人"的极致是画皮"妖是照妖镜：人在骗自己"）
- **断线修复三方案（人形恶收尾 · 伏妖记韩老爷 2026-08-08 实测）**：判定"人的恶"断线后，收尾三方案——①**后果落人间（推荐，零加戏）**：妖死同一刻补一个镜头/一拍（山神被碾碎时，韩家宅院方向村民的喊声、绸衫被拖出来、拢袖的手终于沾血）——妖=贪念的具象，妖碎=贪念碎，体面的恶被撕破体面；判据"妖的恶被除了，人的恶被放过了=借异类说人只做了一半"，方案①补后半。②**现形戏（中改动，伏妖记用户拍板选此）**：中段给半场现在时戏，恶从转述变实体，衔接主角情绪点燃物（如莲儿失控的动机）；代价=加戏1-2分钟+连锁检查（台词与闪回一致/插入位置节奏）。③**对白交代（会被打回）**：借角色台词说后果（"庙塌时他被梁压死了"）=说了没演了，违反 show-don't-tell 纪律。⚠️ **陷阱**：文档拍"不现身/不展开支线"（克制性决策）≠"无后果"——克制决策会悄悄退化成无后果=断线；审文档时两者分开判断，克制可以有，但恶行必须有着落。**B方案落地要点（2026-08-08 第13场实测）**：①形象三件套逐字一致（绸衫/圆脸/拢袖/「声音很轻，甚至有些和气」——与闪回逐字对照，观众认得出是同一个恶）；②**恶的日常化=送人已成 routine**（新祭品穿粗布衣裳=连嫁衣都不给了，"你爹欠的，就该你还""抬轿子的，多备一顶"=送死像办差事）——日常化的恶比一次性献祭更瘆人；③主角点破「他是人。你想在村口动手？」=体面的恶=人的恶，伏妖师除不了（借异类说人的刀：妖的恶能除，人的恶就在眼前却除不了）；④**复仇从人转向神**（「他送过花莲。他现在，还在送」→「他是人。我杀不了他。可庙里那个，是他的神。神没了，看他还拿什么送人」）——杀不了人，就杀他的靠山=釜底抽薪，同时给韩老爷后果预告（留白观众可推）；⑤顺手修同场已知缺口（"镜妖在作祟"删=清醒堕落不被外力解释/「像换了一个人」删=AI味/孩子玩石子改"嗒，嗒"声音触发闪回=听觉锚）
- **"X在作祟"表述回退"被控制"框架**（清醒堕落已成立时，一句"是镜妖在作祟"削弱角色主体性——清醒堕落比被控制更悲剧，见§0.5）
- 审视结论汇报格式：**三关分类（合理性/精彩度/可能性）+ 真 bug 直接修 / 强化项给方案对比让用户拍板**——加戏/改台词等创作决策先呈现发现让用户选，不擅自改

### 10. 情绪转折触发物——软→狠/动摇→决绝必须有物理触发（第18场实测）

反派（或角色）在同一场内从"露软"转到"变狠"时，**不能靠抽象写法**（"眼里最后一点温度，灭了"被否——这是叙事者解读，观众看不见）。转折必须有**一个具体的物理触发物**——角色看见/触到某个物件，情绪被点燃：

- 例（镜妖 软→狠）：她说"你比我有福气"（软）→ **看见陆青山手背的灼印**——"被护过的印记。她抬手，看着自己的手。空空的。没有疤，没有印，什么都没有。" → 声音才冷下来（"连本带利收回来"）
- **原理**：灼印=他被护过的证据（他有），她的手空空的（她没有）——**嫉妒在具体的物件上被点燃**，观众看到了"为什么变狠"，而不是被告知"她狠了"
- **触发物要回收全片母题**：灼印是第2场诞生的母题，这里用它当转折触发物=母题在反派视角的回收
- **写法模板**：角色（看见物件）→ 物件带一个"被护/被爱/被选择的证据"属性 → 角色对照自己（我没有）→ 情绪转变。对照动作（抬手看自己的手/空空的）比任何台词都狠

### 11. 机制用足模式——世界观机制不能只给不用（用户"设计了镜中世界不知道用吗"）

世界观里设计了独特机制（镜像=记忆投影/规则=命/媒介=反光面），**不能只在"介绍机制"的场次出现一次就闲置**——机制必须在情感最高点被"用足"。给机制（第17场她抬手造人影=记忆投影）→ 用机制（第22场由妒生恨段）：

- **倒影重演**：废墟断壁的水洼/碎镜/瓦砾反光里，十八年前"梳头→收紧→掐死→笑凝固"一遍遍重演（=记忆投影机制在情感高点复用）
- **反着用**："她没有看那些倒影。她看着那道黄光。"——过去在周围炸裂，眼睛在看别人的光（恨与渴望同框，比任何对白都狠）
- **情感有物理落点**：说完"没有人为我点过一盏灯"，所有倒影同一瞬间碎了——恨碎了，她才甘愿被封印（情绪转折挂靠在可视画面上）
- **只重演"被杀"不重演"反杀"**——她的恨来自被杀，不是杀人（画面内容精确对位情感内核）
- 自检法：grep 该机制的介绍场次，问"机制在后续哪场被复用/被用足？"——答不上来就是"规则立而未用"

### 12. 道具时态终检——道具离体后不能再"在体内"（第23场丹时态漏洞）

道具轨迹检查的**时态维度**（§五.4 已有轨迹链，这里补案例）：道具离开载体后，后续场次台词/动作不能仍按"还在"写。例：第22场"镜妖连同那颗青色的丹，一起落回铜镜"（丹随封印回镜，主角亲眼看到）→ 第23场原句"我体内，有颗丹"（现在时）——**矛盾**。改"那颗丹……是我娘渡给我的"（过去式+求证语气——他知道丹是娘渡的（第17场镜妖说的），想听师父亲口确认，比原句还多一层情感）。

**检查法**：列道具轨迹（渡入→被偷→物归原主→被夺→吞入回镜），对每一态 grep 所有涉及该道具的台词，逐个标"此句发生时道具在哪"——时态/位置不一致就是漏洞。全篇检查时区分"现在时/过去时"（第12-17场"体内有丹"都发生在第22场丹回镜之前=合法；第23场在回镜之后说"体内有"=漏洞）。

**两个补充案例（2026-08-07 深推敲实测）**：
- **第20场认妖金句"我体内有她的丹"**——第18场镜妖**当着男主的面**吞下丹（"镜妖吞下那颗丹"），第20场还说"我体内有她的丹"=时态错误。改"我娘是大妖——我是妖"（身份=娘是大妖，力量=关系——与第21场"你的丹在我手里！你拿什么赢我！→拿她信我"呼应：丹被夺，他赢靠的是信不是丹，主题还升华了）。检查法：**角色亲历的事件（眼睁睁看丹被吞）不能让角色后续台词当没发生**
- **"心口那团青光"→"体内"（防观众视觉误读）**：第12场丹从**心口**浮出是青光（观众记住了"心口=丹的位置+青光=丹的颜色"）→ 第20场丹已被吞，但写"他心口那团温热的青光"会让观众误以为丹还在体内。改"他体内那团温热的青光"——位置词从"心口"（丹的专属位置）改为"体内"（泛指半妖血脉的妖力，第21场"青色的妖力"确立青光=妖力）。**道具时态检查要延伸到"观众记忆"维度：道具位置词/颜色词会被观众当锚点，道具离体后同类描写要避开原位置/原颜色**

### 13. 武器库=依赖外物的具象化（角色成长弧线，2026-08-07 符箓系统实测）

能力弱的角色（学艺不精/画符总废）在故事中段需要战斗手段时，**给他一个\"武器库\"并把成长弧线挂在上面**——武器=外物依赖的具象化，成长=从依赖外物到信任自己。与身份觉醒线同构（伏妖记：依赖师父的符 → 血符转折 → \"我是妖。我认\"后不再依赖）。

**设计要点（伏妖记符箓系统实测）**：

| 要素 | 做法 | 例 |
|---|---|---|
| **武器来源≠正式交付** | 不是长辈郑重给（师父下山和主角出发不同时，给不了），用**偷拿/翻找存货**——喜剧调节阀+来源交代一次解决，还延续角色既有行为模式 | 小白第4场翻屋找吃的翻出铜镜（人设已立）→ 第9场带男主翻杂物间/床底拿走师父攒的一包袱符：「师父走了之后呀！我把杂物间的柜子全翻遍了！」男主：「师父回来，肯定心疼。」 |
| **多功能武器清单** | 每种武器一个功能，**全部进战术层**（不同场景用不同武器），不是摆设清单 | 镇妖符（压妖气）/火符（火焰攻）/定身符（定妖）/引雷符（雷击，难画）/寻踪符（追踪）/闭气符（藏匿）/血符（血激活，威力×N） |
| **依赖点破** | 强敌/反派一句台词点破\"外物撑不了多久\"——观众看到依赖的脆弱 | 山神：「他的符，你学不会他的力气。跟这庙里的香火一样——借来的，撑不了多久。」 |
| **转折=自己的东西更灵** | 用武器库打不动，改用**自己的东西**（血/身体/本能）反而有效——外物不如自己，为身份伏笔预热 | 师父的符燎掉一层灰又涌回 → 咬破手指用血抹符，威力反超，炸开神位缝（L2「你血里有东西」前奏） |
| **独立后外物还在** | 觉醒独立后不再依赖，但武器还带着（情感：是师父的东西，不是工具用完就扔） | 第20-21场妖力+伏妖术合击，包袱还在背上 |
| **武器清单进项目文档** | 多功能武器+三台阶（拐杖期→转折→独立）写进人物小传，导演/分镜拿到战斗手段全貌 | NSZK/主文档补\"符箓系统\"小节 |

**检查法**：给角色武器库后逐问——①武器从哪来（来源要合角色处境，正式交付 vs 偷拿各有戏）②每个武器在剧本里有几场真用过（0 用=摆设清单）③有没有\"外物打不动→自己的东西有效\"的转折点（没有=成长弧线没挂上）④觉醒后武器如何处理（还带着=情感，扔掉=决裂，都是选择）。



重大改动（设定升级/重写大场景/文档重写）完成后，用户要求"自检检查几遍"时，不要泛泛通读，按轮次做**定向核对**，每轮查一个维度（《伏妖记》v2.1 实测 10 轮）：

| 轮 | 检查维度 | 具体操作 |
|---|---|---|
| L1 | **金句存在性** | grep 所有已验证金句（主题句/角色金句/母题句）——重写后是否还在？本会话发现"我是妖。我认"和"本事不分人妖"都在重写时丢了 |
| L2 | **逻辑事实** | 逐句审逻辑（"她和你娘，一起锁在里头"——母亲是死不是锁，改"她锁在里头。你娘，也死在那里头"） |
| L3 | **主题句** | 核心主题句是否在位（丢了要补回，且可升级与新增线呼应） |
| L4 | **道具闭环** | 道具三态/四态闭环每态都有剧本描写（灼印：烙下→发烫→金光入剑——重写后第18场断链，补回） |
| L5-L6 | **台词精确性** | 台词与角色认知/道具位置一致（第15场"你身上那颗丹"——丹已被取出；第17场"你体内那颗丹"——丹已在怀里，改"身上"） |
| L7 | **重复/冗余** | 重复标记（（全剧终）×2）、残留旧概念（"我是人=锁"应 0 命中） |
| L8 | **文档同步** | 引语同步：大纲/项目文档引用的金句措辞必须与剧本实际一致（"我用师父教我的本事赢你"→剧本实际"用她给我的力气——赢你"） |
| L9 | **人物小传细节** | 小传描述与剧本一致（"全片没说过我信你"→实际第18场对镜妖说了"我信他"） |
| L10 | **概述事实交叉** | 概述每句回溯剧本场次（"下山除妖路上救白骨"错——白骨是师父家晾了18年的） |

**教训**：重写大场景最容易丢的是"旧版验证过的台词和设定"——不是新写的不好，是旧的没搬过来。多轮核对不是流程形式，是找回丢失资产的最后防线。每轮发现的问题修复后，最后统一做一次全剧本完整性验证（19场/金句计数/无重复标记）。

**项目文档（飞书正本）同样适用多轮核对——且是独立于剧本的第二战场**（2026-08-07 NSZK 审视 9 轮实测）：剧本改完 ≠ 项目文档对。正本落后于剧本是常态（本轮发现 6 类错位），逐轮核对才能暴露：

| 错位类型 | 实测案例 |
|---|---|
| **场次引用错位（拆场/扩场后最高发）** | 剧本 19→23 场拆场后，道具时态表 4 处终点场次全错：灼印"第18场金光入剑"实际第21场、铜镜"第19场映出自己"实际第23场、空绳"第19场收进怀里"实际第23场、母亲丹"第18场随封印回镜"实际第22场；小白感情线"第18场我把信给你"实际第20场。**核对法：`grep -n "^### 第" 剧本` 建场次基准表 → 文档每个"第N场"引用对照剧本实际内容** |
| **旧概念残留（文档滞后于已删设定）** | 大纲时间轴"心智被迷"（早已改为清醒堕落）、"金光碾碎香火甲"（已改香灰）、小白小传"管师父叫老骗子"（已改老头儿）——都在正本里残留 |
| **逻辑矛盾（文档声称 vs 剧本实际）** | 莲儿小传"她不知道那丹是钥匙"——剧本第12场镜妖明说"那颗丹，就是那把钥匙"（她听过"钥匙"，只是不懂"取走丹=封印松动"因果）。修：文档改"听过钥匙，但不明白因果" |
| **概述表述偏差** | 概述"镜妖从镜子里出来"——剧本实际是"雾从镜面涌出，把他们拉进镜中宫阙"（不是她实体走出镜子） |
| **术语标签越界** | "半妖"在项目文档 14 次（创作者视角，合法）vs 剧本正文 0 次——**这个分层是对的，检查时别误改**；但信息层表格 L5 不要写"你是半妖"（剧本无此句），写"你娘是大妖→男主自悟" |
| **西方术语残留** | 三幕/建置/弧光/节拍/抽丝剥茧 应 0 命中（走国人的艺术） |

**审视流程**：①`docs +fetch --scope full` 拉正本全文 → ②按维度逐轮核对（道具时态表/大纲时间轴/人物小传/概述/信息层/术语）→ ③表格单元格是独立 block（道具时态表 4 格=4 个 block），用 XML 定位逐格替换 → ④每轮改完 `--scope full` 全量验证（含"0 残留"和"新句在位"双向检查）→ ⑤最后跑一次全库终检：场次引用全 ≤ 总场数、旧术语 0、新表述在位。**mermaid 时间轴里的残留走 whiteboard +update 不走 block_replace**（见§八）。

## 五、设定升级（用户拍板大改，如 v2.1 镜妖前史重写）

用户发起"我说一些设定改动"时，这是**重写级改动**（改角色动机/封印机制/第三幕结构），不是逐场打磨。流程：

### 1. 先确认，后动手（用户逐项拍板）

用户口头给一串设定改动时，**不要立刻改剧本**。先：
- 复述完整逻辑链（前史→主线→结局）让用户确认抓对
- 列出**连锁影响映射表**（哪些场次要改/哪些保留/哪些新增）
- 列出**拍板点**（用户没说全的细节，如"男主本身是妖吗？""父辈身份？""黑化手段？"）——用户偏好逐点回答，不要替他决定
- 节奏要过：设定确认后直接干活，不再反复请示

### 2. 设定升级的常见提升方向（v2.1 实战验证）

| 手法 | 原理 | 例 |
|---|---|---|

**反派动机三层模型**（用户补充"镜妖对男主的嫉妒也是真的"后确立）：反派动机不是单一信念，是三层叠加，**每层都是真的**：

| 层 | 性质 | 例（镜妖） |
|---|---|---|
| ① 物理目标（夺丹破封/复仇/自由） | 情节骨架 | 拿钥匙破封 |
| ② 信念驱动（证明/报复/执念） | 主题内核 | 用自己被背叛的经历证明"世上没有真心" |
| ③ 真实情绪（嫉妒/渴望/不甘） | 人性厚度 | 他有师父护着、有人信他、有人愿意把命给他——她从来没有过。「你倒有人护」那声轻叹，是真的想要 |

**关键**：③不是①②的工具或伪装，是反派真实的情感。嫉妒让"你孤单吗"那一击完整——她嫉妒了一辈子的"有人护"，最后以"现在有人问你了"的形式落到她身上。写反派动机时自问：他/她**想要而得不到**的是什么？这一层给了反派人性厚度，也让她的失败更有分量。

### 3. 信息一层一层揭开（身世悬念释放链）

身世/真相悬念按"剥洋葱"设计，**每层信息都要让观众"啊原来如此"，然后发现下面还有一层**：

```
L1 异常（血能救妖/画符总烧）→ L2 外人点破（"你血里有东西"）→ L3 力量失控（金光觉醒）
→ L4 钥匙真相（"丹是你娘渡的"）→ L5 身世揭底（"你娘是大妖"→男主自悟"我是妖。我认"）→ L6 闭环（"你娘是个好妖"）
```
- **L1 载体注意（2026-08-07 拍板）**：原"心口闷"载体已删除（与除妖师身份冲突，见§三.6 伏笔链全局一致性教训）——现 L1=血能救妖（第8场）+画符总烧（第3场，观众以为他笨）
- **L5 解说 vs 自悟（2026-08-07 实测）**：**剧本正文不说破身世术语标签（"半妖"全剧 0 命中）**——身世揭底靠「你娘是大妖」（第19场）→男主自悟「我是妖。我认」（第20场）让观众自己完成推理，比反派直接说"你是半妖"（贴标签=解说）高级。术语（半妖/妖丹）只存在于**创作者文档**（分场分析/项目文档=创作者视角），不进正文；项目文档信息层表格引用 L5 时也不要写「你是半妖」（那会让文档与剧本不一致），写「你娘是大妖→男主自悟」。**检查法**：grep 术语标签在剧本正文应 0 命中
- **身世留白（2026-08-07 用户拍板"父亲留白处理"）**：身世信息**不是每块都要填满**——观众只需知道"他娘是妖、他是妖、从小当人养"（身世悬念能成立的最小集），父亲是谁/人妖混血细节/父母怎么相识都留白。留白让悬念更纯粹（不引入观众不需要追踪的旁支），也省掉一堆要自洽的设定（混血怎么来的/父系家族线）。**创作文档里写"父亲留白（创作决策）"标注**，防止后来者手痒补设定。判断标准：这条信息**不补，观众会困惑吗？**——不会（他娘是妖已解释他的异常）就不补；会才补。

- 每层由不同角色/场景承担，信息释放节奏写入文档（大纲/分场分析）
- 主角和观众同步逼近，主角总是最后一层才知道

### 3.5 形象/道具推敲铁律（用户"所有形象、场景等都要反复推敲"）

**道具先问"贴不贴人物形象"，再查考据**（用户纠正"不只是年代问题，更重要的是人物形象贴不贴"）：

| 原则 | 说明 | 例 |
|---|---|---|
| **道具=人物本质的物化** | 道具先匹配人物核心特质（深不可测/执棋者/亦师亦父），考据是第二关 | 师傅=执棋者（"他算好的"）→ 烟袋（市井老江湖）不贴、铜钱（算卦先生）也不贴 → **深不可测的人，手上越干净越可怕**——删道具，不塞替代品，他的"道具"只剩有功能的（桃木剑=吃饭家伙、陶罐=封印法器），人后松弛靠行为（下摆掖腰间）不靠物件 |
| **反派形象=恨的物化** | 反派的"标志物"是其执念/恨的视觉证据，拒绝天真化。**法器必须真正用起来，不能只是摆着**（用户"表现的不好"——头骨原来只在供台/被看/滚落三处出现，从没在战斗/施法中用：摆设=装饰，用起来=法器） | 镜妖带着**师傅的白骨头颅**做法器（供台十八年）：第17场亮相（"像一件旧法器"，眼窝对着老道影像="她带着他的头，看自己被杀"）→ **第21场法器觉醒（决战才用）**：头颅离台飞起入她手，眼窝亮两团暗红（她透过他的眼窝看人）→ 剑光劈在头骨上裂开一道缝（恨的容器碎了）→ 第22场滚落时带裂缝"她看了一眼，没捡"（恨已裂，连捡都不捡）。核心台词："他的丹，他的剑，他的命——都有来处。我只有这个""我恨他拿我当炉鼎。我也恨——他死了，我连恨都恨不痛快"（她恨到需要恨的对象活着才能继续恨） |

| **形象随心境变化** | 反派多套形象=存在形态（不只是服装），每套代表她的心理状态 | 雾态（本相，什么都不是只剩恨）/倒影态（媒介生存，只能活在反光面）/人态（她给自己造的"人"的样子）——情绪失控时形态退化 |

**宗教敏感边界**（用户"不明确设计宗教等敏感题材"）：**明确宗教身份/场所/行为必须去**（道髻→删、道观→荒居、念经→陪她坐几天、"他教我修行"→"他教我本事"）；**民间信仰可保留**（山神庙/山神/香火/泥塑——因为批判立场明确：黑土妖=伪神被铲除、山神为恶被斩杀，符合"批判立场明确、不宣扬迷信"备案铁律）；伏妖术职业工具（桃木剑/符）属民间传说体系，保留。

### 4. 设定升级的连锁验证（必做）

设定改了，**grep 全局旧概念残留**（v2.1 例：`我是人|自认是人|锁着我的印|金碧楼阁|镜阵|被弃镜灵` 应 0 命中），并逐项核验：
- **道具轨迹**：丹（渡入→被偷→物归原主→被夺→吞入随封印回镜）全程一致
- **形态递进**：反派活动形态与封印状态逐级对应
- **信息差闭环**：主角不知道的真相（师父废墟助攻）要在第19场前不泄露
- **旧设定废除后的台词改向**：`"我是妖。我认"` 不再解锁封印→改为拒绝黑化，含义升级而非删除
- **新增能力先查既有规则能否覆盖**（用户"通灵不行吧"）：想给角色加能力解释行为时（如"纯阴命=通灵，所以花莲看得见别人看不见的白兔"），**先查设定体系内是否已有规则**——镜妖明说过"尾巴还藏不住"（低等妖藏不住形）→ 受伤的白兔路人应该也看得见 → "路人看不到兔子"与既有规则矛盾。被否后修正：救兔=普通善良（不需要特殊能力解释），纯阴命只保留"被山神选中"（第11场），**救兔的善与被选的命解绑**（不硬造因果）。教训：**为解释一个画面硬加新能力 = 污染设定体系**——先看已有规则能不能解释，不能才考虑新设定，且新设定必须与既有体系自洽

### 6. 重写大场景的金句保留纪律（v2.1 实战教训）

**重写/覆写大场景（第18-19场级别）时，已验证的金句和主题句会静默丢失**——v2.1 重写时弄丢了"我是妖。我认"和"本事不分人妖，分的是用的人"两处多轮自审确认的关键台词，靠用户说"自检检查几遍"才在多轮核对中发现。**重写前必做**：

1. **建关键台词清单**：从旧版剧本+自审报告+分场分析里 grep 出所有"已验证台词"（金句/主题句/母题句），写进项目文档决策区
2. **重写后逐句核对**：清单里的每句在重写后的剧本必须存在——不存在要判断是"有意的替换"还是"丢失"
3. **金句保留的判定**：主题句（本事不分人妖）绝不能丢，只能升级（v2.1 升级为与母亲线呼应："你娘是妖，她救过的人比你见过的人都多。你也是妖，你能护的人，不会比她少"）；角色金句（我是妖。我认）保留但可升级措辞（"用她给我的力气——赢你"呼应新力量来源）
4. **道具闭环同样会断**：重写后检查道具三态（烙下→发烫→金光入剑）是否每态都在剧本里有对应描写——丢失就补

### 7. 概述/摘要类内容：去 AI 味 + 事实交叉核对（用户两次纠正后确立）

用户对概述类内容（一句话故事/概述/梗概）有两条铁律：

**① 直观的事件叙述，不是文案腔**（用户："一句话故事改为概述，内容AI感太重，也不直观"）：
- ✗ 文案腔：总结式表达（"以雾形态重返人间""要拿丹破封""要把他变成另一个自己"）、评述腔（"一手伏妖术行走江湖"）
- ✓ 事件叙述：按时间线直述"谁→做了什么→结果如何"（"丹一离开，封印就松了。镜妖从镜子里出来，把他和小白拉进一座宫阙"）
- 三段式结构：身世（是什么）→ 事件（发生了什么）→ 结局（结果如何）

**② 概述的每个事实点必须能回溯到剧本具体场次**（用户抓到"下山除妖路上，他从白骨里救活了一只兔妖"——错，白骨是师父家晾了十八年的，师父第5场离开后白骨才求救，第6-8场在茅草屋里救活）：
- 写概述时逐句问"这句对应剧本哪一场？"——地点/时序/因果一个都不能想当然
- 交付前把概述每句与剧本 grep 交叉核对（白骨在哪、师父何时离开、丹何时被偷）
- 概述是指导性文档，事实错误会误导所有后续使用者（导演/分镜）

### 8. 独白/终局对白审查铁律（用户"对白太次了"三连纠正后确立）

**① 遭遇用画面展现，独白只补新信息——画面已给过的不许对白复述**（用户连问"镜妖的遭遇是靠对白展现的？"）：
- 写独白前先查：这场戏/角色遭遇**在剧本其他位置是否已用画面+对白给过**（如第17场镜中映画已演过"师傅梳头→掐死"）
- 已给过的信息，结尾独白**禁止复述**（"我师傅养我二十年，糊里糊涂地养我，明明白白地取我的丹"被否——画面已演过，再说=重复讲述，降维成台词）
- 独白只承载**新信息**（本场的情绪变化/新的认知/由妒生恨的转折），旧信息留给观众自己回想（"没有人为我点过一盏灯"——观众会自己填上第17场的画面）

**② 信息差独白：主角不知道，观众知道，反派知道但不点破**（镜妖由妒生恨终版）：
- 观众知道：师傅在废墟点灯压镜妖（交叉剪辑）
- 镜妖知道：黄光"亮得有人气，像有人守着，像有人续着"——她察觉是师傅在续灯
- 主角不知道：黄光=封印/娘的东西（师傅在废墟，他始终不知）
- 关键笔法："她张了张嘴，又闭上了"——**她选择不说破**（说了=让主角知道有人为他拼命=成全他的幸福）——不说破比点破狠十倍，她的恨里有慈悲，这慈悲让她更恨

**③ 独白必须有知识库支撑**（用户"独白没有知识库支撑吗？"）：
- 反派终局独白查"被迫的恶使爱成立"（倩女幽魂）——恶行有被迫前提，否则观众失去共情
- 恨的落点要落在"命运不公"（同样被人养大，他有人真心护，我被人当丹养），不落在"封印不公"（恨封印=不讲理，削弱共情）
- 对白忌解说腔/书面语（"他算好的。连这一晚，都算在你的路上"被否）——用人物自己的声音（毒、冷、平、带骨气）

**⑤ 角色转述他人行为时，信息源必须自洽——补"他/她怎么知道"的通道（第9场莲儿转述师父"涂药/说最后一步"实测）**：角色叙述自己不在场/无感知能力时发生的事（白骨态莲儿怎么知道师父"擦灰上药"+念叨"最后一步留给别人做"？），不能凭空转述。修复模式：①**信息源合理化**——师父"擦着擦着就念叨"（对着白骨自言自语18年，残魂可感知——第4场"灯早灭了，屋里没有火"火苗却晃、第6场苏醒都是残魂感知的已有铺垫）；②**角色自己的声音收尾**——"那时候我不懂——我连眼睛都没有"（不说"但我听得见"，用留白让观众自己补接收方式，比解释更疼）。检查法：角色转述他人行为/话语时，逐句问"她当时以什么形态/位置存在？怎么感知到的？"——答不上来就是信息源悬空

**⑥ 补设定来源防泄漏**（第12场实测）：给角色补"它怎么知道X"的信息来源时，**不能泄漏后面才揭晓的信息层**。例：镜妖蛊惑莲儿需要解释"它怎么知道陆青山体内有丹"——来源=它是钥匙（它被锁十八年，知道钥匙在哪），但**不能说"丹是他娘渡的"（L4第17场才揭）也不能说"他是半妖"（L5）**。解法：用暗语让观众半懂——"那颗丹，就是那把钥匙。锁了我十八年的那把锁——钥匙一直挂在他脖子上，**他脖子上的锁，是他自己**。我等了十八年。小兔子，你替我去拿，好不好？"（"他脖子上的锁，是他自己"=他不知道体内有丹的暗语，镜妖知道他不自知——讽刺+伏笔且不泄漏）；同时这段让反派露软（"你替我去拿，好不好"=它在求一只兔子），给蛊惑段加一层"它也在求救"的厚度。**检查法**：补来源时逐条问"这句泄漏了L几？"，L4/L5 留到原定场次

**④ 空间逻辑**（用户"师傅也不是守在外面，他们隔了很远很远啊，主角他们在镜中世界啊"）：
- 交叉剪辑的两个战场**不共享空间**（主角在镜中世界，师傅在真实世界废墟）——写反派感知时不能让她"看到"另一战场的细节，只能感知力量（黄光/封印之力），不能说"你师父跪在外面"（她不可能知道师傅的姿势/位置）

**⑤ 旁白硬点必须删**（用户"不能靠独白硬点"）：作者替观众总结意义的独立判断句（"这象征着什么"）删除，让动作自己说话：
- 例：第22场白骨头颅后加"她住不起这座宫阙，可她带着他的头，住了十八年"→ 删，留"她看了一眼，没捡"（供了十八年的东西滚落，她连捡都不捡——观众自己会懂）
- 例：第19场灼印触发后加"被护过的印记。"→ 删，留"她抬手，看着自己的手。空空的。没有疤，没有印，什么都没有。"（有灼印 vs 空手，观众自己会对照）
- 例：花莲通灵画面后加"她一直看得见别人看不见的东西。"→ 删，留"花莲没抬头。她低头，给兔子擦着伤口。"（路人那一眼"她面前什么都没有"就是全部）
- **边界**：删"这象征着什么"，留"发生了什么"——必要的信息传递（"那是她娘留下的灯，灯芯是发丝""那是她的妖力"——观众需要知道才能看懂后续）不是硬点，保留
- 检查方法：grep 独立判断句（"她住不起\|被护过的\|他明白\|那是他的\|这就是"结尾的独立段），删后验证"动作是否已足够承载"

## 六、时代/世界观切换（改时代=查边界，不是换皮肤）
用户要求改时代（如民国→架空）时，四查：
1. **时代标志物盘点**：grep 旧时代专属词（短打/洋/电话/电报/火车/枪/西装/报纸），逐条换或证明合法（如烟袋：烟草万历年间传入，明代有）
2. **称谓体系**：师徒/村民/老爷等是否跨时代通用
3. **世界观设定冲突**：香火/山神/符箓在明代语境反而更顺（志怪黄金期）；新增世界观设定先定定位——**规则（进战术层）or 美术语言（只服务画面）**，美术语言明示"非规则"避免踩"规则立而未用"坑
4. **备案预检**：架空+批判立场最安全，无真实朝代名/年号

**美学三源分配法**（架空东方美学时）：市井烟火（明）→人物与日常场景；留白意境（宋）→空镜头与呼吸；金碧华丽（唐）→幻境/大场面。每个美学源分配一个层级，画面立刻有层次。

**机制层与皮肤层解耦**：志怪密码等题材方法论全部在机制层（妖怎么设定/怎么收/借妖说人），时代在皮肤层（服饰/场景/器物）——改时代不改变任何机制层结论。写志怪初稿刻意避开真实时代标志物，为后期改时代留余地。

## 七、打磨中的节奏纪律

- **无尿点压缩 = 节奏性压缩，不是信息删除**：压缩前先列"这场必须保留的信息点清单"，压缩后逐点核对（伏笔/因果/调节阀一个不能删）
- 调节阀（幽默）在连续高压段（打斗/牺牲/反转连场超过三场）必须存在
- 结尾加首尾呼应（同一声钟/同一物件），收尾有落点不拖

### 飞书项目文件夹组织（用户偏好，2026-08-06 确立并修正）

**飞书 Hermes 文件夹下的文档是正本，不是副本**（用户纠正"飞书文档不是什么副本，这是正本"）——创作成果以飞书为准，Obsidian 项目目录是 git 归档层（版本历史/创作过程留痕），不是权威源。所有创作改动都要落到飞书正本（剧本正文重导/项目文档更新），Obsidian 同步归档。

剧本交付到飞书文件夹（用户给 drive/folder 链接时）：
- **剧本正文独立一份 docx**——纯净剧本，零分析
- **项目文档一份**（最终形态，2026-08-06 拍板）：创作纲领/故事概述/人物小传/时间轴合并——用户称它是"很重要的指导下文档"，值得全量结构化重写（见下节"项目文档指导性结构"）
- **分支管理已放弃**（2026-08-07 用户拍板"分支管理直接放弃，删掉即可"）——不再有分支管理文档，飞书文件夹保持**两件套**：剧本正文 + 项目文档
- **富功能优化**（用户要求"用飞书文档的时间轴、高亮块等功能优化"）：
  - 一句话故事/核心冲突 → `<callout emoji="🎬">` 高亮块（打开文档第一眼看到全片之魂）
  - 起承转合时间轴 → `<whiteboard type="mermaid">` timeline 语法（起/承/转·合逐段挂轴）
  - 决策记录 → callout 绿底"✅ 选定"高亮；逐场决策用 h2 分节
  - 表格保留（定位/逐场/伏笔闭环）
- 实操流程：
  1. 本地 md **必须先删 YAML frontmatter**（`re.sub(r"^---\n.*?\n---\n", "", content, flags=re.S)`）——否则 `tags/date/updated/related` 元数据会显示在飞书文档抬头（用户指出"抬头有不需要的东西"）
  2. CRLF 转 LF（`content.replace("\r\n", "\n")`）
  3. 方案 A：md → `drive +import --type docx --folder-token <文件夹> --name 标题`（表格友好）
  4. 方案 B：XML（支持 callout/whiteboard）→ `docs +create --content @xml`，**创建后文档在根目录**，需 `drive +move --file-token <token> --folder-token <文件夹>` 移入目标文件夹；XML 的 `<title>` 不生效，需 `drive files patch` 改名
  5. 验证渲染（fetch 数 callout/table/whiteboard）→ 确认无 frontmatter 残留
- 换版策略：改过的文档重新导入新 token 后，**删除旧文档**（保留新 token），文件夹保持"剧本正文 + 项目文档"两件套
