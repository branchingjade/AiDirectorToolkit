## 引用约定

- 导演卡片引用：[卡·导演名] = `references/导演美学卡片/<导演>_导演美学卡片.md`
- 深化文档引用：[深·导演名] = `references/导演美学卡片/<导演>_手法体系深化.md`
- 技法卡片引用：[卡·片名#N] = `references/大师技法卡片/<片名>_技法卡片.md` 卡片 N
- 题材密码引用：[题材·XX] = `references/题材密码/XX题材密码.md`
- 创作 skill 约束引用：[AI导演 3.x] = `AI电影导演/SKILL.md` 章节 x
- 工具参考：[Seedance 2.5] = `references/Seedance2.5官方理解.md`

## 质量纪律

1. **每条论断带来源**——从知识库现有资产（导演卡片/深化/技法卡/约束章节）提炼，不凭空写
2. **零新抓取优先**——批 1 的 6 份密码全部从存量合成；外部理论补强（如《眨眼之间》）放批 2/批 3
3. **不重复题材密码**——叙事结构/人物/题材层面的东西归题材密码，学科密码只讲本专业领域
4. **诚实声明**——合成来源 vs 外部理论要标注；推断要标【推断】
5. **泛用导向**——可复用时机按创作场景归类，不绑定单一项目
