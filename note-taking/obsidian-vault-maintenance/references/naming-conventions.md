# 命名规范

> 生效日期：2026-07-21
> 所有新建笔记遵守此规范。存量笔记渐进迁移。

## 目录

| 规则 | 示例 | 说明 |
|------|------|------|
| 中文优先，简洁直白 | `犬子无双/` `工具与集成/` `Hermes运维/` | 不用缩写 |
| 子目录用语义命名 | `设计/` `配置/` `超分/` | 避免 `docs/` `files/` 等通用名 |
| 日志用年月分组 | `2026-07/` | `YYYY-MM` 格式 |

## 文件

| 类型 | 格式 | 示例 | 说明 |
|------|------|------|------|
| 日报 | `YYYY-MM-DD.md` | `2026-07-21.md` | 全日期（搜索友好） |
| 周报 | `YYYY-MM-W{N}-周报.md` | `2026-07-W2-周报.md` | W号按月重置 |
| 月报 | `YYYY-MM-月报.md` | `2026-07-月报.md` | 一文件双职（索引+总结） |
| 普通笔记 | `中文描述.md` | `网页抓取任务复盘.md` | 不含 `:` `\|` `/` |
| 参考文档 | `中文描述.md` | `人名条设计参考.md` | 放 `references/` 下 |

## 分隔符

- 统一用 `-`，不用 `_` `~` 混搭
- `2026-07-21` ✓ / `2026_07_21` ✗

## 路径冗余原则

- 普通笔记：路径含分类信息，文件名不重复
- 日报/周报/月报：全日期命名，因为搜索/Quick Switcher需要文件名自描述
- 这是"搜索便利"对"路径不冗余"的实用主义覆盖

## 日志结构

```
日志/2026-07/
├── 2026-07-月报.md          ← 月报=索引
├── 2026-07-W2-周报.md
├── W2/ 2026-07-07.md ...   ← 只建有用到的周目录
├── W3/ 2026-07-15.md ...
└── W4/ 2026-07-21.md
```

规则：周号按月重置、空周不建目录、三级双向related链接。

## Obsidian 特例

- 不用 `README.md`（Obsidian不渲染）→ 用 `索引.md` 或合并到月报
