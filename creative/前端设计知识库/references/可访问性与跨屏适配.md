# 可访问性与跨屏适配

> 2026-08-10 | 面向：工具型 UI 的无障碍合规（WCAG 2.2）与多屏适配（4K/缩放）。含本工作区实测结论（4K + Windows 缩放下的 CSS 媒体查询失效问题）。
> 来源标注：训练知识（WCAG 2.2 标准、W3C 规范）+ 本机实测（2026-08 记录）

## 一、无障碍不是加分项（WCAG 2.2 合规）

WCAG 2.2 四大原则（POUR）：可感知、可操作、可理解、健壮。工具型 UI 最常踩的条款：

| 条款 | 要求 | 出处 |
|---|---|---|
| 1.4.3 对比度 | 正文 4.5:1，大文字 3:1 | WCAG 2.2（AA） |
| 1.4.11 非文本对比 | UI 组件/图形边界 3:1 | WCAG 2.2（AA） |
| 2.4.7 焦点可见 | 键盘焦点有明显指示（outline） | WCAG 2.2（AA） |
| 2.1.1 键盘可操作 | 所有功能可键盘到达（Tab/方向键/Enter） | WCAG 2.2（A） |
| 2.4.3 焦点顺序 | Tab 顺序 = 视觉顺序 | WCAG 2.2（A） |
| 2.3.3 动效可关 | 非必要动效可关闭（`prefers-reduced-motion`） | WCAG 2.2（AA，2023 新增） |
| 1.4.1 颜色传达 | 颜色不能是唯一信息通道（配图标/文字） | WCAG 2.2（A） |

## 二、键盘导航（工具 UI 重度依赖）

| 模式 | 实现要点 | 出处 |
|---|---|---|
| 全局快捷键 | Ctrl+Enter 提交、Ctrl+K 搜索、方向键导航列表 | Nielsen #7（灵活高效） |
| 焦点陷阱 | 弹窗/抽屉内 Tab 循环，Esc 关闭，焦点回触发元素 | WCAG 2.4.3 + 弹窗模式 |
| 可见焦点 | 自定义 outline（`focus-visible`），不删默认 focus 样式 | WCAG 2.4.7 |
| 列表键盘 | 方向键移动选中项，Enter 激活 | ARIA listbox 模式 |
| 可点击元素 | 用 button/可聚焦元素，不用 div+onclick（无法键盘触发） | WCAG 2.1.1 |

## 三、动效与减少动效

| 规则 | 实现 | 出处 |
|---|---|---|
| 非必要动效可关 | `@media (prefers-reduced-motion: reduce)` 关闭动画/骨架屏闪烁 | WCAG 2.2, 2.3.3 |
| 动效时长 | 见 [[UI交互设计逻辑与动效]] 套6（100-500ms） | Material / NN/g |
| 避免 | 大视差、持续抖动、缩放脉动（前庭不适） | NN/g 无障碍研究 |

## 四、跨屏适配（4K + Windows 缩放实测）

### 4.1 问题背景（本机实测 2026-08）

4K 显示器 + Windows 缩放（150%/200%）下，**CSS 媒体查询按 CSS 像素触发，物理分辨率高的设备可能永远命中断点**——本工作区工具实测：`@media (max-width: 1280px)` 在 4K 150% 缩放下不触发（浏览器 CSS 宽度 = 2560/1.5 ≈ 1707px，远超断点）。

### 4.2 可靠方案

| 方案 | 做法 | 适用 |
|---|---|---|
| JS 检测物理分辨率 | `screen.width * window.devicePixelRatio` 判断真实物理宽，再切布局类 | 需要精确知道「用户屏幕多大」时 |
| rem + clamp() | `html{font-size: clamp(14px, 12px + 0.35vw, 18px)}` 流式缩放，覆盖 1080p/2K/4K | 全局字号与间距（本工作区已采用） |
| 容器查询 | `@container` 按容器宽度响应，不依赖视口 | 面板/卡片内部布局 |
| 双端确认 | 桌面工具先保证 ≥1280px 设计，再做窄屏兜底 | 工具型 UI |

### 4.3 实测结论（本工作区）

- 字号用 `rem + clamp()` 后 1080p/2K/4K 三档实测正常
- 布局切换类需求（如双栏 → 单栏）用 JS 检测 `screen.width × devicePixelRatio`，不用媒体查询
- Windows 缩放 ≠ 浏览器缩放：`devicePixelRatio` 在 100%/125%/150% 下分别为 1/1.25/1.5

## 五、测试清单（上线前跑一遍）

- [ ] 对比度：Chrome DevTools 逐个检查主/次文字、按钮、图标（1.4.3/1.4.11）
- [ ] 键盘：不用鼠标走一遍全部功能（Tab/Enter/Esc/方向键）
- [ ] 焦点：每个可交互元素有可见焦点指示（2.4.7）
- [ ] 减少动效：系统开启「减少动态效果」后动效消失（2.3.3）
- [ ] 读屏抽查：表单 label 关联、按钮有 aria-label（1.3.1/4.1.2）
- [ ] 4K 缩放：150% 缩放下布局不破、字号可读（4K 实测）
