# 暗色主题设计

> 2026-08-10 | 面向：工具型 UI 暗色主题设计。本工作区基准：Linear 风格暗色（`#08090a` 底色）+ 白底按钮做唯一重色。
> 来源标注：训练知识（Material Design 3 官方色彩规范、WCAG 2.2 对比度标准、NN/g 研究）

## 一、为什么暗色（用途边界）

| 论点 | 说明 | 出处 |
|---|---|---|
| 暗色 ≠ 默认更好 | 亮暗无绝对优劣；暗色适合长时间观看的创作/监控工具（视频、调色、代码），亮色适合内容阅读 | NN/g, "Dark Mode vs. Light Mode: Which Is Better?", 2020 |
| 一致性铁律 | 暗色主题必须**全站一致**——半亮半暗的混合状态最伤眼（页面切换闪白） | 同上 |
| 跟随系统 | 默认跟随 `prefers-color-scheme`，同时允许用户手动覆盖 | W3C Media Queries Level 5 |

## 二、色彩系统（先定色板，再定语义）

### 2.1 Material Design 3 色彩系统（HCT 模型）

| 概念 | 逻辑 | 出处 |
|---|---|---|
| 主色（Primary） | 品牌色，用于主按钮、选中态、链接 | Material Design 3, "Color system" |
| 次要色（Secondary） | 次级强调，不抢主色 | 同上 |
| 表面色（Surface） | 背景层叠（surface → surface-variant → surface-container），层级靠明度差表达 | 同上 |
| 错误色（Error） | 错误提示专用色，独立于主色 | 同上 |
| 语义色 | 成功/警告/信息（绿色/橙/蓝），暗色下饱和度要降 | 同上 |

### 2.2 本工作区基准（Linear 风格 + 唯一重色）

| 元素 | 取值 | 逻辑 |
|---|---|---|
| 页面底色 | `#08090a` | Linear 风格极暗底，非纯黑（纯黑 OLED 下对比度失控） |
| 面板/卡片底 | 比底色亮一档（如 `#101114`） | 用明度差分层，不用边框 |
| 白底按钮 | 唯一重色（主操作） | 全界面只有一个高亮主操作，其余全暗——注意力收敛 |
| 文字层级 | 主文字 `#e8eaed` 系 / 次要 `#9aa0a6` 系 / 禁用更暗 | 层级靠明度，不靠字号硬撑 |

## 三、对比度硬标准（WCAG 2.2，AA 级门槛）

| 场景 | 最小对比度 | 出处 |
|---|---|---|
| 正文/常规文字 | 4.5:1 | WCAG 2.2, 1.4.3 |
| 大号文字（≥18pt 或 14pt 粗体） | 3:1 | 同上 |
| UI 组件与图形（图标、按钮边界、输入框） | 3:1 | WCAG 2.2, 1.4.11 |
| 聚焦指示（键盘焦点可见） | 3:1 | WCAG 2.2, 2.4.7 + 1.4.11 |
| 增强级（AAA，可选） | 7:1 | WCAG 2.2, 1.4.6 |

**陷阱**：
- 禁用态文字/按钮**不要求**满足对比度（WCAG 明确豁免「disabled/inactive」组件）——这是唯一可以放心做灰的地方
- 占位符文本按正文标准算（4.5:1），但**不推荐用占位符当标签**（见 [[表单设计]]）
- 暗色下红色容易过饱和刺眼，错误色要降低饱和并提亮

## 四、层级与分层（暗色下的空间表达）

| 层级手段 | 用法 | 出处 |
|---|---|---|
| 明度分层 | surface-container 逐级提亮，不用描边 | Material Design 3, "Elevation" |
| 阴影 | 暗色下阴影几乎不可见——改用边框（outline）或提亮面区分 | 同上 |
| 聚焦 | 用 outline/光环 而非 box-shadow 表达焦点 | WCAG 2.4.7 |
| 选中态 | 选中项底色 + 主色左侧条/勾，不只靠文字变色 | Material Design 3 |

## 五、暗色模式实现要点

| 要点 | 说明 |
|---|---|
| CSS 变量承载 | 所有颜色走 `--color-*` 变量，亮暗主题只换变量不换组件代码 |
| 图片/视频 | 暗色下嵌入的白底截图突兀，可加 `filter: invert()` 容器或统一卡片底 |
| 滚动条/选区 | 系统级元素要跟着主题走（`scrollbar-color`、`::selection`） |
| 闪烁防护 | 主题切换用 `color-scheme: dark` + 过渡，避免页面闪白 |
| 对比度工具 | 开发期用 Chrome DevTools 对比度检查（元素审查 → 颜色圆点）实测每个色对 |

## 六、实战对照（本工作区偏好 → 权威依据）

| 既定偏好 | 依据 |
|---|---|
| Linear 风格 `#08090a` 暗底 | NN/g：暗色适合长时间观看工具；Material：极暗 surface 规范内 |
| 白底按钮唯一重色 | Material 主色唯一性 + Nielsen #8 美学极简（唯一主操作） |
| 深色 + 高密度不花哨 | Material 暗色降饱和原则（避免霓虹感） |
| 参数区常显（不折叠） | 见 [[布局与信息架构]] 密度逻辑 |
