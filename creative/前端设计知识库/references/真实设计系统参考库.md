# 真实设计系统参考库

> 2026-08-10 引入 | 54 个真实世界设计系统（Stripe/Linear/Vercel 等），每个含完整视觉语言：色板、字体层级、组件样式、间距系统、阴影、响应式行为。
> 来源：popular-web-designs skill（Hermes 内置，模板源自 VoltAgent/awesome-design-md，MIT）——**模板文件按需加载，不进 vault**，本页是指南与速查。

## 怎么用

```text
1. 按下面目录挑一个设计系统（按风格/场景）
2. 加载模板：skill_view(name="popular-web-designs", file_path="templates/<site>.md")
3. 把模板里的设计令牌（CSS 变量/字体/间距/阴影）套进目标页面
4. 配合 [[UI交互设计逻辑与动效]] 的交互/动效逻辑使用——模板给皮，交互逻辑给骨
```

⚠️ 模板是 HTML/CSS 视觉词汇，不是组件库代码——落地时仍要按交互逻辑（表单/状态/无障碍）补行为层。

## 字体替代速查（CDN 不可用时的保真关键）

| 原字体 | CDN 替代 | 备注 |
|---|---|---|
| sohne-var（Stripe） | Source Sans 3 | 字重 300 优雅感靠字重+字距，不靠字体 |
| Circular（Spotify） | DM Sans | 圆润几何感 |
| figmaSans | Inter | 干净人文感 |
| Berkeley Mono | JetBrains Mono | 技术等宽 |
| Geist 系 | Geist（Google Fonts 有） | 无损 |
| IBM Plex 系 | IBM Plex（Google Fonts 有） | 无损 |

> 替代字体时严格照抄模板的字重/字号/字距值——这些比字体本身承载更多视觉身份。
