## 一、完整段落示例（3镜）

以下为一段完整的3镜头分镜，展示段级资产锁、配置行+描述行、空间继承的完整格式：

```

画幅：16:9横屏，风格：1996铁北年代写实，真人短剧风格，电影级质感，8K超精细，负面：画面抖动，人物变形，时间闪烁，构图混乱，字幕/Logo/水印，BGM，横向构图失衡，主体占比过小 |
整体风格：年代写实，自然窗光+昏黄灯泡，真实怀旧氛围感，无过度调色
角色：陈强@图片1、李素贞@图片2、陈静@图片3
场景：陈家屋内@图片4
道具：铝饭盒@图片5
配音：陈强@音频1

中景 | 缓推 | 傍晚
      陈强推门进来，手里拎着两个馒头。塑料袋破了馒头掉地上滚了一圈，他弯腰捡起来吹了吹"还热乎"。李素贞从缝纫机前抬头看了他一眼没说话。横屏三人：陈强画左、李素贞画中、陈静在画右桌前写作业。窗外的天已经暗了，屋里只有昏黄灯泡照着饭桌。[音效: 门"吱呀"推开，馒头滚地的轻响，缝纫机踏板声骤停]

特写 | 固定 | 傍晚
      陈强把十五块钱塞到陈静手里——一块两块五块的零钱攥成一团。他避开妹妹的目光，眼睛看向别处。陈静攥着钱低头看，手指慢慢收紧，纸钞在手心里发出细碎的声响。李素贞在背景中捂住嘴，眼泪夺眶而出但没有声音。[音效: 纸钞的细碎声，李素贞压抑的抽气声]

远景 | 固定 | 傍晚
      陈强坐在饭桌前大口吞咽馒头，脖颈绷紧，目光垂在脏兮兮的地面上。窗外是铁北区破败的厂区剪影，烟囱在暮色中站成黑色的轮廓。昏黄灯泡在画面最上方，光晕刚好罩住一家三口。[音效: 陈强吞咽声，远处工厂下班的汽笛声]
```

**格式要点**：
- 段首5行资产锁（画幅+整体风格+角色+场景+道具+配音）统一声明，段内各镜不重复
- 每镜严格两行：配置行（景别 | 运镜 | 日夜）+ 描述行（6空格缩进，中文画面+末尾[音效]）
- 配置行只有3个字段，无秒数、无场景、无资产
- 空行分隔各镜

## 二、竖屏示例（9:16）

竖屏差异：负面不含横屏追加项，整体风格适配竖屏窄幅。

```
整体风格：柔和现代，自然窗光+暖调室内，轻微柔光
角色：林晓@图片1、陈强@图片2
场景：咖啡厅@图片3
道具：铝饭盒@图片4
配音：林晓@音频1、陈强@音频2

近景 | 固定 | 日
      林晓坐在咖啡厅靠窗位置，铝饭盒放在桌上没打开。她看着窗外，手指无意识地摸着饭盒的边缘。阳光透过玻璃在她的侧脸上投下半明半暗的轮廓。陈强从门口走进来，在她对面坐下，她转回头时嘴角动了一下但马上收住了。[音效: 咖啡厅轻音乐(剧情内音源)，陈强拉开椅子的声音，林晓手指划过铝饭盒的轻响]
```

## 三、段间空间继承示例

**段1末**：
```
> **→ 段末空间状态**: @陈强站在饭桌前(画中)，刚把十五块钱塞给@陈静。@陈静坐画右攥着钱低头。@李素贞站画左缝纫机旁捂嘴。桌上三副碗筷+白菜豆腐。昏黄灯泡亮。
```

**段2首**：
```
**← 段前空间继承**: @陈强站在饭桌前(画中)。@陈静坐画右攥着钱。@李素贞站画左缝纫机旁。桌上白菜豆腐未动。昏黄灯泡亮。情绪：陈强刚说完"家里有我"——母亲在哭、妹妹在忍。
```

**三条铁律**：
1. 只继承"事实"（角色站位、道具位置、光源状态），情绪锚点可选加
2. 不继承"描述"（不写"气氛压抑""陈强感到愧疚"）
3. 字面一致（`@陈强站在饭桌前(画中)`在段末和段首逐字相同）

## 四、聚簇Brief模板

父Agent写给子Agent的创作brief（≤60行）：

```
# 簇X创作brief — EP{start}-{end}

## 叙事定位
本簇在全集中的位置：开局建立/中期推进/高潮释放/尾声收束
核心冲突：谁要什么？障碍是什么？

## 空间世界
共享场景清单+空间地图关键点（门/窗/台/光源位置/权力位置）
空间演化弧线：从什么状态→经过什么变化→到达什么状态

## 情绪弧
起点情绪 → 拐点 → 终点情绪
呼吸设计：哪里蓄/哪里爆/哪里沉默

## 视觉语言约束
主导视点 | 光的主角身份 | 海报镜头候选 | 禁止使用的运镜/光型

## 声音设计约束
主导听觉视点 | 关键声音motif | 静默策略节点

## 角色状态快照（承前簇）
每个角色的起始站位/姿态/情绪/持有道具

## 衔接要求
与前簇末集的空间+情绪对位 | 向后簇传递的悬念
```

## 五、子Agent自检报告模板

每簇产出后提交（≤25行）：


## 六、父Agent审查报告模板

每簇审查后产出，聚焦8锚点：

```
## 簇X审查 — EP{start}-{end}

### 创作锚点
- 空间建立: [首段空间地理是否完整？权力关系可视化？]
- 中段转折: [情绪拐点是否有视觉重量？视点转换有理由？]
- 集末落点: [情绪是否落地？钩子是否自然？]
- 海报镜头: [定义性画面是否成立？]

### 资产锚点
- 资产完整性: [出场实体是否入地基？]
- 服装细节: [剧本服装细节是否在分镜对应？]
- 道具追踪: [关键道具跨镜状态是否一致？]
- 格式一致性: [配置行/描述行/音效/秒数是否符合2.6标准？]

### 判定
[通过/需修正] — [具体问题+修改建议]
```

## 七、标准AI剧本格式示例 v10.0.0

### 7.1 完整场次

```
场1  医院病房  日(阴)  内
人物：陈强（21岁，偏瘦，短发凌乱，皮肤偏黑）、护士（二十三四岁，白制服）
声场：空调低频嗡鸣+远处护士站呼叫铃
衔接：开场

△病房门"砰"推开——声先于人。护士端金属药盘进场。

护士：（敲托盘）陈强。换药了。脱裤子。撅腚。

△陈强磨蹭。手伸到裤腰——停——缩回——又伸——又停。
△他鼻翼微动——极轻微。眼睛闭上，眼球在眼皮下转动。

[异: 嗅觉增强]

陈强：（闭眼，低声）嗯？不对……这啥味儿？奶呼呼的？

△他睁开眼。困惑——不是"闻到了什么"，是"我怎么能闻到"。
△不受控制转头——身体先于大脑——朝味道方向。护士正转身拿药——胸口对着他脸。鼻尖几乎碰到护士制服。

△"啪——！"耳光。脆响。陈强脸侧过去。护士手停半空。

护士：（尖叫）你——你干啥？！闻你妈去！臭流氓！

陈强：（VO）我操……我他妈要变狗了？！

△窗外无声闪电划过灰暗天空。

（第一集完）
```

### 7.2 VO / OS / VO·电话

```
陈强：（VO）我眼睛……耳朵……鼻子……咋这么好使了？！     ← 内心独白
赵国斌：（VO·电话）废物。这么点事都办不好。              ← 电话中的声音
王秀娟：（OS）房本到手就成了一半！明天一早我就跟洪刚去过户！ ← 三楼传来的声音
法官：（VO·大喇叭）判处无期徒刑，剥夺政治权利终身——      ← 大喇叭声音
```

### 7.3 感情语言检查点

```
陈强=做不说    → 全剧未说"我爱你们"。检查每集对白：是否有"心里话"泄漏？
林晓=给不说    → 铝饭盒+排骨。检查：是否在某集说出了"我喜欢你"？
万倩=给空间    → "你不用现在答复我。"检查：是否在某集施加了情感压力？
王秀娟=表演    → 99%的嚎啕是武器。检查：EP24公审那次是否是真的？
```
