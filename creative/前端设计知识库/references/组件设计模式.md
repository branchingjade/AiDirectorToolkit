# 组件设计模式

> 2026-08-10 | 面向：工具型 UI 常用组件的选择逻辑与实现要点。每个组件给「什么时候用、什么时候别用」。
> 来源标注：训练知识（Material Design 3 组件规范、Apple HIG、NN/g 研究）

## 一、选择决策树（先选对组件，再谈实现）

```
需要用户操作 →
  单点触发 → 按钮
  从几个选项选一 → 单选/下拉/分段控件
  从很多项选 → 搜索+列表
  输入新值 → 输入框（见 表单设计）
  确认破坏性操作 → 弹窗确认 或 撤销机制（见下）
需要展示信息 →
  就地展示 → 文本/表格
  详情浮层 → 抽屉（编辑类）/ 弹窗（确认类）/ 气泡（轻量说明）
  平行切换 → 标签页
```

## 二、按钮（最基础的交互单元）

| 层级 | 用途 | 出处 |
|---|---|---|
| 主按钮（实心/白底） | 每屏一个主操作，视觉唯一 | Material Design 3, "Buttons" |
| 次要按钮（描边/文字） | 并列的次级操作 | 同上 |
| 危险按钮 | 破坏性操作，红色/错误色 | 同上 + WCAG 1.4.11 |

要点：
- **每屏只一个主按钮**——两个主按钮 = 用户不知道点哪个（Nielsen #8 美学极简）
- 按钮文字用动词（「保存」「删除」），不用「确定/OK」——Jakob 定律：惯例如此
- 禁用态：置灰即可，不加 tooltip 解释为什么禁用（要解释就保留可点并提示）

## 三、弹窗 vs 抽屉 vs 气泡（浮层的选择）

| 组件 | 什么时候用 | 什么时候别用 | 出处 |
|---|---|---|---|
| 弹窗 Dialog | 必须阻断才能继续（确认、关键错误）；内容短 | 内容 >1 屏；只为了展示信息 | Material Design 3, "Dialogs" |
| 抽屉 Sheet | 编辑详情、上下文操作，用户要边看背景边填 | 仅一次确认 | 同上 "Side sheets" |
| 气泡 Tooltip | 轻量解释、图标含义 | 承载交互操作 | HIG, "Tooltips" |
| 弹出菜单 Menu | 一组操作，鼠标跟随 | 表单输入 | Material "Menus" |

弹窗三铁律（NN/g）：
1. **确认框不如撤销**——「你确定吗」打断流，给「撤销」更友好（NN/g, "Never Use a Warning When You Mean Undo", 2019）
2. 弹窗必须有关闭路径：Esc、点遮罩、× 三选二
3. 弹窗打开时焦点必须锁在弹窗内（焦点陷阱），关闭后焦点回到触发元素（WCAG 2.4.3）

## 四、表格（工具 UI 的主力组件）

| 设计点 | 逻辑 | 出处 |
|---|---|---|
| 行高 | 紧凑 32-36px，数据密集场景可到 28px | Material density 规范 |
| 表头冻结 | 滚动时表头常驻，用户知道每列是什么 | NN/g 表格研究 |
| 列宽 | 关键列优先，不强制全列等宽 | 同上 |
| 排序/筛选 | 放在表头/表顶，就地操作不跳页 | Material "Data tables" |
| 行操作 | 悬停显示行操作（编辑/删除）比永远显示更干净 | NN/g, "表行操作"实践 |
| 批量操作 | 选中后顶部出现批量工具条——不做全选隐藏 | Material "Data tables" |
| 空状态 | 见 [[状态与反馈]]（不能只写「无数据」） | |

## 五、开关/复选/单选/分段控件

| 控件 | 什么时候用 | 出处 |
|---|---|---|
| 开关 Switch | 立即生效的设置（开/关），且生效状态可见 | Material Design 3, "Switches" |
| 复选框 Checkbox | 多项选择、批量操作 | 同上 "Checkboxes" |
| 单选 Radio | 互斥选项 ≤5 个且全部可见 | 同上 "Radio buttons" |
| 分段控件 Segmented | 2-5 个互斥视图/选项切换 | 同上 "Segmented buttons" |
| 下拉 Select | 选项 >5 个或空间紧张 | 同上 "Select" |

规则：**开关用于「立即生效」**，如果开关后面还要点「保存」，用复选框（Material 官方区分）。

## 六、搜索与列表

| 设计点 | 逻辑 | 出处 |
|---|---|---|
| 搜索框可见 | 工具 UI 搜索常驻顶栏，不藏进菜单 | Nielsen #6 |
| 空结果 | 给「没有匹配项 + 清除筛选」动作，不白屏 | 见 [[状态与反馈]] |
| 输入防抖 | 300ms 防抖再查，避免每次击键请求 | 工程实践（非规范） |
| 列表项操作 | 悬停操作 + 右键菜单 + 批量（选中模式）三通道 | NN/g 列表研究 |

## 七、提示类组件

| 组件 | 用途 | 出处 |
|---|---|---|
| Toast/Snackbar | 非阻断的轻量结果反馈（已保存） | Material "Snackbars" |
| 行内错误 | 表单校验错误就地显示，不弹窗 | 见 [[表单设计]] |
| 进度指示 | 不确定时长用转圈，确定时长用进度条 | NN/g "Progress Indicators" |
