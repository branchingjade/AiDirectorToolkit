## 关键决策记录

1. **电影拆出独立成树**：不是给短剧导演助手加"电影模式"——因为导演助手的核心资产（视点/光/镜头对）本来就是电影语言，短剧只是降级应用。加模式 = 把高级形态降级成低级形态的选项。
2. **21:9 默认**：Seedance 原生支持，无需裁切方案。宽银幕不是"更宽的画面"，是"更多不在场之物的容身之处"。
3. **🔒 类型强制门禁**：加载先判断项目类型并询问用户，未确认禁止开工。判断素材事实是识别（自动），决定类型是创作决策（必须用户拍板）。
4. **好莱坞格式 + 国内双轨**：AI 生成分镜用好莱坞格式（结构语义清晰 AI 友好），国内备案/剧组用国内格式（日本式场次标题）。审查预检只标风险不自我审查。

## 短剧污染检查清单（电影套件零继承）

创建后必须全文扫描以下词，区分"正当引用"（类型门禁选项/对比说明/不继承声明）与"内容依赖"（应清除）：
- "同短剧版" / "见 AI短剧导演助手" —— 内容依赖，必须改为独立编写
- 9:16 / 竖屏 / 集末钩子 / EP0 —— 出现在创作原则上即污染
- 实测发现并修复：AI电影导演 3.8 情绪工程写了"同短剧版生理映射"，改为完整独立映射表 + 电影版补充（微表情渐进跨3-5镜 / 长特写呼吸 / 群像情绪对位）
- **评估时必须复查**：修复后仍要用 grep 全文扫描确认无残留（"短剧"字样剩余须逐条判断正当性）

## 理论补强阶段（第三批，McKee 体系）

用户要求"深挖理论知识、发掘实际案例、尺度只做风险判断不影响创作"。薄弱点补齐方式：
- 编剧层：控制思想（theme 是句子不是词=删戏标准）/ 欲望vs需求（Blanche 例子）/ 场景=价值转换（存在性测试）/ 节拍=行为交换 / 预期与结果之缝 / 节奏四级 / 潜台词信息差
- 导演层：运镜语义学 / 构图（三分法1797出处）/ 色彩（冷暖/饱和度）/ 蒙太奇vs巴赞 / 声音三层 / 场面调度（Sikov"每个细节都是意义的陈述"）
- 理论落地原则：**每条理论必须写成可操作规则**（控制思想→删戏标准、场景→存在性测试、运镜→使用场景表），不做知识堆砌
- 审查尺度纪律：预检环节"只标风险点，不修改创作"——创作自由与合规分开，用户明确定调

## 评估→补齐阶段（第四批，用户要求"拉高水平、拒绝短板、不计成本"）

### 评估框架（从专业角度 + 观众交付两个维度）

**专业角度**（创作层）评级 ★★★★：理论扎实但缺 9 项——编剧（人物塑造体系/类型惯例/对白体系/序列设计/副线管理）+ 导演（动作场面编排/转场设计/场景内镜头逻辑/表演可控性）。

**观众交付**（制作层）评级 ★★：**从分镜到成片链路几乎空白**——这是最大短板。
```
分镜 → ①逐段生成(450-750段) → ②拼接剪辑(无方法) → ③跨段一致性(无方案)
     → ④声音(无链路) → ⑤调色(无) → 观众
```
核心判断："这套 skill 是高分电影的**创作引擎**，不是**制作引擎**。分镜是设计图，电影是盖好的楼。"

### 补齐落地（14 项缺口全修复）

- 编剧 v2.3.0 新增二·六章：人物塑造（小传两层/矛盾句/抉择验证/配角矩阵）+ 类型惯例表（6类）+ 对白体系（逐行双功能自检/语域/独白）+ 八序列法+副线管理
- 导演 v1.2.0 新增三·六章：场景标准镜头构成（7步）+ 动作编排（黑泽明/成龙/吴宇森三范式+打击感）+ 六种转场对照 + AI连续性四条落地

## 系统性自检阶段（用户要求"系统地完善地自检"）

构建完成后用户要求系统自检，**每次都能抓到真 bug**，本轮抓到 2 个：

1. **AI电影编剧 引用缺失**：正文五章"留白与呼吸"跟脚引用《导演研究-东方.md》，但该文件只在 AI电影导演 的 references/ ——正文引用正确、文件缺失 → 复制文件 + 参考列表补登记
2. **AI电影导演 冗余引用**：参考列表有《高分剧本分析.md》《格式规范研究.md》但正文从未引用 → 从列表删除（保持列表=正文实际引用的双向一致）

**双向一致性检查法**（用 Python set 差集，勿用 sort——中文文件名 sort 报错）：
```python
refs_cited = set(re.findall(r'《([^》]+\.md)》', open(skill_path, encoding='utf-8').read()))
refs_actual = set(f for f in os.listdir(refs_dir) if f.endswith('.md'))
missing = refs_cited - refs_actual   # 引用但缺失 → 复制文件
extra = refs_actual - refs_cited - {'CHANGELOG.md'}  # 有文件未引用 → 删列表项
```

其他自检发现：sort 对中文报 "string comparison failed"（LC_ALL 问题，改用 Python）；AI短剧编剧助手早期"形态规划含电影"残留引用了不存在的"二·六电影专项"锚点（方向变了电影独立成树后成死链）→ 回退为集数规划 + 引导加载 AI电影编剧；AI短剧导演助手锚点 `[5.2](#52-父agent审查维度)` 指向不存在的锚点（实际 5.2 是地基工作流、父Agent审查在 6.2）→ 修正指向。

**自检纪律**：修复后同步正本并 commit（自检 fix 也是发布的一部分）；delegation 日志（live/deleg_*、subagent-summary-*）清空——用户问"还有个子代理"时真相往往是超时任务的日志残留，不是活跃进程。
