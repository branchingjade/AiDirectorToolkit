# UI 设计方向预览

当需要在扩展开发中探索 UI 方向时：

1. 在 `.design/` 下创建独立 HTML
2. 内联所有 CSS，2-3 个方案并排展示
3. Shadow DOM 中不依赖外部样式表
4. 用 `start "" path` 在浏览器打开

## 设计方向生成原则

- 给每个方案一个**明确的命名**和差异化视角（如"精炼暗色"、"毛玻璃"、"胶囊式"）
- 用 `backdrop-filter: blur()` 实现现代毛玻璃效果
- 用 CSS 变量 `--accent` 统一主色调
- 按钮形状、标签风格、输入框样式各方案应有明显区分
- 状态文案（success/error）用不同颜色区分

## 确认方向后

将选定的 CSS 写入 Shadow DOM 的 `STYLES` 常量中，直接替换。
