# CHANGELOG — AI电影编剧

## v2.1.0 — 2026/08/05

### 国内适配（格式对照 + 备案审查预检）

- **新增六·五章「国内适配」**：好莱坞格式（AI生成友好）与国内格式（备案/剧组）双轨对照
- **国内格式研究**：文学剧本→分镜头剧本（工作台本）→完成台本三阶段流程、日本式场次标题（`第8场 民舍 门外 日 外`）、对白/动作/OS·VO 国内惯例——15 个真实中文来源入库
- **备案审查预检**：以《电影管理条例》第二十五条禁止内容十项为法规依据，转化为 8 项剧本预检清单——**标注风险，不自我审查**，创作自由与合规分开
- **法规跟脚**：政府网《电影管理条例》公报全文（第24/25/26条原文）+《电影产业促进法》主席令公告 + 国家电影局政策法规栏目
- **顺带修复**：参考研究文档列表移除错误的导演研究引用（编剧 skill 不需要导演研究）

### 来源

- 用户要求：好莱坞格式在国内的适用性研究 + 适配国内审核

## v2.0.0 — 2026/08/05

### 标准行业格式重建（v1.0.0 作废）

- **格式彻底重写**：废弃 v1.0.0 的短剧简化格式（场标/△），改用好莱坞行业标准剧本格式——Courier 12pt、Slugline（INT./EXT.+地点+时间）、Action（现在时+只写可见可听+人物首现大写）、对白（角色名居中大写+括注克制+O.S./V.O.扩展名）、转场（右对齐+spec script禁镜头指令）、1页≈1分钟
- **全部规范带跟脚**：Final Draft / Writers Store（David Trottier）/ StudioBinder / Wikipedia / John August 五来源，原文引文入库
- **三幕结构带跟脚**：Syd Field 三幕范式 + Plot Point 定义 + Climax/Resolution 原文（Wikipedia 三幕结构条目）
- **剧本实证**：6 部高分电影剧本分析（肖申克/教父/寄生虫/银翼杀手2049/低俗小说/卧虎藏龙）——编号场景制、动作/对白比例、潜台词写法全部实证入库

### 保留（v1.0.0 继承）

- 🔒 类型强制门禁（加载先判断+询问，未确认禁止开工）
- 电影能力哲学、画面锚点、双路径入口（改编/原创）、场次节奏、电影美学宪法、审查、去AI味

### 来源

- 用户要求：剧本用标准行业规范，电影项目不能马虎，所有内容要有跟脚
