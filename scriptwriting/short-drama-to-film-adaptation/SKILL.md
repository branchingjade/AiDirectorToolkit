# 短剧改编电影

把多集短剧（单元剧/系列剧）改编为电影剧本的工作流。核心原则：**改编不是压缩**——不是"删掉哪几集"，是重新选择"这部电影在写什么"。

## 一、核心判断：单主线

- 短剧（单元剧）= 串珠：每案独立起承转合，观众随时可看可弃
- 电影 = 单主线：主角一个欲望、一条弧光，所有场景推着它走
- **改编第一刀不是删戏，是决定主线**。从素材里识别两层结构（案件层 / 暗线·身世层），选一层做主心骨；被放弃的层要么压缩为过场，要么砍掉
- 主线反派的错误写法：写成"被主角一路撞上的妖怪"。正确写法：**执棋人**——她/他从开场就在，每个案件的转折都是她推的，片尾揭示"主角从第一次下山的每一步都是她安排的"
- 判断标准：电影要的是一个人物的变化。素材里哪条线自带完整弧光（怀疑→否认→接受），哪条线就是主心骨

## 二、资产盘点法

改编前先盘点素材价值，分档决定留/压/砍：

| 档位 | 资产类型 | 处理 |
|---|---|---|
| ★★★★★ | 情感发动机（如师徒关系） | 全保留，电影的心脏 |
| ★★★★★ | 完整弧光（身世线） | 做主线 |
| ★★★★ | 主题题眼（可贯穿全片的价值观句子） | 开头说一次、结尾再说一次 |
| ★★★★ | 自带起承转合的案件（可直接做第三幕） | 保留 |
| ★★★ | 单元剧填充（主题重复度高的案件） | 压缩为过场或砍掉 |

## 三、概念迭代：用户的否定信号

改编讨论中用户反复否定时，每句否定都是一个方向信号，不是让你换方案重来：

| 用户说的 | 含义 | 应对 |
|---|---|---|
| "一生被告知你是人很奇怪" | 角色认知要用**默认值**而非**宣告** | 改："他从来没被告诉过任何事，所以'我是人'是默认值，不是宣告。他不知道自己有什么好怀疑的——直到反派把问题塞给他" |
| "不够精彩，深度也不够" | 设定是套路（反派模板的排列组合） | 从**物理事实**出发发明（如镜子的本质=映照/被看见才存在），不从"反派想要X"模板出发 |
| "太单薄" | 你在做**功能设计**（她能干什么、蛊惑谁），不是**人物设计** | 停下来问三件事：她是谁？她想要什么？她和主角是什么关系？ |
| "段落感太强" | 各案件独立起承转合，拼成三段短剧 | 融成单线：砍次要案件，让主线反派贯穿每个环节（蛊惑/操控推动每个转折） |
| "镜妖不能只限制在镜子中" | 反派不能是被动等待的囚徒 | 给她自由行动的方式（附着于所有反光面），她主动搅局 |
| 反派"有自己的不幸，但不应少这条主线" | 反派可以有悲剧性，但不能抢主线 | 反派的动机服务于主线：她的不幸是"不和"的结局，主角的胜利是"和解"的证明 |
| "靠镜妖的蛊惑来推动" | 反派的功能定位是幕后执棋人 | 她蛊惑不同的人推动每个转折，唯独蛊惑不动主角（主角的特质成为免疫的原因） |

**核心纪律**：用户否定方向时（"太烂了，我再想想"），**停止给新方案**，把空间让给用户，等他说出内核。用户给出内核后（如"最终应该落在主角对伏妖师和妖力的和解上"），抓住它，所有设定重新围绕它收拢。

## 四、世界观自洽检查清单

改编讨论中用户会连环追问逻辑漏洞，写设定前先自查：

- [ ] **地理逻辑**：修行地不能挨着大妖领地（师父不可能留大妖在眼皮底下）→ 大妖领地在远方，复仇靠"远行过场"衔接
- [ ] **道具行为逻辑**：封印物/秘密不会被随身携带（藏了十八年的铜镜放暗格，不放包裹）→ 被激活要有合理解释（贪吃的萝卜精翻遍全屋找吃的，翻到暗格）
- [ ] **角色行为逻辑**：师父的原则要一致（表面见妖必收，内核渡妖不杀妖——捡白骨是"渡"不是"收"，捡的是"死透的材料"或"有灵之物"要有明确动机）
- [ ] **精与妖的光谱**：精=灵智初开的白纸（无害、力量弱、连妖气都藏不好）；妖=有修为有经历的存在。善恶是**经历**出来的，不是天生的——这决定每个妖的角色逻辑
- [ ] **敏感情节预判**：涉及婚姻欺骗、女性受害等情节，现代观众敏感——要么用受害者视角处理（骗局精心设计、受害者无辜不蠢），要么换一种恶行
- [ ] **角色认知**：秘密要用"从未被告诉"而非"被告知谎言"（后者奇怪，前者是默认值）

## 五、用户偏好的改编方向（本用户）

- **结构**：一波三折；三场打斗递进（小→中→大），大场面打斗在开阔空间
- **美术**：国风意境——烟雨江南、竹林古桥、大漠孤烟、金碧楼阁雕梁画栋
- **男主**：大智若愚（郭靖式）——笨拙、慢、认死理，护人本能快过思考（眼疾手快挡符）；"憨"成为对抗蛊惑的天然武器（听不懂鬼话）
- **师父**：双面人格——人前高深莫测的大师（一句话应下除妖），人后不拘小节的小老头（晾白骨、喝妖灵酒、骂徒弟"孽徒"）
- **主角的"和解"**：承认+驾驭，不是二选一（不是"不用妖力赢了"=否定，也不是"用妖力赢了"=堕落）
- **喜剧调节器**：天真型小妖（如萝卜精）贯穿全片——大咧咧、贪吃、管主角叫"傻大个"；天真免疫蛊惑（"你孤单吗？"成为反派的破防点）；她的引入要跟主线触发合成一场戏

## 六、后期定型的关键手法（本会话验证）

### 反派 Boss 的动机：嫉妒主角"有人护"

反派的不幸要**具体到人际关系**，不是抽象的力量欲望。本会话定型：镜妖嫉妒主角有个好师傅——"你师父护着你长大。我当年……没人护我。"她的恨来自"从没被护过"的委屈，不是妖力失控。

- 主线咬合：主角能和解（不被妖力吞噬）是因为有人护着长大（根基）；反派被吞噬是因为没人护（没有根基）
- 反派的失败设计：她输给的正是她嫉妒的事实——**三人合力**：主角正面打、天真者一句话破防、师父千里外削弱（反派恨"有人护"，压垮她的正是"有人护"）
- 双反派对比：一个是被供奉的恶（黑土妖：村民拿人命喂出来的山神，不觉得自己是恶，"我收祭品天经地义"），一个是被抛弃的苦（镜妖：知道自己苦）。"被供奉的恶" vs "被抛弃的苦"

### 喜剧角色兜底原则（用户原话："不合理的地方就让萝卜精干"）

故事里**逻辑不通、太巧合**的地方，全部交给天真喜剧角色去圆——她贪吃、满屋乱跑，做什么都合理，还白赚喜剧。本会话实例：
- 封印物怎么被激活 → 她翻遍全屋找吃的，翻出暗格铜镜
- 沉睡的白骨怎么恰好这时醒 → 她碰到白骨，白骨"动了一下"
- 主角怎么发现关键信息 → 她跟反派唠嗑说漏嘴（她成了反派的信息源）；她传话给主角（"傻大个！骨头说话啦！"）
- 同一个窗口喂了反派（信息源）又戳了反派（破防点）——结尾她的天真让反派沉默

### 配角死亡设计：失败者的死亡 > 胜利者的牺牲

配角（兔妖）死法：**复仇未竟、被仇人杀死**——她拼尽全力仍打不过（力量本源在仇人肚子里，注定赢不了），死在主角怀里。比"为救主角挡刀而死"更惨：
- 她偷了主角的丹（背叛一个恩人）→ 带丹复仇仍失败被杀 → 临死把丹塞回主角手里 + 传话（"偷你丹的事……是镜子里的人让我做的。她在看着你。"）——一命还一命，且把线索递给主角引爆下一幕
- 反派蛊惑的棋子"用完就丢"：蛊惑她偷丹（夺钥匙）→ 迷心智杀生（毁掉她的干净）→ 借他人之手杀她（灭口）

### 师父掉线 = 有目的的离场（布棋）

师父中段全程不在场不是剧情漏洞，是他的局：
- 离场前埋线（两三笔）：晾白骨不是随手，是"渡"——擦骨、涂药、念咒十八年；离场前回头看一眼白骨（他知道它会醒，也知道徒弟会走完这一步）
- 留下天真者在主角身边（蛊惑不动的人），自己千里外做削弱反派的事
- 结尾收伏笔：师父回来，看到绳上白骨空了（配角已散），沉默，收绳——"渡，在他手里开始，在徒弟手里完成"
- 掉线的情感价值：配角死时观众会想"师父在就好了"——"师父不在"本身就是戏

### 引入与主线触发合成一场戏

喜剧角色的首次出场不要做成纯插科打诨——**她的引入就是主线触发**。本会话定型：打戏收尾→师父顺手收草丛里的她（顺手=见妖必收的职业惯性）→主角眼疾手快挡符（手背灼印，跨场追踪的道具）→"带着吧"（留白：师父为什么留她）→回茅草屋她翻出铜镜激活反派。一场戏完成：角色立住+主线触发+师徒价值观冲突（见妖必收 vs 妖分好坏）第一拍就响。

### 概要文案的设定一致性自检（本会话末尾教训）

用户锁定人设后，**后续所有产出（概念卡、一句话故事、callout、时间轴）必须逐字对照已锁定设定**——很容易在总结性文案里把被否定的旧设定写回去而不自知。本会话实例：用户明确"男主不知道自己是妖、不知道有内丹"，但一句话故事写成"内丹被偷妖力尽失，只能靠伏妖术"——"妖力尽失"暗示他曾经拥有（错），"只能靠"暗示退而求其次（错），实际是他从未用过妖力、伏妖术就是他本来的活法。

自检清单（每次写概要/总结性文案后过一遍）：
- [ ] 主角认知：他"不知道"的事，文案里不能写他知道/失去
- [ ] "只能/被迫"类措辞：只在他真的失去过选项时才用；本来就只有一条路时直接陈述
- [ ] 每个角色属性逐项对照人物小传（身份、认知、能力边界），不凭印象写
- [ ] 写完用用户自己的话复述一遍设定，看文案是否被"常识直觉"污染（人设反常识处最容易被顺手写成常识）

## 七、工作流

改编分析（资产盘点+主线方案对比）→ 用户拍板方向 → 画面锚定（对准暗线，不选明线趣味画面）→ 概念卡迭代（接受用户多次否定修正）→ 大纲构建（时间线+一波三折+打斗递进）→ 分场设计 → 初稿。

画面锚定注意：改编的画面锚点要从素材里长出来，但必须**只属于这部电影**（含暗线要素），能跨场追踪（道具的时态替不在场的人说话）。

## 八、知识库笔记的"去 AI 味"

改编讨论的产出（大纲/人物小传）写入 Obsidian 时，用户要求**去 AI 味**（"AI感有点重"）。具体病症与修法：

| 病症 | 例子（✗） | 修法（✓） |
|---|---|---|
| 评述腔（影评人语言） | "——离场，他的局开始走""价值观冲突开场第一拍就响" | 只写发生了什么，删"这象征着什么" |
| "不是X，是Y"句式 | "不是抛弃，是布棋""不是听不懂，是恶对她无效" | 直接陈述事实："他留下小白，自己走" |
| 抽象总结代替画面 | "护不住""有人护着"（概念反复出现） | 具体事件："他陪她复仇，她死在他怀里——他不知道自己丢的是什么" |
| 术语堆砌 | 弧光、感情语言、跨场追踪、具象化、世界观锚点 | 换大白话："变化""表达感情的方式""他的安排" |
| 重复强调 | "全片唯一让镜妖沉默的话"×2 | 保留一次 |

原则：**只写发生了什么，不写这象征着什么**。人物写他做什么/怕什么/要什么，大纲只写事件序列——读起来是创作笔记，不是影评。写作时直接按此标准产出，不要等用户纠正。
