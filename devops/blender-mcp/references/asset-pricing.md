# 3D 资产渠道费用对比

## 内置渠道

| 渠道 | 费用 | 单模型成本 | API Key | 备注 |
|------|------|-----------|---------|------|
| **Poly Haven** | 🟢 免费 | $0 | 不需要 | CC0 许可，HDR/纹理/模型可直接下载 |
| **Hyper3D Rodin** | 🟡 按量 | ~¥3-10/个 | 免费试用 key `vibecoding` | Free tier: $1.5/credit; Creator: $24/月 ~60模型 |
| **Sketchfab** | 🟠 订阅 | 免费浏览 | 需 API key | 下载需 Pro 计划 (~$15/月起) |
| **Hunyuan3D** | 🟡 按量 | 按腾讯云计费 | 需 SecretId/Key | 新用户有体验额度 |

## Hyper3D Rodin 订阅详情

| 档次 | 年付月费 | 月模型数 | 单模型成本 |
|------|---------|---------|-----------|
| Free | $0 | 按需 | $1.5/credit 现结 |
| Creator ($30) | $24 | ~60 | ≈$0.40 |
| Creator ($60) | $48 | ~120 | ≈$0.40 |
| Enterprise | 定制 | 无限 | 洽谈 |

## 推荐策略

1. 先用 Poly Haven 搜免费资产
2. 搜不到用 Rodin Free 预览生成（确认前不扣费）
3. 批量需求开 Creator 订阅
4. Sketchfab / Hunyuan3D 作为补充

## 外部 3D 生成 API（不内置，需自行写 Python 调用）

- **Meshy**: 文/图转 3D，$16-96/月
- **Tripo3D**: 图转 3D，中文友好，免费额度+按量
- **Luma AI**: 手机扫描转 3D，免费基础版
- **CSM**: 单图转 3D，API 按量
