# AI Skills for Seedance 2.0

两个用于 Seedance 2.0 视频生成的 Claude Code Skill。

## AI导演助手 v10.2.0

完整导演流程——从剧本到分镜的全链路工具。

- 导演初感协议（三问）：情感合同审查
- 导演反问机制：防autopilot决策
- 剧本遵循协议：台词逐字嵌入 + 动作强制继承 + 剧本遵循度门禁
- 分镜代码块格式：标准化Seedance 2.0提示词
- 父-子Agent架构：多集并行产出
- 地基五件套：角色/场景/道具/配音/全局锁

**触发词**：短剧 分镜 提示词 剧本 Seedance storyboard 中剧 格式

## AI提示词助手 v1.1.0

轻量提示词优化——改一段、润一段、不启动全套流程。

- 不编造原则：只优化原文已有内容，不添加原文未暗示的元素
- 禁文学化修辞 + 精确数值替换表（含时间）
- 四层动作体系 + 环境反馈（可选）
- 运镜/光线速查
- 仅 ~3K tokens，不会浪费上下文

**触发词**：优化提示词 改写提示词 润色提示词 改这段 prompt优化

## 安装

将 `.skill` 文件拖入 Claude Code 对话框即可安装。或手动解压到 `~/.claude/skills/` 目录。
