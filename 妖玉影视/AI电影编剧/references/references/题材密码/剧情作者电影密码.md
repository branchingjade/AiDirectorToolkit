# 剧情/作者电影题材创作密码（AI电影编剧 · 题材库 06）

## 一、作者电影的定义（先分清楚你在写什么）

**作者电影的核心不是"讲一个好故事"，是"用一种独特的方式看世界"**。剧情片/文艺片的评判标准不是情节强度，是**观察的真诚度**。

**关键认知（贾樟柯式写实）**：作者电影不靠情节推进，靠**真实时空的累积**——让生活自己说话，导演只负责看。

## 二、串珠结构（小山回家式，作者电影的结构解法）

**一条动作线串起多颗人物珠**：
- 主角的一个未满足欲望是主线（求同行回家）
- 每一颗"珠子"= 一次走访（同一动作的变奏）：发起=求助、收束=落空
- **冲突不升级、不反转**——靠人物群像累积成时代横截面
- 结尾无高潮无解决，只是一个日常动作（剪发）——反戏剧化

**落地**：作者电影不要硬造三幕冲突，用"行走/寻找"母题串起人物，让每个相遇都成为一个时代的切片。

## 三、贾樟柯式写实五件套

1. **长镜头凝视**：剧本直接写"镜头长时间地凝视着小山"——把摄影机写进剧本
2. **非职业演员感**：素人演员、即兴拍摄标注——真实感从选角开始
3. **纪录式拍摄策略入剧本**：场标题直接标注（实地跟踪拍摄）（现场跟踪记录）（即兴拍摄）——剧本即拍摄方案
4. **声响层写实**：京韵大鼓/锅炉鼓风/电锯/《新闻联播》前奏曲/电视广告女声——环境声与广播声拼出城市底噪（每场给 1-3 个具体声源，不用"嘈杂"概括词——声音即景深）
5. **物件写实**：蜂窝煤/旧铁丝/糊满报纸的墙/写在手心的呼机号/"不量也是四毛钱"的体重秤——道具全是时代的证物

## 四、作者电影的对白手法

- **方言粗口的真实生态**：河南话"中不中/俺"×北京话"我告儿你"——语言即人物身份
- **复读机对白**：同一应答机械重复三次，第四次变奏（改词+发抖）引爆全部潜台词（"我知道"×3）
- **时代错位**：食指的诗×民工食堂——两个世界在一句台词里相撞

## 五、常见坑（剧情/作者电影为什么烂）

1. **硬造冲突**：作者电影不需要"升级反转"——串珠结构/日常累积就是它的戏剧
2. **导演腔**：镜头术语/调度写进剧本可以（贾樟柯式），但必须是"观察"不是"炫技"
3. **人物符号化**：底层人物写成"苦难符号"——要具体（真实地名/真实物件/真实方言）
4. **无高潮就乱**：反戏剧化不等于没结构——串珠的"线"（未满足的欲望）必须一直在
5. **旁观冷漠**：作者电影可以有距离，但不能没有情感立场（小山回家对民工的凝视是温暖的）
6. **家庭戏直说爱**：说"我们是一家人"=煽情——饭桌戏/日常戏的动作比台词有力（小偷家族：没有一句"我们是一家人"，但每个动作都在说）
7. **秘密藏太深**：秘密藏在闲笔里但观众回看时找不到线索=作弊——秘密要"摆在明面上没人看的"（小偷家族：审讯室拼出全貌，线索此前全在日常里）

## 五·五、克制家庭戏四写法（小偷家族式）

- **饭桌戏=人物关系总装**：一场饭桌戏完成全部关系交代（经济窘迫/递菜暖意/家族鄙视链/祖孙斗嘴）——没有一句"我们是一家人"，每个动作都在说
- **动作告白**：不说的爱用动作——烧衣服（信代烧掉尤里的旧衣=接纳）、递可乐饼
- **日常戏的"无用时刻"**：看石头里的"大海宇宙"/喊"加把劲"看蚕脱壳——不推进情节的戏是情感地基，**先让观众相信这家人是家人，崩塌才有重量**
- **秘密的时序表**：六人秘密的埋设线索（观众可回看）与揭开场次（审讯信息瀑布，按"伤害最小→最大"倾倒）——**克制的高级形态：秘密不是藏起来的，是摆在明面上没人看的**

## 五·六、大智若愚主角三装置（阿甘式）

- **旁观者视角**：低智主角是纯真过滤器——他如实看见时代（越战/民权/水门），不判断，观众自己判断
- **无动机动机**：主角的行动没有野心（"妈妈说……"），但每个行动恰好撞上时代节点——**笨拙的坚持=时代的照妖镜**
- **串珠结构**：年份珠串起三十年（1951→1981）——与小山回家同构（一条线串多颗珠），但阿甘是"被动卷入"型：时代来找他
- **配角镜像**：珍妮=阿甘的反面——同一时代的两种选择（一个坚持一个坠落），主题在对照里显影

## 五·七、家族即历史（悲情城市式）

- **家族=社会剖面**：四兄弟各代表一种被时代吞噬的方式（江湖/战争/精神/政治）——观众记住的不是历史概念，是四个具体的人怎么被拆散
- **固定长镜头=不介入的观看**：时间自然流淌，事件在时间里发生
- **画中画构图**：门框/窗栏框住人物=命运被框住
- **连失去都是平和的**：悲剧的高级形态——不是没有悲伤，是悲伤被时代压成了日常

## 五·八、青春群像+时代解剖（牯岭街式）

- **杀人不是高潮是尾声**：四小时史诗——真正的戏剧在杀人之前（青春怎么走到这一步），杀人是结果不是爆发
- **帮派=阶级谱系**：小公园/217 帮——少年帮派是社会结构的微缩，**群像不功能化**（100 人物无反派，每个都是时代里的位置）
- **道具链=心理外化**：手电筒→匕首——物的升级=内心黑化的刻度
- **理想化之爱**："小明"=男主角自我投射的女神——他爱的是自己想象的世界，不是她（两个世界碰撞：理想 vs 现实）
- **弱者刺向更弱者**：激情杀人的对象是"世界的无反应"——暴力不是强者的，是无力者的
- **省略式叙事**：杀人后不拍审判——事件后置+后事补刀，观众自己完成道德判断

## 五·九、食叙事东方家庭（饮食男女式——李安）

1. **"食"作为叙事语言**：开篇厨房蒙太奇（8 分钟无对白）——**食物=家庭关系的容器**；六次家宴"人数递减=家庭解体"的容器结构（固定场景+人数变化=关系变化）
2. **开场即埋最大暗线**：第一场电话戏就把最大反转（父亲再婚）埋进日常——观众回头看才懂
3. **宣布炸弹序列**：四人轮流在饭桌上宣布离开/再婚——句式统一、位置统一，**团聚处即离散刑场**
4. **生理隐喻贯穿**：味觉=掌控——"失去味觉"（怀疑）→"尝不出"（失控）→"恢复了"（和解），一个生理设定走完主题弧
5. **结尾交接戏**：一碗汤完成继承与和解——**最日常的动作承载最重的感情**
6. **误导装置**：误导线（梁伯母）从第一场铺到高潮前，真线（锦荣）同样第一场就埋——**反转靠双线铺设，不是临时转折**
7. **对比小偷家族**：是枝裕和=底层温情（共同犯罪蓄力），李安=中产冲突（饭桌宣布引爆）——东亚家庭戏两种范式

## 五·十、莎剧改编史诗（乱式——黑泽明）

1. **本土化七机制**：三箭之训替换爱的表白、三女→三子、战国时代替换宫廷——**保留核心冲突，替换全部文化装置**
2. **动作是圆心不是句号**：火烧城在正中心 41.6-50%（对比七武士：动作在结尾 12%）——**史诗片的动作是结构中心，不是高潮**
3. **彩色符号系统**：旗色/天空颜色随命运变化——**色彩=命运的视觉语法**
4. **弄臣寓言直陈主题**："生而哭"——让最边缘的角色说出主题
5. **弱者之器**：盲者以笛声击溃疯王——**最弱者用最弱的武器对抗最强**
6. **终场坠画**：佛画坠落+"悲哉"——**主题物化的死亡意象**

## 六、自检清单

- [ ] 有"线"吗？（未满足的欲望/行走母题——反戏剧化不等于没结构）
- [ ] 每颗"珠子"是同一动作的变奏吗？（发起=求助/收束=落空）
- [ ] 时空真实吗？（真实地名/时间/物件/方言）
- [ ] 声响层具体吗？（1-3 个具体声源，不是"嘈杂"）
- [ ] 结尾是"日常动作"还是"硬高潮"？
- [ ] 有情感立场吗？（凝视的温暖，不是冷漠旁观）
- [ ] 家庭戏靠动作还是靠台词？（饭桌/日常戏优先）
- [ ] 秘密有可回看的埋设线索吗？（不是作弊式隐藏）
- [ ] 大智若愚主角用了吗？（旁观者视角/无动机动机/配角镜像）
