## 一、志怪题材的定义与谱系（先分清楚你在写什么）

**志怪 ≠ 恐怖 ≠ 玄幻**。志怪的根在"志"——记录奇异之事。它从六朝志怪小说（《搜神记》"粗陈梗概"）长出来，到蒲松龄《聊斋志异》成熟为"用传奇法，而以志怪"（鲁迅《中国小说史略》评语——继承六朝志怪的奇异题材，吸收唐传奇的情节曲折与人物塑造）。

**题材三分法**（《聊斋志异》491篇的构成，百度百科）：
1. **人与异类的情感故事**——爱情主题占比最高（聂小倩/婴宁/连城）
2. **社会矛盾揭露**——借鬼狐刺贪刺虐（郭沫若评："写鬼写妖高人一等，刺贪刺虐入骨三分"）
3. **道德训诫**——因果报应、劝善惩恶

**谱系分层**（本项目《民间伏妖记》世界观同源）：
```
精（草木器物小兽通灵，如孩子）→ 妖（精修炼/经历后有了执念恩怨）→ 鬼（人死后的执念）→ 魔/神（被供奉或堕落的更高存在）
```

**关键认知：志怪的核心不是"吓人"，是"借异类说人"**——妖魔鬼怪是容器，装的是人间的事。纯吓人是恐怖片，不是志怪片。

## 二、世界观三界规则（志怪片的"物理定律"）

志怪世界观必须自洽——观众可以接受有鬼，但不能接受规则混乱。立规则三问：

1. **异类从哪来**？（精修炼成妖？人死成鬼？执念化形？）——决定世界观的根本
2. **异类的限制是什么**？（怕光/怕桃木/不能离本体/需要香火）——限制=戏剧冲突的来源，没有限制的妖是编剧偷懒
3. **人怎么对付它们**？（法术体系/器物/咒语——必须和世界观同源，不能"需要时凭空出现"）

**范本规则**：
- 《倩女幽魂》：鬼不能见光、姥姥控制女鬼、黑山老妖抢亲（规则驱动情节——见下方范本分析）
- 《民间伏妖记》：妖丹是力量之源、妖气可闻可辨、香火养神（本项目的三界规则）
- 《妖猫传》：幻术体系（白龙化猫）、"咒术源于人心怨念"（梦枕貘原著核心设定——百度百科）

**规则自洽检查**：把每个超自然现象列出来，问"这个现象为什么能发生？它受什么限制？"答不上来的就是漏洞——观众会抓（本项目实战：镜妖实体化机制、丹灵去向都被逐环追问过）。

## 三、核心结构范式（志怪片的骨架）

### 范式一：遇妖→查真相→收妖/超度（民间故事结构）

```
① 遇（异类闯入日常，或人误入异界）
② 疑（异常现象堆积，人开始察觉"不对劲"）
③ 查（人主动调查，逼近真相——异类的真面目/来历/冤屈）
④ 情（人与异类产生情感连接——同情/爱/理解，志怪片的魂）
⑤ 决（外部威胁（真正的恶）逼到面前，必须做选择）
⑥ 收（超度/封印/放生/共存——"收"的方式决定主题落点）
```

**关键**：⑥"收"的方式 = 主题落点。超度=慈悲、封印=秩序、放生=尊重、共存=和解。选哪个，电影就在说哪个。

### 范式二：借异类说人（聊斋式反讽）

聊斋的成熟手法：**超现实反转揭穿现实虚伪**（百度文库引例："回头一看房子、院子都没有了，只有一个高大的坟墓"——用超现实场景揭穿封建家庭关系的虚伪）。

**落地**：异类行为折射人间——狐妖比人更重情、鬼比活人更守诺、山神比官员更贪婪。志怪片的高级写法是让"妖"成为照妖镜，照出人的问题。

### 范式三：人异情感（聂小倩式）

人鬼/人妖恋的结构：相遇→身份隐瞒→真相暴露→世俗不容→舍命相救→超度/牺牲/共存。情感是志怪片的发动机——观众为"异类的情"流泪，不为"异类的惨"流泪。

## 四、调性混搭（志怪片独有能力）

志怪片能同时恐怖+温情+幽默——这是它的独门武器，也是最大难点：

| 调性 | 功能 | 来源 |
|---|---|---|
| 恐怖 | 建立世界观的"危险感" | 异类的威胁、规则的可怖 |
| 温情 | 建立情感的"连接感" | 人异之间的理解、守护 |
| 幽默 | 建立观众的"松弛感" | 反差（胆小的收妖者/不懂规矩的异类） |

**混搭要领**：三种调性不是平均分配，是**节奏切换**——恐怖蓄压→温情释放→幽默调节。切换点必须是剧情节点，不是随意跳。范本见《倩女幽魂》（燕赤霞的豪迈幽默 vs 黑山老妖的阴森恐怖 vs 宁采臣小倩的深情）。

## 五、范本分析

### 《妖猫传》（2017，陈凯歌，梦枕貘原著）

**结构**：探案式志怪——妖猫作祟（遇）→ 空海+白居易联手调查（查）→ 白龙化猫的真相（情：白龙对杨贵妃的执念）→ 揭开杨贵妃之死（决）→ 执念化解（收）

**创作密码**：
1. **历史×志怪**：把真实历史（杨贵妃之死）改成志怪谜题——历史给观众"已知"，志怪给"新解"。观众带着"我知道杨贵妃怎么死的"进入，被"我不知道的真相"颠覆——信息差即悬念
2. **执念即妖**：白龙不是"坏妖"，是"执念化形"——他化猫复仇三十年，因为放不下杨贵妃。**妖的动机=执念（爱/恨/冤），不是"天生邪恶"**——这是志怪片塑造异类的核心（与《民间伏妖记》镜妖"执念"同构）
3. **幻术体系**：妖猫传的世界观是"幻术"——一切妖异都可归因于幻术，幻术源于人心怨念。**世界观有"解释一切"的总原理**，规则自洽

**大师做法（陈凯歌）**：用大唐盛景（视觉奇观）包裹一个小人物的执念（情感内核）——奇观是皮，执念是骨。志怪大片的正确做法。

### 《倩女幽魂》（1987，程小东/徐克）

**结构**：四段式——遇妖→感妖→爱妖→救妖（知乎"磐石之玄"归纳）。原著团圆（纳妾）改为"超度转世、人鬼殊途"悲剧——**志怪改编的常见升级：把团圆改成悲剧换取情感重量**。

**创作密码**：
1. **现代化隐喻（徐克核心密码）**：小倩=夜总会小姐、姥姥=妈妈桑、宁采臣=收账社畜——古代女鬼现代化为**被胁迫的风尘女子**。恶行皆有被迫前提，受害者身份使爱情成立。**异类作恶必须"被迫"**，否则观众无法共情
2. **三调并存的结构位置**：恐怖（兰若寺/长舌/鬼域抢亲）=外壳，爱情（琴音邂逅/十里平湖赋诗）=内核，幽默（燕赤霞×宁采臣误解互动）=调节阀——"喜剧与恐怖片的混搭让古装鬼片重成港产片顶尖潮流"（凤凰网评）
3. **世界观三铁律闭环**：①鬼不能见光（时间压力——爱情推入"天亮即死别"倒计时，插曲《黎明不要来》直接服务设定）②姥姥控制女鬼（动机压力——尸骨被弃即受制，害人=被迫服役）③黑山老妖抢亲（升级压力——冥婚升级为地府级决战）。**三规则同源"尸骨不得归葬则魂魄受制"，一个根因长出三重压力**——世界观规则的教科书写法

### 《青蛇》（1993，徐克/李碧华）

**结构**：妖学做人（白蛇教小青走路/说谎/流泪）→ 人间规则反讽 → 情欲觉醒 → 悲剧定价（千年道行换一段凡情）。

**创作密码**：
1. **双向异化**：妖学"做人规矩"成人（规训），法海从人到"佛"先失人性——**妖往人走、人往神走，两条线反向交叉**，中间相撞就是主题
2. **异类质感靠具象细节**：走路（"不说爬了，人们叫爬做'走路'"）、说谎（"说谎说得好，都要练习的"）、流泪（"你连眼泪都不知道是什么"）——**妖与人的区别不是外形，是行为规矩的错位**。写异类要写"它学人学的别扭处"
3. **异类视角=间离反讽**：小青"一千五百年就陪他一个人玩啊？"——以妖眼拆穿人言自相矛盾，结尾"情为何物连你们人都不懂"构成全片最大间离。**给一个"不懂规矩的异类"当观众替身，用它的眼睛看人间**
4. **情欲的妖形编码**：水下灰黑巨蛇=法海欲望化身、蛇舞、丝衣顺水流走——**不可直说的主题借异类的形态表达**（蛇自古象征欲望）

### 《画皮》（2008，陈嘉上）

**结构**：妖披人皮入人世 → 皮相惑人 → 捉妖者调查 → 真相与牺牲 → 妖走人活。

**创作密码**：
1. **皮相vs真心的意象系统**：原著"铺人皮于榻上，执彩笔绘之，披于身，遂化为女子"——人皮=欺骗的具象；电影原创"皮须用人心养护"——**皮相之美以"心"为代价**，把意象升级为全片隐喻
2. **主题反转（最值得学的一招）**：真正"画皮"的是**人**——"你外表忠贞不二至死不渝，可你其实是在画皮""画皮容易，画心难"。**妖是照妖镜：表面上妖在骗人，实际上人在骗自己**——"借异类说人"的极致执行
3. **除妖=感化而非斩杀**：原著道士降妖前感叹"此物亦良苦，予亦不忍伤其生"；电影小唯自毁修为救活众人、化狐而去（"尘归尘，土归土，人复人生，妖回原型"）——**妖从被消灭的恐怖客体，变为主动牺牲的悲剧主体**，这是志怪改爱情片的核心改写
4. **古典→现代的改造法**：因广电对恐怖题材敏感，定调"武打、魔幻、言情"的"东方新魔幻"——**志怪改造不是删恐怖，是换内核**（警世寓言→爱情悲剧，探索"婚姻质变和爱情的两难"）

## 六、常见坑（本题材为什么烂）

1. **规则混乱**：妖想强就强想弱就弱——观众一质疑就崩。必须立规则、守规则、用规则制造冲突
2. **妖=人穿皮套**：异类只是"长得像怪的人"，没有异类的"异"（习性/认知/道德观都和人一样）——浪费志怪设定
3. **恐怖堆砌无情感**：全程吓人，没有"情"的连接——观众吓完就忘
4. **主题缺失**：收妖就是打怪升级，不知道"借异类说人"——志怪片没有主题=没有灵魂
5. **调性撕裂**：恐怖和搞笑硬切，没有剧情节点支撑——观众出戏
6. **规则立而未用（实战坑）**：立了规则（如香火=力量来源）但高潮用"力量碾压"解决，规则变成背景设定——观众会问"既然断香火能釜底抽薪，为什么不这么做？"**实战修正**（《民间伏妖记》场11）：规则必须进入战术层——主角发现香灰线→香炉=命脉→选择断香火→反派护炉露破绽→声东击西。规则从"设定"变成"对抗的手段"，再和后续呼应（断不了→后来真断了）形成闭环
7. **对抗段幽默真空（实战坑）**：恐怖/温情/幽默三调性在前期分配好，但连续高压段（打斗/牺牲/反转连场）忘了放调节阀——观众连喘五口气会疲劳。**实战修正**（《民间伏妖记》场11）：在打斗中给配角一句天然插入的吐槽（被香灰呛到的小白"这炉子是它的命！"）——既是调节阀，又顺势点题

## 七、自检清单（写完过一遍）

- [ ] 三界规则自洽吗？（异类从哪来/限制是什么/人怎么对付）
- [ ] 每个超自然现象都有规则解释吗？
- [ ] 异类有"异"的质感吗？（不是人穿皮套）
- [ ] 有"情"的连接吗？（人异之间的理解/守护/执念）
- [ ] 主题落点清楚吗？（收的方式=超度/封印/放生/共存，选了哪个）
- [ ] 三种调性（恐怖/温情/幽默）切换有剧情节点吗？
- [ ] **规则进战术层了吗？**（立了规则就要让主角用它对抗——发现弱点→利用→反派防守→破绽→声东击西，不能靠力量碾压跳过）
- [ ] **连续高压段有调节阀吗？**（打斗/牺牲/反转连场超过三场，要给配角一句天然插入的吐槽或轻点）
- [ ] 借异类说人了吗？（异类行为是否折射人间）
- [ ] 备案审查：灵异/民俗/志怪题材——明确批判立场，不宣扬迷信？（《国内备案审查研究.md》）
