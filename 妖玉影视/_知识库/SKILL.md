## 〇、走国人的艺术（特定项目/题材专用，用户拍板）

**结构语言用中国叙事，不用好莱坞教材术语。** 骨架是国人的，镜头是电影的——两者不冲突，也不要互相污染。

> **适用范围：特定项目/题材**——国风/志怪/武侠等中国叙事项目（如《伏妖记》）用起承转合；**非国风题材（西幻/都市/悬疑等）照用三幕结构，不受本节约束**。由项目题材决定，不是全套件默认。

| 西方术语（国风项目禁用） | 国人骨架（用这个） | 说明 |
|---|---|---|
| 三幕结构 / 第一幕·建置 / 第二幕·对抗 / 第三幕·解决 | **起承转合**（起/承/转·合） | 诗论/戏曲骨架（元代范德机《诗法》四字法，明清戏曲/评书/章回沿用）；起=立人立事，承=铺排发展，转=高潮反转，合=收束和解 |
| 节拍 | **拍** | 戏曲用语（一段戏的情绪单元）；McKee 的 Beat 称"拍" |
| 抽丝剥茧 / 信息释放链 | **信息一层一层揭开** | |
| 弧光 / 递进 | 用内容说（"三场打斗一场比一场大"而非"打斗递进"） | 大白话优先 |
| 建置 / 对抗段 | 起部 / 打斗段 | "对抗手段"这类战斗描述词不是结构术语，保留合法 |

**落地纪律**（国风项目内）：
- 项目文档/剧本/分场分析/大纲标题全部用起承转合 + 内容命名（"起（0-15min）· 师父走了，白骨开口"），不用抽象结构标签
- 对话回复里同样禁用西方术语——跟用户说话时分段描述也用起承转合
- **术语重构必须同步飞书正本**（伏妖记 08-07 实测：只清 Obsidian 本地，飞书 mermaid 时间轴漏改，直到用户抓用词才暴露）——grep 残留时飞书侧必须 `docs +fetch --scope full` 拉全文检查
- 全文 grep 清理：`三幕|第一幕|第二幕|第三幕|建置|对抗|解决|节拍|抽丝剥茧|弧光|递进`
- 西方编剧理论（Syd Field/McKee/Frank Daniel）保留为**理论跟脚**（用于思考为什么成立），不用于命名骨架
- 研习外部范本时"幕"是分析语言（描述他片原结构），结论落到本项目创作时一律映射起承转合

## 核心招式速查（默认带着，不占检索动作）

> 从 94 部卡片提炼的最高频、跨场景可落地招式——写任何一场戏/一个镜头/一段提示词时直接对照。每条一句话落法+出处（详版见对应卡片）。51 条按场景分组：人物建置/对白/结构/空间/暴力动作/情感/超现实/时代时间/成长弧线/奇幻力量/Boss设计（+3 条伏妖记实战验证，2026-08-07）。

|---|---|---|---|
| **异类出场** | 学人的别扭处=异质感 | 不写"它是妖"，写它学人学不好的细节（走路/说谎/流泪） | 青蛇卡片1 |
| **真相揭露** | 同镜反转三拍 | 偷窥视角→同一镜头内完成变形全过程→变形后复位到"美"，让观众带着真相重看 | 画皮卡片4 |
| **情感交付** | 最轻动作 | 越重的感情越用越小的动作（烧旧物/理衣领），台词说给第三方，动作说给观众 | 小偷家族卡片3 |
| **反派动机** | 投时好 | 恶以人之欲为形——每个受害者的死法/堕落对应其欲望；恶伪装成爱 | 聂小倩卡片2 |

## 使用纪律

1. **写任何创作内容前**（剧本/分镜/提示词）：先扫核心招式速查（默认在场）→ 判断题材加载题材密码 → 判断场景类型查检索表 → 需要细节时读卡片全文（读根因，不照抄结构）。**导演层**（分镜/画面/节奏/提示词）：先查导演美学卡片索引 → 读对应导演卡片（美学体系/桥段设计/AI提示词对接节）
2. **知识库是土壤不是模板**——读技法根因（"它在这里成立是因为什么"），不照抄结构
3. **缺口驱动**：创作中发现知识库没覆盖的手法 → 找范本研习 → 新卡片入库（`电影大师研习` skill 负责生产）
4. **正本唯一**：本目录是知识库唯一正本——各创作 skill 的 references 不再持有副本，统一引用这里
