## 通用纪律

1. 每部片先记**版本**（早期稿/拍摄稿/流传稿/译稿/重映版差异），差异大的单独解剖（七宗罪 1992 早期稿无盒子反转 vs 成片）
2. 英文摘录必须 grep 自本地存档 + 行号可溯（本轮 0 条凭记忆：七宗罪 50/50、木兰花 102/102、安妮霍尔 130/130、社交网络 57/57）
3. 文本层损坏处理：断背山 PDF 字母级损坏（times→tirr,es）→ 人工清理+声明；教父式场景标题丢失 → 换源或标注不可统计
4. PDF 优先 Script Slug 官方稿，HTML 优先 IMSDb（统计可靠）；双源交叉校验是质量底线
