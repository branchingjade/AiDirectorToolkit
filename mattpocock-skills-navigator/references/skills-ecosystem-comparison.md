# Skills 生态系统对比

三种不同深度的 AI skill 范式，按实用价值排序。

## 对比矩阵

| 维度 | 用户自建技能 | mattpocock/skills | theneoai/awesome-skills |
|------|:---:|:---:|:---:|
| 类型 | 可执行工作流 | 方法论文脉 | 角色扮演提示词 |
| 数量 | 3（精） | 30（密） | 956（广） |
| 技能间关系 | 管线上下游 | 强耦合主流程 | 弱引用 |
| 可执行性 | 有完整流程+约束 | 有步骤+完成标准 | 系统提示词模板 |
| 迭代深度 | v11.0.0 | 体系成熟 | v1.0.0 批量生成 |
| 自带脚本 | 有 | 部分有 | 无 |
| 适用场景 | 专业领域深度工作 | 工程方法论 | 快速角色原型 |

## 三者互补关系

```
用户自建技能（深度领域专家）
    ├── AI短剧导演助手 v11 → 制作执行管线
    ├── AI短剧编剧助手 v1.0 → 剧本创作管线
    └── AI提示词助手 v1.2 → 约束同步

mattpocock/skills（工程方法论）
    ├── 需求→实现全流程（grill → PRD → issues → implement → review）
    ├── 架构设计词汇（深模块/接缝/适配器）
    └── 双轴审查（Standards + Spec 平行 sub-agent）

awesome-skills（灵感目录）
    └── 956 角色模板 → 翻翻可以，深度不够
```

## 关键教训

- **角色扮演 ≠ 技能**：awesome-skills 的 956 个 persona 本质是让 LLM 即兴发挥的角色卡，没有流程约束
- **深度 > 广度**：30 个有方法论文脉的技能比 956 个模板有价值得多
- **自建是最终形态**：最好的技能来自对自己工作流的反复迭代和编码
- **模板不能替代流程**：有模板无流程（awesome-skills）= LLM 自由发挥；有模板有流程（mattpocock）= 可预测输出
