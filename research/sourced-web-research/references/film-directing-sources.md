## 2. 转场设计
| 条目 | 内容锚点 |
|---|---|
| Match_cut | 定义（两镜构图/动作/主体匹配）；graphic match = 图形匹配制造隐喻比较；《2001 太空漫游》骨棒→卫星；与 jump cut 的断裂对照 |
| Jump_cut | 定义（抽掉中段时间前跳）；**30 度法则**（机位变化 <30° 观感即跳切）；速度感；Brechtian 间离用法 |
| Dissolve_(filmmaking) | 时间流逝/地点变化/闪回；时长 1-2 秒（24-48 帧）；6-12 帧短叠化柔化硬切；《公民凯恩》慢叠化（沉重）vs 快叠化（活力）对比 |
| Wipe_(transition) | 类型（iris/star/clock wipe）；**隐形划像** = 动作段落顺运动方向/墙体遮挡藏剪辑；George Lucas 学自黑泽明 |
| Sound_bridge（重定向→Split edit） | split edit 定义；L cut（前场声音叠后场画面）/ J cut（后场声音提前）；藏场景切换；防"tennis match"式对话 |
| Cut_(transition) | 核心论断 "The cut represents a continuous transition in setting and time—the dissolve and wipe respectively identify changes in time and setting"；cutaway/cross cut/match cut 变体定义 |

## 3. 场景内镜头逻辑
| 条目 | 内容锚点 |
|---|---|
| Master_shot | 全场景从头到尾单镜头覆盖 = camera coverage 地基（"the foundation of what is called camera coverage"）；拍摄时第一个划掉的镜头 |
| Establishing_shot | 定义（全景/大远景给空间+时间）；可作 reestablishing shot 再锚定空间 |
| Shot/reverse_shot | 定义（A 看画外的 B → B 看回 A，反向面向即互视）；classical continuity 特征、eyeline match 实例 |
| Eyeline_match | 前提 "audience will want to see what the character on-screen is seeing"；画外视线设置要素（180 度法则/焦段/高度/距离） |
| Insert_(filmmaking) | 切入 = 重拍主镜头已覆盖动作、强调细节（钟/信/报纸标题/物件）；**与 cutaway 的区别：cutaway 拍主镜头没有的东西**；连续性要求（物件相对位置+灯光与主镜头一致） |
| Cutaway_(filmmaking) | 三大用途：调节奏 / 掩盖删除的主镜头片段 / 拼接两版本 take；本身不必有戏剧内容 |
| 180-degree_rule | 轴线一侧机位；**"particularly important in the narration of battle scenes"**；越轴需 buffer shot（轴线缓冲镜头）；故意破例（Breathless 等） |
| Continuity_editing | 空间连续性四件套：establishing shot / 180-degree rule / eye-line match / match on action；match on action 定义（下一镜接续同一运动阶段）；30 度法则；dissolve = 模糊省略号 |
| Storyboard | 镜头清单（shot list）环节（"work out any screenplay, camera positioning, shot list"）；分镜 = 低成本预拍、片场回忆工具 |

## 4. 表演连续性
| 条目 | 内容锚点 |
|---|---|
| Continuity_(fiction) | 定义（人物/情节/物件/地点特征一致）；**微错误（杯内水位/香烟长度）vs 明显错误（角色外貌剧变→破坏悬置不信）**；视觉错误（服装变色/影子变化/物件移位）；场记职责与记录内容；三措施：同场连拍 / 每日开拍收工照片对照 / 棚拍控光；CGI "airbrush" 修补 |
| Continuity_editing | 服装跨场景一致、牛奶杯全场满/空一致（"whether an actor's costume remains the same from one scene to the next"）；场记记录交给剪辑师 |
| Insert_(filmmaking) | 插入/切出镜头须保持物件相对位置与灯光一致（导演头疼点） |
