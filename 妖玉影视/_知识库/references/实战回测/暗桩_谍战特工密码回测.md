## 一、逐节对照摘要

### 1.1 定义与谱系（密码"一、"）
定义"谍战的内核是身份——身份是信息差的载体"【谍战·一】对项目是**正中靶心**：一句话故事就是身份问题，无高科技依赖、无枪战堆砌，纯靠"我是谁/我为谁做事"驱动。谱系"写实端身份可以是真谜（失忆）"【谍战·一·谱系】直接命中选型——项目主引擎即失忆引擎。但"古装谍战"作为与写实/经典并列的第三谱系被项目质疑（见 F1）：古装不是独立谱系而是落地语境，写实（失忆剑客）与仪式（夜不收官僚仪式）两型在古装里都能成立。

### 1.2 核心语法（密码"二、"）
- **语法 1｜失忆身份引擎：完全适用，且是项目主引擎**。"技能记得、记忆不记得"【谍战·二·语法1】即项目核心设定；技能显影=小反转、旧物=保险箱道具、身份玩笑收束【谍战·二·语法1】逐条落地。但项目是失忆×双面×替身三层身份叠加，密码的"单谜底"引擎需堆叠扩展（G2）。
- **语法 2｜双线悬疑：高度适用**。寻根线×追杀线互为引擎、信息差分三层投放、日常时刻危险化、官僚冷血【谍战·二·语法2】全部命中。但"文戏负责交换信息差"在双面局被反转——文戏才是主战场（F3）；"观众比角色多"在双面局有专属等待层未覆盖（G5）。
- **语法 3｜环境武器化格斗：适用**。客栈茶楼打斗"市井器物皆兵刃"、借力打力【谍战·二·语法3】即项目第二场戏的动作纲领；城楼决战预埋更鼓/铜锣/灯笼/旗杆。
- **语法 4｜偷拍美学：适用**。铁衣城追捕戏用"偷拍式"纪实运镜，"赶时间"叙事压力（宵禁鼓响/换防时辰）为摇晃提供动机【谍战·二·语法4】；手持只在信息急迫时用。
- **语法 5｜系列重构：不适用**。单部原创无老 IP 可重构，007 式"自嘲→致敬→旧物成为情感事件"【谍战·二·语法5】是系列向语法；其可降维挪用部分（旧物闭环）已被语法 6 覆盖。
- **语法 6｜怀旧主题：部分适用**。弱点=伏笔（"暗桩"二字=心理冻结词）、旧伤=道具（铜鱼符下旧疤）【谍战·二·语法6】直接命中；主场决胜（十年更夫记忆=战术地图，对应"童年记忆=战术地图"【谍战·二·语法6】）可转译落地；"中年"变量适配（主角设定为中年更夫）；M 之死式三段退场对白【谍战·二·语法6】可挪用至夜不收指挥使之死。不适用部分："50 周年创作自觉"与"旧世界挽歌"主题对原创单部无锚点。

### 1.3 范本实证（密码"三、"）
谍影八条中七条直接命中（失忆身份引擎/双线悬疑/环境武器化/偷拍美学/镜像刺客/官僚冷血/结局换档），地理蒙太奇一条国风转译适用（铁衣城多点实拍拼接，地理逻辑让位于剪辑逻辑【谍战·三·谍影7】）。007 七条中三条命中（人性化特工/回家叙事主场决胜/反派镜像）、三条边缘适用（功能化动作、实拍特技装置、M 之死退场仪式）、一条不适用（系列重构）。两型对照表【谍战·三·两型对照】验证了"写实本能型"选型零歧义；选择判据"主引擎只能选一个"【谍战·三·选择判据】被验证，但项目显示仪式型语法可作辅料（堂审官僚腔、更鼓切换）——判据可扩展为"主引擎唯一、辅料可混"。

### 1.4 常见坑（密码"四、"）

## 三、缺口清单（密码未覆盖、项目暴露的盲区）

| # | 缺口 | 说明 |
|---|---|---|
| G1 | **双面细作无专属语法** | 密码谱系表只给"中间地带是卧底/双面间谍——身份既是面具也是牢笼"一句推断【谍战·一·谱系】，无独立语法。《暗桩》需要三件套：①切换节拍器（信物/暗号/更鼓时辰=切换的仪式化开关，每次切换=一场小事件）；②双面信息差设计（观众知道哪一面/甲方知道什么/乙方知道什么/角色自以为知道什么——比悬疑信息表多"哪一面"一维）；③双面结局三种收法（选一边/都不选/被两方同时抛弃）。失忆引擎（单身份谜）与神话身份（确定传统）都不是"同时扮演两个身份"的语法 |
| G2 | **多层身份堆叠的揭晓节奏缺失** | 密码失忆引擎是单谜底（伯恩只有一重"我是谁"）；《暗桩》是失忆×双面×替身三层叠加——每揭一层必须同时重写"他是谁"与"他为谁做事"（渡口喊出"暗桩"=重写前两层，城楼真相=重写全部）。密码缺"多层身份揭晓的堆叠语法"：每揭一层，前一层被重估；观众的信息差随层数递增而非递减 |
| G3 | **古装谍战谱系无实证支撑，国风对接缺仪式一脉** | 密码自己声明古装谱系"未取证到专门技法卡"【谍战·一·谱系】；六节国风提示词全部是写实本能型转译（失忆剑客/官差追捕/市井打斗）。《暗桩》证明国风仪式型同样成立：夜不收的奏折/密令/堂审官僚仪式、更鼓时辰=身份切换节拍器、面具接头=仪式化伪装。缺"仪式型国风对接"条目 |
| G4 | **古代通讯/交通速度对悬疑节奏的约束无覆盖** | 密码追杀线是电话/卫星时代的节拍（康克林随时调人）；《暗桩》的灭口线受飞鸽、驿站、马程、宵禁、换防约束——"灭口令要三天才到"本身可以是悬念结构（在途的密令=观众比角色多的等待层）。密码无古代信息传播速度的节奏语法 |
| G5 | **"观众比角色多"在双面局的完整玩法缺失** | 密码只在追杀线提"观众比伯恩多（等'何时'被抓）"【谍战·二·语法2】；双面局有专属玩法：观众知道他是被派回的假暗桩（角色不知自己旧身份）→"等何时暴露"与"等何时想起"双等待轨并行。密码无双面局专用信息差投放层 |
| G6 | **双面细作的"伪装职业"语法缺失** | 卧底需要"装什么像什么"的职业外壳（更夫/账房/仵作），职业行为=伪装也是线索（更夫能背全城时辰表=职业病证据）。密码"特工=风格化执行者"（怎么做事）与"谍战=身份博弈"（我是谁）之间缺"伪装职业"一层——双面局的执行者风格化=职业外壳的逼真度与裂缝 |

## 六、最值得回写 3 条

1. **新增"语法 7｜双面细作身份引擎（身份既是面具也是牢笼）"**——三件套：①切换节拍器（信物/暗号/更鼓时辰等仪式化开关，每次切换=一场小事件，切换即暴露风险）；②双面信息差四表（观众知道哪一面/甲方知道什么/乙方知道什么/角色自以为知道什么——比悬疑密码信息表多"哪一面"一维，《暗桩》堂审后观众>主角即此玩法）；③双面结局三种收法（选一边/都不选/被两方同时抛弃，对应减法收束）。同步扩展选择判据为"主引擎唯一、仪式型辅料可混"（《暗桩》堂审官僚腔+更鼓=仪式辅料）。回写位置：二、核心语法 + 一、谱系表。
