## 鉴权方式

| 方式 | Header | 说明 |
|------|--------|------|
| 新版控制台（推荐） | `X-Api-Key: <key>` | 单头鉴权 |
| 旧版控制台 | `X-Api-App-Id` + `X-Api-Access-Key` | 双头鉴权，即将下线 |
| AKSK | HMAC-SHA256 签名 | 控制台接口用 |

- HTTP 请求：`openspeech.bytedance.com`
- 控制台接口：`open.volcengineapi.com`

## 异步接口模式

统一 submit + query 模式：
- submit: 提交任务，返回 task_id
- query: 通过 task_id 查询结果

## WebSocket 接口

- 4 字节二进制 Header + Payload
- 大端序
- Message Type: 0b0001=FullClientRequest, 0b0010=AudioOnly, 0b1001=FullServerResponse, 0b1111=Error
