# 视觉工作流踩坑记录

## 1. 参考图像视觉宪法

当用户提供场景/空间参考图时，必须忠实提取并再现图像中的具体视觉细节。参考图像是场景的"视觉宪法"。

**禁止泛化 → 必须具体：**
- ❌ "老式酒店走廊" → ✅ "暗色人字拼木地板+铜质壁灯乳白织物灯罩+深色长条地毯金边纹样+深色木墙裙+黄铜门牌"
- ❌ "窗边沙发" → ✅ "深蓝天鹅绒单人扶手椅，绗缝靠背，卷边扶手，复古短腿"

**提取清单**（每个参考图逐项过）：
- 材质：木种/织物/金属/玻璃/石材
- 色彩：色调/饱和度/反光/做旧程度
- 光源：灯具类型（壁灯/吊灯/窗光）、灯罩材质、色温
- 家具：款式（年代/风格）、尺寸比例、摆放位置
- 装饰：画框/花瓶/植物/地毯纹样
- 空间层次：前景/中景/后景各有什么

**实战案例**：万倩套房参考图 → 深蓝天鹅绒扶手椅、白瓷花瓶+白花、纱帘+深蓝绒布窗帘、人字拼木地板、两扇大窗、老式暖气片。所有这些细节都进入分镜描述，无一泛化。

## 2. 入场POV铁律

当角色进入一个新空间时，观众与该角色一同进入。镜头不能跳越进入者的眼睛。

**正确流程**：
```
段X：    进入者推门/迈步（观众跟进入者一起）
段X+1：  进入者环顾（POV摇镜 + 视线落点）
段X+2：  切到空间内已有角色/物件的特写
```

**禁止模式**：
```
❌ 陈强推门 → 立刻切万倩特写（摇酒杯/红肿眼眶）
   问题：观众还没跟陈强一起"看到"万倩，预切破坏了发现感
```

**正确模式**：
```
✅ 段1：走廊（阿彪+陈强）
✅ 段2：陈强推门进入+环顾房间（POV摇镜扫过空椅/茶几/花瓣/酒杯）→ 视线停在窗边
✅ 段3：万倩特写（她窝在椅子里摇酒杯/红肿眼眶）
```

**判断标准**：问自己"这一镜是谁在看？"如果进入者还没看到室内角色，观众也不能先看到。

## 3. 迭代修订工作流

当用户说"这段要改"但未指定方向时：
1. 先问具体改什么方向（格式/内容/节奏/风格），给选项不要猜
2. 每次只做用户指定的那一个修改，改完展示结果等确认
3. 不要在一次回复中做多个未确认的改动
