# 外部验证方法论

> 创意产出（剧本、文案等）通过 Skill 内部审查后，用外部 AI 检测工具（如朱雀）做独立验证。内部自审存在 LLM 自评盲区——写出问题的模型检查时也会漏掉。

## 验证流程

1. 提交完整文本到外部检测工具
2. **看片段分值，不是总分**——总分可能 88% 以上，但某个片段 AIGC 值偏高才是真问题
3. 回溯被标疑段落的原文，对照 Skill 审查清单逐句排查
4. 区分真违规（审查漏了）和假阳性（格式骨架/稀有词组合/统计噪声）

## 常见假阳性

- 重复结构骨架（场景头格式）在统计上接近模板生成模式
- 低频专业词汇被误判（赛博朋克术语、技术名词）
- 文学精度被识别为 AI 推断性语言（「仿佛」在物理描述语境下是合法的）

## 根因分类

| 类型 | 修复方向 |
|------|---------|
| Skill 规则覆盖但审查漏了 | 补「翻旧账」步骤——前几轮发现的违规类型，逐类搜全文确认零残留 |
| Skill 规则未覆盖 | 升级 Skill |
| 文本本身不够好 | 用精度层重写，不是加注释 |

## 参考

《手心人》v1 朱雀验证：场 7 两处「不是X，是Y」在第五轮审查中被漏检（审查者第四个小时注意力衰减）。修复方式：不是加 grep 步骤——是用精度层重写△本身。
