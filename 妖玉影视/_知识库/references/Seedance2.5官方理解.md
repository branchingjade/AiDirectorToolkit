# Seedance 2.5 官方文档理解

> 本文是官方《Doubao Seedance 2.5 教程》+《提示词指南》的深入理解存档。**不改变 AI提示词助手 v1.5.1 的约束主本**——以现有 skill 为准，本文只做知识库参考。

## 一、核心定位

2.5 = 2.0 的「长叙事 × 强参考 × 准编辑 × 多语言」工业级升级：**30 秒长叙事直出 + 50 个多模态参考素材 + 时间戳级编辑控制 + MOV 专业后期格式**。

## 二、相对 2.0 关键变化表

| 维度 | 2.0 | 2.5 |
|---|---|---|
| 单次时长 | 4~15s | **4~30s**（可多轮延长） |
| 参考素材上限 | 15（9图+3视频+3音频） | **50（30图+10视频+10音频）**，音/视频总长 15s→30s |
| 纯音频参考 | ✗ 需搭配图/视频 | **✓ 支持** |
| 时间戳控制 | 只认镜头序号 | **响应整数秒时间戳** |
| 主体多视图参考 | 不建议 | 支持 |
| 输出宽高比 | 固定 6 档 | 固定档 + **adaptive**（编辑/延长自动对齐输入） |
| 输出格式 | 仅 mp4 | **mp4 + mov**（H.264 + yuv444p + PCM） |
| 原生语言 | 中英为主 | **11 种**（中/英/西/印尼/马来/泰/阿/葡/越/日/韩） |
| 分辨率 | 480p~4k | **仅 480p/720p**（⚠️ 2.5 暂不支持 1080p/4k） |
| 参考生视频关键词误判 | 无此机制 | **prompt 出现编辑/延长词会误判任务类型触发报错** |

Model ID：`doubao-seedance-2-5-260628`

## 三、任务类型两级判定（最关键的坑）

模型通过 **content.role 取值 + prompt 关键词** 双重判定任务类型：

| 任务 | 触发条件 | 参数硬限制 |
|---|---|---|
| 视频编辑 | role=reference_* + prompt 含"编辑/增加/删除/修改/替换/改成" | ratio 仅 `adaptive`，duration 仅 `-1`（不可自定义） |
| 视频延长 | role=reference_* + prompt 含"延长/延续/续写" | ratio 仅 `adaptive`；duration 可 [4,30] 或 -1 |
| 首帧/首尾帧 | role=first_frame/last_frame | ratio 仅 `adaptive`；duration 可 [4,30] 或 -1 |
| 文生/参考生视频 | 无特殊触发 | 无限制（但 **prompt 禁出现编辑/延长相关词**，防误判） |

违规不报同步错误，而是**异步报错**（错误码 `InvalidParameter.TaskTypeConstraint`），排队等模型判定后才返回。多个参数同时违规时报错一次性列出全部违规项。

## 四、官方提示词指南要点（对照用）

### 基础公式
主体 + 动作/事件 + 场景环境 + 视觉风格 + 运镜切镜 + 声音（按顺序，缺省可省）

### 素材指代
- 按上传顺序编号（图 1/视频 1/音频 1），每个素材文本绑定
- 分工具体到"参考什么"："参考视频 1 施法的动作，视频 2 的环绕运镜"
- 素材精准时只指代不复述
- **不建议只在图片里写映射信息**（图内写"张三"+prompt 直接喊张三 → 易混淆）

### 声音专用符号（官方建议）
音乐 `()`、音效 `<>`、台词 `{}`、字幕 `【】`

### 时间戳（2.5 专属能力）
- 整数秒为单位；区间要连续（避免"0-3 秒…5-6 秒"断层）
- 不支持用时间戳控频率（"一秒摇头 3 次"）
- 三种写法：明确区间 / 时间点（"第 5s 快速向左横移转场"）/ 相对时间（"3 秒后周围的人纷纷摇头"）

### 镜头语言
- 景别/运镜（推拉摇移跟环绕俯冲、一镜到底、希区柯克变焦、FPV、子弹时间）可直接写
- 小众专业词转 **[名词 + 描述性解释]**（如"移焦，画面焦点发生平滑转变……"）
- 转场写清触发点与方式："第 5s 快速向左横移转场（向左擦除+自然叠化）"

### 动作/表情
- 动作优先概括描述（"连续几组高抬腿和空翻"），只在记忆点写细节，不重复相同动作
- 表情写描述句少用成语（"津津有味地吃饭"→"脸上带着满足的笑容，大口地吃饭"）

### 负向控制
- 支持"不要字幕"、"无 bgm 只生成环境音"、细分控制音效/bgm/对白

## 五、素材输入规格（边界）

- **图**：jpeg/png/webp/bmp/tiff/gif/heic/heif；宽高比 [0.4, 2.5]；边长 [300, 6000]px；单张 <30MB；参考 1~30 张；首帧 1 张、首尾帧 2 张
- **视频**：mp4/mov（H.264/H.265）；单段 [2,30]s 最多 10 段总 ≤30s；FPS [24,60]；单段 <200MB；总像素 [409600, 8295044]
- **音频**：wav/mp3；单段 [2,30]s 最多 10 段总 ≤30s；单段 <15MB
- **请求体 ≤64MB**（大文件别用 Base64）
- **真人人脸**：不支持直接上传含真人脸的参考图/视频，需走便利创作方案（信任模型产物/预置虚拟人像/已授权素材）
- **URL 时效**：任务记录 7 天；视频 URL 仅 **24 小时 / 100 次下载**，需及时转存
- **限流**：个人 180 RPM / 3 并发；企业 600 RPM / 10 并发
- **开通条件**：余额 >200 元或购买资源包

## 六、对创作管线最有价值的三个新能力

1. **白模参考/渲染**：粗粒度白模（简单几何体拼接）做运镜/运动/调度预演 → 渲染成片；细粒度白模用于"上色重渲染"。3D 预演→实拍质感工作流
2. **多关键帧参考**：分镜逐张作为独立关键帧按顺序传入，画面**相对严格对齐**分镜图——严格按分镜出片的路径（宫格图不严格对齐，15 宫格以下才稳）
3. **MOV 输出**：yuv444p 色度采样 + PCM 音频，调色/抠像/合成友好——编辑、延长任务官方建议 input/output 都用 mov，无缝衔接最好

## 七、与 AI提示词助手 v1.5.1 的差异对照（用户拍板：以现有 skill 为准）

### 架构一致的部分（殊途同归，无需改）
- 整体结构：一句话概述 → 分镜情节 → 结尾贯穿细节 ≈ 景别运镜开头 → 分镜序列 → 细节收尾
- 分镜组织：镜头 N / 时间轴 ≈ "切"字切镜
- 画面写作：物理描述、正向描述 ≈ 物理优先、禁文学修辞（我们更严）
- 动作/表情：概括+记忆点 ≈ 四层动作体系（我们更细）
- 运镜：直写景别运镜 ≈ 运镜速查表 + 危险关键词
- 声音：画面自然结果 ≈ 音效物理化融入（同一思路）
- 负向控制：≈ 部分覆盖

### 真实差异 5 点（仅存档，不按官方改 skill）
1. **时间戳控制**：官方 2.5 响应整数秒时间戳，我们 skill 全用"镜头 N"切分，无时间戳写作规范——2.5 专属能力，2.0 主本不收录
2. **声音符号冲突 ⚠️**：官方建议音乐 `()`、音效 `<>`、台词 `{}`、字幕 `【】`；我们 skill 明确"音效作为物理描述自然融入，不用标签"——真实冲突，以现有 skill 为准
3. **R2V 素材指代**：官方 `@图片1` 编号指代、多主体映射——我们 skill 无此章节
4. **任务类型误判防护**：参考生视频 prompt 禁出现"编辑/延长/增加/删除"等词——API 层硬约束，2.0 主本无此机制
5. **负向控制维度**：官方支持细分音效/bgm/对白（"无 bgm，只生成环境音和动作音"），我们只有笼统的"不写段级资产声明"

### 官方提示词 Skill
官方提供 Seedance 2.5 提示词调优 skill（npx 安装，`/sd25-pe` 命令调用）——与自有 AI提示词助手定位相同，可作对照，不替代。
