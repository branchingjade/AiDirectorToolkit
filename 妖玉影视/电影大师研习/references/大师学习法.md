# 大师学习法 · 详解与模板

本文件是「电影大师研习」SKILL.md 二章的展开——三读法的操作细节、技法卡片/研习报告完整模板、问题集示例。

## 一、三读法操作细节

### 第一读 · 粗读（结构层）

一口气读完（IMSDb HTML 版约 40-60 分钟/部），**不划线、不摘抄**，只记三件事：

| 记什么 | 怎么记 |
|---|---|
| 三幕转折点 | 第几场/全片百分之几处（例：肖申克越狱戏约在 78% 处） |
| 每幕场次与节奏 | 第一幕 N 场 / 第二幕 N 场 / 第三幕 N 场；哪一幕场次最密 |
| 角色何时"变" | 主角第一次做出"之前的他不会做的事"在哪一场 |

**纪律**：粗读阶段不许打开第二读的工具。读太快没关系，读太细才危险——细读会提前锁死你的第一印象。

### 第二读 · 细读（手法层）

挑印象最深的 3-5 场，逐句读，四层各记 2-3 条：

**1. 画面锚点层**
- 这场戏哪个画面装着"不在场之物"？（画面里没有的东西，被感觉到了）
- 例子（电影能力哲学）：老周的手放在胸口——画面上只有他的手，但她被感觉到了
- 记法：一句画面描述，不许写"这象征着……"

**2. 对白层**
- 每句台词在"给信息"还是"藏信息"？
- 潜台词在哪句？（嘴上说的 ≠ 心里想的）
- 谁在说反话？为什么此刻说反话？
- 信息差：观众知道什么、角色不知道什么（悬念的根）

**3. 动作层**
- 行文怎么暗示景别？（"壁上一排油灯，火光颤动"=全景/环境先入；特写=直接写细节）
- 行文怎么暗示节奏？（长句铺陈=缓；短句连发=快切）
- 动作行有没有表演提示？（"像是急着要去上门出诊"——国内范本《大明劫》写法）

**4. 信息控制层**
- 这场戏给了观众什么新信息？通过什么途径给的（对白/画面/道具）？
- 什么信息被故意扣住不给？扣到哪一场才给？

### 第三读 · 反拆（为什么成立）

选一场戏（第二读里最让你"说不出哪里好但就是好"的那场），问到底：

1. **位置**：这场戏为什么现在出现？往前删掉行不行？往后挪行不行？
2. **认知差**：观众此刻以为____，实际____。这个差是这场戏的情绪来源吗？
3. **对白依赖测试**：把这场戏的对白全删，画面还讲得清吗？
   - 讲不清 → 这场戏靠对白活（对白戏，看的是信息交锋）
   - 讲得清 → 这场戏靠画面活（动作戏，看的是空间调度）
   - 两种都成立 → 这场戏是大师手笔，重点标记
4. **删减测试**：删掉这场戏，全片损失什么？如果什么都不损失——它为什么还在？

## 二、技法卡片模板

```
## 技法卡片 ·《片名》· 第N场「场景一句话」
- **大师**：谁（注明编剧/导演）
- **场景**：发生了什么（3 句话内）
- **技法**：这场戏在手法上做了什么（1 句话，动宾结构，不许用术语堆砌）
- **原文摘录**：剧本原文（中文保留原文；英文保留英文原文+注明版本：初稿/拍摄稿）
- **画面锚点**：最强画面是什么（1 句话画面，不写象征）
- **可复用时机**：我自己的戏里哪种情况能用（诚实评估：这场戏的手法和我的题材兼容吗）
- **对接**：编剧（结构/对白/信息控制）or 导演（画面/节奏/景别暗示）
```

**写卡片的纪律**：
- 原文摘录必须真实——从渠道页面/PDF 里 grep 出来复制，不许凭记忆写台词
- 摘不到的标注「原文未取到」，不许编
- 一张卡片只写一个技法。一场戏有三个技法就写三张卡

**卡片示例（格式示范，内容虚构）：**
```
## 技法卡片 ·《×××》· 第4场「开场三分钟给观众一个错的方向」
- **大师**：××
- **场景**：主角误认凶手，观众跟着误认
- **技法**：用一个看似无辜的细节把观众注意力钉在错误的人身上
- **原文摘录**：（grep 自 IMSDb 原文）
- **画面锚点**：他弯腰捡起不属于他的东西
- **可复用时机**：我写悬疑开场时，需要一个"观众以为"的锚点
- **对接**：编剧（信息控制）
```

## 三、研习报告模板

```
# 研习报告 ·《片名》
- **大师 / 编剧**：
- **版本**：初稿 / 修订稿 / 拍摄稿（必须注明；网上流传多为早期稿，如卧虎藏龙抓到的 Schamus 1999 修订初稿）
- **来源渠道 + URL**：
- **结构观察**：三幕转折点位置 / 每幕场次 / 节奏特征
- **画面锚点清单**：8-15 个，一句话一个（只写画面，不写象征）
- **对白手法**：3 个潜台词实例（带原文摘录）
- **动作层写法**：3 个景别/节奏暗示实例（带原文摘录）
- **技法卡片**：5-10 张（链接）
- **一句话**：这部片最值得偷的一招
- **⚠️ 诚实声明**：文本层质量（PDF 有损/OCR 噪声）、版本不确定性、来源 URL
```

**存放**：Obsidian `工具与集成/妖玉影视skill/` 或创作项目目录，wikilink 可达。文件名规范：`研习-《片名》-大师名.md`

## 四、问题集示例（学习提问，不是学习规则）

| 场景 | 问题式提问（✅） | 禁令式总结（❌） |
|---|---|---|
| 看完群像戏 | 这场群像戏怎么让观众分清 8 个人？靠对白标签还是画面动作？ | 大师的群像戏从不靠台词介绍人 |
| 看完动作戏 | 这场打斗为什么中间插了一个静场？删掉静场会怎样？ | 大师的动作戏从不连续打 |
| 看完反转 | 前面埋的哪个细节在反转后变成了另一种意思？观众会回头找它吗？ | 大师的反转都有伏笔 |
| 看完结尾 | 这个结尾给观众留了什么没解决的？为什么留着？ | 大师的结尾从不给答案 |

**根因原则**：任何手法，先问"它在这里成立是因为什么"，不急着总结"大师的规矩"。规矩会骗人（换个题材就不成立），根因不会。

## 五、与用户创作偏好的对接点

| 用户偏好 | 学习时的关注点 |
|---|---|
| 国风意境美术（烟雨江南/大漠孤烟） | 读东方大师（黑泽明/贾樟柯/王家卫/侯孝贤）时重点看：环境怎么进戏、空镜怎么用 |
| 暗线贯穿主线 | 读结构型大师（诺兰/科恩兄弟）时重点看：暗线什么时候给观众"第一次看见" |
| 双面人设/大智若愚 | 读对白型大师（昆汀/PTA）时重点看：人物人前人后两副面孔怎么用场景切换呈现 |
| 一波三折/大场面 | 读类型片大师（伊纳里图/卡梅隆）时重点看：折点在哪、大场面前的信息铺垫 |
| 主题落点"和解"而非"二选一" | 读主题型大师（黑泽明/是枝裕和）时重点看：和解用什么画面收束，不用台词宣布 |
