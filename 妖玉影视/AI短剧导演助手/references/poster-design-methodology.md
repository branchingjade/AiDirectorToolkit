# 海报设计方法论

> 从剧本到最终海报提示词的完整工作流。本文件是 [AI短剧导演助手 SKILL.md 1.6 海报镜头](../SKILL.md#16-海报镜头) 的实操扩展。
> 基于《犬子无双》28集中剧海报设计实战提炼。

---

## 一、设计哲学

### 1.1 海报 ≠ 分镜截图

海报不是从分镜中挑一帧好看的——它是那部剧的**一次视觉概括**。一张海报要说完整部剧，但只用一个画面。

### 1.2 不煽情（与创作宪法对齐）

海报同样遵守"不煽情"原则：
- 不拍英雄仰角
- 不拍金色光辉
- 不拍悲情凝视
- 不拍哭泣特写
- 角色可以站着、走着、看着——但叙事者不替角色做感情劳动

### 1.3 三类海报策略

| 类型 | 核心 | 角色 | 适用 |
|------|------|------|------|
| **道具叙事** | 一件关键道具说完整部剧 | 角色不出现，或只出现手/背影 | 概念海报、先导海报 |
| **角色驱动** | 主角面孔/身体是画面核心 | 主角特写、半身、全身 | 主海报、角色海报 |
| **群像阵列** | 所有角色如浮雕般展开 | 全阵容，各自在各自的光里 | 终版海报、院线横幅 |

**选型原则**：先问"这一版海报的目的是什么"——吸引注意（道具/概念）→ 建立情感连接（角色驱动）→ 展现世界（群像）。

## 二、工作流

### 2.1 提取视觉锚点

从剧本中提取具备海报潜力的叙事时刻：

| 提取维度 | 示例（犬子无双） |
|----------|-----------------|
| **关键道具** | 项圈、BP机、搪瓷缸、铝饭盒、绿挎包 |
| **关键动作/余波** | 扑击之后坐在地上（EP02）、对蜡发誓（EP03）、翻BP机（EP28） |
| **关键空间** | 钢厂大门、陈家屋内灯泡下、铁北窄巷、三岔路口 |
| **关键光源** | 停电后的蜡烛、路灯钠灯、医院冷白灯 |
| **关键关系** | 陈强-项圈（身份）、陈强-万倩-林晓（选择）、十人-铁北（世界） |

### 2.2 确定方案数量与差异化

每个方案必须有**不同的叙事锚点和视觉策略**。判断标准：两个方案的主角、情绪、色调、构图不能同时相同。

实战产出参考（犬子无双）：
- **方案一·项圈**：道具叙事，无人，冷灰+棕
- **方案二·灯泡蜡烛**：光源叙事，面孔半隐，黑+暖光
- **方案三·铁北地图**：空间叙事，伪档案风格，泛黄纸+墨蓝
- **方案四·扑击**：动作余波，坐地面孔，冷白+条纹
- **方案五·BP机**：物件特写，手部微距，黑+绿光
- **方案A·凝视**：角色驱动，面孔特写，侧光明暗
- **方案B·行走**：角色驱动，背影/侧身，夜景深蓝
- **方案C·群像**：全阵容，浮雕阵列，光色渐变

### 2.3 多画幅覆盖

| 画幅 | 构图策略 | 电影感来源 |
|------|---------|-----------|
| **9:16 竖屏** | 纵向深度（上中下三层）、面孔特写、道具微距 | 肖像摄影、黑色电影侧光 |
| **16:9 横屏** | 左右分区、对角线引导、窄巷透视 | 经典电影横版构图 |
| **21:9 超宽** | 全景天际线+极小人物、浮雕阵列横跨、安琴拉伸感 | 史诗宽银幕、全景深 |

**21:9 特殊手法**：
- 人物在画面中极小（约占高度 1/10），城市/天际线是真正的主体
- 使用"安琴宽银幕拉伸感"关键词——横向压缩的光斑、椭圆散景、横向拉长的烟/云
- 适合"世界即角色"的场景：铁北全景、十人阵列

## 三、GPT Image 2 提示词写作

### 3.1 与 Seedance 提示词的区别

| 维度 | Seedance 2.5 | GPT Image 2 |
|------|-------------|-------------|
| 格式 | 结构化字段（画幅/风格/@图片） | 自然段落描述 |
| 长度 | 60-100 词/镜 | 可更长（200-400 词），细节越多越稳 |
| 文字渲染 | 不支持 | 支持中文片名竖排/横排 |
| 参考图 | @图片编号 | 上传后提示词中引用 @图片1 |
| 风格锚点 | 年代写实/真人短剧风格 | 35mm胶片颗粒/暗角/电影海报摄影 |

### 3.2 提示词结构模板

```
创作一张[风格定位]电影海报，[画幅]。[质感描述]。

[构图总述——一个段落说完画面分区]。

[主体描述——人物/道具的详细物理特征。如有角色参考图，用 @图片N 引用]。

[环境描述——空间、背景、氛围]。

[光线设计——光源位置、方向、色温、明暗对比。这是最关键的渲染触发器]。

[色调——整体色板，暖色/冷色分布，高光位置]。

[片名排版——位置、方向、字体风格、颜色、纹理]。

[氛围——一句总结，点出情绪但不煽情]。
```

### 3.3 关键渲染触发器

以下关键词对 GPT Image 2 的影调和质感有显著影响：
- `35mm胶片质感` / `35mm film grain`
- `四角暗角` / `vignette`
- `暗调高反差` / `low key high contrast`
- `中国独立电影风格` / `Chinese independent cinema poster`
- `安琴宽银幕拉伸感` / `anamorphic lens compression`（仅 21:9）
- `微距摄影质感，浅景深` / `macro photography, shallow depth of field`（特写方案）

### 3.4 字体渲染备选

GPT Image 2 可渲染中文但不够稳定。策略：
1. 首轮：完整提示词含片名
2. 失败（2-4 次后仍不行）：删除文字描述 → 生成纯画面 → Photoshop 后期排版
3. 横排大字比竖排小字成功率更高

### 3.5 角色参考图使用

```
角色使用参考图：陈强@图片1、万倩@图片2。
```

- `@图片N` 对应对话中上传的第 N 张图片
- 提示词中用自然语言描述角色的姿态/服装/情绪——GPT Image 2 会将参考图的相貌特征与文字描述的姿态/服装融合
- 参考图最好是正面定妆照，避免遮挡

## 四、方案文档输出格式

### 4.1 输出目标

默认输出到 Obsidian vault 中的项目目录（如 `犬子无双/犬子无双_海报方案_角色版.md`）。
不要保存到 Hermes 工作目录再让用户手动移动。

### 4.2 Markdown 结构

```markdown
# 《剧名》影视海报方案

> 元信息行

## 通用角色参考（表格）

## 方案 X · 标题 ——「一句话核心」

### 思路（一段话说明叙事锚点和视觉策略）

### X1 · 竖屏 9:16（完整提示词代码块）
### X2 · 横屏 16:9
### X3 · 超宽 21:9

---

## 方案对比总览（表格）

## GPT Image 2 生成说明（参数+备选+文件命名）
```

### 4.3 Wikilink 互相引用

同一项目多版海报方案之间用 Obsidian wikilink 互链：
- 道具叙事版 → `[[犬子无双_海报方案]]`
- 角色驱动版 → `[[犬子无双_海报方案_角色版]]`

方案文档产出后立即更新 MOC。
