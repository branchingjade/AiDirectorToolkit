## 字体选择

- **铅印老宋体** `SimSun` — 报纸/告示正文，年代感最强
- **粗黑体** `SimHei` — 标语标题，力量感
- **楷体** `KaiTi` — 手写/粉笔感
- **仿宋** `FangSong` — 文书/公文

## 动画原则

- 上限 = 淡入淡出（0.4-0.8s）
- 可硬切
- 禁用弹跳/缩放/旋转等现代动效
- 逐元素错开出现（0.15-0.3s 间隔）为最大装饰

## 纹理手法

- `text-shadow: 1px 1px 0 rgba(r,g,b,0.2)` → 铅印溢墨感（必须 rgba，不能用 hex+alpha）
- `box-shadow: 2px 2px 0 rgba(r,g,b,0.15)` → 铆钉投影
- `border-bottom` + 从 0 到全宽的划出动效 → 铁锈划线感
- SVG 内嵌角饰 + 印章 + 噪点纹理 → CSS 无法实现的细节质感
