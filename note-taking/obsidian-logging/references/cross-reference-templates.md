# 日志文档间交叉引用模板

## 日报 → related 模板

```yaml
related:
  - "[[W{N}_周报]]"           # 本周周报
  - "[[YYYY-MM_月报]]"        # 本月月报
  - "[[<关联项目文档>]]"       # 产出关联的项目文档
  - "[[踩坑记录]]"             # 如有踩坑
```

## 周报 → related 模板

```yaml
related:
  - "[[YYYY-MM_月报]]"        # 本月月报
  - "[[<日报1>]]"             # 本周日报
  - "[[<日报2>]]"
```

## 月报 → related 模板

```yaml
related:
  - "[[W{N}_周报]]"           # 本月各周周报
  - "[[<跨月关联文档>]]"       # 跨月项目文档
```

## 反孤岛检查

```python
# 每个日志文件至少应被一处引用（入链≥1）
# README索引引用每条日报 → 日报至少有一条入链
# 日报related引用周报月报 → 日报至少有2条出链
```
