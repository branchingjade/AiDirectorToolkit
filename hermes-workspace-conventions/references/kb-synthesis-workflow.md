# 从存量知识库合成新文档（学科密码类）工作流

> 来源：2026-08-08《声音设计密码.md》写作实录（妖玉影视知识库「制作学科库」批次首份）。素材 13 份共 ~434KB，成文 23KB。适用：任何"从知识库存量资产合成新文档"任务（9 份学科密码批次、题材密码、研习报告汇总等）。

## 步骤

1. **模板先行**：先读目标目录的 `00-模板规范.md`（或同目录既有文档）——文件结构、引用格式体系、质量纪律（每条论断带来源/零新抓取/诚实声明/泛用导向）在动笔前定死，后续所有写作服从它。
2. **定位素材**：任务给的素材清单常是文件名级（如"王家卫_导演美学卡片.md"）。先 `find <知识库根> -maxdepth N -type d` 确认目录结构，再按清单逐个确认文件存在。
   - ⚠️ `search_files(target="files", pattern="*.md")` 对中文路径曾返回 0 结果——用 terminal `find` 兜底（与 knowledge-base 技能记录的"含空格路径"同属一类工具怪癖）。
3. **关键词簇提取，不全文读**：素材单份 15-45KB、合计 400KB+，全文读浪费上下文。对每份文件跑 `grep -n -B2 -A6 -E "音乐|配乐|BGM|声" 文件`——按主题词簇（含简写与英文，如"声"要覆盖声音/环境声/声画）提取匹配块及其上下文；grep 命中少的文件（<5 处）直接看全量输出即可。再对关键章节（如约束章节 3.6）用 read_file 精读。独立文件的 grep 用并行批处理。
4. **按模板合成**：每节严格对照模板章节号；**每条论断带引用编号**，引用格式用模板规定的体系（`[卡·导演名]`/`[深·导演名]`/`[卡·片名#N]`/`[AI导演 3.x]`/`[Seedance 2.5]`），无现成体系的（如知识库招式表、提示词助手章节）在来源清单里登记新前缀。
5. **诚实声明**：合成来源 vs 推断必须区分——推断处行内标【推断】；跨文档归纳的命名归类（如把两个导演的手法归入"音乐即立场"）标注"命名归类为本密码提炼"；来源清单末尾附诚实声明段，列清哪些是取证、哪些是推断、哪些是提炼。
6. **体积预算**：中文 UTF-8 每字 3 字节；"12-18KB"目标 ≈ 4-6K 汉字。覆盖点 10+ 且每节带来源时，动笔前先列覆盖点清单+估每节字数，否则必超 30%（实测 24.3KB→压 6 轮→23.1KB）。超预算时优先：删重复表述、合并表格列（出处列并入正文）、EN 提示词精简；不牺牲来源标注与诚实声明。
   - **压缩先分节核算，不零敲碎打**（2026-08-08《服化道密码》实测 26KB→18.5KB）：用 Python 按 `## ` 标题切分，逐节输出 UTF-8 字节数 + ``` 代码块总字节，**先砍最大节**（一次省 1KB+）；逐句替换效率极低（每轮只省几十字节）。压缩顺序：删冗余→合并节（如提示词 7 条并 5 条）→精炼措辞→最后动表格。每轮压缩后验证结构：章节数、``` 代码块成对、`- [ ]` 自检项数、来源标注数——只验字节数不验结构会悄悄丢内容。
7. **论断溯源（【用户决策】类标注）**：任务描述里的用户决策若知识库无记载 → `session_search` 定位原始会话（discovery 命中后 scroll 到锚点消息） + grep 项目文档（Obsidian 项目目录）找决策演变——**"被否版本 vs 被认可版本"的差异本身就是内容**。实测（镜妖白骨头颅）：用户 2026-08-07 否"师傅头骨是她的法器"直白表现 → 项目文档 v2.1.2"恨的物化贯穿道具时态"重设计被认可——两版差异（拿着法器打斗 vs 恨的物化）正是密码要写的内容。不要凭任务描述直接写。
8. **多轮 patch 后全文件复读**：patch 多次后 `read_file` 通读全文 + `grep -c "章节标题"` 查重——两类静默事故高发：①锚点标题被 new_string 吞掉；②段落被插入两次。详见 workspace 主技能「多轮 patch 编辑后必须全文件复读验证」。
   - **陷阱：正则改表格毁格式并静默失效后续替换**（2026-08-08《服化道密码》实测）：`re.sub(r'\|\s*([^|]+?)\s*\|\s*$', r'|\1|', t, flags=re.M)` 这类"清理表格行尾空格"的正则去掉 `|` 两侧空格，破坏 markdown 表格渲染；且文本变化后，先前写好的 old_string 精确替换全部未命中（**替换函数必须打印"未命中"提示才暴露**）。表格行一律用精确字符串替换，不用正则；正则动过表格后必须复查 `|` 分隔格式。

## 实测数据点

- grep 提取法：13 份素材每份只需读 1-5 个匹配块，未全文读任何一份 30KB+ 文件。
- 引用体系：19 组来源映射（9 导演卡片 + 4 技法卡片 + 2 约束章节 + 知识库招式表 + Seedance 文档）。
- 范本实证表：13 行（手法|成片实例|出处|可复用时机），全部来自既有卡片，零新抓取。
