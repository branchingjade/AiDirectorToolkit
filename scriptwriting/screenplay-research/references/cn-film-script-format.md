# 中国大陆电影剧本格式惯例（2026-08 调研）

来源：知乎 / 百度知道 / 360问答 实抓 + 百度百科 openapi 摘要（见文末来源表）。知乎、百度知道均为从业者 UGC 说法，权威性有限，引用时如实标注；大陆并无官方统一剧本格式标准（区别于国家电影局的剧本（梗概）备案制度）。

## 分级流程：文学剧本 → 分镜头剧本（工作台本）→ 完成台本

- 大陆通行的"三种剧本"框架：**电影文学剧本 / 电影分镜头剧本（导演台本）/ 电影完成台本**。同一影片三本内容大致一样，由不同职务人员在不同制作阶段完成。
- **文学剧本**：编剧完成，影片创作第一环节；对主题/人物/情节/结构/风格样式有明确规定，导演通常无法根本改动；正文结构 = 故事梗概（≤1500 字）+ 人物小传 + 剧本正文；特点"可读性强、电影感弱"；读者为制片人/导演/演员/摄影/美术等主创，一般不公开发布出版。
- **分镜头剧本**：又称导演台本 / 导演剧本 / 摄制工作台本；导演（或与摄影、美术、录音等主创讨论）在文学剧本基础上完成；规定镜号、景别、镜头运动（推/拉/摇/移）、画面内容，并安排同景/同季戏份；是摄制组工作依据。英文对应 shooting script；"脚本"一词系 script 的误译混淆。
- **完成台本**：又称镜头记录本；整片拍完后由场记完成；逐镜头记录技术与艺术内容、镜头呎数、导演对分镜的改动；随拷贝发行，供理论研究与拷贝检查修复。
- **分场景剧本（分景剧本）**= 业内口语：按场划分的普通剧本（场次号/景象/人物动作/对白），多用于电视剧；分镜头剧本在其基础上再分镜，多用于电影。

## 场次标题（日本式为主流）

- 要素：场号 + 地点 + 时间（±内/外景），中文自然语言；不用 INT./EXT. 全大写；不用或少用专业电影术语（"不戴领章、帽徽的解放军"——分镜的事交给导演）。
- 实例（原文）：「第8场 民舍 门外 日 外」（《大明劫》）；「1、满洲旷野、夜（1944年）」「6、上海陆军医院病房，日」（《啊，无声的朋友》铃木尚之）；「22、长安街、晨」「23、李芸卧室、晚」；电视剧「23-1，外，武当山玄岳门，日」（一场分若干小场用 23-1/23-2）；「一、故宫。日。外。」（场景名小四号加粗）；集号+场号「1-1」= 第一集第一场（电视剧，供剧本统筹）。
- 剧本课"每场五要素"：场号（换场景即换场）、时间（日/夜/黄昏/清晨，清晨黄昏需特殊标注）、场景（内/外）、地点（具体拍摄地，套拍需要）、人物（出场角色）。"剧本是要给统筹老师看的"。
- 好莱坞对照：`INT. CABIN - NIGHT` 全大写+连字符，一页≈一分钟（120 页≈2 小时）。

## 对白 / 动作 / 画外音

- 对白：人名+冒号+台词，内容不加双引号；情绪/状态提示用括号插在人名后：「方可可（有点不乐）：抱不动也要抱。」；台词一般不超过三行。
- 动作：大陆传统用三角形△（后传港台），现多用中括号/大括号或干脆不标；台湾式每行前加△；动作说明可在对白上或下；与对白分段、段首空两格。
- OS/VO（直接沿用好莱坞）：**O.S.** = 角色在现场但不在摄影机视图中（同场景隔房喊话、画面外对白）；O.C. = O.S. 的古旧同义词；**V.O.** = 声音来自现场之外（电话/对讲机/广播、回忆中他人声音、闪回旁白、内心独白、旁白叙述、画面外的声音）。电视屏幕/视频通话画面内可见者按正常对话处理不标。从业者坦言"内地没有规范的剧本写法"，OS/VO 系借用国外惯例——引用时须如实说明。

## 国内 vs 好莱坞差异速查

| 维度 | 国内（日本式主流） | 好莱坞 |
|---|---|---|
| 篇幅 | 无"一页一分钟"铁律 | 120 页 ≈ 120 分钟 |
| 场景标题 | 中文「第8场 民舍 门外 日 外」 | INT./EXT. 全大写 |
| 镜头术语 | 正文禁用/少用，交导演分镜 | 剧本内含剪辑提示 |
| 流程 | 文学剧本(编剧)→分镜头剧本(导演)→完成台本(场记) | Screenplay→Shooting script |
| 文学性 | 文学剧本可读性优先（有争议） | 排斥文学化 |
| 电视剧场号 | 集号+场号（1-1） | 连续编号 |
| 动作标记 | △/括号/无标记 | 角色名全大写居中 |
| 备案 | 国家电影局剧本（梗概）备案、立项公示 | 无政府备案 |
