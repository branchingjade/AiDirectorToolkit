## 一、分级流程：文学剧本 → 分镜头剧本（工作台本）→ 完成台本

**核心结论：大陆通行的"三种剧本"框架是 文学剧本 / 分镜头剧本（导演台本）/ 完成台本**，而非字面意义的"分场景剧本"。分场景剧本是业内口语，指普通分场文体的剧本（多用于电视剧）；任务标题里的"工作台本"对应两个概念：分镜头剧本（又称导演台本/摄制工作台本，拍摄前）与完成台本（拍摄后场记记录）。

### 1. 电影文学剧本
- 由**编剧**完成，是影片创作的第一环节，对主题、人物、情节、结构、风格样式有明确规定 [S5][S10]。导演通常无法对文学剧本核心内容做根本改动 [S5][S10]。
- 结构包含三部分：**故事梗概（1500字以内）+ 人物小传 + 剧本正文** [S9]。
- 特点：**可读性强（文学性）、电影感弱**。"春天，踩着湿淋淋的步子来到了"——导演分镜头时必须删掉文学性、视听语言无法表现的内容，重新用视听语言表达"诗情画意" [S2][S12]。
- 读者对象：制片人、导演、演员、摄影、美术等主创，一般不出服不公开 [S9]。编剧写给导演、摄影师、制片人看 [S3]。

### 2. 分镜头剧本（=常说的"工作台本/导演台本"）
- 由**导演**（或导演与摄影、美术、录音等主创共同）在文学剧本基础上完成 [S3][S5][S10][S12]。
- 百科定义："电视导演基于文学剧本改编设计的镜头摄制剧本""将文学内容分切成为一系列可以实地摄制的镜头的一种剧本"，别名**导演剧本（导演台本）**，包含**镜号、景别、镜头运动、画面内容**等标准化要素 [S15]。
- 艺考教材口径："分镜头脚本又称**摄制工作台本**，是将文字转换成立体视听形象的中间媒介" [S6]。
- 与文学剧本的关系：分镜细化每个镜头的角度、距离、推拉摇移方式，安排哪些戏同景拍摄、同季拍摄 [S5][S10][S12]。
- 注意：按 S3、S13，英文对应为 *shooting script / storyboard*；文学剧本为 *script*。"脚本"一词是 script 的误译混淆 [S3]。

### 3. 完成台本
- 影片拍完后由**场记**完成，又称**镜头记录本**；详细记录每个镜头的技术与艺术内容、镜头呎数，反映导演拍摄中对分镜头剧本的改动；每卖出一拷贝附一册 [S5][S10]。

### 4."分场景剧本"术语辨析
- 分场景剧本=分景剧本，"就是我们平常看到的那种剧本，一幕一幕来的，大段台词+角色神态动作刻画，给演员提示剧情用"；分镜头剧本则按镜头处理拍摄方式，"给摄影师、编导在拍摄剪辑中使用" [S11]。
- 分场景剧本常用于电视剧，电影较短多用分镜头剧本更直观 [S7]。这是一个行业共识但非官方定义，权威性中等。

## 二、场次标题（场景标题）的国内惯用写法

**主流是"日本式"格式——标题要素：场号 + 地点 + 时间（有时加内外景），冒号或顿号分隔，不写"INT./EXT."，不用全大写** [S1][S12]。

### 典型写法（均有原文例证）
1. **电影常用**：《大明劫》"**第8场 民舍 门外 日 外**"——场号+地点+空间细节+日景+内外 [S1]。《啊，无声的朋友》"**1、满洲旷野、夜（1944年）**""**6、上海陆军医院病房，日**"；"**22、长安街、晨 23、李芸卧室、晚**" [S12]。
2. **电视剧常用**：场号（有时带集号）+地点+时间（+内外），如"**1-1**=第一集第一场" [S1 S1]；"**23-1，外，武当山玄岳门，日**"（一景分若干小场时用 23-1、23-2）[S7]；"**一、故宫。日。外。**"（小四号加粗）[S8]。
3. **五要素说**（剧本课笔记）：每场须含**场号（换场景即换场号）、时间（日/夜/黄昏/清晨，清晨黄昏特殊标注）、场景（内/外）、地点（具体拍摄地）、人物**五个要点，因为"剧本是要给统筹老师看的"（套拍需要）[S9]。
4. 新闻式顺序：场（幕）次号 → 外景/内景与室内/室外 → 地点 → 时间，即"**场号、外/内、地点、日/夜**" [S7]。

### 与好莱坞对比
- 好莱坞：`INT. CABIN - NIGHT` 全大写+缩略语+连字符，一页约一分钟（120页≈2小时）[S1][S14]。
- 国内（日本式）：中文自然语言、简洁，"每段开头注明场号、地点、时间"即可，**不用或少用专业电影术语**（"不戴领章帽徽的解放军"）[S12]。台湾式则在动作行前加"△" [S1]。

## 三、对白、动作描述、画外音标注

### 对白
- **人名+冒号+台词**，内容不加双引号 [S8]。例："松本：'大家都睡吧。'"（日式剧本用引号的也有）[S12]。
- 情绪/状态提示用**括号**插在人名后："方可可（有点不乐）：抱不动也要抱。"；连续性对白可用多重括号："化雨（对婶婶）：没事。（对方可可）刚才没发现……" [S7][S9]。
- 台词一般不超过三行（口读体会时长）；避免"动作+重复台词的套话"（如"A点头：好"）[S1]。

### 动作描述
- 大陆传统用**三角形**符号标记动作（后传入港台）；现多用**中括号、大括号**或干脆不标 [S1 S7]；香港台湾式是每行前加△ [S1]。
- 动作说明位置可在对白之上或之下，按人物讲话先后 [S7]。
- 动作/情景/环境描写与对白分开成段，各段段首空两格 [S8][S9]。
- 文学性强、情绪性的句子可作为"表演提示"（《大明劫》"像是急着要去上门出诊"），但不写"镜头移动到""全景"等术语，用行文暗示景别 [S1]。

### OS / VO 画外音（直接沿用好莱坞缩略语）
- **O.S. = 角色在现场、但不在摄影机视图中**（同一场景内喊话、隔房间对话都算）；O.C. 是古旧同义词 [S4]。
- **V.O. = 声音来自现场之外**：电话/对讲机/广播、回忆中他人声音、闪回叙事、内心独白、旁白、角色叙述、"看不见的人"说话（如《星球大战》欧比旺）[S4]。
- 电视/视频通话屏幕在画面内则按正常对话处理，不需标记 [S4]。
- **诚实声明**：S4 回答者明确说"内地没有规范的剧本写法，以下讲的是国外上课时候学的"——OS/VO 标注是国内直接沿用好莱坞的惯例，并无国内自成的规范。

## 四、国内 vs 好莱坞核心差异总结

| 维度 | 国内（日本式主流） | 好莱坞 |
|---|---|---|
| 页面/篇幅 | 无"一页一分钟"铁律 [S1] | 约120页=120分钟 [S1][S14] |
| 场景标题 | "第8场 民舍 门外 日 外"，中文、无 INT/EXT [S1] | `INT. CABIN - NIGHT` 全大写 [S1] |
| 镜头术语 | 正文禁用/少用，由导演分镜时处理 [S1][S12] | 剧本即含剪辑提示（CUT TO 等） |
| 流程 | 文学剧本（编剧）→ 分镜头剧本/导演台本（导演）→ 完成台本（场记）[S5][S9][S10] | Screenplay（编剧）→ Shooting script（导演）→ 无完成台本对应物（有 lined script/continuity） |
| 文学性 | 文学剧本可读性优先，存在"文学性"争议 [S1][S2] | 排斥文学化，强调纯拍摄功能 [S1] |
| 电视剧场号 | 集号+场号（1-1）[S1] | 场景编号连续 |
| 动作标记 | 传统△/括号/无标记 [S1][S7] | 角色全大写居中，动作段固定缩进 |
| 备案流程 | 国家电影局剧本（梗概）备案立项公示 [S14] | 无政府备案 |
