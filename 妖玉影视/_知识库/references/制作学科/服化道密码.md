# 服化道设计密码

> 触发：写任何需要服化道落地的戏（服装/化妆/道具系统设计）、做分镜或提示词涉及"人物穿什么/拿什么/脸上是什么状态"时加载。制作学科密码——不是规则清单，是"服化道怎么设计才成立"的根因研究。
> 方法：范本实证（知识库 7 部技法卡片 + 3 份导演手法深化）+ 伏妖记实战回写（白骨头颅/符箓系统/色彩语义/道具时态）。每条带来源。
> 版本：v1.0（2026-08-08，从知识库存量资产合成，零新抓取）

## 一、服化道的定义与谱系（先分清楚你在设计什么）

服化道 = 服装 + 化妆 + 道具三分，是画面里**可触摸的实体叙事层**：

| 支 | 管什么 | 一句话定位 |
| --- | --- | --- |
| 服装 | 人穿在身上的叙事——身份/阶层/处境/变化轨迹 | 服装是"人物的皮肤" |
| 化妆 | 脸与身体的状态叙事——年龄/伤病/异化/精神状态 | 妆容是"人物的时态" |
| 道具 | 人物手里、生活中的物件——武器/信物/工具 | 道具是"叙事的引擎" |
**边界与分工**（不重复题材密码、不越界抢活）：
- **与布景**：布景=空间叙事，道具=物件叙事；可移动的布景是道具，固定的道具是布景——大红灯笼的灯笼既是空间装置也是权力道具 [卡·大红灯笼高高挂#1]。
- **与摄影/灯光**：光线决定"怎么看"，服化道决定"看什么"——杜琪峰双空间光线是摄影侧，同场景长官黑灰西装 vs 白衬衫（穿衣颜色即做事风格）是服化道侧，两侧配合才成立 [卡·黑社会#5]。
- **与配乐/题材密码**：配乐反讽（《永远的微笑》衬权力交易 [卡·黑社会#4]）与色彩反讽（最喜庆的红=最残酷的制度 [卡·大红灯笼高高挂#8]）是同一"反差"原理在两条轨道；叙事结构/人物弧线/世界观归题材密码，本密码只讲"这一件衣服、一张脸、一个物件怎么设计才成立"。

## 二、核心语法（本学科的"物理定律"）

### 语法 1：服装 = 人物

**1.1 身体即人物。** 出场不靠对白靠身体与重复劳动 [知识库 SKILL.md·核心招式]——服装是身体的第一层台词，服装动作是第二层。伏妖记实证：陆老邪「手上干净」（深不可测的人手上越干净越可怕）+「擦骨时下摆掖进腰间露出洗白里衬=人后小老头，放布时抖下摆直起身=切回人前」——换装/掖摆/挽袖这类**服装签名动作**，零台词完成身份翻转 [伏妖记 v2.1.3]。

**1.2 服装反映身份与变化。** 服装是一条随人物移动的状态轴，不是一次性人设：颂莲初入白衣→争宠大红衣（服装变化=人物跨坎）[卡·大红灯笼高高挂#8]；《活着》服装随年代越来越朴素（写实线服装服从时代）[深·张艺谋]；大D穿当选时定做的西装赴最致命的约（"体面道具"=悲剧反讽）[卡·黑社会#6]；慈禧三片妆淡→越往后越艳丽越邪气（妆/服变化=权力状态递进）[深·李翰祥]。

**1.3 服饰色彩语义。** 颜色一变，观众就知道"阶段/视角/状态变了"：张艺谋色彩状态轴暖→红→冷→白 [卡·大红灯笼高高挂#8]、五色章节一色=一视角 [深·张艺谋]；伏妖记金光=失控/青光=受控 + **稀缺色纪律**（全片红只给 N 处，出现即重音）[知识库 SKILL.md·核心招式]；色彩自带反讽——「大红本是喜庆祝愿，却成了阴森狰狞的血舌」[卡·大红灯笼高高挂#8]。

### 语法 2：道具 = 叙事引擎

**2.1 道具流转 = 权力流转。** 让一个器物承担全部权力语义，成为剧情发动机：龙头棍实用价值与象征价值分离、百年历史由角色亲口点破、**每个拿到棍的角色都有一场"触摸特写"**（瞳孔放大）、信物的旅途=叙事的暗线地图 [卡·黑社会#3]；两杆大烟枪枪的 9 站接力——每次转手把两组无关人物焊在一起，**知情权错位**是反转发动机，价值揭示放最后一步=全片最大反转 [卡·两杆大烟枪#5]。

**2.2 道具身份反转。** 道具的属性反转即剧情反转：玩具斧先以无害身份（露营玩具）登场，爆发时刻才揭真身——"认知反转取代血浆描写" [卡·寄生虫#6]；感应灯追溯反转——以为的智能家居实为囚徒的"欢迎仪式"，**背景道具自己翻案** [卡·寄生虫#7]。

**2.3 缺席的主角。** 主角不露面/标题物不出现——缺席即在场 [知识库 SKILL.md·核心招式]；陈老爷全片无正面镜头（背影/帘后/画外音），压迫者移出画面压迫感更大 [卡·大红灯笼高高挂#4]。

**2.4 一物定情。** 用一件物承载全片感情，三层结构：物证（血渍=伏笔回收）+ 物重（衬衫"seems heavy"——里面还套着一件）+ 物喻（"two skins, one inside the other"）。**物必须早埋**（31% 埋、94% 收）[卡·断背山#5]。

**2.5 信物接力 / 仪式道具。** 把抽象概念物化成可执行的道具与仪式：千与千寻把"自由"物化成"名字"这个可夺可还的道具，规则只有一句（夺名=控制你）却被用满全片四次（夺名→藏名→报名→归名）——**规则不是背景板，是情节本身** [卡·千与千寻#01]；大红灯笼发明一套可反复执行的仪式（挂灯/锤脚/点菜），权力每夜重新分配一次，压抑感来自"知道接下来会发生什么" [卡·大红灯笼高高挂#1]。

### 语法 3：道具四段弧（埋-显-验-用）

超自然/规则道具分四段释放 [卡·聊斋志异_原著#3]（剑袋，知识库核心招式「超自然道具·四段弧」）：
1. **埋**：主人立禁忌（「幸勿翻窥箧襆」）——观众知道有事但不知道是什么；
2. **显**：禁忌被打破的瞬间道具自动展示威力（剑光裂窗）——一次奇观完成交代；
3. **验**：用环境证据把奇观钉进现实（窗外血迹、白杨乌巢）——**"验"最容易被偷工，也是聊斋独有的严谨**；
4. **用**：终局按预埋规则运作（革囊收夜叉），顺带解释先前疑点。

纪律：道具每次出现都要推动认知升级，禁止说明书式交代。

### 语法 4：道具三身份法（职业工具 + 罪证 + 情感信物）

一个核心道具最好同时背负三重身份：**职业工具**（角色用它干活）、**罪证**（记录/指认罪与恨）、**情感信物**（关系与记忆的容器）。

**伏妖记白骨头颅——道具恨的物化【用户决策，2026-08 拍板】**：反派核心道具不是"战力外挂"，是**恨的物化**。用户先否掉"师傅头骨是她的法器"的直白表现（2026-08-07：「表现的不好」），v2.1.2 重设计后才被认可——从"拿着法器打斗"升级为"恨的物化贯穿道具时态"：头骨从"供着的摆设"变为真法器，她摄来迎向剑光，**眼窝亮起暗红（她透过师傅的眼窝看人）**；剑光劈裂骨缝（恨的容器碎了）；宫阙崩塌头颅滚落，她看了一眼没捡——「她住不起这座宫阙，可她带着他的头住了十八年」。工具+罪证+信物三身份齐备，挂进时态表（第17场供台→第22场崩塌滚落没捡）[伏妖记 v2.1.2 + 2026-08-07 会话拍板]。

配套工具——**道具时态表**（伏妖记实战）：为每个核心道具建表，逐场登记"在哪、在谁手里、替谁说话"。实例：空绳（第5场挂白骨→第23场收进怀里）、铜镜（第4场映出另一张脸→第23场映出自己的脸）、灼印（第2场烙下→第15场发烫→第21场金光入剑）、母亲的丹（渡入→被偷→物归原主→被夺→随封印回镜）——**同一物件散落各场的出现连起来就是一条暗线**。

### 语法 5：妆容 = 状态

妆容不是装饰，是"状态计量器"，两类用法：
- **受伤不自知型**：角色带伤却无感——伤妆是身心状态错位的视觉证据；设计"谁看见伤/谁不知道伤"的信息差（伤口被他人先看见=关系揭示点）；
- **状态变化型**：给人物一条"状态妆轴"（干净→带伤→染血→毁容/妆淡→艳丽→邪气），每次变化绑定一个事件——慈禧三片"越往后越艳丽"=权力递进刻度 [深·李翰祥]；颂莲疯癫=被剥夺话语权后的剩余表达（红衣游走）[卡·大红灯笼高高挂#7]；伏妖记把状态直接编码进视觉 [知识库 SKILL.md·核心招式]。

### 语法 6：道具时间线（时代考据与架空边界）

**6.1 考据三档纪律**（李翰祥/朱家溍）：一档真实大事与人物结局不可改；二档制度细节（官制/礼仪/刑罚/器物名）准确到术语级，宁可少拍不可拍错；三档日常情节可虚构但"怎么吃饭、怎么行礼、怎么走路"不得违反时代 [深·李翰祥]。考据从氛围走向制度：倾国倾城棚拍被故宫专家逐条订正（"细节没有一点对的"）→ 垂帘听政实景+顾问（"真实二字是很地道的"）[深·李翰祥]。
**6.2 实景+棚拍混合**：真建筑给"真实"，模型给"奇观"（故宫实景+大水法模型焚毁）[深·李翰祥]。
**6.3 架空时代的道具边界**：李翰祥"念念不忘的是真实"（考据即方法论）vs 徐克"背景根本不重要"（青蛇）[深·徐克]；张艺谋"视觉决定历史"——先有黑宫殿再定秦代、敦煌色倒推唐代，**架空世界道具由视觉倒推，内部自洽优先于外部考据** [深·张艺谋]。
**6.4 物件时代矩阵**（徐克）：用一件小器物承载时代史——手扇刻满不平等条约（家国=角色处境）、西洋相机=文明符号 [深·徐克]。一件对的道具 > 十句年代字幕。

## 四、常见坑（本领域为什么烂）

1. **道具一次性说明书式交代**：法器出场即全知——不懂四段弧，奇观一次放完没有"验"。按埋-显-验-用重排 [卡·聊斋志异_原著#3]。
2. **服装只有"好看"没有"状态"**：全片服装不随人物变化——服装当造型不当状态轴。每人一条服装变化线，换装绑定事件 [卡·大红灯笼高高挂#8][深·张艺谋]。
3. **色彩没有纪律**：五彩斑斓、红色滥用——色彩当装饰不当语义。锁死色域+稀缺色纪律 [深·张艺谋][知识库 SKILL.md]。
4. **关键道具不提前埋**：凶器/信物需要时才凭空出现——反转没有地基。凶器提前以无害身份登场 [卡·寄生虫#6]；物证早埋晚收（31%→94%）[卡·断背山#5]。
5. **信物规则不自洽**：观众问"抢到信物为什么不直接称王"——只给了象征没给规则。补仪式合法性（需香主主持/宣誓）[卡·黑社会#3]。
6. **时代考据两极化**：要么全错要么被考据绑架——不懂三档纪律。三档分开查 [深·李翰祥]。
7. **伤妆/状态妆只是装饰**：带伤不影响任何人——妆容没绑定信息差与事件。设计"谁看见伤/谁不知道伤"，变妆绑事件 [深·李翰祥][伏妖记实战]。
8. **道具流转没有知情权设计**：转手但"谁不知道什么"没写清，接力变流水账——把道具链当路线图不当因果链。每站交代知情权错位，价值揭示压到最后 [卡·两杆大烟枪#5]。

## 六、AI 提示词对接（Seedance 落地）

核心：给模型"锚点"而非"形容词"——一致性靠固定锚点，变化靠显式指令，色彩靠色票声明。

**服装锚点（防穿帮核心）**：每角色一条固定服装签名（颜色+材质+结构），每次出场重复；变化必须显式声明。
```
fixed costume signature (grey-blue tunic, cloth belt, talisman pouch; pouch bulges only after scene 9); second lead: faded red dress, loose bun, curled fingers; contrasting palettes in frame
```
（依据：伏妖记人物造型 v2.1.3）

**色彩纪律**：
```
locked palette, one dominant hue per chapter, red scarce (max N accents), state color-coded (chaos=mixed, control=pure)
```
（依据：五色章节 [深·张艺谋] + 伏妖记红色纪律）

**道具提示词（特写标记 + 四段弧）**：
```
object handoff beat with close-up anchor at every transfer (gripping hand, dilated pupils); condition (crack/blood/wear) accumulates across scenes; four-beat arc: plant (taboo), reveal (one spectacle), verify (physical evidence), use (pre-established rule)
```
（依据：黑社会触摸特写 [卡·黑社会#3] + 剑袋四段弧 [卡·聊斋志异_原著#3] + 伏妖记时态表）

**时代考据三档（历史剧）**：
```
three-tier accuracy — events immutable, institutional terms exact, daily life plausible; location+set hybrid keeps scale
```
（依据：朱家溍考据分寸 [深·李翰祥]）
