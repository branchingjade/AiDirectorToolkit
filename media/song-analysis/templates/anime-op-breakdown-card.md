## 七、Suno Style 翻译
```
[Style] <英文风格词：genre + 人声 + 律动 + 段落特征>
[Key] <调>
[BPM] <值>
[Structure] intro → verse → pre-chorus(build) → chorus(full band) → interlude → verse → bridge(breakdown) → final chorus(explosive)
```
- 四和弦循环用罗马数字描述（i–VI–III–VII）比具体和弦名稳——Suno 对移调鲁棒
- 落ち断崖必须显式写进提示词，否则没有落差感
- 半速律动写 "half-time feel" / "double-time chorus"
- 小调必须显式 [Key] minor，或情绪词绑定小调
