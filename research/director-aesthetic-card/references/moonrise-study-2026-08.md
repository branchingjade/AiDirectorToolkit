## 新坑（本轮实测）

1. **Ebert wayback 无 meta/无 article 容器 → `class="review"` div 区间提取法**：`t.rfind('<div', 0, t.find('class="review'))` 起、到 Copyright/Ebert Club 截尾，正文 17 段干净（meganav 下拉摘录混入 `<p>` 提取是假象——晚春轮 h1 定位法的第三变体；本例连 h1 也无，靠 class 区间）。
2. **NPR/VF/Collider wayback `<p>` 长段提取直接可用**（分别 19/65/33 段）；VF 正文页面内双份（slideshow+main）内容相同——引用照引、不重复计数、不判污染。
3. **enwiki ref 的 archive-url=一手访谈直抓通道**：NPR 2013/IndieWire 2012 Cannes/Collider/VF 四条导演原话访谈全由 ref archive-url 一次拿齐——维基转引升级为原文核实（本轮「memory of a fantasy」等核心论断全部原文级）。
4. **校验新坑：模板剥壳吞 infobox 内译名行与 ref 内文章标题**（「月昇冒險王國」在 {{Infobox film}} 内、「An Enchanting Old Ruin」在 {{cite web}} ref 内）——校验脚本加 **raw 兜底**：规范化失败后对原始文本压空白+小写+繁简映射再比（与搏击俱乐部轮 raw 兜底同族，本条管「剥壳误删」）。
5. **execute_code 内 os.chdir('/c/...') MSYS 路径在 Windows Python 无效**（写入 /c/c/...）——黑泽明轮已载「execute_code 与 terminal cwd 不一致坑」，本轮复现并确认：execute_code 一律用 `C:/...` 原生路径或干脆不 chdir、写绝对路径。
6. **「长评=剧本」转载稿的译注标记**（注1-注7）：引文含译注锚点时须原样保留（「本杰明·布里顿（注1）写了一个大乐段」）或显式标注省略，否则逐字校验必 MISS——与译者脚注同族：转载稿的编辑性标记是原文一部分。
7. **豆瓣长评=中译剧本全本再添一例**（7125852 火村/奚虞译 47K 字，标题直写「《月升王国》电影剧本」，80 有用）——选稿关键词「剧本」一次命中；剧本质量高（舞台指示级描述+人物动作完整），可支撑桥段/技法卡片的场景级证据。
