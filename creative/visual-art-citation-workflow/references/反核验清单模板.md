# 反核验清单模板（v1.0）

适用：考据完成后对项目美术规范做反向核对——找出规范内部的冲突/不自洽处，作为决策留档等待用户拍板。

## 反核验的目的

规范文档（美术设计_8more / 八美术纪律 / 等）只回答"做什么"，不查"是否合理"。**反核验 = 在做之前先识别出可能让制作翻车的点**。

## 模板（实际项目参考伏妖记 v1.4）

```markdown
## 反核验结论汇总（本次最大增量）

### 3.1 已发现的真冲突（必须决策留档）

| 编号 | 冲突项 | 来源 | 建议路径 | 紧急度 |
|---|---|---|---|---|
| **F001** | <冲突 1> | <规范文档位置> | <路径 A/B/C> | 高/中/低 |
| **F002** | <冲突 2> | <规范文档位置> | <路径 A/B/C> | 高/中/低 |
| ... |

### 3.2 已落地的可制作性结论（CG 落地无门槛）
- <角色/器物/场景>：<✅易/⚠️需预算/❌需替代方案>

### 3.3 已落地的可替代方案（CG 成本评估）

| 高成本项 | 替代方案 | 成本节省 |
|---|---|---|
| <如金翅鸟本体百万片羽毛> | <金色光翼+粒子云> | 70% |
| ... | ... | ... |
```

## 反核验常见冲突类型（5 大类）

### 类型 1：稀缺色配额冲突

**症状**：规范设定"红只三处"vs实际角色戏物里的红色物件 >三。

**反核验做法**：扫红色物件清单（嫁衣 / 灼印 / 指尖血 / 剑穗 / 朱漆红柱 / 红盖头...）→ 数总数 vs 规范配额 → 撞配额立即标决策留档。

**推荐路径**：
- 路径 A：维持"红只三处"硬铁律 → 把红剑穗改为**赭红/朱砂红/枣红以外的深绛色**或改**青黑色**
- 路径 B：放宽红配额到"主线红 + 次要红"两档
- 路径 C：保持规范不变，但红色物件**只在某场戏出现一次**，且镜头不放大

### 类型 2：角色撞色

**症状**：同门师徒 / 同阵营 / 同身份角色用同色衣服，视觉上区分不开。

**反核验做法**：扫同门师徒 / 同阵营角色服装表 → 同色立即标。

**推荐路径**：
- 路径 A：让后期成长版**深一档**（如 #1F3A40 暗深），形成层级
- 路径 B：靠**头饰**区分（混元巾 / 莲花冠 / 光头）
- 路径 C：同色不同调（**石石青偏冷** vs **铜铜青偏暖**），同色相不同色温

### 类型 3：色彩语义分层不足

**症状**：规范用单一色名表示多重含义（如"金色妖力"），观众从色彩看不出"妖力状态"。

**反核验做法**：扫所有色名 → 每色多重含义？→ 必须**分层**（暖金/高亮金/深金/浅金），按色相/亮度/饱和度三层区分。

**推荐路径**：
| 色名 | HEX | 用途 |
|---|---|---|
| 暖金 | `#FFB860` | 妖力觉醒（失控） |
| 高亮金 | `#FFD700` | 伏妖术（受控） |
| 深金 | `#D4A74A` | 反派金色灵光 |
| 浅金 | `#FFEB99` | 双流合一击 |

### 类型 4：实体形象违背八美术纪律 #5

**症状**：规范把抽象概念做成具象符号（如"善恶是天平的平衡"）——八美术纪律 #5 明确"避免抽象概念做成具象符号"。

**反核验做法**：扫所有"实体形象"设定 → 检查是否"善恶/正邪/因果"等抽象概念具象化。

**推荐路径**：
- 抽象 → **行为映射**（妖对照出主角自己）— 符合八美术纪律 #5
- 抽象 → **场景化**（庙=牢笼+手段）— 不需要"天平"符号
- **不要**：做"半人半山"（人形象不行）/"无形体"（CG 不能制作）/"玩具模型感"（质感不足）

### 类型 5：设定道具不进剧情使用

**症状**：规范设定了一个道具/法器，但剧本正文里它只是**摆着**，没有真正在剧情中使用。

**反核验做法**：扫道具时态表（起点/中点/终点）→ 每场戏是否用？→ 没用就标"表现的不好"。

**推荐路径**：
- 道具必须**真的用起来**（白骨头颅→供台正位/映画对峙/宫阙崩塌滚落）
- 不能用就**砍掉**——不为了道具多而保留不用的道具

## 反核验决策纪律

1. **不擅自解决**——发现即列清单，等用户拍板
2. **不写死进规范**——决策前规范文件不动
3. **决策进 OV / OpenViking 项目记忆 `12-待定与OpenItems.md`**——保留决策过程可追溯
4. **决策落定后**——规范文件更新 + 考据文档同步 + Obsidian git 归档

## 反核验清单 vs 全片审查清单

- 反核验清单：针对**单部作品**的美术设定，找**规则内部的冲突**
- 全片审查清单：针对**单部作品**的剧本/分镜/全片，找**叙事/结构的冲突**

两者**不重叠**——反核验是技术规则层面，全片审查是叙事层面。
