# 知识库先行·六步串联管线（v2.0 M3）

> 版本：v1.0（2026-08-09，v2.0 大目标 M3 管线）
> 适用范围：所有创作类 skill（AI电影编剧/AI电影导演/AI短剧编剧助手/AI短剧导演助手/AI提示词助手）
> 本文件是「六步串联」的唯一正本——5 个创作 skill 的知识库先行章节都引用本管线，不各自为政

## 为什么是六步

v2.0 大目标：知识库从「查得到」（研习库）到「用得上」（创作引擎）。
创作时不是「想查才查」的资料，是**每次创作必走的流程**——六步缺一不可：
**少一步 = 漏一个层面的判断 = 创作时犯错。**

## 六步管线

写任何一场戏/一个镜头/一段提示词之前，按序走六步：

```
① 题材密码 → 定骨架
   判断题材 → 加载对应题材密码（题材密码/<题材>.md）
   → 世界观规则/结构范式/调性/常见坑 = 本片骨架
   （写任何一场戏前，先知道这个题材为什么成立、通常会死在哪）

② 检索表 → 定招式
   判断本场场景类型（打斗/群像/留白/反转/情感…）→ 查场景检索表
   → 读对应大师技法卡片（读根因，不照抄结构）→ 挑 2-3 个可落地技法
   （这一场戏的技术弹药从哪来——从范本实证里来，不从套路里来）

③ 导演卡 → 定风格
   本场该用什么「作者语气」？→ 查导演美学卡片索引 → 读对应导演卡/手法体系深化
   → 风格不是「加滤镜」，是镜头的组织方式（快剪/长镜/留白/对称…）
   （同一场戏，胡金铨拍是剪辑造武打，王家卫拍是情绪时间，风格=导演语法）

④ 学科密码 → 定制作
   本场涉及哪个制作学科（服化道/美术置景/色彩/光影/构图运镜/声音/剪辑/调色/视效）
   → 查制作学科库索引 → 读对应学科密码（制作学科/<学科>设计密码.md）
   （这个领域怎么设计才成立——服装=人物/道具=叙事引擎/空间即命运…）

⑤ 大师卡 → 定参照系
   本场的制作环节有没有对应的大师（摄影/美术/配乐/剪辑/视效…）？
   → 查制作大师卡索引 → 读对应大师卡
   → 用大师的「做减法/做加法」哲学当参照系（不是抄，是校准品味）
   （学科密码给规则，大师卡给品味上限——规则保证不出错，参照系保证做得好）

⑥ AI 提示词 → 定落地
   把上面五步的成果翻译成画面约束 → 查 AI 提示词助手 / 学科密码的「AI 提示词对接」节
   → 招式翻译成画面约束（同镜反转→一镜到底不切镜头；最轻动作→镜头停在手上）
   （前五步是「怎么写」，这一步是「怎么生成」——提示词是落地前的最后一道门）
```

|---|---|---|---|---|---|---|
| AI电影编剧 | ✅全量 | ✅全量 | ✅全量 | 边缘（剧本层） | 边缘 | 不适用（编剧管故事） |
| AI短剧编剧助手 | ✅全量 | ✅全量 | ✅全量 | 边缘 | 边缘 | 不适用 |
| AI电影导演 | ✅继承 | ✅全量 | ✅全量 | ✅全量 | ✅全量 | ✅全量 |
| AI短剧导演助手 | ✅继承 | ✅全量 | ✅全量 | ✅全量 | ✅全量 | ✅全量 |

## 六步纪律

1. **顺序不可跳**：①→⑥ 是按依赖排序的——骨架没定就挑招式=无根之木，风格没定就写提示词=贴标签
2. **每步只读需要的**：不是六份文件全读（那是翻库不是创作）——按场景类型/题材/学科**精准加载**对应文件
3. **读完要落地**：每步不是「读了就行」，是「挑出能用的」——招式挑 2-3 个、风格选一种语气、学科取 1-2 条语法、大师定一个参照系
4. **写完对照**：本场用了哪个技法？没用上的，是刻意不用还是根本没想到？→ 没想到就改（这是唯一闭环步）
5. **少一步 = 犯错**：创作中如果发现「这场戏不知道该怎么写」——回查是哪一步漏了
