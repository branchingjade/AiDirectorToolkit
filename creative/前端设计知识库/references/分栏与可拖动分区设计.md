# 分栏与可拖动分区设计

> 2026-08-10 | 面向：工具型 UI 的多栏布局与可调整分区——分隔条、最小宽度、布局持久化、窄屏降级。补 [[布局与信息架构]] 的静态骨架之后，这块管「用户能不能自己调」。
> 来源标注：训练知识（Microsoft Fluent 2 Splitter、Apple HIG、Nielsen #6、WAI-ARIA 规范）

## 一、分栏基础（先定栏，再定可调性）

| 栏数 | 什么时候用 | 栏宽逻辑 | 出处 |
|---|---|---|---|
| 单栏 | 内容聚焦（阅读、编辑单一对象） | 内容区定宽或流式 | Material 响应式布局 |
| 双栏 | 工具型默认：左内容 + 右参数/详情 | 主栏 60-75%，副栏 25-40% | 本工作区基准（TTS 工具迭代五版） |
| 三栏 | 创作/配置型：导航 + 内容 + 参数 | 导航窄（≤240px）、参数中（280-360px）、内容吃剩余 | 同上（火山引擎体验中心参照） |

要点：
- **栏宽初始值用预设比例，不平均分**——主内容永远比工具栏宽（F 型扫描，见 [[布局与信息架构]]）
- 栏数 ≤3，超过三栏 = 认知负荷超载（Miller 7±2 组块上限）

## 二、可拖动分区（Splitter）设计

### 2.1 分隔条（Splitter）交互规范

| 规则 | 说明 | 出处 |
|---|---|---|
| 拖动反馈 | 拖动时实时预览（低延迟）或显示分隔线（高成本重排场景）；松手落定 | Fluent 2 Splitter |
| 悬停态 | 分隔条悬停高亮 + 光标变 resize（col-resize/row-resize） | Fluent 2 |
| 双击重置 | 双击分隔条回到默认比例——用户迷路时的逃生口 | 桌面应用惯例（VS Code/飞书） |
| 键盘调整 | 分隔条可聚焦，方向键调整栏宽，步进 10px | WAI-ARIA separator |
| 拖动热区 | 分隔条本身窄（4-8px）但命中区域要宽（≥16px），避免难抓 | Fitts 定律（[[UI交互设计逻辑与动效]] 套1） |

### 2.2 最小宽度（硬约束）

| 约束 | 理由 |
|---|---|
| 每栏最小宽度 | 内容栏最小 320px、参数栏最小 240px——拖动到看不见内容 = 无效布局 |
| 最大宽度 | 参数栏最大 480px（再宽是浪费），内容栏不设上限 |
| 越界钳制 | 拖动超界时钳制在 min/max，分隔条不跟手跑出视口 |

### 2.3 可折叠分区（Collapsible Panel）

| 模式 | 用法 | 出处 |
|---|---|---|
| 参数栏折叠 | 工具栏可折叠成图标条（chevron/图标），悬停或点击展开 | Fluent 2 / Material 导航抽屉 |
| 折叠 ≠ 默认 | **默认展开**，折叠是用户主动行为——工作工具默认折叠参数 = 把决策藏起来 | 本工作区铁律（TTS 工具迭代教训） |
| 折叠状态持久化 | 记住折叠/展开 + 栏宽（见下） | Nielsen #6 |

## 三、布局持久化（用户调完要记住）

| 规则 | 说明 | 出处 |
|---|---|---|
| 记住用户布局 | 栏宽、折叠状态、栏顺序存 localStorage/用户设置，重开恢复 | Nielsen #6（识别优于回忆） |
| 记住的粒度 | 按用户 + 按视图（每个页面/模式独立记忆） | 同上 |
| 重置入口 | 提供「恢复默认布局」——用户调乱后的退路 | 桌面应用惯例 |
| 多屏适配 | 记住的宽按比例存（百分比）而非像素，避免换屏后溢出 | 工程实践 |
| 不记住的 | 临时性操作（临时预览面板）不持久化 | — |

## 四、窄屏降级（响应式收栏）

| 断点 | 行为 | 出处 |
|---|---|---|
| 宽屏（≥1440px） | 三栏全开，参数常显 | Material 响应式断点 |
| 中屏（1024-1439px） | 参数栏收成抽屉（按钮唤起） | 同上 |
| 窄屏（<1024px） | 双栏叠成单栏，导航收汉堡 | 同上 |
| 工具型底线 | 即使窄屏也保持「内容 + 可唤起参数」，不裸单栏 | 本工作区偏好 |

⚠️ 4K + Windows 缩放下 CSS 媒体查询失效问题：断点判定用 JS 检测物理分辨率，见 [[可访问性与跨屏适配]] 第四节。

## 五、实现要点

| 要点 | 说明 |
|---|---|
| 拖动性能 | 拖动监听用 `pointermove` + `requestAnimationFrame` 节流，避免每像素重排 |
| 布局状态 | 栏宽用 flex-basis/CSS 变量承载，拖动只改变量，不触发整树重排 |
| 存储时机 | 松手（pointerup）时存一次，不每帧写 localStorage |
| 无障碍 | 分隔条 `role="separator"` + aria-valuenow 报当前宽度，方向键可调 | WAI-ARIA 1.2 |
| 参考实现 | VS Code / 飞书 / Linear 的分隔条手感（实时拖动 + 双击重置） |

## 实战对照（本工作区偏好 → 权威依据）

| 既定偏好 | 依据 |
|---|---|
| 宽屏双栏、参数常显不折叠 | 分栏基础表 + 折叠 ≠ 默认 |
| 记忆上次视图/筛选/搜索词 | 布局持久化（Nielsen #6）同源 |
| 空间利用率优先 | 栏宽预设比例 + 最小宽度钳制 |
| 4K 检测 | 窄屏降级用 JS 物理分辨率判定 |
