# AiDirectorToolkit — AI 短剧/中剧导演工具包

三层 Skill 架构，覆盖 AI 短剧/中剧从剧本创作到视频生成的完整流水线。

```text
AI编剧助手 v1.0.0 ──→ AI导演助手 v11.0.0 ──→ 制作交付
（剧本创作阶段）       （制作/执行阶段）        （分镜+资产+字幕）

AI提示词助手 v1.2.1 ──→ 约束体系主本，提示词写作约束从此同步
```

---

## AI编剧助手 v1.0.0

**剧本创作引擎** — 从概念到锁定剧本的六阶段完整工作流。

| 阶段     | 产出                                   |
| -------- | -------------------------------------- |
| 概念锚定 | 一句话梗概 + 类型定位                  |
| 大纲构建 | 人物网络 + 集数规划 + 关键节点         |
| 分场设计 | 全剧场次清单                           |
| 初稿写作 | 标准AI剧本格式逐场产出                 |
| 自审打磨 | 密度审查 + 感情语言审查 + 三问初感      |
| 锁定交接 | 锁定剧本，交接给 AI导演助手             |

含创作宪法（七条）、标准剧本格式、感情语言框架（十个角色类型）、城市详规方法论、内容密度审查。

**前置依赖**：AI提示词助手（提示词约束引用）

## AI导演助手 v11.0.0

**制作/执行阶段** — 以电影导演思维驱动分镜设计的全链路工具。

- **导演初感协议（三问）**：读剧本后第一反应，理解情感合同
- **剧本遵循协议**：台词逐字嵌入 + 动作强制继承 + 剧本遵循度门禁
- **导演主动性原则**：在剧本之上的视觉层主动创造（视点/光/运镜/声音）
- **导演反问机制**：防 autopilot，在关键决策点暂停
- **导演创作原则**：视点权力/空间地理/光叙事/镜头对/节奏呼吸/海报镜头/声音第二层叙事
- **情绪工程**：情绪→生理映射 + 四层动作体系 + 环境反馈
- **分镜代码块格式**：标准化 Seedance 2.0 提示词
- **父-子Agent架构**：叙事聚簇并行，父审子产
- **地基五件套**：角色/场景/道具/配音/全局锁

**前置依赖**：AI提示词助手（提示词约束同步）

## AI提示词助手 v1.2.1

**Seedance 2.0 提示词约束主本**（canonical source）— 单条提示词优化引擎。

约束体系（AI导演助手和AI编剧助手的提示词约束均从此同步）：

- **不编造原则**：只优化原文已有内容
- **禁文学化修辞**：比喻/拟人/象征/夸张 → 物理世界直述
- **精确数值替换**：厘米/角度/秒数 → 身体参照系
- **物理优先法则**：光线/动作/表情/空间的可感知描述
- **动作设计**：四层体系 + 补全原则 + 环境反馈
- **声音设计速查**：环境声/动作声/呼吸声/情绪声/静默
- **运镜与光线速查**：10种运镜 + 5种光线 + 危险关键词
- **避免AI角色木偶化**：反蜡像四原则
