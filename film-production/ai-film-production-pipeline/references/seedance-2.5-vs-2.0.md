# Seedance 2.5 模型/API/提示词要点（官方文档研读 2026-08）

来源：火山引擎文档 82379/2607688（Seedance 2.5 教程）+ 2607689（Seedance 2.5 提示词指南），经 SPA 提取全文。

## 模型定位
Seedance 2.0 的工业级升级：30 秒长叙事直出 + 50 个多模态参考 + 时间戳级编辑控制 + MOV 专业格式。
**Model ID：`doubao-seedance-2-5-260628`**
开通条件：余额 >200 元或已购资源包。

## 任务类型两级判定（最容易踩的坑）
判定依据：**content.role 取值 + prompt 关键词**双重判定；违规触发**异步报错** `InvalidParameter.TaskTypeConstraint`（排队等模型判定后返回）。

| 任务 | 触发条件 | 参数硬限制 |
|---|---|---|
| 视频编辑 | role=reference_* + prompt 含 编辑/增加/删除/修改/替换/改成 | ratio 仅 `adaptive`；duration 仅 `-1` |
| 视频延长 | role=reference_* + prompt 含 延长/延续/续写 | ratio 仅 `adaptive`；duration [4,30] 或 -1 |
| 首帧/首尾帧 | role=first_frame/last_frame | ratio 仅 `adaptive`；duration [4,30] 或 -1 |
| 文生/参考生 | 无特殊触发 | 无限制；但 **prompt 禁出现编辑/延长相关词**（防误判） |

## 提示词写作要点（官方指南精华）
- **基础公式**：主体+动作/事件+场景环境+视觉风格+运镜切镜+声音（按序，缺省可省）
- **素材指代**：`@图片1`/`@视频1`/`@音频1` 按上传顺序编号；多主体逐一列映射（"图 1 的侠客"、"img1-2 是人物 1 对应音频 1"）；分工具体到"参考什么"；素材精准时只指代不复述；**不建议只在图片里写映射信息**（图内写名+prompt 直呼 → 混淆）
- **声音符号**：音乐 `()`、音效 `<>`、台词 `{}`、字幕 `【】`；非中文台词前注明语言
- **时间戳**：整数秒；区间连续（避免"0-3 秒…5-6 秒"断层）；**不支持控频率**（"一秒摇头 3 次"）；三种写法=区间/时间点/相对时间
- **镜头语言**：景别/热门运镜直接写（一镜到底/希区柯克变焦/FPV/子弹时间）；小众专业词转 `[名词+描述性解释]`；转场写清触发点与方式
- **动作/表情**：动作优先概括（"连续几组高抬腿和空翻"）+记忆点细节；表情写描述句少用成语（"津津有味地吃饭"→"脸上带着满足的笑容，大口地吃饭"）
- **负向控制**：不要字幕；细分音频（"无 bgm，只生成环境音和动作音"/"不要任何声音"）
- **白模参考**：粗粒度（简单几何体拼接）效果好；白模主体别建四肢/翅膀（易僵化）；细粒度白模视频别含轨迹线/坐标线/相机 cone（会泄露到成片）
- **多宫格分镜**：≤15 格；推荐火柴人/线稿分镜；宫格**不严格对齐**分镜（要严格对齐用多关键帧）
- **关键帧**：独立分图按顺序传，prompt 第一句写「以图片 x 至图片 x 的顺序作为关键帧」

## 素材规格边界
- **图**：jpeg/png/webp/bmp/tiff/gif/heic/heif；宽高比 [0.4,2.5]；边长 [300,6000]px；单张 <30MB；参考 1~30 张
- **视频**：mp4/mov（H.264/H.265）；单段 [2,30]s 最多 10 段总 ≤30s；FPS [24,60]；单段 <200MB；总像素 [409600, 8295044]
- **音频**：wav/mp3；单段 [2,30]s 最多 10 段总 ≤30s；单段 <15MB
- **请求体 ≤64MB**（大文件别用 Base64）
- **真人人脸**：不支持直接上传含真人脸的参考图/视频（需便利创作方案：信任模型产物/预置虚拟人像/已授权素材）
- **URL 时效**：任务记录 7 天；视频 URL 仅 **24h / 100 次下载**，需及时转存
- **限流**：个人 180 RPM / 3 并发；企业 600 RPM / 10 并发
- **mov 播放兼容**：VLC/mpv/ffplay 全平台 ✓；IINA 仅 macOS

## 与自家 AI提示词助手 v1.5.1（Seedance 2.0 主本）对比（2026-08 会话产出）
**架构一致（无需重构）**：结构化分镜、物理描述优先、运镜体系、声音自然融入、负向控制——官方指南与自家约束殊途同归。
**我方更严（官方没有）**：禁文学修辞、禁精确数值、四层动作体系+动作四要素、木偶化防护。

**5 个缺口（待用户拍板是否升级 skill）**：
1. 时间戳写作规范——2.5 新能力，自家 skill 全用"镜头 N"切分无时间戳章节
2. 声音符号冲突——官方 `()/<>/{}/【】` vs 自家"音效物理融入不用标签"，**真实冲突需二选一**（决定提示词长相）
3. R2V 素材指代写法（@编号映射）——自家无素材指代章节
4. 任务类型误判防护——参考生视频 prompt 禁编辑/延长词（API 层硬约束，自家约束主本未覆盖）
5. 负向控制维度——官方支持细分音效/bgm/对白，自家只有笼统"不写段级资产声明"
