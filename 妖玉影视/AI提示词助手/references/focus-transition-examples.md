# 焦点转移示例集

焦点转移通过描述行内的自然语言描述，不独立成行。以下为常见写法。

## 一、基础类型

### 1. 动作驱动型
焦点跟随角色的肢体动作移动。

```
镜头从两人交握的手部缓缓摇至王秀娟面部。
焦点从阿彪面部自然过渡到钞票上。
视线从王秀娟面部滑到证书上。
```

### 2. 光线引导型
焦点沿光束的投射路径移动。

```
焦点落在窗光光束中浮动的微尘上，缓缓移向陈强头发边缘的轮廓光。
```

### 3. 视线引导型
焦点跟随角色的视线方向移动。

```
王秀娟眼睛从李素珍脸上滑到证书上。
陈强视线方向——三幅木框画像。
```

### 4. 空间建立型
焦点在场景空间中逐层推进。

```
镜头从门玻璃上"强子民生服务社"字迹推进，玻璃后陈强模糊身形渐清。
```

### 5. 物件扫描型
焦点在桌面/墙面上的物件间依次移动。

```
镜头从奖状白纸摇向旧木刮痕，再移向刷子蘸浆糊拉出的细丝。
```

## 二、复合类型

### 6. 人物→物件→人物
焦点从角色跳到关键道具再回到角色反应。

```
焦点从磊子入画的脚步移到桌面，再回到磊子悬在半空的手。
```

### 7. POV 主观视角
焦点模拟角色眼睛的观看顺序。

```
王秀娟主观视点——证书封面在画面正中，双手微微发颤。
```

### 8. 环境→人物→环境
从空间环境进入，落到人物，再回到环境。

```
焦点从窗光光束中浮动的微尘移到陈强轮廓光，再落向他胸口起伏。
```

## 三、与运镜的配合

| 运镜 | 焦点转移写法 |
|------|-------------|
| 固定 | "焦点落在...上" |
| 缓推 | "镜头缓缓推近至..." |
| 缓拉 | "镜头缓缓拉远，露出..." |
| 跟拍 | "镜头跟随...移动" |
| 摇镜 | "镜头从...摇至..." |
| 手持 | 焦点轻微跳跃，描述中体现不稳定感 |
