# 8bit h264 素材调色约束

通过 `media_analysis` quick 分析获得每个片段的技术参数后，需注意以下约束：

## 位深限制

**8bit yuv420p 素材的调色余量极小。**
- 暗部提亮超过 1.5-2 档即出现可见 banding
- 饱和度提升在蓝天/肤色渐变区域最容易暴露色阶断裂
- 大面积渐变区域（天空、墙壁）比锐利纹理区域更敏感

## 编码特性

- h264 是 Long-GOP 编码，I 帧之后依赖 P/B 帧预测
- 关键帧之间的 block 边界在高反差场景下可能显现
- 8bit 色阶在暗部比亮部更稀疏（gamma 编码特性）

## 调色策略建议

1. **保持暗部密度**——不要 lift 暗部，让黑色区域保持在 0-5 IRE
2. **用 gain/gamma 控制曝光**——不要动 lift
3. **饱和度保守增长**——超过 +15% risk banding
4. **冷调天然适合 8bit**——蓝/青通道在人眼感知中色阶敏感性低于暖色
5. **暖调风险更大**——肤色区域的色阶断裂比冷色场景更容易被察觉

## 节点工具检测

通过 `probe_node_graph` 的 `tools` 字段可以检测节点中使用的工具类型（如 "HDR", "RGB混合器"），但 Resolve API **不暴露工具的具体参数值**。只能确认"做了调色"，无法读取数值。
