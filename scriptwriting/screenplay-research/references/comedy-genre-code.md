## 1. 定义与谱系

- **喜剧的底层机制 = 预期与落差的循环**：笑 = 认知反转（观众以为 A，实际 B）+ 落差释放（紧张→安全）。
- **元叙事喜剧**：把"拍摄/制作/表演"本身当作喜剧素材，观众笑的是"创作者自己"——自指是元叙事喜剧的独有笑源。
- 谱系：闹剧（slapstick）→ 讽刺喜剧 → 黑色喜剧 → 元叙事喜剧。可混搭惊悚/恐怖：恐怖提供紧张，喜剧提供释放，两者交替升级（本片即喜剧×惊悚）。

## 2. 喜剧机制规则（对应"立规则三问"）

- **笑点从哪来**：信息差——观众知道的比角色少（看"烂片"）、或比角色多（看幕后）、或发现知道得还是太少（彩蛋反转）。信息差每释放一层，之前所有笑点重新生效（**递归笑点**）。
- **限制是什么**：喜剧必须"可信地烂"——**烂在情绪节奏与逻辑（喊口号式恐惧、荒诞推进），物理细节必须全部真实**（血、呕吐物、撞击是真的）。物理层假 = 反转不成立。
- **人怎么应对**：层层揭示。每揭示一层，"烂"被洗白一次，笑点爆发一次。

## 3. 核心结构范式（三层嵌套元叙事）

1. **烂片层（要长、要真烂）**：先给观众一部"烂"到真实的成品（本片 37 分钟一镜到底僵尸片），建立低预期。
2. **揭秘层（逐条洗白）**：时间倒流回到筹备+制作当天，**烂点清单 → 事故清单一一回收**——每个"烂"都对应一个真实、具体、狼狈的事故原因（拉屎/醉酒/腰伤/即兴发挥）。原因越俗越好笑。
3. **彩蛋层（点题即止）**：连"揭秘"也是戏（本片：上田慎一郎"好，卡！"，无人机升起露出全部拍摄设备）。第三层只用一个镜头，不写成另一个篇章。

辅助手法：
- **假结尾/假演职员表**：正片中途插入完整片名+演职员表，把预期压到最低，反转才响；还能制造"撑过 X 分钟就封神"的口碑传播机制。
- **双线剪辑 + 倒计时**：指挥室（知道全貌、无法干预）× 现场（不知道、硬扛），交叉剪辑制造紧张；倒计时数字反复出现制造仪式感。
- **重复即笑点**：台词/动作重复建立仪式，仪式被事故打破的瞬间就是笑点（本片晴美"我很冷静。我现在非常冷静。"说完即暴走）。
- **物理喜剧 + 情感回收共用同一画面**：笑点与泪点同框（叠罗汉 = 全组肉搏的笑点 + 父女照片复刻的泪点）。
- **贫穷即设定**：资源限制直接写进剧情（没钱请好演员 → "演技差"是剧情；没钱做特效 → "道具粗糙"是笑点）。限制即风格。

## 4. 调性/独有能力

- **只有喜剧能"先让观众看不起，再让观众看哭"**——羞辱预期是喜剧独有的情感杠杆。
- 元叙事喜剧的独特情绪：**被骗的快乐**——观众被骗两次后依然开怀，因为骗局本身是创作者用结构完成的最后一声"卡"。

## 5. 范本分析：《摄影机不要停》

- 预算 300 万日元（约 2.5 万美元）→ 日本票房 31.2 亿日元，**回报超 1000 倍**，影史纪录。低成本高概念的极致案例。
- 结构实证（剧本分场）：烂片层 = 场景 1–16（页首注明"场景1至16均为一镜到底拍摄"）；揭秘层 = 场景 17–108（"字幕：一个月前"起）；彩蛋层 = 场景 111。
- **8 个可复用技法**（详见技法卡片源稿）：
  1. 三层嵌套·戏中戏中戏（元叙事总开关）
  2. 假演职员表骗局（观众预期管理）
  3. 烂点清单→事故清单一一回收（8 组对应：录音师拉屎/摄影师醉酒真吐/腰伤换人/即兴巴掌/尖叫拖时间/提示板指令/叠罗汉补俯拍）
  4. 提示板救场（幕后指令变戏内台词，戏内戏外信息差）
  5. 人肉摇臂·叠罗汉（物理喜剧+情感升华）
  6. 道具伏笔·童年照片（场景 29 埋设 → 场景 111 回收，父女暗线全程只靠一件道具）
  7. "演得烂"的表演设计（烂的三规则：情绪过火、逻辑缺环、物理认真）
  8. 直播倒计时双线剪辑（指挥室×片场，Deadline 压力喜剧）
- 一句话偷师：**把"穷"和"烂"写进设定，再用结构把它们全部洗白——先让观众看不起，再让观众看哭。**

## 5.5 情境错位范式（伪装喜剧）——《热情如火》核心范本（2026-08-06 新增）

**范式定义**：喜剧 = 一个不可维持的情境 × 角色按欲望挣扎 × 观众全程知情。笑点不是包袱的堆叠，是情境压力的必然分泌物。男扮女装/卧底/假身份/假结婚是标准载体（伪装必须被逼——活命/还债/任务，自愿的伪装是闹剧）。

**五件套**（热情如火实证，行号=L/7693）：
1. **被逼的伪装 + 临时性承诺**：站台决定男扮女装（L1610 "The name is Josephine"），当场立誓 "The minute we hit Florida, we'll blow this set-up."（L1629）——临时承诺为后面"散不了伙"埋伏笔，因为有人爱上了面具。
2. **自我暗示独白**：把身份焦虑念出来（L2234 "I'm a girl. I'm a girl. I'm a girl -"），配物理锁（撤梯子 L2261、"Fight it." L2277）——重复是仪式，破功瞬间即笑点（与摄影机不要停"我很冷静"同构）。
3. **一句两用系统**：每个伪装场景至少一句双关，另一层意思指向角色真正的欲望/恐惧（L2286 emergency brake / L7409 convention / L3545 Type O / L3607 slap it）。
4. **知情差侧写**：配角"准确怀疑 + 错误归因"替观众点破真相（Sue 的溃疡 L2302-2305），兼任长篇伪装戏的"提醒器"。
5. **对仗收尾**：最大坦白 × 最小反应（L7678 "I'm a MAN!" → L7682 "Well - nobody's perfect."），四连拒 × 四连答逐轮升级，最后一句全场最短（≤5 词）且不再回应。

**辅助手法**：
- 玩笑变奏不重复（Milk Fund 五拍：义卖→十万支票→欠款→百万→收据，L5757-5834）——每拍换角度/×10 升级。
- 道具即人物（spats 鞋罩 10+ 次出现，名/道具/行为三位一体，连死亡都收在道具上 L7504）。
- 主题词四拍回收（lollipop：fuzzy→fuzzy→sweet→sweet 但人不要了，L1974/L2994/L3090-3092/L7605-7608）。
- 双线并线（外部逃亡线×内部伪装线，每一条外部威胁翻译成内部喜剧）。
- 喜剧中段=游乐场：第二幕占全片 70%，第三幕只 8%，追杀一回归就收网。

**与另两范本的边界**：情境喜剧笑"身份"（热情如火）、元叙事笑"结构"（摄影机不要停）、话痨喜剧笑"语言"（安妮·霍尔）——三种笑源可混用，主引擎只能有一个。好莱坞谱系：热情如火（1959）→ 窈窕淑男 Tootsie（1982，AFI 百大喜剧第 2 名）。

## 6. 常见坑

1. 烂得不可信（物理层面也假）→ 反转不成立。
2. 揭秘层的事故原因不够具体狼狈 → 洗白无笑点（"导演状态不好"不行，"憋不住拉屎"才行）。
3. 彩蛋层过重（第三层写成另一个完整篇章）→ 冲淡点题。
4. 烂点清单没有一一兑现 → 观众记住的"烂"没被解释，认知反转落空。
5. 假结尾不够真（观众一眼看穿）→ 预期没压下去。
6. 反转只做一层（戏中戏到此为止）→ 结构平庸，缺"被骗两次"的元叙事乐趣。

## 7. 自检清单

- [ ] 假结尾有完整片名+演职员表+收尾画面，骗得够真？
- [ ] 第三层反转只用一两个镜头点题？
- [ ] 物理细节全部真实（血/呕吐物/撞击是真的）？
- [ ] 情感回收与笑点共用同一画面（笑泪同框）？
- [ ] 有 deadline 实体化（倒计时/直播/截稿）驱动群像戏？
