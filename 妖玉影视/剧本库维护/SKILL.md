# 剧本库维护 v1.0.0

> 触发：把抓到的剧本原文入库 Obsidian 剧本库、或对库内剧本做质检/清理时。
> 目标库：`~/Documents/KnowledgeBase/Obsidian Vault/剧本库/`（华语/海外双区结构）

---

## 一、库结构（双区）

```
剧本库/
├─ 剧本库MOC.md          ← 索引（导演/题材/技法三维 + 可信度分级）
├─ 华语剧本/             ← 国内标准格式（第N场 地点 时间 内外）
│  ├─ 剧本原文/ 5 份
│  └─ 研习报告/ 15 份
└─ 海外剧本/             ← INT./EXT. 格式
   ├─ 剧本原文/ 22 份
   └─ 研习报告/ 22 份
```

**分类规则**：按剧本**内容语言**分（不是按片源地域）——中文格式归华语（含日片中文译稿如摄影机不要停、婚姻故事中文译本），英文归海外。

## 二、入库流程（七步）

### 1. 编码检测（第一步，最易踩坑）

```python
raw = open(path, "rb").read()
n_utf8 = raw.decode("utf-8", errors="replace").count("\ufffd")
n_cp1252 = raw.decode("cp1252", errors="replace").count("\ufffd")
enc = "cp1252" if n_cp1252 < n_utf8 else "utf-8"
```

**坑**：pdftotext 从 PDF 提取的文件**绝大多数是 cp1252**（断背山 604 处乱码/七宗罪 182/七武士 189……）——直接用 utf-8 打开必产生 �。**必须先检测再解码**。

### 2. 内容清洗（三类残留必清）

| 残留 | 来源 | 处理 |
|---|---|---|
| `\f` 分页符 | pdftotext 每页一个 | 替换为 `\n` |
| ASCII 装饰行（`--- .·.`/`·` 居中线/`~~.`） | PDF 页眉页脚 | 正则删除（保留合法 `---`/`***`/`___` 分隔符） |
| Tab 残留（`\tForrest Gump` 页脚） | IMSDb HTML | 替换为空格 |
| 网页 JS（`if (window!= top)`） | IMSDb 反框架脚本 | 正则删除 |
| "第X页" 标记 | juben.pro 分页容器 | 正则删除 |

### 3. YAML frontmatter（每份必带）

```yaml
---
来源: "IMSDb（imsdb.com/scripts/Memento.html）"
版本: "Shooting Script（修订标注）"
与成片差异: "结构上与上映版一致"
可信度: "🟢 拍摄稿"
抓取日期: "2026-08-06"
研习报告: "[[海外剧本/研习报告/记忆碎片_研习报告]]"
---
```

**注意**：
- **不要**在 frontmatter 外用 `>` 引用块放元数据（Obsidian 渲染出蓝条）
- **不要**加 `# 文件名` H1（Obsidian 文件名即标题，加了就两个标题）
- frontmatter 结束 `---` 后**不要**再跟一个 `---` 分隔线
- wikilink 里的 `|` 别名在 Python 字符串里会转义成 `\\|`——直接用不转义的纯链接最稳

### 4. 可信度分级（诚实声明）

| 级别 | 含义 |
|---|---|
| 🟢 原稿/拍摄稿 | 编剧原稿或接近成片的拍摄稿 |
| 🟡 流传稿/译稿 | 流传稿或署名译者译本，与成片有出入 |
| 🟠 早期稿/整理稿 | 与成片差异大（七宗罪1992无盒子/新龙门客栈网版/饮食男女整理稿），或非原稿 |
| 📄 原著对照 | 非剧本，为改编来源 |

**诚实铁律**：库里没有官方原版扫描件——IMSDb/Script Slug/juben.pro 的流传稿/译稿/整理稿**适合学技法，不适合当文献引用**。每份必须标注真实身份。

### 5. 双区落位

- 华语：`剧本库/华语剧本/剧本原文/`
- 海外：`剧本库/海外剧本/剧本原文/`
- 研习报告同步分到对应区

### 6. 同步三地

```
Obsidian 剧本库（权威副本，已修复）
   ↓ 复制
film-suite-research/华语剧本+海外剧本（本地源）
   ↓ 复制
妖玉影视/_知识库/references/大师技法卡片（skill 正本，GitHub AiDirectorToolkit 同步）
```

### 7. 更新 MOC + 质检

- MOC 加新片行（导演表/题材表/技法表）
- 最终质检：乱码 0 + 无 H1 重复 + frontmatter 完整 + MOC 链接全有效

## 三、质检清单（入库后必跑）

- [ ] 全库乱码检测（`count("\ufffd") == 0`）
- [ ] frontmatter 完整（来源/版本/与成片差异/可信度/抓取日期/研习报告 6 字段）
- [ ] 无 `# 文件名` H1（Obsidian 文件名即标题）
- [ ] frontmatter 后无多余 `---`
- [ ] 无 `\f`/`\t`/`\r` 控制字符
- [ ] 无 ASCII 装饰残留行
- [ ] MOC 链接全部有效（wikilink 路径与实际文件一致）
- [ ] 三地同步（Obsidian/本地源/skill）

## 四、常见坑

1. **cp1252 当 utf-8 打开**：全库最大坑——检测编码是第一步，不是最后一步
2. **元数据用引用块**：Obsidian 蓝条丑且占位——用 YAML frontmatter
3. **加 H1 标题**：与剧本自己的标题重复——文件名即标题，正文从剧本原标题开始
4. **wikilink 转义**：Python 写 `\|` 会变 `\\|`——用不转义的纯链接
5. **只复制不质检**：入库 ≠ 完成——七步流程走完才叫入库
6. **不标注可信度**：流传稿当拍摄稿引用=误导——每份必须诚实标注身份
