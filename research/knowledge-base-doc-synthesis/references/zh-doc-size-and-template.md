# 中文文档体积换算与模板校准（2026-08-08 实测）

## UTF-8 体积换算

- 中文 1 字 = 3 字节；ASCII/标点/表格符号 ≈ 1 字节。
- 目标"12-18KB" ≈ 4000-6000 汉字 + Markdown 结构开销（标题/表格竖线/引用符号）。
- 判断达标一律 `wc -c <file>`（git-bash 可用；注意 wc 在 MSYS 下对 UTF-8 按字节计数）。

## 制作学科模板规范要点（00-模板规范.md v1.0 提取）

八节结构：一、定义与谱系（含与相邻学科分工）｜二、核心语法（每条带范本）｜三、范本实证（表格：手法|成片实例|出处|可复用时机）｜四、常见坑（每条=症状+根因+修法）｜五、自检清单（- [ ] 形式）｜六、AI 提示词对接（EN+中注）｜来源清单｜实战回写记录。

引用约定：
- [卡·导演名] = references/导演美学卡片/<导演>_导演美学卡片.md
- [深·导演名] = references/导演美学卡片/<导演>_手法体系深化.md
- [卡·片名#N] = references/大师技法卡片/<片名>_技法卡片.md 卡片 N
- [题材·XX] = references/题材密码/XX题材密码.md
- [AI导演 3.x] = AI电影导演/SKILL.md 章节 x
- [Seedance 2.5] = references/Seedance2.5官方理解.md
- 模板未定义的（如知识库 SKILL.md 招式表）可自定 [知识库·招式表] 等并在来源清单解释。

质量纪律：每条论断带来源；零新抓取优先；不重复题材密码（学科密码只管本专业领域）；诚实声明（合成 vs 外部理论 vs 推断）；泛用导向（可复用时机按创作场景归类）。

## 压缩优先级（实测排序，从最有效开始）

1. 来源清单表格 → 紧凑段落（省 1-2KB，最大的单项收益）
2. 3-6 行小表格 → 内联进正文行（如黑白切换语法表 → 定律行列举）
3. 提示词/模式示例删到最少（可推导的合并一条，指向正文小节）
4. 相邻子弹合并（反讽律并入仪式感；色域变奏+沙漠极值）
5. 范本实证表单元格压缩（时机列短词化）
6. 定律/落地行去冗余措辞
7. 底线：模板强制小节与任务点名主题不可删

## 压缩补丁防翻车

- patch 的 old_string 必须完整覆盖要删块（含标题/空行），否则误删标题或焊行。
- 每批 patch 后 `grep -n "^#\|^##\|^###"` 校验结构；误删立即反向 patch 恢复。
- 压缩轮次多时优先整体重写而非几十个微型 patch（本会话最终用整体重写收敛）。
