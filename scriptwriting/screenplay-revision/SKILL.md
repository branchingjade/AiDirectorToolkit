# 影视剧本改造升级

> 本 skill 处理**已锁定剧本的升级改造**（v1.0→v2.0 类工作）：改名迁移、时代切换、美学文笔强化、全篇无尿点压缩。
> 从零创作/改编走 AI电影编剧（妖玉影视，user-owned，后台不可编辑）；本 skill 是它的升级侧搭档。改造完成后同样走交付物三分离。

## 一、改造前：全量盘点

1. 通读全部交付物四件套：大纲/剧本/分场分析/自审报告
2. grep 扫描时代标志物（见 2.1），评估时代切换成本——往往比想象低
3. 逐场诊断"尿点"（慢节奏点），列出压缩清单
4. 关键决策点用 clarify 确认后再动手（如架空程度：纯架空 vs 半架空——本用户拍板纯架空，见 七）

## 二、时代切换 = 查边界，不是换皮肤

### 2.1 时代标志物盘点（先 grep 再动手）

- 旧时代词一次扫全：`grep -nE "民国|短打|洋火|电话|电报|火车|枪|西装|报纸" 剧本.md`
- **有明确传入时间线的道具逐件核验**：烟袋=烟草万历年间传入→明代合法，保留；火铳/玻璃/报纸类要查
- 经验：民国→明代的架空切换成本极低——剧本核心是人物与因果，时代只在皮肤层

### 2.2 查四边界

| 边界 | 查什么 |
|---|---|
| 称谓体系 | 师徒/村民/老爷/娘子——多数通用，零调整 |
| 道具时间线 | 每件道具的传入时间/时代归属（逐件查） |
| 世界观契合 | 香火/山神庙/符箓在明代语境反而更顺（志怪黄金期） |
| 备案预检 | 架空+批判立场最安全；不涉真实历史人物事件 |

### 2.3 美学三源分配（东方美学大融合）

**每个美学源分配一个画面层级，画面立刻有层次**：

| 源 | 分配 | 例 |
|---|---|---|
| 市井烟火（明） | 人物与日常场景 | 青灰短褐/青瓦/灯笼/香火/酒旗/鸱吻 |
| 留白意境（宋） | 空镜头与呼吸 | 烟雨/山岚/月色/空椅/门槛落叶 |
| 金碧华丽（唐） | 幻境/大场面 | 朱漆柱/描金梁/灯火通明 |

### 2.4 世界观微调服务画面

新增设定要**同时服务镜头语言与主题**。例：「人间烟火=妖的边界」——灯火通处妖气薄，孤灯暗处妖气浓。一个设定 = 市井灯火 vs 荒庙孤灯天然成画 + "妖住在缝隙里"的主题。

## 三、无尿点压缩纪律（核心）

- **只做节奏性压缩，不做信息删除**：删冗余/合并闪回/拆独白/压缩对白；不删伏笔、因果、调节阀
- **压缩前先列"这场必须保留的信息点清单"，压缩后逐点核对**——这是防信息丢失的硬流程
- **重写/压缩前先备份"已验证台词清单"**（实战教训：《伏妖记》v2.1 重写第18-19场时，验证过的金句「我是妖。我认」和主题句「本事不分人妖，分的是用的人」静默丢失，直到用户要求多轮自检才 grep 发现——重写大场景必须带着关键台词清单对照，不能只盯新情节）：grep 计数核验（金句/主题句/道具闭环各应出现 N 次，少了就是被吞了）
- 高频压缩点：
  - 连续重复动作：练符×3→×2（保留"胸口闷"伏笔节拍）
  - 闪回连排：×4→×2（合并同信息段）
  - 长独白：拆"动作+台词"交替（画面跟着台词走，不整段独白）
  - 收尾：加首尾闭环（同一口钟）让结尾有落点
  - 对白：压 20-30%，保留笑点调节阀（牛粪梗类）

## 四、美学文笔强化

- **光影体系**：烛火/月色/香火青烟为骨，暗处沉、亮处烫
- **色彩纪律**：主色青灰；红只给关键两处（嫁衣褪色暗红/灼印焦黑里的红）；唯一鲜红=莲儿的指尖血（第8场设定"十指连心，指尖血带阳气"——动作是咬指尖，说"心头血"不自洽，动作与说法必须一致）
- **道具时态**：同一物件不同场次替不在场的人说话（空绳5→19/铜镜4→19/灼印2→15→18）
- **21:9 横向构图意识**：竹林横展/石阶纵深/镜阵包围
- **纪律**：强化="可见可听"的物理细节（夕照/余火/青烟/竹影），不是抽象抒情——不违反去AI味（无「不是X是Y」/无评述腔/无术语堆砌）

## 五、自审专项轮（改造后强制）

1. **时代切换核验表**：标志物清零（grep 复核）/无真实朝代名/服饰锚点更新/世界观自洽/备案预检
2. **压缩核验表**：每处压缩的"动作+时长变化+判定"；压缩纪律核验=信息点清单逐点核对
3. **美学宪法核验表**：留白/光影/道具时态/21:9/去AI味
4. **结构与伏笔计数核验**：场数/起承转合比例/伏笔 grep 计数（如灼印12处/胸口闷2处/血救妖4处）与旧版持平
5. 全过才更新锁定状态，可交接 AI电影导演

### 5.1 多轮交叉核对（用户要求"自检检查几遍"时的做法）

**用户对改造质量不满时（如"自检检查几遍""剧本AI味很重"），跑多轮交叉核对而不是单遍通读**——实战：《伏妖记》v2.1 用户要求多轮自检，10 轮交叉核对发现 7 处问题（金句丢失/主题句丢失/道具闭环断链/事实错误/引语不同步/重复段落）。

每轮一个检查维度，全部用 grep/脚本可复现：

| 轮次 | 检查项 | 典型命令 |
|---|---|---|
| L1 金句 | 已验证台词是否还在 | `grep -c "我是妖。我认" 剧本.md`（应为 1） |
| L2 主题句 | 主题落点句是否还在 | `grep -c "本事不分人妖" 剧本.md` |
| L3 道具闭环 | 道具链各节点是否完整 | `grep -n "灼印" 剧本.md`（应覆盖第2/15/18场） |
| L4 事实核对 | 概述/文档与剧本逐项一致（地点/时间/人物行为） | 交叉读两文件对照 |
| L5 引语同步 | 文档引用台词=剧本实际措辞 | `grep -o "我是妖。我认[^」]*" 文档.md` |
| L6 重复/残留 | 重复段落、旧设定残留 | `grep -c "（全剧终）" 剧本.md`（应为 1） |
| L7 格式 | 场数/序号/对白格式 | `grep -c "^### 第.*场"` |

**关键认知**：
- 单遍通读会漏（人脑对已看过的内容钝化）；每轮一个 grep 维度，10 轮 = 10 次独立的客观检查
- 重写大场景后**必查 L1/L2/L3**——重写时最容易静默吞掉旧版验证过的金句（见 三）
- 文档（概述/大纲/项目文档）里的引语必须与剧本逐字一致——文档会漂移，剧本是唯一事实源

## 六、改名迁移（Obsidian 项目）

1. 新目录写入全部新文件（write_file 直接建新目录）
2. `git rm -r -f` 旧目录（有本地改动必须 -f）
3. MOC 更新小节+引用
4. **全库 grep 旧名残留，区分两类**：
   - 合理历史引用（自审记录/复盘说明/改编来源标注）→ 保留
   - 需同步引用（其他笔记的 wikilink，如研习报告/踩坑记录）→ 必须改，否则悬空链接
5. wikilink 悬空检查：grep `[[新名` 确认目标存在
6. commit message 写清改造内容；git 自动识别 rename（58-86% 相似度）保留历史

## 七、用户偏好（妖玉，2026-08 确立）

- **架空=纯架空**：不出现真实朝代名/年号；服化道不限于明代，东方美学大融合（不脱离东方美学即可）
- **全篇无尿点**：节奏性压缩、零信息删除
- 国内标准格式：第N场 地点 时间 内外；对白无引号；画外音中文标注
- 交付物三分离：剧本正文纯净 + 分场分析 + 自审报告
- 全部规范带来源跟脚；去AI味（只写发生了什么，不写这象征着什么）
