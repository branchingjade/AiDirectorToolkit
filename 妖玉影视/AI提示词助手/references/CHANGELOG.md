# CHANGELOG — AI提示词助手

## v1.5.0 — 2026/08/04

### 三棵树架构（哲学对齐）

- **核心哲学段同步**：从"前面编剧和导演的工作全部白费"→"三棵树（编剧的树、导演的树、提示词的树）的果实全部白费"——提示词约束是共享土壤，不是下游翻译
- **版本整理**：正文标题/加载提示版本号对齐 1.5.0；删除 versions/ 遗留 CHANGELOG，统一到 references/

### 来源

- 用户铁律：编剧→导演→提示词不是流水线——是同一片土壤上各自扎根的三棵树

## v1.4.0 — 2026/07/27

### 核心哲学定位

- **新增开篇哲学段**：约束在保护一件事——画面里的物理事实不被翻译成抽象概念。每一帧的光、动作、质感是电影的最后一道门，翻译错了三棵树的果实全部白费

- 版本号：1.3.0 → 1.4.0

### 来源

## v1.3.0 — 2026/07/17

### 格式范式转换

基于 Seedance 2.0 优质案例（飞书文档 AwKkds5GxoxxHzxmDHtcfO5jnRg）的生产验证格式，将输出格式从结构化标签转为自然描述。

### 修改

- **输出格式**（§六）：取消独立配置行（`景别 | 运镜 | 日夜`）、独立焦点转移行、`[音效: xxx]` 标签，全部融入自然描述行
- **焦点转移**（§2.4）：从独立行 `焦点转移：A → B → C` 改为描述行内自然语言（"焦点落在陈静脸上"、"视线从...摇至..."）。原则不变，仅格式调整
- **音效**（§三）：从 `[音效: xxx]` 标签改为物理描述自然融入（"钞票在空中翻转折开"、"车架刮过砖墙，蹭出细碎粉尘"）。标题从"声音设计速查"改为"声音设计与音效标注"
- **镜头切换**：用"切"字作为自然过渡标记（"切王秀娟特写"、"切中景，越过王秀娟右肩框住"）
- **处理流程**（§六）：新增第4步"音效"——根据画面内容合理补全音效描述，自然融入描述行
- **精简单镜格式**：合并入默认格式，不再单独区分
- **references/streamlined-shot-format.md**：重写为新格式参考+示例
- **references/focus-transition-examples.md**：重写为描述行内嵌格式示例

### 不变

- 核心约束（§一~§五）：不编造、禁止修辞、物理优先、动作四层体系、避免木偶化
- 运镜与光线速查（§四）
- 台词逐字嵌入铁律

### 来源

- 用户提供飞书优质案例文档，展示生产验证的有效格式
- 格式差异：案例无独立配置行/焦点转移行/音效标签，所有元素融入自然描述行

## v1.2.0 — 2026/06/18

### 新增

- **动作设计四层体系**（§2.1）：微动作→惯性动作→神经反应→失控反应
- **动作四要素**（§2.2）：起点→过程→终点，动作间必须有过渡
- **环境反馈**（§2.3）：四级动作强度→环境反馈链
- **焦点转移**（§2.4）：每镜强制执行，独立行格式 `焦点转移：A → B → C`
- **声音设计速查**（§三）：环境声/动作声/呼吸声/情绪声/静默
- **运镜与光线速查**（§四）：运镜表+光线表+危险关键词
- **避免AI角色木偶化**（§五）：反蜡像四原则
- **精简单镜格式**：触发条件+格式模板+示例

### 来源

- 融合自 AIGC自修室「情绪导演 Skill v2.1」和「Mx-Shell Prompts v1.5」
