# 表单设计

> 2026-08-10 | 面向：工具型 UI 表单——标签、校验时机、默认值、错误处理。表单是工具 UI 出错率最高的区域，本文给出可直接抄的规则。
> 来源标注：训练知识（NN/g 表单研究、Material Design 3、Nielsen 10 启发式）

## 一、标签（Label）——最重要的表单元素

| 规则 | 逻辑 | 出处 |
|---|---|---|
| 标签永远可见 | 占位符（placeholder）不能当标签——用户输入后标签消失，无法回看字段含义 | NN/g, "Placeholders in Form Fields Are Harmful", 2014 |
| 标签放字段上方 | 顶部标签比左侧标签扫描更快（尤其窄表单）；左侧标签省纵向空间但加重横向扫描 | NN/g 表单研究（Label Position） |
| 必填标记 | 标必填（`*`），不标选填——用户默认「都要填」更符合直觉 | Material Design 3, "Text fields" |

## 二、校验时机（什么时候提示错误）

| 时机 | 逻辑 | 出处 |
|---|---|---|
| 输入时即时校验 | 格式类错误（邮箱、数字范围）边输边查，改完即消 | NN/g 表单校验研究 |
| 失焦时校验 | 用户离开字段才提示，避免打字中途被打断 | 同上 |
| 提交时总校验 | 兜底：提交时全量查一遍，失败则聚焦到第一个错误字段 | 同上 + WCAG |
| 不要边打字边报错 | 输入过程中每击键都报错 = 噪音 | NN/g |

## 三、默认值与预填

| 规则 | 逻辑 | 出处 |
|---|---|---|
| 合理默认值 | 常用项给默认（语言、格式、分辨率），用户只改例外 | Nielsen #7（灵活与高效） |
| 记住上次值 | 用户上次的输入/选择自动恢复——识别优于回忆 | Nielsen #6 |
| 预填要诚实 | 别把示例当默认值填进去（用户会误提交示例） | NN/g 表单研究 |
| 敏感字段不预填 | 密码、支付信息不预填 | 工程安全共识 |

## 四、错误处理（Nielsen 启发式 #9 落地）

| 规则 | 逻辑 | 出处 |
|---|---|---|
| 错误就地显示 | 行内错误贴在字段下方，不弹全局框 | Material Design 3, "Text fields" |
| 错误信息具体 | 说「密码至少 8 位含数字」，不说「输入无效」 | Nielsen #9（帮助用户识别、诊断、恢复） |
| 红色 + 图标 | 颜色不能是唯一标识（色盲），配错误图标或文字 | WCAG 1.4.1（用颜色传达信息） |
| 不惩罚用户 | 失败不清空已填内容，保留输入 | Nielsen #9 |
| 提交失败 | 聚焦第一个错误字段，错误列表滚入视野 | WCAG 3.3.1（错误识别） |

## 五、输入控件要点

| 控件 | 要点 | 出处 |
|---|---|---|
| 输入框 | 宽度对应预期内容（短字段不长框）；输入类型设对（number/url/email） | Material Design 3 |
| 数字输入 | 用步进器还是自由输入取决于精度需求；给范围校验 | 同上 |
| 下拉 | 选项 >5 用下拉；带搜索的下拉用于大选项集 | 同上 |
| 文件上传 | 拖拽区 + 点击选择双通道；传完显示文件名+大小+状态 | Material "File upload" 实践 |
| 日期 | 用平台日期控件，别自造 | HIG |

## 六、表单流程与提交

| 规则 | 逻辑 | 出处 |
|---|---|---|
| 提交按钮 | 主按钮右侧，Ctrl/Cmd+Enter 可触发（快捷键） | Nielsen #7 + 本工作区偏好 |
| 提交反馈 | 提交后必须反馈：成功 toast / 进度指示 / 跳转 | Nielsen #1（系统状态可见） |
| 防止重复提交 | 提交中禁用按钮（防抖），网络慢时显示进度 | 工程实践 + Nielsen #1 |
| 破坏性表单 | 删除类操作：行内确认或撤销机制，见 [[组件设计模式]] | NN/g, "Never Use a Warning When You Mean Undo" |
| 长表单 | 分组 + 分步（每步 ≤7 项），进度可见 | Miller 7±2 + NN/g |

## 七、无障碍（表单专项）

| 规则 | 出处 |
|---|---|
| 每个输入必须有 label（`<label for>` 或 aria-label）——占位符不算 | WCAG 1.3.1 + 3.3.2 |
| 错误通过 aria-describedby 关联到字段，读屏能读出 | WCAG 4.1.2 |
| Tab 顺序 = 视觉顺序 | WCAG 2.4.3 |
| 焦点可见（输入框聚焦有明显 outline） | WCAG 2.4.7 |

## 实战对照（本工作区偏好 → 权威依据）

| 既定偏好 | 依据 |
|---|---|
| 参数常显不折叠（表单全部可见） | 标签永远可见 + 密度原则 |
| 记忆上次选择状态 | Nielsen #6 识别优于回忆 |
| 拖拽上传 | 文件上传双通道 |
| Ctrl+Enter 提交 | Nielsen #7 灵活高效 |
| 合理默认参数（参考音频 3 条等） | Nielsen #7 合理默认值 |
